# decisions/ — тома ADR (полные тексты), когда журнал перерос один файл

Пока `decisions.md` меньше ~40 КБ — тома не нужны, всё живёт в одном файле. Когда аудит скажет
`DECISIONS-BLOAT`, журнал делится на **индекс + тома**:

- `../decisions.md` — canonical **индекс**: одна строка на решение (`- **ADR-NNNN** · дата · тема ·
  название · отменяет/отменён`), блок «По темам» (тема → действующие номера) и «как читать».
  Записей `## ADR-…` в индексе быть не должно (аудит: `ADR-IN-INDEX`).
- `adr-0001-0050.md`, `adr-0051-0100.md`, … — тома по блокам номеров, полные тексты дословно.
  Шапка тома: `tier: 2`, `topic: decisions-0001-0050`, `tier1: ../decisions.md`,
  `source_of_truth: historical` у закрытых томов, `supporting` у текущего.
- Формат записи в томе: `## ADR-NNNN — YYYY-MM-DD — Название` + Решение / Почему / Альтернативы /
  Влияет на. Номер = max по всем ADR + 1; номера не переиспользуются (аудит: `ADR-DUP`);
  отменённое решение не стирается — новая запись «отменяет ADR-NNNN».
- Новое решение: текст → в ТЕКУЩИЙ том, строка → в индекс (блок тома + «По темам»). Том заполнился
  до верхней границы — завести следующий.

## Свой префикс номера
Журнал, нумерующий не `ADR-NNNN`, а, скажем, `D127` (sup2, sib), объявляет префикс в
`_kit/adr-prefix.txt` — одно слово (`D`). Тогда id записи = `<префикс><число>`, сравнение по числу
(`D7` = `D007`), имя тома — `<префикс в нижнем регистре без дефиса>-NNNN-MMMM.md` (`d-001-050.md`),
и все проверки (`ADR-DUP` / `ADR-IN-INDEX` / `ADR-NOT-INDEXED` / `ADR-INDEX-ORPHAN` / `ADR-RANGE`)
идут через него. Заголовок записи начинается с номера; ссылки на другие решения — в скобках,
иначе `ADR-AMBIGUOUS` (запись без id, дубли по ней не считаются).

## Живой журнал без номеров
Записи `## [дата] Название` (шаблон до v1.8) легитимны и не флагаются — но дубли и ссылки по ним
невозможны. Нумеровать начинают со следующей записи; старые получают номера при разрезке на тома.
Образец разрезки (474 КБ → индекс 36 КБ + 4 тома, сверка по хешам) —
`remlab/tools/memory-migrations/2026-09/split-decisions.mjs`.
