# P-010 · владелец · Деньги проб не спрашивать — расход строкой; проба в одобренном направлении ≤~$1 — сразу

## Правило

По деньгам проб владельца не спрашивать — расход строкой; кончились деньги — написать где (TG 2567/2568, 20.11). Проба в одобренном направлении ≤~$1 — запускать сразу, не держать на ❓ (TG 2342, 20.11). Всё платное — сперва пробная партия и проверка результата, потом массовый прогон; счётчик отказов обязателен, молчаливый `except` запрещён.
