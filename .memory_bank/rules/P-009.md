# P-009 · владелец · Задачи и планы без владельца не придумывать; находки — ❓ с советом; план — с его ведома

## Правило

Задачи без владельца не придумывать; находки работников — ❓ владельцу с советом; свободному — только его задачи из плана (TG 981, 12.11; ADR-0396). Новые планы без его ведома не добавлять (TG 718, 10.11). Планы-вопросы не плодить; юридическое (лицензии, UK) не приносить и не напоминать — РФ первым, UK — тесты (TG 1038, 12.11).
