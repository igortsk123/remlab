# P-041 · платное · Автоочистка всегда: шаг и проба сами удаляют свои рабочие файлы после успеха; в брифе — «что чистит шаг»

## Правило

Каждый шаг конвейера и каждая проба сами удаляют свои рабочие файлы сразу после успеха; остаётся результат (модель, кадры проверки, короткий журнал). У долгой работы — сторож места: мало места → новую работу не берёт, платную машину гасит. В брифе — строка «что чистит шаг»; без неё — CHANGES REQUIRED (TG 2678, 20.11).
