# P-033 · приёмка · Приёмка работника и кода — 14 пунктов по `review-checklist.md`; PASS — только после зелёного CI и живой проверки

## Правило

Приёмка всегда по порядку `.claude/rules/review-checklist.md` (владелец 18.11, TG 1951; с Codex): точный SHA от base; бриф ↔ отчёт; main зелёный; diff в чистом merge-worktree; общее правило, не заплатка; дефект товара — строка в паспорт типа; доказательство непустое; проверки на итоговом merged tree; prepush «не успел N» — не зелёный; новый тест в правильном CI job; деньги/миграции/кроны — разрешение, потолок, бэкап; видимое смотрю сам; продуктовый путь через боевую службу; вливаю проверенный SHA (READY TO MERGE ≠ PASS); PASS — после зелёного CI и своей живой проверки. Подробно — `guides/review-checklist.md`.
