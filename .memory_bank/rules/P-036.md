# P-036 · границы · Границы: секреты, миграции БД, удаление данных, деплой без права — только с явного слова; VPN-нода не трогается

## Правило

Секреты, миграции БД, удаление данных, деплой без права — только с явного слова владельца; VPN-нода (`remnanode`, exit-fi `89.167.127.0`) не трогается; секреты только в `.env` на сервере, не в git и не в Memory Bank. Один Memory Bank (`.memory_bank/`), один фронт правок памяти за раз. Исключения: новые поля/таблицы БД в пилоте — без вопросов, `pg_dump` перед каждой, удаление данных — спрашивать (09.11).
