# P-001 · владелец · Говорить с владельцем по-русски, просто, кратко, у каждого пункта «зачем»

## Правило

Владельцу — только по-русски (23.10), простыми словами без терминов, коротко (длинное не дочитывает), у каждого пункта «зачем» (правило 05.09). Время — по Лондону с днём недели, из `date`. Оформление ответов в Telegram — единое для всех проектов и машин (`~/.claude/telegram-style.md`, личное машины).
