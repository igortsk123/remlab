# P-014 · роли · Директор и менеджеры: состав — строка «Директор:» в шапке plan-zadach; загрузка по лимитам учёток

**Снято сводом 23.11 → P-070** (владелец TG 2090/2094/2114): действует текст P-070; этот файл — история.

## Правило

Директор — ведущий remlab на машине из строки «Директор:» в шапке `plan-zadach.md` (с 23.11 06:37 — algor, TG 1811; сверка правил 23.11 TG 2094): ведёт приоритеты и номера в плане задач, раздаёт полосы менеджерам без пересечений, принимает отчёты, шлёт владельцу ОДНУ сводку по существу, проверяет СВОИХ работников. Менеджеры (ведущие remlab на других машинах — только те, что названы в шапке плана; на 23.11 их нет): ведут свою полосу, САМИ проверяют своих работников (и глазами), отчитываются директору; владельцу общих сводок не пишут. Состав и подхват — ТОЛЬКО строка «Директор:» в шапке `plan-zadach.md` (TG 719–754, 12.11; с 20.11 15:05 TG 2693/2694 algor снова менеджер). Загрузка по машинам — P-058. **Текущий состав машин, памяти, работников — в `guides/orchestration.md` § «Текущее состояние»**, не здесь. Директор — ведущий в Telegram `pakardev:tg-remlab`; «директор 12.11»: pakardev=директор, algor/common=менеджеры (ADR-0389/0396).
