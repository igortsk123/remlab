# P-065 · владелец · Промежуточный результат — владельцу после КАЖДОГО этапа конвейера (кроме покраски — исключение ниже)

## Правило

1. **Закончился этап конвейера на наборе** (форма TRELLIS, приёмка Ш0, покраска UltraTex, камера 04, перенос фото 06,
   заливка 07, итог) — владельцу сразу одно сообщение: что за этап, сколько товаров прошло / отказ (числа — из журнала
   прогона, P-063), и **ссылка, где посмотреть** результат этапа (P-004: «куда нажать, что увидеть»). Не ждать конца всего
   конвейера и не выбирать за владельца, что показать (урок 834).
2. **Всегда ссылкой со ВСЕМИ товарами этапа, размещёнными на странице** (владелец TG 1546: «присылаешь всегда ссылкой с
   товарами размещёнными») — каждый товар рядом с фото магазина; без ссылки «готово» не писать. Показ — **одной страницей этапа** (модели крутить / кадры полным размером, P-005), не россыпью снимков в чат: это и
   есть «без спроса не заваливать кадрами» (TG 1245) — страница вместо пачки картинок.
3. Перед показом смотрю сам (P-006); дефект, найденный на этапе, — строкой «что не так» в том же сообщении.
4. Рабочий в отчёте об этапе готовит страницу/кадры этапа; директор публикует и отправляет.

Связано: P-004, P-005, P-006, P-062, P-063, урок 834.

- **23.11 (владелец TG 2029, после страницы /test/rt-material-1123/ с 12 старыми моделями):** «никогда мне хуанан не показывай модели при отработке конвейера — в этом нет смысла». На страницах и кадрах этапов конвейера — только товары нового конвейера (форма Trellis + наша покраска); старые модели каталога (Hunyuan) — только во внутренних проверках, владельцу не показывать.
- **23.11 (владелец TG 2063):** старые модели каталога (Hunyuan) не чинить и не перекрашивать — каждый товар заново через Trellis по лучшему фото и весь новый конвейер; старые заменяются новыми целиком после отработки правил на текущих товарах (ADR-0467).
- **23.11 (владелец TG 2256/2258/2260, голос) — ИСКЛЮЧЕНИЕ для покраски:** промежуточные результаты покраски НЕ присылать, пока не «в целом хорошо» по 5 признакам (нет заплаток; чёткая; однотонно где надо; рисунок перенесён; нет жёстких недокрасов, переходы плавные). Круги — без владельца: прогон → листы всех товаров со всех сторон → разбор → план `plans/paint-cycles-1123.md` → GPT → правка → проба. Обходы — без кадров и ссылок покраски (ADR-0468).
