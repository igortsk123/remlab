# Реестр правил работы (P-NNN)

Одно правило — один файл `P-NNN.md` (шапка: id, status, version, scope, trigger, approved_at, approval_ref, review_after, supersedes, superseded_by, enforcement). Короткий индекс «всегда в контексте» — `.claude/rules/00-operating-index.md`, гейты — `.claude/rules/10-decision-gates.md`, приёмка — `.claude/rules/review-checklist.md`. План и порядок — `plans/rules-registry-01.md`. Правила и реестр меняет только директор; новое правило владельца — сразу файл (`active` или `trial` со сроком) + строка здесь и в индексе (P-035). Подтверждение — кнопка разрешения на запись (владелец TG 2680). Статус правила — поле `rule_status` (`active | trial | suspended | superseded | retired`); поле `status` занято словарём аудита памяти (`working`).
