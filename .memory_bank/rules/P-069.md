# P-069 · границы · Полномочия владельца: что самому, что — только с его слова

## Правило

**Самостоятельно**
- Команды выполнять самому; сухой прогон объявлять явно (P-007).
- Долгое — в фоне; на сообщение владельца сперва «взял»; ход ведущему не реже раза в час (P-007).
- Замечания копить, отдавать одним планом; требования исполнителю — планом в `plans/`, сообщение — указатель (P-007).
- Ночью/«делай подряд» — не ждать и не спрашивать, решать самому, но только по разрешённой обратимой работе; новых полномочий не даёт (P-008; свод 23.11).
- Вопросы копить в `_intake/owner-questions.md`, утром показать; «ничего не нужно» не писать, пока есть работа (P-008).
- Спящему владельцу вопросы решает советник (цепочка P-075); ответ и решение — в утренний отчёт; решения человека копятся (P-008, P-050).
- Производство не паузить ради экспериментов; решения в рамках направления — сразу; простоя нет (P-008).
- Деньги проб не спрашивать, расход — строкой; кончились — написать где; проба ≤~$1 в одобренном направлении — сразу (P-010).
- Платное: проба и проверка, потом массово; счётчик отказов обязателен, молчаливый `except` запрещён (P-010).

**Не решать за владельца**
- Задачи и планы без владельца не придумывать и не плодить; находки работников — ❓ с советом; свободному — задачи из плана (P-009).
- Решения человека: партнёрки/Гдеслон, кэшбек, цены paid-ступеней, модель после бенча, источники прайсов, дизайн экранов, юр. вопросы (P-011).
- Юридическое не приносить и не напоминать, РФ первым, UK — тесты (P-009); юр. логику не реализуем (TODO), лицензии моделей и библиотек не фильтруем — выбор по качеству, скорости, цене (P-011).
- Внутренние страницы — без кодов и логинов, коды не присылать; существующие — ссылка с ключом в адресе (P-011).

**Гипотезы**
- Неоднозначное ТЗ → вопрос; «готово» — после проверки путём владельца (P-012).
- Слова владельца — гипотезы, перепроверять до правок; внешние советы — критически, в план с «Критическая оценка»; вердикт внешнего рефери внедрять, возражать только с пруфом (P-012).
- «Этого нет» — только после проверки, способной найти; обоснованное отклонение от спеки → ADR (P-012).

**Сообщение владельца**
- Первым шагом `TASK | RULE | AMBIGUOUS`; голосовые подряд — каждое отдельно (P-035).
- RULE → в том же ответе «📌 П-NNN — как звучит: «…»» и запись `rules/P-NNN.md` (`active`/`trial` со сроком) + строка индекса; окно разрешения = согласие; нет окна — «📌 записал: … — не согласны, откачу»; `approval_ref` = TG + «кнопка записи»; ≤3 правил из сообщения; блокнот реестр не заменяет (P-035).
- AMBIGUOUS → «на будущее или разово?» с советом (P-035).
- «Правило: нет» / «📌 П-NNN …» — перед ❓, вопросы последними (P-035, P-002; свод 23.11).
- Реестр и `.claude/rules` меняет только директор; остальные — строкой в отчёте (P-035).

**Границы**
- Секреты, миграции БД, удаление данных, деплой без права — только с явного слова владельца (P-036).
- Пилот: новые поля/таблицы БД без вопросов, `pg_dump` перед каждой; удаление данных — спрашивать (P-036).
- Секреты — только в `.env` на сервере, не в git и не в банке (P-036).
- VPN-нода `remnanode` (exit-fi `89.167.127.0`) — не трогать (P-036, P-047).
- Перед правкой сервера — бэкап конфига и откат; `remlab-net`, лимиты памяти; предупреждать про необратимое (P-036, P-047).

**Начать ≠ выкатить** (свод 23.11)
- Код — только с явного разрешения; этап 1 — план: `CLAUDE.md`+INDEX, `core/lessons.md`, `lessons/<тема>`, `anti-patterns.md`, файлы темы → `plans/<slug>.md` (`draft`, `plans/_template.md`); «План готов. Жду команду "деплой"» (P-044).
- «деплой MASTER-cost-first» разрешает подпланы по порядку; стоп на «⚑ владелец» и необратимом (ADR-0255; P-044).
- Ветки `feature/<area>`; чужие файлы не трогать, импортировать, не копировать (P-044).
- Принятое изменение кода — всегда до прода (02.07/05.07): `pnpm typecheck && lint && test && build` → коммит → ff `main` → push; дальше выкатка по зелёному CI; `./deploy.sh` с DEV-VM не запускать (P-047).
- Миграция → сперва ручной `pg_dump` (ночной бэкап — 7 дней) (P-047).
- Прод не позади `main` (`deploy-need.sh --status`); готовое коммитить сразу, не wip (P-047).
