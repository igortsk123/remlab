# P-044 · workflow · План first, code second: без явного «деплой» код не пишем; план — файл `plans/<slug>.md`, статус `draft`

## Правило

Агент НИКОГДА не пишет код без явного разрешения. Этап 1 — план (исследование в Plan Mode; план Plan Mode эфемерен — файл в `plans/` обязателен): прочитать `CLAUDE.md` и INDEX, свериться с `core/lessons.md` и `lessons/<тема>`, прочитать файлы по теме, составить план по `plans/_template.md` (цель, scope in/out, файлы, задачи, критерии), сохранить `plans/<slug>.md` со статусом `draft`, показать план: «План готов. Жду команду "деплой".» Исключение (ADR-0255): «деплой MASTER-cost-first» разрешает все подпланы очереди мастера по порядку; остановка — на точках «⚑ владелец» и на необратимом. Ветки `feature/<area>`, чужие файлы не трогать, чужой компонент импортировать, не копировать. Агент с большим контекстом склонен «сразу чинить» — поэтому план до кода.
