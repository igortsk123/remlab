# P-048 · советник · Codex — независимый советник: свой вывод → вопрос Codex → сверка по коду → решение моё; 7 обязательных случаев

## Правило

Codex CLI (`codex exec`, read-only) — советник: он лучше исследует. Порядок: свой краткий вывод → вопрос Codex → сверка по коду/тестам → решение и ответственность мои; ответы Codex — не приказ, проверять. Только в проектах remlab и sup2 (20.08). ОБЯЗАТЕЛЬНО до действий: ① причина дефекта не очевидна или первый фикс не сработал; ② архитектурные/алгоритмические решения (ярусы, ключи сравнения, бюджеты, новые сущности, контракты); ③ нормы предметной области (пороги, «как принято») — с источниками; ④ данные и каталог (роли, атрибуты, фиды, обогащение); ⑤ любой новый план/метаплан и крупные правки плана — на критику ДО показа владельцу; ⑥ разбор внешних оценок; ⑦ рискованные изменения (безопасность, миграции, платежи, конкурентность). Постоянная сессия — id в `domain/integrations.md` § Codex; синтаксис `codex exec --sandbox read-only -C <корень> -o answer.md resume <ID> - < prompt.md` (флаги ДО `resume`); `--ephemeral` — когда важна независимость; два `resume` одной сессии параллельно не запускать. Конфликты — `source-of-truth.md`; живые факты: прод wins → обновить память. Живая сессия 01a00a62 сломана 15.10, онбординга нет — `domain/integrations.md` § Codex «Сейчас».
