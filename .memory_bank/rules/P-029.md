# P-029 · приёмка · Цикл задачи: PLAN → DELEGATE → IMPLEMENT → REVIEW → DECIDE (PASS/CHANGES REQUIRED/BLOCKED) → MEMORY; до 3 циклов правок

## Правило

1 PLAN (ведущий): контекст из банка, план `plans/<slug>.md`, критерии приёмки, Codex по правилу. 2 DELEGATE: `T-YYYYMMDD-NN`, slug плана, скоуп, ссылки, интерфейсы, ограничения, тесты, DoD. 3 IMPLEMENT: код → `pnpm typecheck && lint && test && build` → выкладка → отчёт. 4 REVIEW: по `review-checklist.md`. 5 DECIDE: `PASS` / `CHANGES REQUIRED` (конкретные правки тому же рабочему, тот же ID) / `BLOCKED`; до 3 циклов правок, дальше — стоп, владельцу: доказательства и рекомендация; «готово» со слов рабочего — не приёмка. 6 MEMORY: после PASS — банк, план → `completed_plans/`, отчёт владельцу. Требования исполнителю — планом в `plans/`; задание — задание, отчёт и независимая проверка (ADR 17.10).
