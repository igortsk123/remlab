# P-021 · роли · Та же проверка правит план задач и планирует: % по фазе, счётчик, косяк, 🕓; дубли склеить, порядок выстроить

## Правило

Та же проверка правит план задач (TG 2705): у каждого сдвинувшегося пункта — % по фазе; счётчик хода в конце строки коротко («5 из 39 · $0,5»); косяк — 3–6 слов и кому отдан; стоит — «🕓 ждёт: чего». Только Edit по свежему чтению, без пересказа хода; шапка — `plan-procent`; подробности — `plan-zadach-detali.md`. И та же проверка — этап планирования (TG 2714): дубли склеить, близкие задачи объединить, порядок выстроить (зависимости и общий вход «норма → состав → банк → меши → туры»), готовое (90 %+) убрать из «сейчас», свободному — следующая задача. Что изменил — строкой в отчёте владельцу. 5-минутная проверка = короткий отчёт владельцу (P-020, TG 2700) + правка плана (TG 2705) + планирование полосы (TG 2714). План по машинам и работникам (владелец 20.11, TG 2706): у каждого работника своя строка «П1.n · р.N · % — что делает · ход»; жирная — работает прямо сейчас; менеджер держит свои строки сам (Edit по свежему чтению). Обход «кто что делает» (ssh-проба, сессии, время отчёта) — P-020, TG 2559/2560/2563.
