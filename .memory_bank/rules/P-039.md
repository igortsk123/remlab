# P-039 · платное · Платные машины: только пакетами, прогревы экономить, свободную гасить; конвейер не ждёт; тихий лог >10 мин — разбор

## Правило

Платные машины (владелец 20.11): только пакетами, прогревы экономить — работа в очередь на прогретую машину, не новый под под мелочь, свободную — гасить сразу (TG 2602/2603); оплачиваемая машина не ждёт нашего процессора: конвейер (следующий товар, пока запекается прошлый), подготовка для пода — nice 0, запекание — nice 10. Платная машина + молчащий лог >10 мин = разбирать сразу, `platnoe-hod` каждые 5 мин (TG 1897, 19.11; урок 748). Не хватает мешей по правилу — продлить lease волн и делать самому, запись на сайт после экзамена и проверки глазами (TG 1886, 18.11).
