# P-039 · платное · Платные машины: только пакетами, прогревы экономить, свободную гасить; конвейер не ждёт; тихий лог >10 мин — разбор

## Правило

Платные машины (владелец 20.11): только пакетами, прогревы экономить — работа в очередь на прогретую машину, не новый под под мелочь, свободную — гасить сразу (TG 2602/2603); оплачиваемая машина не ждёт нашего процессора: конвейер (следующий товар, пока запекается прошлый), подготовка для пода — nice 0, запекание — nice 10. Платная машина + молчащий лог >10 мин = разбирать сразу, `platnoe-hod` каждые 5 мин (TG 1897, 19.11; урок 748). Не хватает мешей по правилу — продлить lease волн и делать самому, запись на сайт после экзамена и проверки глазами (TG 1886, 18.11). Новый запуск на Salad (владелец router TG 953, 21.11) — не с нуля, а на общем наборе, вынутом из рабочей архитектуры мешей: создание группы, ожидание образа, сервер на «::», проба /health, сторож молчания от started, потолок, стоп с проверкой 0 нод; своё — только код модели; перед первым платным запуском — сверка с уроками `lessons/mesh-salad-pool.md`. Обход директора каждые 5 мин проверяет ВСЕ платные запуски по их логам, строка 💰 «состояние · деньги/потолок» в каждом отчёте владельцу (router TG 1051). Медленная докачка образа — сторож мешей: прогресс тяги, пересадка ноды ≤3 раз, «медленно все» = образ/сеть (уроки 734, 357; TG 1069/1070). **Рецепт мешей — до каждого нового платного запуска (router TG 1133/1135/1143, 21.11):** новые платные пробы (UltraTex, P3-SAM, PartLLM, SegviGen и др.) — только когда выполнен весь рецепт конвейера мешей по таблице (веса внутри образа, digest, предел образа 35 ГиБ по ADR-0137, живой ход по стадиям + `JobStall`, отказ `worker_file` до группы, OOM → broken, гашение с проверкой 0 нод) и директор сверил таблицу по пунктам; живой ход — обязательная часть kit. Бэкенд, ни разу не гонявшийся на GPU, — до платного прочитать по исходнику все чтения файлов (урок 820). «По аналогии с X» = сверка всего рецепта X таблицей, не одного пункта (урок 825).

- **23.11 (перенос практик router → algor (владелец TG 1988/1989/1993/1994, 23.11; разбор журнала директора router); владелец TG 1754, 19.11):** не больше 10 машин Salad одновременно; на каждом обходе — `r 'bash ~/remlab-logs/router-r4/salad_live.sh | tail -2'` (живые группы, подъём, пробы).
