# P-015 · роли · План задач — один файл на всех (plan-zadach.md); менеджер правит свои пункты, приоритет и номера — директор

## Правило

План задач — `.memory_bank/plan-zadach.md`, один на всех (TG 744–754); бот отдаёт его по `/plan` как есть. С 20.11 (TG 2443) — коротко: строка на пункт «номер · машина · работник · % — что и зачем», только то, что сейчас; ход и журналы — `plan-zadach-detali.md`, сделанное и ждущее проверки — `plan-gotovo.md`. Менеджер правит СВОИ пункты сразу при выдаче, отчёте, PASS (Edit по свежему чтению); приоритет, номер, перенос между полосами — только директор. % по фазе: 0 очередь · 10 выдано · 40 в работе · 70 отчёт работника · 90 PASS менеджера/выложено · 95 живая проверка · 100 → «Готово сегодня». Доска в `plans/README.md` не ведётся.
