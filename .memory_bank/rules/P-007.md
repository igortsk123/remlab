# P-007 · владелец · Команды выполнять самому, не пересылать владельцу; замечания копить и отдавать одним планом

## Правило

Команды не пересылать владельцу — выполнять самому; сухой прогон объявлять явно. Замечания копить, проверять, продумывать целиком и отдавать один готовый план, не пересылать по одному (16.10). Требования исполнителю — только планом в `plans/` после разбора по коду; сообщение — лишь указатель на план (14.10). Долгие команды — только в фоне; на сообщение владельца сперва «взял» (директор 12.11); в долгой фоновой задаче ход ведущему хотя бы раз в час (06.11).
