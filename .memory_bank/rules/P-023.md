# P-023 · роли · Модели: ведущие — Opus 5.5 high, рабочие — Sonnet 5.5 high; модель выбрать в начале сессии, посреди не менять

## Правило

С 16.11 (владелец TG tamara 842, tamara ADR-0211, для всех проектов): ведущие — Opus 5.5 `--effort high`, исполнители — Sonnet 5.5 `--effort high` (`~/common-remote/start-rabochiy.sh`). «Opus» у исполнителя в старых документах — по-старому. Замер 18.11 (TG 1752): Sonnet дешевле на 28–36 % за задачу, вызовов больше. Кэш: модель выбрать в начале сессии, посреди не переключать (новый кэш с нуля); effort на Opus 5.5 / Fable 5.1 кэш не сбрасывает; `/compact` — на границе задач, пока кэш тёплый (основной разговор — час; субагенты — 5 мин); попадание — `/usage`, «Prompt cache (main)» (владелец 19.10, ADR-0166 tamara). Порог сжатия 400 тыс. остаётся (P-026).
