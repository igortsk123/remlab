# P-049 · советник · Codex НЕ звать на баги и мелкие правки; тупик — сперва Codex, владельца — в крайнем случае

## Правило

Codex нужен там, где надо реально исследовать, а не на баги и мелкие доработки (владелец 18.10): мелкие визуальные доработки, тривиальные правки, очевидные однострочные фиксы, рутинные команды, числовые гейты по готовым правилам, вопросы, уже закрытые в памяти/ADR без нового аргумента. Планы таких правок — без критики Codex. Тупик/неэффективность → сперва Codex, владельца — в крайнем случае (TG 1551, 11.11).
