# P-068 · приёмка · Правила ↔ код раз в час; урок — только с автопроверкой

## Правило

1. Раз в час (обход ЧЧ:02) директор сверяет по каждой Ш-строке `plans/paint-photo-fill-01.md` и строке паспорта
   `plans/mesh-type-rules-01.md`: **правило записано ↔ код есть ↔ работает в прогоне** (включено по умолчанию или
   запущено в последнем прогоне). Принятое правило без кода и без исполнителя → ❗ в отчёт обхода и задача рабочему.
2. Урок или правило считается действующим, только если превращён в автопроверку в коде: тест, сторож, мерка в check.json.
   Строка урока без автопроверки — с пометкой «нет автопроверки» и задачей.

## Почему
22.11 (урок 844): записанные правила покраски неделями не имели кода — владелец находил те же дефекты снова.
