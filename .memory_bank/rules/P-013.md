# P-013 · роли · Две роли: ведущий (план, приёмка, память) и рабочий (код, тесты, отчёт); владелец говорит только с ведущим

## Правило

Владелец говорит ТОЛЬКО с ведущим (директором). Ведущий (fable-lead, с 18.10 — Claude Opus 5.5): требования, Memory Bank, план и критерии приёмки, делегирование, приёмка по отчётам и выборочно глазами, вердикт, память, отчёт владельцу; продакшен-код сам не пишет; механику (пробы на проде, сверки памяти `verify`, правки сводок, длинные прогоны тестов) — исполнителям. Fable 5.1 — точечно (новый план с нуля, спорное решение, разбор внешней оценки, недельный итог). Рабочий (opus-worker): исследование деталей, код, тесты, lint/typecheck/build, скриншоты и воспроизводимые доказательства, структурный отчёт, исправления; задачу «принятой» не объявляет, архитектурные решения в памяти не меняет (предлагает в отчёте). Планировщик-исследователь: я исследую, смотрю глазами покупателя, пишу планы, ставлю задачи, код не пишу (14.10).
