# P-028 · роли · Активные задачи — только в plan-zadach; у пункта скрытая строка T-ID · план · машина:сессия · worktree

## Правило

Активные задачи — только в `.memory_bank/plan-zadach.md`. У пункта скрытая строка `<!-- T-ID · план · машина:сессия · worktree -->`: увидев незавершённый пункт, любой агент читает журнал той сессии (`~/.claude/projects/-home-pakar-igor-remlab/<id>.jsonl` на её машине) и план, а не начинает заново. Старая доска (22.10–12.11) — `changelog/board-2026-10-22--11-12.md`. Решения по ходу — в план (лог) и блокнот сразу. Перед выдачей — доска по сути, не по T-ID (06.11: дубли).
