# P-059 · приёмка · Модели нового способа (покраска и др.) — сперва владельцу ссылкой, на сайт только после его «принято»

## Правило

Модель, сделанная новым способом (покраска StableGen, новый генератор), заменяет прежнюю на сайте и в турах только после
«принято» владельца по ней (владелец 20.11, TG 2734: «крашенные модели надо мне показать же сначала»). Порядок: сам осматриваю со
всех сторон → ссылка владельцу со списком «что нашёл, иду править» (P-004, P-006) → его «принято» → строка в файле привязки
(SKU → источник, дата, TG). Код сам строки привязки не добавляет; без отметки побеждает прежняя модель.

## Как проверить

Тест привязки победителя (`painted-to-rt-01`, задача (г)): `guard: pass` без отметки владельца → побеждает прежняя модель.
