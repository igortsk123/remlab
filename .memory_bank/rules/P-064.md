# P-064 · приёмка · Приёмка формы — шаг конвейера Ш0: проверяет директор по правилам брака, владельцу — итог числом

## Правило

1. **Всегда, на каждом прогоне форм** — шаг Ш0 конвейера (`plans/paint-photo-fill-01.md`, порядок v3) между «форма» и
   «покраска/UltraTex». Формы владельцу на утверждение не носить: проверяет директор (ведущий) сам, владельцу — одной
   строкой «брак N из M (№ … — почему), пропущено K, дальше по конвейеру».
2. **Правила брака и пропуска** — таблица `plans/mesh-type-rules-01.md` § «Приёмка формы TRELLIS.2» (по типам; составлена
   с советником 22.11). Суть: брак — то, что покраска с фото не закроет (дыры, рваный фасад, сломанная видимая спина,
   пропавшие ножки, стекло → выдуманная деталь, нарост, меняющий контур); мелкий бугорок, потеря мелкой резьбы — пропуск
   с записью в журнал паспорта.
3. **Брак → сперва вход** (HD ли фото, вырезка, размер предмета), потом не больше 2 новых seed, повтор дефекта →
   «форма не годна». Каждый найденный дефект — строкой в журнал паспорта (review-checklist п.5б).
4. **Глаз — на всех формах**, пока автопроверки не откалиброваны (≥30 моделей на тип глазом, ~300 принятых без брака для
   «<1 % ложно пропущенных»); автопроверки до этого — только вхолостую. Кадры — 5 видов глиной (0°, 225°, 180°, 90°, сверху
   30–45°; у мягкой — низкий боковой), два света; проверять, что дефект — в форме, а не в показе (нормали).
5. Новый дефект, которого нет в таблице, — правило на тип с советником (P-034, P-048), затем строка в таблицу.

Связано: P-031 (визуальную приёмку делает ведущий сам), P-034 (дефект → правило типа), P-042 (масштаб 50k), P-062.
