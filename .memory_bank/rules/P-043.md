# P-043 · масштаб · Демо безопасно — вливать и выкладывать сразу; CI зелёный, перед отчётом typecheck, CI через API не опрашивать

## Правило

Демо безопасно: вливать и выкладывать сразу, проверять на живом, не держать в ветках (TG 406, 07.11). CI должен быть зелёным (TG 439, 07.11); с 12.11 CI через API не опрашивать — `deploy-need.sh --status`, один запрос только если прод позади main >15 мин; до push тесты без `| tail`. Перед отчётом с TS всегда `pnpm -s typecheck` rc=0 (директор 13.11, T-48/2). Перед push памяти: `node tools/memory-audit.mjs --check . && node tools/memory-project-audit.mjs .`; коммитить только свои пути.
