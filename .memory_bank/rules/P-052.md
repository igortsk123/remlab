# P-052 · память · Цикл сессии: старт INDEX → core; в процессе — блокнот сразу; конец — /memory-check; несколько сессий — свод по очереди

## Правило

Старт: `INDEX.md` → `core/<тема>.md` по decision tree; `project-state.md` старше ~2 недель — сверить или начать с `/memory-check`. В процессе: принял durable-факт/решение → СРАЗУ 1–2 строки в `_intake/session-scratch.md` (append-only); ясное — сразу в канон-док. Конец сессии / перед `/clear`: `/memory-check`. Несколько сессий в одной копии — свод по очереди (28.09): в процессе все пишут только в блокнот; `/memory-check` и коммиты памяти — одна сессия за раз; чужие строки блокнота не усекать; `git add` — только своих путей. Извлекать: INDEX → Tier 1 → Tier 2 по `tier2:`/`[[ссылкам]]`, не сканировать всё; anti-rediscovery — перед интеграцией `grep` + `core/access-and-integrations.md`; прежде чем сказать «у нас нет ключа» — `node tools/access-inventory.mjs` и имена из `_secrets/ACCESS.md` (TG 1841, 19.11; урок 57).
