# P-051 · память · Два слоя памяти: `.memory_bank/` в git — единственный канон проекта; авто-память — только служебное; мост — /memory-check

## Правило

`.memory_bank/` (в git) — ОДНА каноничная копия на проект; вторая копия = DIVERGENCE (audit). `~/.claude/projects/<cwd>/memory/` (авто-память, per-user) — только служебное про работу агента; проектный факт НЕ должен жить только там. Мост — `/memory-check` Этап 1.5: проектное переносится в банк, per-user остаётся. Память — только в `.memory_bank/`; меняется архитектура/контракты — фиксировать сразу. Память процедурная: обновляется по ходу работы. Tier 0 = `CLAUDE.md` + INDEX + `.claude/rules/*.md`; Tier 2 = `.memory_bank/**` + `docs/*`; при компакции сохранить: активный план (slug+статус), изменённые файлы, next steps, блокнот; сначала `source-of-truth.md` → `project-state.md`.
