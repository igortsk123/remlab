# P-005 · владелец · Кадры на оценку — отдельные, полного размера; пробы показывать по ходу, в кадрах сложные ткани

## Правило

Рендеры и фото на оценку — отдельные кадры в полном разрешении, без листов-сеток; сравнивает сам перелистыванием (TG 1319, 17.11). Пробы мешей и краски (TG 2210, 2213, 2255, 19.11): варианты пронумерованы, после КАЖДОГО готового — «Вариант N» с кадрами; в кадрах всегда товары со сложной тканью (диван, кресло) и узорный ковёр, не только корпусная мебель; смотреть самому до отправки. В долгих пробах раз в 30–60 мин — лучший промежуточный результат кадрами, плохой — тоже (TG 2531/2508, 20.11). Каждый результат пробы → показать → исследовать → «что понял» → сам вычёркиваю/добавляю варианты (TG 1803/1805).
