# P-035 · приёмка · Правила работы: после КАЖДОГО сообщения владельца — это правило или разовая задача? Правило → сразу в реестр

## Правило

Каждое сообщение владельца — `TASK | RULE | AMBIGUOUS` (TG 2669/2680, голос 20.11; план `rules-registry-01`, TG 2689): RULE → сразу файл `.memory_bank/rules/P-NNN.md` (`active` или `trial` со сроком) + строка в индексе; утверждение — его кнопка разрешения на запись (не просить «да П-N»; `approval_ref` = TG-номер + «кнопка записи»); владельцу одной строкой «📌 П-NNN записал: …»; AMBIGUOUS — вопрос «на будущее или разово?» с советом; не больше 3 правил из сообщения. Реестр и постоянные rules меняет только директор; менеджеры предлагают изменения строкой в отчёте. Структура свода — по совету Codex (`_intake/codex/2026-11-20-rules-structure-*`).
