# P-020 · роли · Обход: днём каждые 5 мин, ночью каждые 30 мин: работники, менеджеры, план; короткий отчёт владельцу; любая проблема — сразу ❗

**Снято сводом 23.11 → P-070** (владелец TG 2090/2094/2114): действует текст P-070; этот файл — история.

## Правило

Директор держит CronCreate: днём 07:00–21:00 каждые 5 мин, ночью 21:00–07:00 каждые 30 мин (владелец TG 54/72, 20.11) (после перезапуска — заново). После КАЖДОГО дневного обхода (ночью 21:00–07:00 — только ❗ авария, утром одна сводка 07:04; router TG 1155, 21.11 — отменяет «днём и ночью» 20.11) — НОВОЕ сообщение владельцу «*Обход ЧЧ:ММ · план N %*» с блоками 🔍 проверил · 🛠 исправил · 📤 кому что раздал · ❗ проблема (владелец TG 199/204 router, 20.11; отменяет «ночью — правка одного сообщения»); сводка в 07:04: свои работники (простой → следующая из плана; ≥15 мин без отчёта → толчок), менеджеры (молчит >30 мин или свободные работники → толчок в tmux, ответ строкой в `otchety-direktoru.md`), план и % (TG 837). Каждая проверка — короткий отчёт владельцу 2–4 строки (что проверил, все ли заняты, идёт ли по плану, косяки и кому отдал, новые правила); нечего сказать — «✅ всё по плану» (TG 2700, 20.11). Каждый обход — кто что делает (TG 2559/2560): ssh-проба машин менеджеров, сессия каждого работника, время последнего отчёта; любая проблема (нет связи, работник потерян, >30 мин без отчёта) — СРАЗУ владельцу «❗ что · с какого времени · что делаю» и «🕓 стоит: причина» у пункта плана (урок: router без связи ночь 19→20.11). common с 20.11 не включается — ресурсов нет (TG 2563). Та же проверка правит план и планирует полосу — P-021 (TG 2705, 2714). **Ночью (router TG 1154/1155, 21.11) — отчёты обходов НЕ слать:** только ❗ авария; всё накопленное — утром ОДНИМ отчётом (сводка P-003 + решения ночи + ошибки по P-063 + ❓). Отменяет «после каждого обхода, днём и ночью» для ночи.

- **23.11 (перенос практик router → algor (владелец TG 1988/1989/1993/1994, 23.11; разбор журнала директора router)):** утренняя сводка — постоянный будильник `4 7 * * *` (у router был разовый, 22.11 сводка опоздала до 09:27). Шапка отчёта обхода — «*Обход ЧЧ:ММ · план N % · конвейер M %*», изменения — «было → стало». Ночью и во время свода памяти директор НЕ правит файлы в `.claude/` (урок 829: окно разрешения ночью ждало владельца ~5 ч).
