# P-034 · приёмка · Каждый дефект товара → правило на тип или все товары + Codex → паспорт типа; активным считается применяемое

## Правило

Каждый найденный дефект товара (вырезка, форма, покраска — и исправленный, и «не лечим») — строкой «дефект → на какой тип или все товары → правило → автопроверка → Codex» в паспорт типа (`plans/mesh-type-rules-01.md`; TG 2615/2619, 20.11). Правка: ① чиню сам → ② системное правило (на тип или все) → ③ паспорт/общие правила со статусом «проба» → ④ проверяю на выборке типа (было→стало, автопроверка) → ⑤ сработало — «активно». Активное правило конвейер применяет ко ВСЕМ товарам своего типа; правило, которое конвейер не применяет, активным не считается. Исправленное — снова ссылкой (TG 2662/2687). Дефект без строки в отчёте → CHANGES REQUIRED.
