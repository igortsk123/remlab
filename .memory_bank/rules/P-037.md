# P-037 · границы · В брифе рабочему: DEV-сервисы не останавливать, `.env*` не читать, без удаления, временное — не в `.claude/`

## Правило

Сервисы DEV (`remlab-render` и др.) не останавливать — они обслуживают живое демо (22–24.10); `.env*` не читать (окно на `.env.example` держало рабочего ~13 ч) — ключи только через готовые скрипты. Без удаления в командах исполнителя (22.10): `rm -rf $VAR/…`, `rm -f glob` (и через `ssh`/`r`) Claude Code всё равно спрашивает — ночь 21→22.10 рабочие простояли 11–12 ч; снимки и выводы — в НОВУЮ папку с меткой времени (`mkdir -p $D/after-$(date +%H%M)`), старое не чистить, уборка — шагом ведущего. Чужие процессы не снимать по PID на глаз (05.11). Локальный `rm -rf` по sshfs-симлинку стирает цель (18.11) — удалять через `r unlink`. `Bash` в allow целиком, но `rm -rf $VAR/…` и `rm -f glob` всё равно вызывают окно (P-017).
