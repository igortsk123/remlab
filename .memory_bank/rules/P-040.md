# P-040 · платное · Модель на сайте ≤5 МБ — только лёгкая копия; конвейер сам проверяет размер

## Правило

На сайт — только лёгкая копия (`tools/assets/runtime_mesh.py`); конвейер сам проверяет размер, тяжелее 5 МБ — не выкладывает. Рабочие файлы прогона (blend, промежуточные кадры) моделью не считаются (TG 2671, 20.11).
