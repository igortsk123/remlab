# P-008 · владелец · «Делай подряд, я сплю»: не ждать, решать самому, вопросы копить; не отчитываться, пока есть работа

## Правило

Ночью и по слову «делай подряд»: не ждать ответов, согласования не спрашивать — решать самому, вопросы копить в `_intake/owner-questions.md`, утром показать всё (11.11). Не отчитываться «ничего не нужно», пока есть работа без ответов (14.10). Производство (меши, К%) не паузить ради экспериментов; решения в рамках направления — сразу самому; простоя без задачи нет (07.11 «барьер»).
