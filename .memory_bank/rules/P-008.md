# P-008 · владелец · «Делай подряд, я сплю»: не ждать, решать самому, вопросы копить; не отчитываться, пока есть работа

**Снято сводом 23.11 → P-069** (владелец TG 2090/2094/2114): действует текст P-069; этот файл — история.

## Правило

Ночью и по слову «делай подряд»: не ждать ответов, согласования не спрашивать — решать самому, вопросы копить в `_intake/owner-questions.md`, утром показать всё (11.11). Не отчитываться «ничего не нужно», пока есть работа без ответов (14.10). Производство (меши, К%) не паузить ради экспериментов; решения в рамках направления — сразу самому; простоя без задачи нет (07.11 «барьер»). **Пока владелец спит (router TG 1151, 21.11): «за меня Codex, в его отсутствие Vercel»** — вопросы, которые шли бы владельцу, решает советник по цепочке P-050 (Codex → `vercel-sol` у того, у кого ключ в окружении → субагент); решения человека (P-011) — не решаются, копятся; ответ советника и решение — в утренний отчёт.
