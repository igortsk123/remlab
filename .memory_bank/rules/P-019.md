# P-019 · роли · План ведёт директор сам: на каждую задачу или отчёт — разбор плана целиком; % только скриптом plan-procent

## Правило

На КАЖДУЮ новую задачу или отчёт — разобрать план целиком: куда поставить, что убрать, что изменить; дубли и пересечения склеить; проверить, не меняет ли новая задача вход соседней (норма → состав → банк → меши → туры) — тогда соседнюю придержать (пример 12.11: банк спален на старой норме проходов). Общий % — только скриптом `~/.local/bin/plan-procent` (готовое за день = 100 %), время — только из `date` (TG 794–826). Подхвативший директорство делает так же.
