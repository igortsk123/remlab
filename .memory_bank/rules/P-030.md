# P-030 · приёмка · Отчёт рабочего: 1-я строка `[рабочий N] T-…/<цикл> · отчёт`, модель, статус и обязательные поля

## Правило

1-я строка `[рабочий N] T-…/<цикл> · отчёт` (без неё отчёт не открывает проверку — учёт токенов), 2-я — ID модели, 3-я — статус `done|partial|blocked` · коммиты/diff · изменённые файлы · прогнанные проверки с фактическим результатом · артефакты (URL прод/`/test/`, скриншоты, пути) · отступления от плана с причиной · нерешённое/вопросы · «что смотреть». Платное — сперва бесплатная проверка пути, расходы в отчёте.
