# P-050 · советник · Лимит подписки Codex → тот же вопрос через Vercel `vercel-sol` (экономно); иначе — свежий независимый субагент

## Правило

Основной советник — подписка ChatGPT (профиль по умолчанию). Подписка упёрлась в лимит → тот же вопрос через Vercel, профиль
`--profile vercel-sol` (экономно, один вопрос — один вызов; владелец 20.11, TG 2784 «запускай Vercel если кодекс встал», утверждено TG 2787).
Vercel недоступен (нет кредитов шлюза `gateway_no_credits`) — свежий независимый субагент Opus (ADR-0415).
**Без владельца (TG 74, 20.11):** вопрос владельцу без ответа за один интервал обхода (днём 5 мин, ночью 30) → директор решает сам, но всегда с советником по той же цепочке Codex → `vercel-sol` → субагент Opus; решение и ответ советника — строкой в otchety, владельцу — в сводке. Решения человека (P-011: партнёрки, цены, дизайн, юр.) так не решаются — копятся. Профиль `vercel` (astra) не звать;
перед профилем `vercel*` — `set -a; . tools/scout/.env; set +a` (файл не читать, значения не печатать); подписку и шлюз в одной сессии
`resume` не смешивать — только `--ephemeral`. Детали — `domain/integrations.md` § Codex. История: ADR-0253 (13.10) → ADR-0301 (17.10, шлюз
только для продукта) → ADR-0327 (23.10, запасной `vercel-sol`) → ADR-0415 (субагент) → 20.11 TG 2784 — снова `vercel-sol` первым запасным.

## Снято этим правилом (superseded)

v1 (20.11): «запасной — только свежий субагент» — заменено v2 (TG 2784/2787): сперва `vercel-sol`, субагент — если шлюз недоступен.
