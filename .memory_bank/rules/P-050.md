# P-050 · советник · Запасной советник при исчерпанной подписке — свежий независимый субагент (ADR-0415); Vercel — только для продукта

## Правило

Основной советник — подписка ChatGPT (профиль по умолчанию). Подписка исчерпана → свежий независимый субагент (ADR-0415, новее ADR-0327). Деньги Vercel — только для продукта (фото), не для советника (17.10, ADR-0301); профиль `vercel` (astra) не звать; перед профилем `vercel*` — `set -a; . tools/scout/.env; set +a` (файл не читать). Детали — `domain/integrations.md` § Codex. История: основной советник — подписка (владелец 13.10, ADR-0253); 17.10 ADR-0301 — деньги шлюза для продукта; поправка 23.10 ADR-0327 (запасной `vercel-sol`) — снята ADR-0415.

## Снято этим правилом (superseded)

Снято (противоречие 6): «`--profile vercel-sol` как основной запасной путь» (ADR-0327, 23.10).
