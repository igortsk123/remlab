# P-038 · платное · Тяжёлые прогоны — только под `tools/ops/heavy-slot.sh`; платное впереди (`--prio 2`, `--min-gb`), бесплатное — `--prio 0`

## Правило

Тяжёлые прогоны — только под `tools/ops/heavy-slot.sh` / `heavy_slot.py` (05.11, T-57; до 5 по заявкам (11.11; было 3, T-74), по факту ядер — до 8 (T-20261112-75, TG 1031); обгон головы мелкими, защита 20 мин — T-79, 06.11): свои циклы `free -m` не писать; долгое — порциями. Платное впереди (TG 2201, 19.11, ADR-0453): шаг, которого ждёт оплачиваемая машина (RunPod, Salad), — heavy-slot `--prio 2` и `--min-gb` по замеру; бесплатное, пока идут платные, — `--prio 0`; форма перед запеканием ≤150 тыс. граней с UV. Нет `--prio 2` в платном драйвере — CHANGES REQUIRED. Ядер 16, ОЗУ 29 ГБ фиксированы (TG 1490/930) — не просить.
