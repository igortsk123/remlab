# P-066 · платное · Salad: машина — только по профилю типа работы; тариф low → medium, выше и batch нельзя

**Снято сводом 23.11 → P-072** (владелец TG 2090/2094/2114): действует текст P-072; этот файл — история.

## Правило

1. **Тариф:** сперва `low`; машин не дают — один раз `medium`; **выше medium не поднимать, `batch` не брать** (там часто
   машин нет).
2. **Ресурсы — по профилю типа работы** — файл профиля salad-resources.json в папке правил scout (ветка
   feat/salad-resources-1122, в main — после вливания; карта, запасные карты, vCPU, память,
   диск, shm, тариф, ожидаемые время и пики, `basis` measured/estimate). Группу создаёт только `kit_driver` по строке
   профиля; нет строки, свои числа мимо профиля, тариф вне {low, medium}, карта вне профиля — отказ до создания группы
   (код 3). Обход ловит тест `tests_kit.py`. Новый тип работы — сперва строка профиля.
3. **Профиль по замеру:** воркер отдаёт пики в /health (RAM, VRAM, диск, скорость весов); после прогона
   `resource_profile.py --suggest` — расхождения; строку правит директор; `estimate` в журнале помечено «по оценке».
4. Медленный диск/веса — сторож DiskGuard гасит и пересаживает ноду (≤2 раза), дальше стоп.

Связано: P-010, P-038, P-039, P-041, P-042.
