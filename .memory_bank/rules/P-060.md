# P-060 · роли · Свободному работнику без задач — следующий пункт с паузы по порядку; владельцу — строка «снял с паузы»

## Правило

Работник свободен, задач в «сейчас» для него нет, а остальное на паузе → сразу снимать с паузы следующий пункт по порядку
(П1 → П2 → П3, внутри — как в плане; лёгкое по ядрам — вперёд, если очередь тяжёлых забита) и делать (владелец 20.11, TG 2783
«снимать задачи с паузы и делать», утверждено TG 2787). Владельцу — одна строка «снял с паузы: что, кому». Пункт, отложенный владельцем
с условием («после X»), — только когда условие выполнено. Дополняет P-016 (поток задач без простоя); вопрос «задач нет» (TG 2631) —
только когда и пауза пуста.
