# P-016 · роли · Поток задач: работник → отчёт менеджеру и «готов к следующей»; менеджер сразу выдаёт следующую; директор так же

## Правило

Работник сделал → отчёт менеджеру + «готов к следующей»; менеджер проверяет и сразу выдаёт следующую своей полосы — первую по П1→П2→П3 и номеру, без незакрытых зависимостей и занятого ресурса; полоса пуста → «свободен: N работников» директору; чужую полосу сам не берёт (TG 754). Поручение владельца менеджеру напрямую — сразу директору. Директор — так же со своими (TG 2631, 20.11): увидел свободного работника — следующая задача по списку; нет задач — ❓ владельцу с советом, не держать пустым (отменяет «на pakardev новых не давать», TG 992). Порядок работы = приоритеты П1..П3 (ADR-0380, TG 903, 1512, 1626): свободный помощник — в П1, П2/П3 параллельно не начинать. До 6 помощников сразу, каждый в своём worktree/файлах, общий файл (`tools/scout/flat215-demo/index.html`) — по одному, вливать по очереди (TG 1438/1442). Отчёт директору: строка в `_intake/peredacha/otchety-direktoru.md` + толчок в tmux директора — при PASS, блоке, тратах, вопросе владельцу и не реже раза в 2 часа. Полосы, общие ресурсы, диапазоны T-ID — `.memory_bank/_intake/peredacha/direktor-2026-11-12.md`.
