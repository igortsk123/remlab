# P-003 · владелец · Сводка владельцу — одна, группы по приоритетам, % у строк, ✅ только у 100 %, ⏳/🕓, токены в $

## Правило

ОДНА общая сводка (TG 903, 10.11): группы по приоритетам П1, П2…, % у каждой строки и общий % вверху (скрипт `plan-procent`), готовое — одной строкой; «Готово» — «Гn · что → где смотреть», ссылки внизу с 1 строкой «что смотреть» (TG 845, 12.11); замечание по Гn = возврат в П1. ✅ только у сделанного на 100 % (TG 588, 09.11), выложенное — отдельной строкой без галочки; ⏳ только «в работе сейчас», ожидание — 🕓 «ждёт: чего» (TG 2162/2164, 19.11). В сводке ВСЕ приоритеты (ADR-0380, TG 1793). Временный вид 19.11 (TG 1741/1745/1746): «задача — %», группы «Меши» и «Остальное». Токены — только в долларах (TG 2366, 20.11): лимит ≈$2000/нед, потрачено (% × 20), мы / прочее, остаток; полнота учёта — TG 2362–2374.
