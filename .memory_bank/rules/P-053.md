# P-053 · память · Куда сохранять: архитектура → core/*, решение → ADR, урок → lessons/, доступы → access, этап → project-state

## Правило

Триггеры и адреса (`memory-discipline`): архитектура/маршруты/флоу → `core/*` (+`updated:`) + Tier 2; контракты/API/модели → `domain/` + `core/data-model.md`; принятое решение → ADR (текст в текущий том `decisions/adr-*.md`, строка в индекс `decisions.md`); урок/грабля → `lessons/<тема>.md` (номер из `lessons/README.md`), живое правило → `core/lessons.md`; интеграция/где ключ → `core/access-and-integrations.md`, значения — `_secrets/ACCESS.md` (вне git); новая крупная область → ОБЯЗАТЕЛЬНО `core/<домен>.md`; смена этапа → `project-state.md` (снимок ПЕРЕПИСАТЬ ≤8 КБ), хронология → `changelog/project-history.md`; задача в работе → `plans/<slug>.md`; сырьё до консолидации → `_intake/session-scratch.md`. Решения и грабли писать в блокнот проекта на ходу — ночной свод берёт их оттуда.
