# P-012 · владелец · Неоднозначно — спросить; слова владельца и внешние советы — гипотезы, перепроверять; «нет» — только после проверки

## Правило

Не быть самоуверенным: неоднозначное ТЗ → уточняющий вопрос; «готово» только после проверки путём владельца. Слова владельца — гипотезы, перепроверять по источникам до правок. Внешние советы (GPT) критически оценивать, в планы — с разделом «Критическая оценка»; вердикты внешнего рефери внедрять по умолчанию, возражать только с самостоятельно найденным пруфом. «Этого нет» — только после проверки, способной это найти. Гипотезы, не аксиомы: отклонился от спеки обоснованно → ADR.
