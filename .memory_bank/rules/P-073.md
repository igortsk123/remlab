# P-073 · владелец · Общение с владельцем: язык, вопросы, сводка, показ, ошибки

## Правило

**Язык и вид**
- Оформление в Telegram — только `~/.claude/telegram-style.md`; здесь — что и когда писать (P-001).
- Только по-русски, простыми словами без терминов, коротко, у каждого пункта «зачем» (P-001).
- Время — по Лондону с днём недели, из `date` (P-001).
- Число в отчёте (конвейер, доли, %) — с датой замера; старше суток — пересчитать или не писать (TG 2398, урок 908).
- Запросы советнику, которые владелец пересылает сам, — по-русски, «Запрос N», каждый отдельным сообщением `format: text` (P-001).
- Вопросы — в самом конце, с номерами «❓ 1. суть — советую …»; нет вопросов — блок не писать; «Правило: нет / 📌 П-NNN» — перед ними (P-002; P-069).
- Ночью (21–07) — только ❗ авария; остальное утром одним отчётом (P-070).

**Сводка**
- Одна общая; группы по приоритетам П1, П2…, все приоритеты; % у каждой строки и общий % вверху — только `plan-procent` (P-003; К4).
- Временный вид (19.11, TG 1741/1745/1746): «задача — %», группы «Меши» и «Остальное» (P-003).
- Готовое — одной строкой «Гn · что → где смотреть», ссылки внизу с «что смотреть»; замечание по Гn = возврат в П1 (P-003).
- ✅ — только 100 %; выложенное — отдельной строкой без галочки; ⏳ — только «в работе сейчас», ожидание — 🕓 «ждёт: чего» (P-003).
- Токены — только в долларах: лимит ≈$2000/нед, потрачено (% × 20), мы / прочее, остаток (P-003).

**Показ результата**
- Что владелец проверяет на сайте — ссылка + 1–3 строки «куда нажать, что увидеть»; без ссылки «выложено» не писать (P-004).
- После правок визуализации — сразу ссылка на `/test/` (P-004).
- Готовая 3D-модель — ссылкой на просмотр, без кадров, крутит владелец; найденные косяки — в том же сообщении «что нашёл, иду править сам» (P-004).
- **До ссылки — каждую модель сам со всех сторон** (TG 2185/2202): лист «фото + перед, 3/4, бок, зад, др. бок, верх» на КАЖДЫЙ товар, не выборка; быстро — браузерная съёмка 08-frames (≈20 с), numpy (~5 мин) только запасной; брак невидимого (зад, верх) — тоже брак, автокрутку не выключать, чинить.
- Рендеры и фото на оценку — отдельные кадры в полном разрешении, без листов-сеток (P-005).
- Пробы: варианты пронумерованы, после готового — «Вариант N» с кадрами; в кадрах сложная ткань (диван, кресло) и узорный ковёр, не только корпус (P-005).
- В долгих пробах раз в 30–60 мин — лучший промежуточный результат кадрами, плохой тоже (ночью — в утренний отчёт) (P-005; P-070).
- Результат пробы → показать → исследовать → «что понял» → самому вычеркнуть/добавить варианты (P-005).
- Визуальное — проверить самому до показа (зум слабых мест) глазами покупателя, дизайнера и девелопера; наезды, парящее, чёрное — дефект; без браузера/скриншота «проверено визуально» не писать (P-006, P-004).
- Новый вид страницы — сперва макет/снимок, после «ок» — выкладка; мелочи согласованного — сразу (P-006).
- Элементы в тон страницы, минимум текста, служебное прятать (ADR-0299) (P-006).

**Ошибка, на которую указал владелец**
- Сразу ОДНИМ сообщением, не дожидаясь вопроса: «❗ что не так (прямо, без оправданий) → причина (что сузил/пропустил, какое правило/ADR/урок не сверил, чьё число принял без проверки) → план (текущий запуск, системно, что меняю; кто, что, когда) → как проверим» (P-063).
- «Признаю, поправила» без плана и «буду внимательнее» — не отправлять (P-063).
- Исправлять системно (общий код/правило, P-071), урок в `lessons/` и блокнот сразу; повторная — правило в реестр или чек-лист приёмки; потом дальше по задаче (P-063).
- Ошибку рабочего — так же: разбор и план от рабочего, причину проверяет ведущий (P-063).
- Числа о прогоне — только из сводки/журнала с источником; показ — все товары прогона (страница), не выборка; сводка и страница покраски — автоматом шагом конвейера (P-063).
- «Не пробовали» — после поиска по коду и журналам; «от чего дефект» — после замера; ответ владельца — сразу строкой в план (P-063).
- «По аналогии с X» = таблица всего рецепта X в брифе (P-063).

## Почему
Владелец не пишет код и читает кратко: простой язык, ссылка «куда нажать», вопросы в конце с номерами и честный разбор ошибок экономят ему время и доверие (свод 23.11, TG 2090/2094/2114).
Полный прежний текст, снятое, источники — `history/P-073.md`.
