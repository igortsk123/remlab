# Расстановка — Tier 1

**Правила**: свод `../domain/occupancy-rules.md` (~40 источников) → машиночитаемо
`services/planner-solver/rules/occupancy.json` (ОДИН файл на оба движка, scout читает симлинком);
решения владельца: кап пола / диван↔столик / диван↔ТВ — динамические шкалы от площади;
ковёр — привязка к дивану.
**Сейчас (scout)**: ЗОНА-БИЛДЕР (ADR-0050) — зона атомарным блоком (диван∥ТВ, столик по шкале,
кресло полукругом 135–225°±35° (ADR-0051), пуф вне оси, буфер 65 см, бронь тыла; Г-диван
полигоном), DFS Holodeck — периферия.
**Правила владельца (2026-08-02):** за спинкой дивана — только НИЗКОЕ (≤90 см: консоль/комод),
высокий шкаф/стеллаж за диваном запрещён; диван «по центру» допустим, но тогда стена ЗА ним не должна
пустовать — либо диван к стене, либо за спинкой хранение/консоль (в движке — штраф
`empty_wall_behind_sofa`); промежуточная щель 20–70 см запрещена (или вплотную, или проход ≥76).
**Прод-ядро** (ADR-0052, `services/planner-solver/`, Python+shapely, БЕЗ ML): кандидаты → hard →
beam (20×8) → скоринг по весам → уточнение → top-K с объяснениями. Э1–Э5 в коде,
60 тестов, 1.5–2.2 с/комнату, детерминизм. Э7: scout умеет `--engine beam`,
сравнение на 126 сетах — **beam 110+/122 против DFS 107/126** (берёт большие комнаты, теряет
на 26–30 м²). Комнаты пока прямоугольные (`Room(width,depth)`), но геометрия вся полигонная —
непрямоугольный контур = поле контура + кандидаты «у стены» по рёбрам, не переделка. Осталось:
Э6 LLM-слой, backtracking для тесных 26–30 м². Спека `../guides/layout-engine-spec.md`. **Э0**: 118 добытых правил + 15 модулей к vendor/adapt + 15 конфликтов →
`../guides/layout-mined-rules.md` (при конфликте канон наш). Clean-room: NC-код не копируем.
