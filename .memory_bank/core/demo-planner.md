# Демо-планировщик — Tier 1 сводка

**Что это:** демо `/test/flat215-demo/` (партнёру): план квартиры (№180, 76,5 м²) → расстановка
гостиной → кадр с товарами → отправка подборки. `tools/scout/flat215-demo/index.html`, сборка
`flat215_demo.py`, публикация `publish_demo.sh` (спрайты переживают выкатку — ADR-0150).

- **Вкладки:** план · помещения (работает Гостиная). Варианты — подразделы сверху; кадры и
  подборка живут В РАЗРЕЗЕ варианта (`vid`).
- **Кадр (ADR-0139/0140/0149):** серверный рендер 3D-сцены из мешей БЕЗ ИИ (`scene3d_frame`),
  два вида из противоположных углов; ракурс задаёт человек на плане — решение одно на черновик и
  на платное улучшение (`draft_render.cams_from_request`). Детали рендера и камер —
  `../domain/demo-planner-ui.md` и ADR-0149.
- **План — только схемы (ADR-0149):** накладка `topsprites/<sid>.png` снята; спрайты остались
  в 3D-сцене и серверном кадре.
- **Комплекты (ADR-0151):** «стул 2» берёт товар базовой роли; покупок = `ceil(слотов /
  sku.pack)`, `pack` — из `pack_qty.lookup()`.
- **Управление (ADR-0140):** поворот с наездом разрешён; тап — ±90°, долгий — drag.
- **Отправка себе:** контакт (Telegram/MAX/SMS) → `/api/share`, очередь на проде; токенов ботов нет.
- **Наличие (ADR-0144):** сборка снимает не продающееся (`drop_unavailable`), не дожидаясь
  ночного лечения; ссылки ПАРТНЁРСКИЕ.
- **Планы:** `plans/viz-regional-masks.md` (ADR-0127) · `plans/demo-planner-structure.md`.

- **Вёрстка и UX (ADR-0156):** цвет/радиус/тень только из `:root`; новым блокам префикс класса
  (`fh-`/`pc-`/`ml-`); один вход в съёмку —
  кнопка под планом; цели касания ≥44 px; зум разрешён. Детали и грабли — Tier 2
  `../domain/demo-planner-ui.md`.
