# Демо-планировщик — Tier 1 сводка

**Что это:** демо `/demo` (ADR-0201; было `/test/buildup`, закрыто). Квартира №215, 73,7 м².
Витрина: сертификат → коллекции по стилям → замена мебели; план — в конструкторе.
Код: `tools/scout/flat215-demo/index.html`, сборка `flat215_demo.py`, публикация `publish_demo.sh`.

- **Вкладки:** план · помещения (Гостиная). Кадры и подборка — в разрезе варианта (`vid`).
- **Кадр** — серверный рендер сцены из мешей, два вида; ракурс задаёт человек
  (`draft_render.cams_from_request`). Окно кадра: фото → товары → действия. Грабли — Tier 2.
- **Замена мебели (ADR-0203):** сет + пул `demo_swap_pool.py` («есть меш + стиль сильный»,
  30 на подкатегорию×стиль); товар многостилен (`styles`), лента режется стилем варианта.
- **Ключ модели — `msid` (ADR-0204):** GLB по представителю семейства, не по артикулу товара.
- **Ссылка на вариант (ADR-0205):** `/demo/#v=<id>` — вариант и его фото.
- **Декор (ADR-0206):** ваза стоит на столешнице (`draft_render.decor_layout`), не двигается,
  входит в сумму и ревизию.
- **Комплекты (ADR-0151):** «стул 2» берёт товар базовой роли; покупок = `ceil(слотов/pack)`.
- **Управление (ADR-0140):** поворот с наездом разрешён; тап — ±90°, долгий — drag.
- **Отправка себе:** контакт → `/api/share`; **наличие (ADR-0144):** не продающееся снимается,
  ссылки ПАРТНЁРСКИЕ. **Планы:** `plans/viz-regional-masks.md` · `plans/demo-planner-structure.md`.

- **Два уровня (ADR-0158):** витрина и конструктор; платная генерация — только по кнопке.
- **Кадры хранит сервер** (реестр + миниатюры), длинные запросы — фоновым заданием.
- **Щели (ADR-0165):** лечим в упрощении (`preserve_border`); 0164/0166/0167 — рядом.
- **Вёрстка и UX (ADR-0156):** цвет/радиус/тень из `:root`, префиксы классов, цели ≥44 px.
