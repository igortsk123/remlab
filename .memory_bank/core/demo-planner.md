# Демо-планировщик — Tier 1 сводка

**Что это:** демо `/test/buildup/` (постоянный адрес с 01.09; старый путь — переадресация).
Квартира №215, 73,7 м². Витрина: сертификат → коллекция расстановок по стилям → замена мебели
на месте; план — только в конструкторе на весь экран. `tools/scout/flat215-demo/index.html`, сборка
`flat215_demo.py`, публикация `publish_demo.sh` (спрайты переживают выкатку — ADR-0150).

- **Вкладки:** план · помещения (работает Гостиная). Варианты — подразделы сверху; кадры и
  подборка живут В РАЗРЕЗЕ варианта (`vid`).
- **Кадр:** серверный рендер 3D-сцены из мешей, два вида из противоположных углов; ракурс
  задаёт человек — `draft_render.cams_from_request`. Детали — `../domain/demo-planner-ui.md`.
- **Комплекты (ADR-0151):** «стул 2» берёт товар базовой роли; покупок = `ceil(слотов/pack)`.
- **Управление (ADR-0140):** поворот с наездом разрешён; тап — ±90°, долгий — drag.
- **Отправка себе:** контакт (Telegram/MAX/SMS) → `/api/share`, очередь на проде; токенов ботов нет.
- **Наличие (ADR-0144):** сборка снимает не продающееся (`drop_unavailable`), не дожидаясь
  ночного лечения; ссылки ПАРТНЁРСКИЕ.
- **Планы:** `plans/viz-regional-masks.md` (ADR-0127) · `plans/demo-planner-structure.md`.

- **Два уровня (ADR-0158):** витрина (коллекции по стилям, замена мебели, избранное) и
  конструктор плана полноэкранным окном. Платная генерация — только по кнопке.
- **Кадры хранит сервер** (реестр + миниатюры), длинные запросы идут фоновым заданием —
  `../domain/integrations.md`.
- **Вёрстка и UX (ADR-0156):** цвет/радиус/тень только из `:root`, префиксы классов,
  один вход в съёмку, цели ≥44 px. Детали и грабли — `../domain/demo-planner-ui.md`.
