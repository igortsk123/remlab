# Демо-планировщик — Tier 1 сводка

**Что это:** демо `/test/buildup/` (постоянный адрес с 01.09). Квартира №215, 73,7 м².
Витрина: сертификат → коллекции по стилям → замена мебели на месте; план — в конструкторе на
весь экран. `tools/scout/flat215-demo/index.html`, сборка `flat215_demo.py`, публикация
`publish_demo.sh` (спрайты переживают выкатку — ADR-0150).

- **Вкладки:** план · помещения (работает Гостиная). Варианты — подразделы сверху; кадры и
  подборка живут В РАЗРЕЗЕ варианта (`vid`).
- **Окно кадра:** фото → товары строками → полоса действий (в конструктор, в избранное, закрыть).
- **Кадр:** серверный рендер сцены из мешей, два вида из углов; ракурс задаёт человек —
  `draft_render.cams_from_request`. Грабли — `../domain/demo-planner-ui.md`.
- **Комплекты (ADR-0151):** «стул 2» берёт товар базовой роли; покупок = `ceil(слотов/pack)`.
- **Управление (ADR-0140):** поворот с наездом разрешён; тап — ±90°, долгий — drag.
- **Отправка себе:** контакт → `/api/share`, очередь на проде; токенов ботов нет.
- **Наличие (ADR-0144):** сборка снимает не продающееся; ссылки ПАРТНЁРСКИЕ.
- **Планы:** `plans/viz-regional-masks.md` (ADR-0127) · `plans/demo-planner-structure.md`.

- **Два уровня (ADR-0158):** витрина (коллекции по стилям, замена мебели, избранное) и
  конструктор плана полноэкранным окном. Платная генерация — только по кнопке.
- **Кадры хранит сервер** (реестр + миниатюры), длинные запросы — фоновым заданием.
- **Белые крапины упрощённых мешей (ADR-0164)** чиним в кадре по топологии, а не по числу
  соседей (`draft_render._fill_pinholes`): внутри предметов 3621 → 51 px за 0,17 с.
- **Вёрстка и UX (ADR-0156):** цвет/радиус/тень из `:root`, префиксы классов, цели ≥44 px.
