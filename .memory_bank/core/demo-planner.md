# Демо-планировщик — Tier 1 сводка

**Что это:** демо `/demo` (ADR-0201). Квартира №215, 73,7 м².
Витрина: сертификат → коллекции по стилям → замена мебели; план — в конструкторе.
Код: `tools/scout/flat215-demo/index.html`, сборка `flat215_demo.py`, публикация `publish_demo.sh`.

- **Вкладки:** план · помещения (Гостиная). Кадры и подборка — в разрезе варианта (`vid`).
- **Кадр** — серверный рендер сцены из мешей, два вида; ракурс задаёт человек
  (до 2 камер; не двигал — автоподбор; `draft_render.cams_from_request`). Окно: фото → товары → действия. Грабли, щели мешей — Tier 2.
- **Замена мебели (ADR-0203/0245/0271):** пул `tools/scout/demo_swap_pool.py`, правила `tools/scout/rules/demo-swap.json`:
  30 на подкатегорию × стиль, балл стиля ≥ 6, порядок: универсальные ниже → качество → стиль → цена; проверка `tests_chain.py:live_swap_feeds`.
- **Ключ модели — `msid` (ADR-0204):** GLB по представителю семейства, не по артикулу товара.
- **Ссылка на вариант (ADR-0205):** `/demo/#v=<id>` — вариант и его фото.
- **Коллекции покупателя (ADR-0264):** «Сохранить коллекцию» → снимок на сервере (`app/api/collections/route.ts`),
  ссылка `/demo/#c=<id>`; товары/цены/фото — сервер из витрины (`lib/collections/prices.ts`). Вёрстка — Tier 2.
- **Декор (ADR-0206):** ваза на столешнице (`decor_layout`), не двигается, входит в сумму.
- **Управление (ADR-0140):** тап — ±90°, долгий (~450 мс) — перетаскивание; наезд — только при повороте, при перетаскивании его нельзя увеличить; ковёр не считается.
- **Отправка себе:** не доставляется (28.09), заявка — в базе (ADR-0256). Шапка квартиры — [[partners]].
- **Наличие (ADR-0144):** не продающееся снимается, ссылки ПАРТНЁРСКИЕ.
- **Русский = протокол логики (28.09):** данные не переводить, только показ; `plans/demo-en-gbp.md`.

**Вариант = стиль (13.10, ADR-0244):** `pick_banks` — по набору на стиль (самый собираемый);
кнопка «в 3D» → `/flat?demo=<вариант>`.
- **Кадры (ADR-0280):** очередь с местом и оценкой, ночной прогрев `tools/ops/demo-warm.mjs`, время — `frame_sec`.
