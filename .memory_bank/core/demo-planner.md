# Демо-планировщик — Tier 1 сводка

**Что это:** интерактивное демо `https://remont-lab.online/test/flat215-demo/` (для партнёра):
план квартиры (чертёж №180, 76,5 м²) → расстановка гостиной → AI-фото с товарами и отправка
подборки. Исходник страницы — `tools/scout/flat215-demo/index.html` (в репо), сборка данных —
`tools/scout/flat215_demo.py` (`demo-data.json`), публикация — `tools/scout/publish_demo.sh`
(на `/opt/remlab/test/`, живой статик-путь).

- **Вкладки:** «План квартиры» (SVG с чертежа, клик по гостиной) · «Расстановка комнаты»
  (канвас: drag, поворот, замена товара; ревизия = хеш расстановки). Варианты — подразделы
  сверху (стиль+цена, ≤4 + свой сохранённый), кадры и подборка живут В РАЗРЕЗЕ варианта (`vid`).
- **Фото (ADR-0139/0140):** кнопка отдаёт СЕРВЕРНЫЙ кадр 3D-сцены из мешей БЕЗ ИИ
  (`scene3d_frame`). Полное качество рендерит DEV через ssh-туннель, фолбэк — прод
  (`dev_render_backend.sh`, ~11с). На плане — топ-спрайты `topsprites/<sid>.png`.
- **Управление (ADR-0140):** поворот с наездом разрешён (за стены — заводит внутрь); короткий
  тап — стрелки ±90°, длинный — drag.
- **Отправка себе:** только контакт (Telegram/MAX/SMS); подборка = кадры + товары с ценами и
  ссылками (`/api/share`, очередь `/opt/remlab/test/share/_queue`; токенов ботов на проде нет —
  канал честно «подключаем»).
- **Наличие (ADR-0144):** сборка сама снимает позиции не в продаже
  (`flat215_demo.drop_unavailable` → `catalog_media.media`) — страница не ждёт ночного ремонта
  банка; ссылки в подборке ПАРТНЁРСКИЕ (клик засчитывается).
- **Проверка страницы:** jsdom-прогоны опубликованной страницы; `str.replace` без assert запрещён.
- **Планы:** точность мест мебели — `plans/viz-regional-masks.md` (Трек 1/2, ADR-0127);
  структура демо — `plans/demo-planner-structure.md`.
