# Демо-планировщик — Tier 1 сводка

**Что это:** интерактивное демо `https://remont-lab.online/test/flat215-demo/` (для партнёра):
план квартиры (чертёж №180, 76,5 м²) → расстановка гостиной → AI-фото с товарами и отправка
подборки. Исходник страницы — `tools/scout/flat215-demo/index.html` (в репо), сборка данных —
`tools/scout/flat215_demo.py` (`demo-data.json`), публикация — `tools/scout/publish_demo.sh`
(на `/opt/remlab/test/`, живой статик-путь).

- **Вкладки:** «План квартиры» (SVG с чертежа, клик по гостиной) · «Расстановка комнаты»
  (канвас: drag, поворот, замена товара; ревизия = хеш расстановки). Варианты — подразделы
  сверху (стиль+цена, ≤4 + свой сохранённый), кадры и подборка живут В РАЗРЕЗЕ варианта (`vid`).
- **Фото:** черновик и «улучшенное» — `POST /api/render` (сервис `draft_service.py`, контейнер
  `remlab-draft`, лимит 60/час); лента не удаляется, одна съёмка (2 вида) = одна карточка;
  у каждого кадра «Исходники запроса» — `/test/share/src/<id>/` (ровно то, что ушло в модель).
  Рецепт и модели — ADR-0125..0127, `[[furniture]]`.
- **Отправка себе:** только контакт (Telegram/MAX/SMS), ссылку не показываем; подборка = кадры +
  товары с ценами и ссылками (`/api/share`, очередь `/opt/remlab/test/share/_queue` — токенов
  ботов на проде пока нет, канал честно «подключаем»).
- **Проверка страницы:** jsdom-прогоны ОПУБЛИКОВАННОЙ страницы (скрипты `realtest.mjs` и др. в
  scratchpad сессии) — ловят то, что видит браузер; `str.replace` без assert-якоря запрещён.
- **Планы:** точность мест мебели — `plans/viz-regional-masks.md` (Трек 1/2, ADR-0127);
  структура демо — `plans/demo-planner-structure.md`.
