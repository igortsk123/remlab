# Этажи: плохие планировки → 3D — Tier 1

Приоритет владельца 26.11 (TG 2958). План — `plans/etazhi-walls-model-01.md`; решения — ADR-0485 (набор), ADR-0486 (чтение и проверки), ADR-0487 (имена, ворота, суббота), ADR-0488 (проверки, набор 1000).

## Как устроено (вечер 26.11; скрипты — `~/remlab-logs/etazhi-walls/voronka/`)
- Читает нейросеть: Planwalk v4 (только CLI) → plan.v1; GPT-6.2 Sol ≈$0,05 за лист, Opus ≈$0,17. Правила-читатель — запасной.
- Вход: `tools/floorplan/cleanup.py` (`FP_CLEAN_BG`, выкл); вырезка 4b, бледные линии 4c, сетка 4d — ветки на приёмке.
- Привязка: маска чернил + подгонка масштаба/сдвига (`vetka_fit.py`), класс каждой стены (на линии / сдвинута / выдумана / слабая линия …), правка положения (`vetka_correct.py`) с воротами по стене (`accept_correction.py`, `removal_rules.py`).
- «Проверено» = А (комнаты паспорта, `a_rooms_v2.py`) + Б (нетронутые стены, контроль поперёк, `b_check_v2.py`) + состав; паспорт — три суммы ≤3 % (`passport_sverka.py`), вычисленные площади не в А; читатель v2 — `reader_v2.py`.
- Чистка ответа (ADR-0487): имена — по словам на листе (`words_on_sheet.py`, OCR кириллицы, кэш по sha256), слов нет — «Комната N»; E004-уступы убираются; правка стен откатывается при худшей А любой комнаты. Сторож `~/remlab-logs/etazhi-walls/ustroystvo/storozh.py` П1–П8 — звонок, не приговор.
- Суббота 28.11: 100 свежих, Opus b + GPT d, `~/remlab-logs/etazhi-walls/ustroystvo/run_sb100.sh` только из снимка `~/remlab-logs/etazhi-walls/voronka/versii/`, автоправка выкл.

## Принцип и набор (ADR-0488)
- Модель не проверяем и запросом не лечим — проверка наложением и исправление кодом (TG 3485); цифра на листе главнее рисунка (TG 3494). Острота пика и D25 — в тени до субботы.
- Стенд 88 (`~/remlab-logs/etazhi-walls/ru-plans/`); 100 свежих — суббота, до неё не открывать; набор 1000 для настройки проверок (`ru_collect_1000.py`, 700/300, плохих ≥350).
- Мерка: «ушёл в 3D без правки и верно»; «проверено и неверно» = 0.
