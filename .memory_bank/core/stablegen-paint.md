# Покраска мешей StableGen — как гоняем пакет (T-90/11–12, 20.11)

Проба: результат — `painted.glb`, на сайт только после «принято» (P-059). Код — `tools/scout/stablegen/`.

## Конвейер
- **Форма:** Salad (TRELLIS.2, `trellis_trial.py`) отдаёт GLB **без развёртки** → ОБЯЗАТЕЛЬНО `sg_prep_batch.sh` (`sg_prep_shape.py`: ≤150 тыс. граней + слой `BakeUV`). Без UV запекание не кончается (≈$1,9 впустую 20.11): стоп «форма без UV» ДО пода — `sg_salad.build_cfg`, `sg_drive.py`.
- **Нода:** Salad 5090 (`sg_salad.py --card "RTX 5090 (32 GB)"`, образ Qwen-Image-Edit-2509 Q5_K_M + Lightning) или RunPod A6000 (`sg_runpod.py`). Прогрев 5–13 мин; 504 Salad на create/start — `api_retry`.
- **Очередь прогонов `sg_queue.RunQueue` — одна для обоих драйверов:** нода красит, мы запекаем (следующий товар — когда у предыдущего stage bake/export); сторож запекания >3× ожидаемого (300 с) → убить, «запекание зависло»; проба: первый товар упал — стоп группы; 2 подряд — стоп; сторож места <1,5 ГБ → стоп «диск»; усадка успешного прогона (без session.blend/inpaint/controlnet/baked: 125 → ≈21 МБ).
- **Сбои связи (T-153/1):** мост `sg_relay.py` и Blender повторяют шаг до 3 раз (403 «Salad Connection Error», 502–504 у безопасных запросов, «isn't reachable»); признаки — данные `tools/scout/rules/stablegen-transient.json` (`sg_transient.py`, влито 2b709f23); счётчик повторов — в записи прогона.
- **Подписи видов:** роль из каталога → существительное (`sg_views.role_noun`, порядок слов не важен); фото только видам ≤~100° от переда, подпись без цвета только у первого вида (`variant q2509t5i`).
