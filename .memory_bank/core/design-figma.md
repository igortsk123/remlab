# Дизайн демо в Фигме — Tier 1 сводка

Решение — ADR-0312. Дизайнер правит `/demo` в Фигме; правки читаются обратно задачами рабочим.

**Книги** (папка «RemLab», команда ProdStore; доступ дизайнеру даёт владелец):
Mobile 375 — `KeoB3huA9ce58swtNrDyrx`, Desktop 1440 — `lFSqAHtIH4gb45d1zvIXEY`.

**Страницы по порядку:** «Как пользоваться» (утверждённый текст владельца + «Что где» + «Нюансы») → «Счастливый путь»
(Mobile 18 шагов, Desktop 16; картинки — копии заливок «Экраны RU») → 18 страниц элементов (каждый набор в секции с подписью
и строкой «что это», RU и EN отдельно) → «Экраны RU/EN» (снимки 26.10).

**Как собрать/пересобрать страницу** — `tools/design/figma/README.md`: выгрузка сайта (`tools/design/capture.mjs`,
`build-spec.mjs`) → `gen2.py` (данные + нарезка частями) → `use_figma` по `ПОРЯДОК.txt` → картинки (`upload_assets`, WebP → PNG)
→ `check.js` (все счётчики 0) → снимки. Сборщик, распаковщик и проверка лежат в самих книгах (`figma.root` sharedPluginData
`remlab/builder2|inflate|check`). Скрипты страниц «Как пользоваться» (`howto.js`, затем `nyuansy.js`), «Счастливого пути» и
структурной проверки — в `tools/design/figma/shots/*/` (пути — README).

**Не переживёт пересборку из данных** (доведено руками, перечислено в «Нюансах»): кольцо выбранного цвета («Образцы», «Карточка
товара», списки окна), план квартиры по комнатам (`plan-rooms.js`), фото в средней карточке «Избранного», «Изменить расстановку» в
2 строки, ряд «Со стороны двери / окна» по ширине, переименования «(кадр)».

**Грабли:** SF Pro в коннекторе меряется в 0 → Inter; WebP Фигма не показывает; hash картинки свой в каждой книге; запись в
`.claude/**` даёт окно разрешения даже с allow-правилом (урок 524).
