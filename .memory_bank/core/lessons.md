# Lessons — что НЕ сработало и почему

> Только инкрементальные bullets; писать сразу, читать перед каждым планом.

Все уроки живут в `../anti-patterns.md`; здесь — карта, куда смотреть.

- **1–333** — § Архив: вшиты в код, правила и тесты.
- **334–393 (31.08–03.09)** — пул нод и выкатка на Salad, квота реплик и тело создания группы,
  `storage_amount` как фильтр машин, цена смены образа, границы разрешения, отказ без текста
  ошибки, «СБОЙ» шага → сперва `journalctl`, «Running» у Salad ≠ работает, комментарий в коде ≠
  факт об источнике, тихий фолбэк предиката, trimesh не отдаёт память, инференс из меша против
  приора, порог по сумме источников, оси магазина мерить на выборке, сверять роли после
  пересборки таксономии, новые отрицательные сигналы — только через тень с gold.
- **394–399 (03–04.09, пул мешей)** — проверку ставить туда, где она выполняется; замер только
  в памяти процесса — не замер; проверка пустым файлом — не проверка (канарейка); статус первой
  группы ≠ состояние пула; стопоры без свода правил; мёртвый Bash оказался `EDQUOT`, а не
  последствием `pkill -f` (399-бис).
- **400–404 (04.09)** — `autostart_policy` поднимает группу при СОЗДАНИИ, окно тарифа её не
  гасит; тарифы сравнивать только на сопоставимых часах (грязное окно дало «6× дороже» вместо
  15 %); «медленный темп» без проверки «уже готово» снимает докачавшие ноды; сухой прогон,
  принятый за выполнение; «400» у Salad = кончились деньги.
- **405–408 (04.09, вечер)** — удаление мимо API ломает счётчик, на этом API построенный
  (призрак 2.24 ГБ погасил пул); красивая причина принята без проверки, что она действовала; гард по
  шаблону команды ловит рассказ о команде; пропущенный шаг цепочки даёт ноль, а не ошибку.
