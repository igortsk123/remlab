- 303 [26.08] Диагностика через глобальную переменную врёт: `_axis_contract.media` пишет глобал, который перетирает последний вызов плейсера, и артефакт приписывает победившей гипотезе чужие числа. Диагностику писать в meta той гипотезы, к которой она относится.

## Сессия 26–28.08 (демо-рендер; детали — ADR-0124..0130)
- solver без габаритов — условная комната; `| head -1` убивает до записи; `str.replace()` только
  с assert; без ttf PIL теряет кириллицу; порог видимости в списке/эталонах «выключает» мелкий
  предмет — модель ставит чужое.
- gpt-image: координаты/depth — не управляющий вход; работает геометрия НА кадре + роль
  «renderer»; fal-редакторы без масок; маска OpenAI — guidance, побитовость даёт свой коммит.

## Сессия 28.08 (ориентации/меши; детали — ADR-0129/0130)
- Конвенции 3D — только исполняемым замером; чтение перспективных рендеров агентом ненадёжно —
  арбитр: сцен-A/B-пара человеку.
- VLM перед/зад: работает ТОЛЬКО промпт с признаками сторон роли (qwen3-vl 10/10); haiku врёт
  наоборот; классификация одного кадра лучше сравнения двух.
- Шлюз Vercel: max_tokens ≥ 16 (иначе 400). nohup без -u — пустой лог; pgrep перед перезапуском
  (гонка воркеров). Растеризатор медленный на плотных мешах — упрощать перед контролем.
