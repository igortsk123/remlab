# Lessons — что НЕ сработало и почему

> Только инкрементальные bullets; писать сразу, читать перед каждым планом.

(Уроки 1–296 — в `../anti-patterns.md`: они вшиты в код, правила и тесты. Здесь только
свежие, ещё не «застывшие» в гардрейлах.)

- 297 [21.08] acceptance_run РЕЗЮМИТ по существующему jsonl («готовые сцены не пересчитываются») — после правок кода отчёт ОБЯЗАТЕЛЕН к удалению, иначе экзамен загрязнён сценами старого движка. Поймал владелец по нестыковке темпа (100 сцен за «2 минуты»).
- 298 [21.08] Дельту экзамена сначала бисектить ДАННЫМИ (git stash движка + текущие банки): 8/9 «регрессий» оказались свежим sets3 из крона, а не кодом. Код и данные меняются независимо — вывод «мой коммит сломал» без бисекта не делается.
- 299 [21.08] Две системы отсчёта одной оси: гейт _axis_off мерял от ЦЕНТРА дивана, движок целится в seat_axis_origin (центр главной секции Г) — пока угловых было мало, расхождение пряталось; corner-фикс вскрыл (медиана оси носителя 19 см). Ось — ОДНА функция на все слои.
- 300 [21.08] Г-диван + ковёр: блок с ковром у угловых тихо теряет ковёр при сборке (set93/94/77 — ковёр 230×160 пригоден, в плане отсутствует) — вскрыто ростом числа угловых; разобрать отдельно (остаток в ADR-0120). **Уточнение 22.08:** это НЕ тихая потеря на сборке — гипотеза БЕЗ ковра честно выигрывает лексо-ключ у гипотезы С ковром, то есть вопрос весов ключа, а не пропажи предмета.
