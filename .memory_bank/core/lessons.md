# Lessons — что НЕ сработало и почему

> Только инкрементальные bullets; писать сразу, читать перед каждым планом.

(Уроки 1–333 — в `../anti-patterns.md` § Архив: вшиты в код, правила и тесты. Здесь свежие.)

- 31.08 (наличие каталога, ADR-0141): «есть в фиде + есть цена» — НЕ наличие. Проверка, чей
  результат перезаписывает загрузчик, — имитация защиты: вердикты `health`/`linkcheck` жили до
  утра, 353 ссылки с 404 числились в продаже, снятий по карточке не было НИ ОДНОГО. Лечится
  только разделением источников + один писатель (`stock_truth.reconcile`).
- 31.08 (грабли той же починки): `'\x1f'.isspace()` → True, поэтому `stdout.strip()` съедает
  пустые последние поля строки psql; «captcha» в теле — не антибот (18× `recaptcha_response` на
  живой карточке), судить можно только по URL и короткому телу; `"quantity"` у tvoydom исчез со
  страниц — правило молча деградировало. Сигнал проверять на живом И на снятом товаре.
- 30-31.08 (меши/Salad): pyflakes воркера ДО сборки образа; `pgrep -f`/`pkill` своим же
  паттерном убивает свой шелл; прочее — урок 333, ADR-0137 (`../anti-patterns.md` § Архив).
- 31.08 (конвейер мешей; урок 332, чинено ADR-0142): состав нод, снятый на старте, не переживает
  эластичное облако; ssh-порт НЕ идентичность (за час 3 владельца), обрыв ≠ вердикт задания,
  курсор пачки ≠ её размер. Тарифицируется только `running`; `allocating`/`downloading` бесплатны.
- 31.08 (фронт корпусных): цвет/edge/шейдинг фасада НЕ работают — истина в ГЛУБИНЕ (ступени
  2–15% толщины, полость = фасад, `tools/scout/salad/cabinet_front.py`); поворот — снэп к 90°.
- 31.08 (scene3d, ADR-0140): сдвиг растеризаторов калибровать медианой, а не константой;
  backface culling по нормалям Hunyuan пробивает дырки; ковёр — гомографией, не треугольниками
  (`tools/scout/draft_render.py`).
- 01.09 (меши, ADR-0143): АВТОРЕМОНТ ГОДНОЙ МОДЕЛИ — ЧИСТЫЙ УБЫТОК. С HD-фото геометрия выходит
  чистой, резать нечего, а каждый нож рискует отхватить законную часть товара. Подгонка цвета
  статистикой к фото (Рейнхард + квантильная светлота, `texture_fix.match_photo_color`) тянула
  unlit-**альбедо** к освещённой фотографии — боролась с замыслом модели и портила текстуру;
  по той же причине неверна метрика `color_mismatch` (тексели vs пиксели фото — сравнивать надо
  рендер со светом). Общее правило: постобработка выхода генератора допустима, только если
  доказано «до/после лучше» на выборке, а не по метрике, придуманной под сам же фикс.
- 01.09 (Hunyuan3D-Paint 2.1): текстовой инструкции покраске НЕТ, хотя слот `prompt` выглядит
  живым: `textureGenPipeline.py` шлёт `prompt="high quality"`, а UNet при `use_learned_text_clip`
  (дефолт True) подменяет его обученными токенами `learned_text_clip_albedo/mr`. Цвет берётся
  ТОЛЬКО из референс-фото + геометрии → управлять цветом можно лишь входом (баланс белого фото
  до генерации), не промптом.
