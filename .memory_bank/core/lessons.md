# Lessons — что НЕ сработало и почему

> Только инкрементальные bullets; писать сразу, читать перед каждым планом.

(1–49 — в `../anti-patterns.md`, архив уроков; вшито в код/правила)



**Tier 2:** ../anti-patterns.md (детект в diff; UI — §6–7)
50. [08-03] Правило «предмет у той же стены, что и ТВ» не срабатывает в УГЛУ: предмет числится по соседней стене (ближайшая из двух). Формулировать через положение относительно зоны (например «не глубже линии столика»), а не через стену.
51. [08-03] Габариты в фиде путают оси (кашпо «80x40x50 см» приехало как Ш=40/Г=80) и содержат мусор (настольная лампа с глубиной 130 см). Если размеры есть в НАЗВАНИИ — они истина; декор без габаритов в сет не берём (иначе приезжает «Абажур для настольной лампы» вместо светильника).
52. [08-03] План и кадр рисовались в разных системах координат (кадр нормализует мир под камеру, план — координаты солвера) — владелец видел «генерится не по плану». Любые визуализации одной раскладки обязаны быть в ОДНОЙ нормализации.
53. [08-03] Правило исключения ролей перекрывалось валидатором состава: кресло выбрасывалось правилом «в малой площади — пуф» и тут же возвращалось добором «обязательных по чек-листу». Любое исключение должно вычитаться и из списка обязательных, иначе оно ничего не значит.
