# Lessons — что НЕ сработало и почему

> Только инкрементальные bullets; писать сразу, читать перед каждым планом.

(Уроки 1–312 — в `../anti-patterns.md` § Архив: вшиты в код, правила и тесты. Здесь только
свежие, ещё не «застывшие» в гардрейлах.)

- 31.08 (наличие каталога): «есть в фиде + есть цена» — НЕ наличие. Фиды Гдеслона не отдают
  `available`, API отдаёт `true` даже на 404-карточки, `load3.py` ставит `in_stock=true` каждым
  прогоном (`:173,243`), стирая вердикты `health.py`/`linkcheck.py`. Проверка, чей результат
  перезаписывает загрузчик, — имитация защиты: 353 ссылки с 404 «в наличии»
  (`../domain/catalog-enrichment.md` § Наличие товара).
- 30-31.08 (меши/Salad): pyflakes воркера ДО сборки образа, `pgrep -f`/`pkill` своим же
  паттерном убивает свой шелл, ручной `apply_repairs` при живом конвейере — гонка за
  `repair.json`; Salad-грабли — урок 333 и ADR-0137 (`../anti-patterns.md` § Архив).
- 31.08 (конвейер мешей; урок 332): тёплые ноды снимаются ОДИН раз на старте прогона
  (`tools/scout/salad/ssh_run.py`) — поздние машины простаивают; провал транспорта не
  возвращается в очередь, а `done` растёт на всю пачку — задания теряются молча, счётчик пилота
  завышен. Правка — `plans/mesh-dynamic-node-pool.md`.
- 31.08 (фронт корпусных): цвет/edge/шейдинг фасада тумб НЕ работают (петли боков, фасетки,
  скользящий свет) — истина в ГЛУБИНЕ: ступени 2–15% толщины корпуса, полость = фасад
  (`tools/scout/salad/cabinet_front.py`); полный R давал «фронт под углом» — только снэп 90°.
- 31.08 (scene3d): константный z-допуск вклейки ковра закрашивал низ мебели — сдвиг
  растеризаторов калибровать медианой; backface culling по нормалям Hunyuan пробивает дырки
  (перевёрнутые нормали); два аффинных треугольника вместо гомографии ломают перспективу
  (`tools/scout/draft_render.py`).
