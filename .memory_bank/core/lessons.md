# Lessons — плейбук уроков (что НЕ сработало и почему)

> **Протокол (ACE): ТОЛЬКО инкрементальные правки bullets** — добавить/уточнить/пометить
> `~~устаревшим~~`. Целиком не переписывать (COMPRESS запрещён, MERGE дублей можно). Формат:
> `N. [дата] <ситуация> → пробовали → не сработало: <причина> → правило: <впредь>`.
> **Писать** грабли сразу (блокнот) или на `/memory-check`; «Уроки» планов — сюда.
> **Читать** ОБЯЗАТЕЛЬНО перед каждым планом (`agent-workflow.md`, Этап 1).

## Уроки

1. [2026-07-28] `./deploy.sh` (arm64 под QEMU) OOM'ит DEV-VM (2.7 ГБ); QEMU в раннере крашил
   SWC `SIGILL` → авто-деплой `deploy.yml` на нативном `ubuntu-24.04-arm`; `./deploy.sh` не юзать.

2. [2026-07-30] Гориз. скролл со скрытым скроллбаром в шапке = «меню обрезано» → правило:
   скролл без видимого индикатора в навигации не делать — flex-wrap.
3. [2026-07-30] Захват «м 2» (разорванный `<sup>2</sup>`) ловился, классификатор пробела не знал
   → «за м²» падала в «за упак» → правило: захват и классификацию единиц тестить одной фикстурой.
4. [2026-07-30] ИИ-фолбэк parse-link при валидном ключе молча отдавал `{}` на любую ошибку →
   неотличимо от «не понадобился» → правило: неуспех внешнего вызова всегда console.error.

5. [2026-07-30] Ozon → пробовали Chrome-заголовки + резид./моб. РФ-прокси → не сработало:
   JS-челлендж (`__rr`-цикл, 403) → правило: JS-антибот серверно не обходить — `needs_file`,
   юзер грузит сохранённую страницу (Ctrl+S), DOM там с исполненным JS.
6. [2026-07-30] Параллельная авто-коммит сессия (`git add -A`) захватила чужой staged-код в свой
   коммит (`e813bac`, сообщение врёт) → правило: параллельные агенты — в отдельных worktree;
   перед commit проверять status на чужие staged-файлы.
