# Lessons — маршрутизатор

Перед планом читай свой файл в `lessons/`; здесь только живые правила.

- **Меши/Salad** `lessons/mesh-salad-pool.md`: «Running» ≠ работает (верь `gpu_seconds`/`done`); свой автомат выкашивает пул раньше платформы.
- **Каталог** `lessons/catalog-stock.md`: сбой пробы ≠ вердикт (None, не False); проверяй тот URL, что показываешь; негативный сигнал — сперва тень с gold.
- **Расстановка** `lessons/layout-solver.md`: правило = файл правил + чек; экзамен на снимке банков, код на бегу не править; дельту бисектить данными.
- **Визуализация** `lessons/viz-render.md`: разворот/размер задаёт геометрия в кадре, не текст; кадр проверять планом (`scene_check`).
- **Демо** `lessons/demo-planner.md`: живой сервис держит старый код — перезапусти и проверь сквозным запросом; фолбэк пишет причину; css-классам — префикс.
- **DevOps** `lessons/devops-deploy.md`: `pkill -f` убивает харнесс — только PID; `nohup` внутри фона = ложное «готово»; каталог репо на сервер — `rsync --delete`.
- **Память/процесс** `lessons/memory-process.md`: durable — сразу в канон; слова владельца — гипотезы, уточняй границу; платное — сперва проба; «нет» — после проверки, способной найти.
- **Смета/реклама** `lessons/estimate-ads-leads.md`: дефолт — фолбэк, не показанное число; человеку — партнёрская ссылка, боту — прямая.
