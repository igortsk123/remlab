# Lessons — что НЕ сработало и почему

> Только инкрементальные bullets; писать сразу, читать перед каждым планом.

(1–199 — в `../anti-patterns.md`, архив; вшито в код/правила. Свежайшие из архива: 195 LLM —
зоны/отношения, координаты — солвер; 196 чужие движки не брать, абстракции — модульно;
197 массовые прогоны — параллельно с jsonl-resume; 199 правило в данных ≠ правило в силе —
заводя правило в JSON, сразу пиши чек.)


200. [08-08] **Один лейбл движка — один алгоритмический путь (ADR-0076):** под ENGINE=zoned после планнера молча гонялись 6 DFS-попыток и при меньшем числе нарушений ПОДМЕНЯЛИ результат — A/B контаминирован, таймауты, ×2 время сцены. Скрытые кросс-движковые «спасения» делают цифры бенчмарка недоказуемыми; инвариант закреплён тестом (test_engine_purity).
201. [08-08] **«Просадка» метрики ≠ регресс кода:** прогон с W-правками дал 221/252 против 239 — но 22 из 31 провала оказались «состав стал амбициознее (обеденная/стенка), а required-семантика старая». Прежде чем чинить солвер, разложи провалы по причинам: правки правил, правки составов и качество движка меняются независимо. Фикс — семантика ярусов (retention-priority, дроп ярусом), а не «откат правил».
202. [08-08] **Флаги и позиционные аргументы не смешивать наивно:** `sys.argv[1]` как выходной путь съел флаг `--referee` — файл сохранился под именем «--referee». Разбирай argv фильтром (позиционные = не начинающиеся с --), либо argparse.
