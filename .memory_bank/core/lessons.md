  потолок (задержка ≤1200с), а холодный старт ноды ~35 мин — инстанс при живом сервисе
  навсегда помечался неготовым, шлюз отдавал 503, нода 15 часов тарифицировалась впустую.
  Не подгонять пороги, а убирать зависимость: `/health` = «жив», гейт — в рабочем эндпоинте.
  включая прогрев, докачку весов и простой. Скачивание образа — бесплатно, значит тяжёлый
  образ с весами дешевле лёгкого с докачкой (ADR-0135). Гасить группу сразу после прогона.
  для контейнеров ставить контейнером в ту же сеть, а не на хост — iptables на машине с боевым
  VPN не трогаем.
  прогон при `import` — поймали дважды за день (импорт health в тесте запустил скан 716 страниц
  и чуть не перезаписал наличие). Читать чужой модуль перед импортом; функции доставать
  парсингом файла, если модуль «исполняемый».
- 30-31.08 (меши/Salad): скриптовые диапазонные правки файлов теряют функции молча (2 мины NameError: `dual`, `flat_shape`) → перед сборкой образа ОБЯЗАТЕЛЕН pyflakes по всем файлам воркера (py_compile мины не ловит). `pgrep -f`/pkill с паттерном, входящим в свою же команду, убивают собственный шелл (трижды за день) — паттерн с [к]вадратной скобкой; после kill проверять `ps -p <PID>` — TERM может съесть дочерний шаг, а процесс выживает (двойные конвейеры в гонке). Ручной apply_repairs при живом конвейере — гонка за repair.json: только изолированный REPAIR_SRC. Salad: тег образа = кэш-подмена версий (только digest); «нет тёплых» N раз подряд — проверять статус группы (stopped+отказ старта = баланс); батч-очередь пустеет в вечерний праймтайм США (наши ~00–08), лучшие окна — наш день; группа тянет образ по состоянию на СТАРТ ноды — в группе живёт зоопарк версий, версию кода в /health пока не отдаём.
