# Lessons — что НЕ сработало и почему

> Только инкрементальные bullets; писать сразу, читать перед каждым планом.

(Уроки 1–296 — в `../anti-patterns.md`: они вшиты в код, правила и тесты. Здесь только
свежие, ещё не «застывшие» в гардрейлах.)

- 303 [26.08] Диагностика через глобальную переменную врёт: `_axis_contract.media` пишет глобал, который перетирает последний вызов плейсера, и артефакт приписывает победившей гипотезе чужие числа. Диагностику писать в meta той гипотезы, к которой она относится.

Более ранние уроки — `../anti-patterns.md` § Архив уроков (перенесены 26.08: Tier 1 ≤3 КБ).

## Сессия 26–28.08 (демо-рендер; детали — ADR-0124..0130)
- solver без габаритов — условная комната; `| head -1` убивает до записи; `str.replace()` только
  с assert; без ttf PIL теряет кириллицу; порог видимости в списке/эталонах «выключает» мелкий
  предмет — модель ставит чужое.
- gpt-image: координаты/depth — не управляющий вход; работает геометрия НА кадре + роль
  «renderer»; fal-редакторы без масок; маска OpenAI — guidance, побитовость даёт свой коммит.

## Сессия 28.08 (ориентации/меши)
- Конвенции 3D — только исполняемым замером (selftest/нос-тест): «бумажный» вывод знака дважды
  ошибался; агентское чтение перспективных рендеров ненадёжно (3 противоречивых прочтения) —
  арбитр: сцен-A/B-пара человеку.
- VLM для перед/зад: краткий промпт «спереди/сзади» проваливается на стуле у ВСЕХ моделей;
  промпт с ПРИЗНАКАМИ сторон роли даёт qwen3-vl 10/10. claude-haiku уверенно врёт наоборот;
  сравнение двух похожих рендеров хуже, чем классификация одного.
- Шлюз Vercel: max_tokens ≥ 16 (меньше — HTTP 400, молча ломает «дешёвые» вызовы).
- nohup: питон без -u буферизует насмерть (пустой лог при живом процессе); фон — один уровень,
  перед перезапуском pgrep старого (гонка двух воркеров в один лог).
- Наш растеризатор медленный на плотных Hunyuan-мешах (минуты вместо секунд) — упрощать меш
  перед контрольными рендерами.
