# Lessons — что НЕ сработало и почему

> Только инкрементальные bullets; писать сразу, читать перед каждым планом.

(1–164 — в `../anti-patterns.md`, архив уроков; вшито в код/правила)

165. [08-05] Перцептивный хеш один не доказывает «тот же товар»: CLIP B/32 на 224 px не видит фактуру — один диван в рогожке и велюре дал косинус 0.983. Нужна сверка цвета (сетка 8×8, ≤14 из 255) и порог 0.985; при сомнении отвечаем «изменилось» (`tools/scout/phash.py`).
166. [08-05] Не всякий .sql в папке — миграция: `db_migrate.py` уронил прогон на `bootstrap.sql` (первичная схема с `create or replace view` падает поверх живой базы). Мигрируем только `NNN-*.sql`.
167. [08-05] Правило разнообразия проверяло не того кандидата: `overlap_ok` считал пересечение по всему комплекту, и после превышения лимита отсекался ЛЮБОЙ следующий товар — комплекты теряли весь декор разом (6-7 позиций вместо 11-13). Проверять надо только кандидата, который увеличивает пересечение.
168. [08-05] Лист эталонов строим от состава комплекта, а не от номеров в кадре: номер получает только видимое, поэтому ваза вне кадра выпадала из «эталонов на все позиции» (`viz_final.identity_sheet`).
