# Lessons — маршрутизатор

Перед планом читай свой файл в `lessons/`; здесь живые правила.

- **Меши/Salad** `lessons/mesh-salad-pool.md`: «Running» ≠ работает (`gpu_seconds`/`done`); свой автомат выкашивает пул раньше платформы; гейт, чей вердикт готовность не читает, — не гейт (472).
- **Каталог** `lessons/catalog-stock.md`: сбой пробы ≠ вердикт (None, не False); проверяй тот URL, что показываешь; негативный сигнал — сперва тень с gold; размеры роли — только `unfit` (521).
- **Расстановка** `lessons/layout-solver.md`: правило = файл правил + чек; экзамен на снимке банков, код на бегу не править; дельту бисектить данными.
- **Визуализация** `lessons/viz-render.md`: разворот/размер задаёт геометрия в кадре, не текст; кадр проверять планом (`scene_check`).
- **Демо** `lessons/demo-planner.md`: живой сервис держит старый код — перезапусти и проверь сквозным запросом; фолбэк пишет причину; css-классам — префикс.
- **DevOps** `lessons/devops-deploy.md`: `pkill -f` убивает харнесс — только PID; `nohup` в фоне = ложное «готово»; конфиг сервера новее репо — `diff`; ПДн не в файлах под веб-корнем (473).
- **Память/процесс** `lessons/memory-process.md`: durable — сразу в канон; слова владельца — гипотезы; платное — сперва проба; «нет» — после проверки; `last_verified` массово НЕ двигать.
- **Смета/реклама** `lessons/estimate-ads-leads.md`: дефолт — фолбэк, не показанное число; человеку — партнёрская ссылка, боту — прямая.
- **3D-конфигуратор** `lessons/flat3d-configurator.md`: у камер обратный знак угла; цвет мерить в исходной текстуре; интерфейс — под сценой; 3D-e2e `serial`.
