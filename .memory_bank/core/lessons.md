- 02.09 (демо: блокнот при параллельных сессиях, сила селекторов, скриншот прода) — перенесены в `../anti-patterns.md` § Уроки 365–368.
- **Молчаливый фолбэк — это отказ, которого не видно** (02.09): демо рендерило кадры на
  ДЕКИМИРОВАННОМ запасном пути (диван 40 000 → 9 000 граней, текстура → цвет вершин), потому что
  DEV-бэкенд полного качества отвечал 502 на КАЖДЫЙ запрос. Причина не печаталась нигде: прод
  писал «DEV-бэкенд молчит (HTTP Error 502)», DEV — ничего. Правило: у фолбэка обязана быть
  причина в логе на СТОРОНЕ, где произошёл отказ; иначе деградация живёт неделями.
- **pydantic v2 запрещает запись необъявленных атрибутов** (02.09): `pl.hung = ...` при
  необъявленном поле роняло сборку сцены целиком. Поле объявлено в `planner/models.py`.
  Общий вывод: присваивание нового атрибута модели — это изменение контракта, а не мелочь.
- **Окно, которое человек не закрывал, должно пережить вложенное окно** (02.09): правило владельца
  сперва для листа подбора, теперь и для конструктора — возвращаем окно кадра по «Готово».
- **Наши логи на Salad непригодны для разбора — мы сами их залили** (02.09): воркер печатает
  полосы прогресса `tqdm` (`Volume Decoding: 60%|…`) со скоростью 16 строк/с, и в выгрузке
  логов 971 строка из 1000 — это они. Экспорт обрезан по 1000 строк, поэтому «логи за сутки»
  на деле покрывают 62 секунды. Лечится переменной `TQDM_DISABLE=1` на группе, без пересборки.
  Фильтр в конфигураторе логов: `container_group_name = <группа>` и `text_log !contains %|`.
- **Молчаливый пропуск шага виден только в логах ноды** (02.09): `cut_alien_debris пропущен:
  AttributeError 'Scene' object has no attribute 'faces'` — обрезка артефактов не работает на
  сценах из нескольких мешей, модель уходит без чистки. Найдено случайно, в 29 полезных строках
  из 1000. `except`, который печатает и идёт дальше, обязан считаться, а не только печататься.
