# Lessons — что НЕ сработало и почему

> Только инкрементальные bullets; писать сразу, читать перед каждым планом.

(1–73 — в `../anti-patterns.md`, архив уроков; вшито в код/правила)

74. [08-04] Вся генерация идёт через fal.ai: кадры — `fal-ai/sdxl-controlnet-union`, апскейл — `fal-ai/esrgan`; локально считаются только карты, план, clay и нарезка видов. Разные виды = разные запросы = разный свет: единое зерно (`VIZ_SEED`, по умолчанию 4242) сближает материалы, но полное совпадение даёт только нарезка из одной панорамы.
75. [08-04] Ф2: фото товаров в `tools/scout/thumbs/` — 100 px по длинной стороне, для врисовки бесполезны. Полноразмерное берётся из поля `img` фида (`big.jpg`, ~450 px) и кэшируется в `tools/scout/refs/`; ещё крупнее — только со страниц магазинов (не сделано).
76. [08-04] Врисовка товара: OpenAI `images/edits` принимает И маску, И фото товара в одном запросе — единственный из проверенных, кто даёт и форму, и место. `nano-banana/edit` берёт референс, но без маски (маску применяем сами при склейке). Склейка всегда через маску: за её пределами кадр Ф1 не трогается.
77. [08-04] Артефакты сцен нельзя держать в `/tmp` (tmpfs — чистится при перезапуске, панорама пропала вместе с генерацией). Каталог сцен — `~/scout-scenes` (`SCENE_DIR`).
