# Lessons — плейбук уроков (что НЕ сработало и почему)

> **Протокол (ACE):** только инкрементальные bullets; писать сразу, читать перед каждым планом.

## Уроки

1. [2026-07-28] `./deploy.sh` (arm64/QEMU) OOM'ит DEV-VM → деплой только авто (push в main).
2. [2026-07-30..31] UI-мелочи, читающиеся как баг → перечень в `anti-patterns.md` §6.
3. [2026-07-30] «за м²» падала в «за упак» (разорванный `<sup>`) → единицы тестить одной фикстурой.
4. [2026-07-30] ИИ-фолбэк молча отдавал `{}` при ошибке (= «не понадобился») → неуспех внешнего
   вызова всегда console.error.
5. [2026-07-30] Ozon/WB банят по репутации IP (пулы не спасают) → только анблокер;
   сохранённую страницу владелец отверг.
6. [2026-07-30] `git add -A` захватил чужой staged-код → агенты в отдельных worktree; перед
   commit — status.
7. [2026-07-31] Молчаливый дефолт (рулон 0,53 м) давал «2 рулона» до ввода данных → дефолт —
   фолбэк, НЕ источник показанного числа (ADR-0034).
8. [2026-07-31] ADR-0027 удалил проёмы без явного одобрения владельца → откат (ADR-0035) →
   удаление функциональности — только с явного «да» владельца, одобрение — в ADR.
9. [2026-07-31] Кнопка-пустышка (markSaved «сохраняла» уже сохранённое ради цели Метрики) →
   цель аналитики — на РЕАЛЬНОЕ действие (ADR-0036).
10. [2026-07-31] deployment.md 10 дней врал «авто-деплой сломан» → живой факт (CI +
   health.version) wins; память обновлять при обнаружении.
11. [2026-07-31] Ссылка на товар первой — юзеры не находили ввод размеров → порядок блоков по
   задаче юзера, монетизация после (ADR-0037).
12. [2026-07-31] e2e-локатор упал на регистре текста и мог зацепить ссылки шапки → текстовые
   локаторы с /i + скоупить к контейнеру (getByRole("navigation")).
