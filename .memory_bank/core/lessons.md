# Lessons — что НЕ сработало и почему

> Только инкрементальные bullets; писать сразу, читать перед каждым планом.

(Уроки 1–271 — в `../anti-patterns.md`: они вшиты в код, правила и тесты. Здесь только
свежие, ещё не «застывшие» в гардрейлах.)

- 272 [17.08] Роль без SKU в каталоге (приставной) делает шаблон недостижимым молча — проверять достижимость шаблона по БАНКАМ (счёт по sets3), не по паспорту; композитор обязан давать комплект зоны атомарно (пара + поверхность), иначе «мёртвый груз» passed_not_placed.
- 273 [17.08] Якорь блока с повёрнутым предметом у стены торчит углом в стену → 0 позиций без единого hard в логе; якорить блок на осевом предмете, повёрнутые сдвигать на «вылет» поворота. Диагностика place_* обязана писать причину (QUIET_DIAG), иначе сертификат врёт.
- 274 [17.08] Правило-сторож (ARMCHAIR_TOO_DEEP) может убивать целый класс шаблонов по построению (П/facing: кресло за столиком всегда >80) — при добавлении форм проверять «мёртв ли вариант» замером top_hard по ZDBG, а не по числу сцен.
- 275 [17.08] Гейты по ВЫБРАННЫМ планам сравнимы только на замороженной когорте сетов; после пересборки sets3 планки (two-sofa 37) не переносятся — гейт по сертификатам достижимости (full_valid | причина).
- 276 [17.08] Опциональная форма главной группы (`u`) не должна забирать secondary-роли (кресла 3/4) — решение о scope ролей обязано держаться во ВСЕХ формах, иначе «утечка» обезглавливает вторую зону.
- 277 [17.08] Новые SKU в сеты — только из живых фидов (fail-closed к broken/stale + quarantine_pending); «предпочесть живой» недостаточно: все 72 pod-пары ушли в сломанный nonton.
