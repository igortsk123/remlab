# Lessons — что НЕ сработало и почему

> Только инкрементальные bullets; писать сразу, читать перед каждым планом.

(1–79 — в `../anti-patterns.md`, архив уроков; вшито в код/правила)

80. [08-04] Экономика решает архитектуру: пообъектная правка нейросетью линейна по числу предметов (5–19 центов за предмет) и в лимит ~20 ₽ за кадр не влезает. Вклейка фото товара по геометрии (0 генераций) + один согласующий проход на кадр = ~5 центов независимо от числа позиций (ADR-0057).
81. [08-04] Фото товара перед вклейкой обязано быть без фона: у дивана вклеивался белый ореол, у столика — синяя подложка карточки. Вырезание — `fal-ai/birefnet`, разово на товар, кэш `tools/scout/refs/*-cut.png`.
82. [08-04] Проверены три гипотезы владельца «пусть модель сама разместит»: (1) карта глубины как референс + JSON координат — у gpt-image нет управляющего входа, карта для неё обычная картинка, числа в пиксели не переводятся; (2) план с миниатюрами — проверено 03.08, читает как справку и переставляет; (3) грубая вставка + улучшение — РАБОТАЕТ, но «грубая вставка» выгоднее математическая. Экспериментальное доказательство: тот же кадр с листом референсов → комод/тумба/стеллаж переехали на другую стену; со строгим запретом двигать → состав и места сохранены (`~/scout-scenes/scene21-P-center-gpt.jpg` vs `-center-strict.jpg`).
83. [08-04] OpenAI images/edits принимает до 16 изображений за запрос (по 50 МБ) — `edit_gpt_raw` в `tools/scout/viz_objects.py`. Лист референсов давать ОПАСНО без жёсткого запрета: модель начинает расставлять товары по своему вкусу.
