## Сессия 28.08 (ориентации/меши; детали — ADR-0129/0130)
- Конвенции 3D — только исполняемым замером; чтение перспективных рендеров агентом ненадёжно —
  арбитр: сцен-A/B-пара человеку.
- VLM перед/зад: работает ТОЛЬКО промпт с признаками сторон роли (qwen3-vl 10/10); haiku врёт
  наоборот; классификация одного кадра лучше сравнения двух.
- Шлюз Vercel: max_tokens ≥ 16 (иначе 400). nohup без -u — пустой лог; pgrep перед перезапуском
  (гонка воркеров). Растеризатор медленный на плотных мешах — упрощать перед контролем.
- **Чужой requirements — источник истины, мы ДОПОЛНЯЕМ.** Свой список рядом с апстримовским
  переопределил 9 пинов Hunyuan (huggingface-hub на 3 версии назад): сборка зелёная, ломается
  на ноде при загрузке весов (ADR-0132).
- **Зелёная сборка ≠ рабочий артефакт:** шаг, способный «успешно» ничего не сделать (скрипт
  без pybind11 отдаёт 0 и кладёт пустой `.so`), заканчивать явной проверкой результата.
- **Внешние пины протухают:** `bpy==4.0` исчез с PyPI, официальный Dockerfile Tencent не
  собирается. Перед починкой своей сборки проверить оригинальную.
- Свежий pip изолирует сборку: `setup.py` с импортом torch требует `--no-build-isolation`.
- **`cd` в фоновой команде не переживает вызов** (дважды): `docker build .` собрал Next.js
  вместо Hunyuan под чужим тегом. Для docker — `-f` и контекст абсолютными путями.
