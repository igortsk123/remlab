# Lessons — что НЕ сработало и почему

> Только инкрементальные bullets; писать сразу, читать перед каждым планом.

(Уроки 1–312 — в `../anti-patterns.md` § Архив: вшиты в код, правила и тесты. Здесь только
свежие, ещё не «застывшие» в гардрейлах.)

- 30-31.08 (меши/Salad; детали — урок 333): pyflakes по файлам воркера ДО сборки образа;
  `pgrep -f`/`pkill` паттерном из своей же команды убивает свой шелл; ручной `apply_repairs`
  при живом конвейере — гонка за `repair.json`; Salad-грабли (digest-only, детект баланса,
  окна доступности) — ADR-0137, § Архив.
- 31.08 (конвейер мешей; урок 332): тёплые ноды снимаются ОДИН раз на старте прогона
  (`tools/scout/salad/ssh_run.py`) — поздние машины простаивают; провал транспорта не
  возвращается в очередь, а `done` растёт на всю пачку — задания теряются молча, счётчик пилота
  завышен. Правка — `plans/mesh-dynamic-node-pool.md`.
- 31.08 (фронт корпусных): RGB/edge/шейдинг-детекторы фасада тумб НЕ работают (петли боков,
  фасетки Hunyuan, скользящий свет) — истина в ГЛУБИНЕ: ступени 2–15% толщины корпуса
  (`salad/cabinet_front.py:front_by_depth`), полость = фасад; кандидаты — только 2 широкие
  стороны. Каскад полного R давал «фронт под углом» — только снэп yaw к 90°.
- 31.08 (scene3d): наивный z-допуск (+25см) на вклейке ковра закрашивал низ мебели — сдвиг
  между растеризаторами калибруется медианой по пикселям, а не константой; backface culling
  по нормалям Hunyuan пробивает дырки (перевёрнутые нормали) — в качественном режиме рисовать
  всё, z-буфер сам разрулит; два аффинных треугольника вместо гомографии ломают перспективу.
