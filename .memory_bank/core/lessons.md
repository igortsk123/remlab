# Lessons — что НЕ сработало и почему

> Только инкрементальные bullets; писать сразу, читать перед каждым планом.

(Уроки 1–266 — в `../anti-patterns.md`: они вшиты в код, правила и тесты. Здесь только
свежие, ещё не «застывшие» в гардрейлах.)

- 267 [16.08] Финальные контракты плана (MEDIA_MISSING) — не в validate(): он зовётся на промежуточных блоках посадки; отдельная финальная проверка в обёртке солвера (ADR-0106).
- 268 [16.08] Роли — только через geometry.base_role: 'стол обеденный'.split(' ')[0]='стол' терял dining в ключе beam → beam молча ронял столовую (210→169) при «улучшении».
- 269 [16.08] Ключ сравнения ГОТОВЫХ планов обязан включать богатство ступени и класс оси до суммарных штрафов: иначе beam спускается по лестнице (меньше предметов → меньше штрафов) и меняет 128 см оси на пару см прохода.
- 270 [16.08] Составную зону (инсталляция) нельзя сравнивать с одиночной локально — больше предметов → больше штрафов; только как гипотезу на готовом плане.
- 271 [16.08] Массовые fails=[] в экзамене = исключение подпроцесса (ожившая мёртвая ветка), не нарушения — stderr одной сцены. Роли с qty и «X 2» — одно пространство имён (alt-кресло 2 поверх qty=2 → фантомы).
