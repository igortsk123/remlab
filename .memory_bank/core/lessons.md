# Lessons — что НЕ сработало и почему

(1–18, июль — перенесены в `../anti-patterns.md` §Архив уроков)

19. [2026-08-01] ML-модели расстановки мебели: все на 3D-FRONT → NC. НЕ предлагать (ADR-0042).

20. [2026-08-02] Роль в промпте без вклейки в черновик → «текстовый клон» товара; промпт/QA только по PRESENT.
21. [2026-08-02] VLM-боксы врут → инпейнт-маски только по нашим bbox (≤12%/18%), откат при ухудшении; носителей с декором не перекрашивать.
22. [2026-08-02] `available` в фидах Гдеслона не проставляется → наличие только по карточкам (tvoydom: qty-поля, маркер там ложный).
23. [2026-08-02] mnogomebeli/divanboss: карточки из фида 404 (SPA) → URL резать до серии; ссылки выгрузок хранить в ACCESS.md сразу.
24. [2026-08-02] compose недетерминирован → утверждённые составы замораживать до пересборки.
25. [2026-08-02] pip на DEV-VM только venv (PEP 668); большие файлы на диск, не в /tmp.

**Tier 2:** ../anti-patterns.md (детект в diff; UI — §6–7)
26. [2026-08-02] Правило владельца: решения ТОЛЬКО масштабируемые (для класса случаев, вшитые в конвейер), точечные фиксы «для 1 ситуации» запрещены — хардкод-столик и разовая проверка материала тому примеры.
27. [2026-08-02] psql без ON_ERROR_STOP глотает SQL-ошибки ТИХО (returncode 0) → скрипты собрали пустые сеты; guard на объём выборки обязателен.
28. [2026-08-02] Служебная графика в черновике (рамка-кромка) материализуется рендером в предмет («лампа в каркасе») — маркеры только там, где неотличимы от реальности (кромка ковра).
29. [2026-08-02] VLM-косметика («подправь оттенок») в ретраях ломает больше, чем чинит — принимать только структурные находки (add/remove/missing/extra); спорный ретрай → финал = base.
30. [2026-08-02] Инпейнт чинит только с фото-рефом; без него модель сочиняет (клетчатый ковёр). Большая маска перерисовывает ВСЁ внутри — соседи товара гибнут.
31. [2026-08-02] Пригодность товара для жилой роли по названию не видна (кашпо-«вазон», подвесное 15 см) — проверять params (материал/назначение) + мин-размеры роли.
