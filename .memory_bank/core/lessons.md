# Lessons — маршрутизатор

- **Меши/Salad** `lessons/mesh-salad-pool.md`: «Running» ≠ работает; причина — по событиям Salad (533); проверка — после всех писателей (536); 1 модель на группу не окупает прогрев (575); признак генератора — не брак (577).
- **Каталог** `lessons/catalog-stock.md`: сбой пробы ≠ вердикт; проверяй показанный URL; размеры роли — `unfit` (521); выведенное хранит источник (538); годность — лесенкой (581); модель сцены — своя (583).
- **Расстановка** `lessons/layout-solver.md`: правило = файл + чек; экзамен на снимке банков; одна величина — одна функция (539); стиль без ядра не ломает другие (585); файл в образе ≠ код его видит (586).
- **Визуализация** `lessons/viz-render.md`: разворот и размер — по геометрии, не по тексту и уверенности VLM (580).
- **Демо** `lessons/demo-planner.md`: живой сервис — перезапуск + сквозной запрос; фолбэк пишет причину; путь владельца: порядок окон, RU+EN, 375+1440 (559, 560).
- **DevOps** `lessons/devops-deploy.md`: `pkill -f` убивает харнесс — только PID; `db/init` = миграция прода (531); CI — после каждого push (569); платный API — стоп на locked (570); claim — скалярный `skip locked` (571).
- **Память/процесс** `lessons/memory-process.md`: durable — сразу в канон; слова владельца — гипотезы; платное — баланс ДО (544); `.env*` и запись в `.claude/` — не в брифе (545, 565); таймаут SendMessage ≠ не дошло (564); робот не приписывает решений владельцу (566).
- **Смета/реклама** `lessons/estimate-ads-leads.md`: дефолт — фолбэк, не показанное число.
- **3D-конфигуратор** `lessons/flat3d-configurator.md`: у камер обратный знак угла; цвет — в исходной текстуре; снимок — после текстур (625); без копланарных граней (626).
- **Разбор плана / проба** `lessons/floorplan-trial.md`: регресс — по комнатам против кода ДО правки (598); правки разбора до загруженных туров
  доходят только «Перечитать» (599); порог проёма — от локальной толщины (601); оборванный VLM — повтор и флаг (602); «медленно» — мерить
  longtask, ракурсы на сервере (607); после вливания — перезапуск `remlab-trial-worker` (608).

## Критичные сейчас
- Пул: `autostart_policy` поднимает при создании (481); «нет денег» — лишь `no_credits_available` (519); в отчёте — ограничитель (568).
- Деплой: приёмка — по `version` в `/api/health` (513).
- DEV: код кронов — в worktree (516); worktree без игнорируемых входов врёт, «сухой» — проверить (525, 527); тяжёлое — heavy-slot (573) с реальным `--min-gb`; ядра
  очередь выводит из команды сама (617), снимки 3D — 6–7 ядер (663); вливать до проверенного хеша (612); /demo — только из основной копии (662);
  `prepush_check` вне хука — `</dev/null` (675); юнит systemd — вывод в journald (677); после влития `money_guard` — перезапуск (671).
- Тесты: новое поведение — найти тесты функции во всём `tests/`, новый тест-файл — сразу в список CI (661); влитие правил расстановки — с эталонами (659);
  scout-тест из CI — в чистом `~/venvs/ci-check` с пакетами задачи (665); после вливания — CI публичным API, прод — по `/api/health` (673).
- Конвейер: замок/метка — только по входам сборки, не по всему каталогу (672); `app/`/`lib/` из `tools/` не импортирует (674); сторож «по диску» —
  вывод сборки отсечь до проверки (676); правка правила набора меняет только вытесняемое (681); редирект — относительный `Location` (680).
- Тур «потерял стиль/мебель» — сперва выложенный bundle на проде, не журнал стадии (683); долгая стадия перечитки — память службы
  (`memory.events`), не код (682); тормоза 3D — только с `?live=force` (686).
- Вливание: пачкой в чистом worktree, не в грязном main (669, ADR-0406); влито → проверку работника снять (668); демо не перевыпускать
  поверх идущего refresh_daily (666).
- Владельцу: «проверь» — только когда всё на проде (627); перед сжатием ведущего — `/memory-check` (628, ADR-0381); фазы плана — по факту каждый обход (657, ADR-0397); правило «/demo и туры» — по снимку /demo тоже (667).
