# Lessons — что НЕ сработало и почему

> Только инкрементальные bullets; писать сразу, читать перед каждым планом.

(Уроки 1–287 — в `../anti-patterns.md`: они вшиты в код, правила и тесты. Здесь только
свежие, ещё не «застывшие» в гардрейлах.)

- 288 [19.08] Одно имя на две сущности молча теряет данные: галерея писала карточки `seating.default` от РАЗНЫХ групп в один файл — вторая затирала первую. Единица учёта канона — пара (группа, форма), а не id схемы (ADR-0113).
- 289 [19.08] Схема, которую исполняет боевой код без паспорта, невидима для гейтов: три композиции (`sofa_facing_sofa`, `console_behind_sofa`, `media_wall`) годами жили вне реестра. Исполняемое обязано быть объявленным.
- 290 [19.08] Прятать предмет ради обхода мягкого замечания нельзя: убрал ковёр из `square`, чтобы не мигало предупреждение — это фальсификация эталона, а не исправление. Допустимые отклонения объявляют списком в паспорте.
- 291 [20.08] «Огонь отвлекает» ≠ «камин рядом с ТВ запрещён»: источники бьют только по композиции камин НАПРОТИВ ТВ (отражение в экране), а side-by-side рекомендуют. Замечание владельца проверяем по источникам, а не переносим в правило дословно (ADR-0114).
