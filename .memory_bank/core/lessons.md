## Сессия 28.08 (ориентации/меши; детали — ADR-0129/0130)
- **Bind-монтирование ФАЙЛА ломается при правке:** `sed -i` и запись из Python подменяют inode,
  контейнер держит старый файл и докладывает «config is unchanged», хотя на диске правка есть.
  Править через `cp`/`tee` в существующий файл либо монтировать каталог. 28.08, Caddyfile.
- **На exit-fi `INPUT DROP`:** контейнер не достучится до сервиса на шлюзе docker-сети. Сервис
  для контейнеров ставить контейнером в ту же сеть, а не на хост — iptables на машине с боевым
  VPN не трогаем.
- **Кэш buildkit чистится САМ при нехватке диска:** «инкрементальная» пересборка молча
  становится полной. Проверять число `CACHED` в первых строках лога — секунда против часа.
  Тяжёлую базу и свой код разносить по двум Dockerfile (`Dockerfile.patch`): наш код
  наращивается поверх готового образа за секунду.
- **НЕ чистить кэш docker при итеративной сборке.** `builder prune --filter until=Nh` режет по
  ВОЗРАСТУ СОЗДАНИЯ: старейшие слои — это база (apt, torch), самые дорогие. «Уберу мусор от
  неудачных попыток» — иллюзия, мусор молодой и под фильтр не попадает. 28.08: час пересборки
  на ровном месте, при том что места ХВАТАЛО. Чистить только упёршись в диск, сначала ВНЕ
  docker (pip/npm/vscode-server), `builder prune` — последним и при остановленной сборке.
