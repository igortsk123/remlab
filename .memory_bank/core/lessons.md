# Lessons — что НЕ сработало и почему

> Только инкрементальные bullets; писать сразу, читать перед каждым планом.

(Уроки 1–291 — в `../anti-patterns.md`: они вшиты в код, правила и тесты. Здесь только
свежие, ещё не «застывшие» в гардрейлах.)

- 292 [21.08] Тест, читающий мутируемый файл вне git (sets3.json, перезаписывается кроном 09:40), падает «сам по себе»: mirror/integrity-тесты рухнули без правок кода. Данные тестов фиксировать (fixture или коммит-снимок), не тянуть живой фид.
- 293 [21.08] Суффикс-модификатор в `tpl_variant` (console_behind_sofa+short) ломает все ТОЧНЫЕ сравнения варианта в валидаторе — исключения молча гаснут (NOT_AT_WALL/ACCESS_BLOCKED). Контракт: сопоставление вариантов — по префиксу.
- 294 [21.08] `block_bbox` не расширяет предметы под 45° (w/d без поворота) — контейнмент по bbox пропускал кресло за стену. Проверка вхождения — по реальным футпринтам каждого предмета.
- 295 [21.08] Мини-сцена референса с дверью вплотную к композиции рождает ложные дефекты канона («вход зажат» — аудит Юли №1/№3): проём в витрине ставить на дальний конец стены, а дверную логику проверять отдельной сценой (зеркала — door_side_scene).
- 296 [21.08] Каскад состава, молча выбрасывающий предмет (торшер в эркере, WINDOW_BLOCKED в 6 см), прячет решаемую проблему: прежде чем худеть состав — пробовать вариант раскладки (свет к устью ниши).
