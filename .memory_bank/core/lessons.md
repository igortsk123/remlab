# Lessons — что НЕ сработало и почему

> Только инкрементальные bullets; писать сразу, читать перед каждым планом.

(1–106 — в `../anti-patterns.md`, архив уроков; вшито в код/правила)

107. [08-04] При переходе на стоячие вырезки потерялась проверка ракурса — фронтальное фото клеилось даже когда предмет виден с торца (диван «разворачивался» во всю ширину). Правило вернули: клеим, только если угол между взглядом и лицевой стороной ≥38°, иначе предмет уходит на нейросетевой проход по своим фото.
108. [08-04] Предмет, оказавшийся ЗА камерой, попадал в кадр призраком: проекция «заворачивается» при z≤0. Обязательна проверка, что четырёхугольник вырезки перед камерой и в пределах ~fov/2+30°.
109. [08-04] В легенду для модели добавлено поле видимости («виден целиком» / «обрезан краем кадра, рисовать только видимую часть»), а фрагменты меньше 0,4% кадра в легенду не попадают: иначе модель достраивает целый предмет из куска. Плюс третьей картинкой уходит ПЛАН с точкой съёмки — идея владельца, чтобы модель понимала, как резать предметы.

**Tier 2:** ../anti-patterns.md (детект в diff; UI — §6–7)
110. [08-04] Коллаж не должен терять предметы: непригодные для вклейки (сильный ракурс, плохая вырезка) остаются СЕРЫМ ОБЪЁМОМ из clay-рендера на своём месте, а не исчезают (владелец: «тв-тумбы нет»). База вклейки — полный clay; под успешно вклеенный предмет коробка стирается фоном из рендера пустой комнаты.
111. [08-04] Мягкий декор (подушки, плед) не вклеиваем никогда: снимки на белом фоне и «в наборе», матирование оставляет белую подложку карточки. Проверки на несработавшее матирование: непрозрачная рамка по краю, покрытие >88%, доля почти белых пикселей >45%.
