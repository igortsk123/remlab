# Lessons — маршрутизатор

- **Меши/Salad** `lessons/mesh-salad-pool.md`: «Running» ≠ работает (`gpu_seconds`/`done`); свой автомат выкашивает пул раньше платформы; причину — по событиям Salad, не гипотезе (533); проверка — после всех писателей (536).
- **Каталог** `lessons/catalog-stock.md`: сбой пробы ≠ вердикт (None, не False); проверяй тот URL, что показываешь; негативный сигнал — сперва тень с gold; размеры роли — только `unfit` (521); выведенное хранит источник (538).
- **Расстановка** `lessons/layout-solver.md`: правило = файл правил + чек; экзамен на снимке банков, код на бегу не править; одна величина — одна функция (539).
- **Визуализация** `lessons/viz-render.md`: разворот/размер задаёт геометрия в кадре, не текст.
- **Демо** `lessons/demo-planner.md`: живой сервис держит старый код — перезапусти и проверь сквозным запросом; фолбэк пишет причину; красная проба — пройдёт ли на верном продукте (541).
- **DevOps** `lessons/devops-deploy.md`: `pkill -f` убивает харнесс — только PID; влитие `db/init` = миграция прода (531); образ CI — закреплённый (532).
- **Память/процесс** `lessons/memory-process.md`: durable — сразу в канон; слова владельца — гипотезы; платное — сперва проба и баланс ДО (544); «нет» — после проверки; `.env*` в брифе не читать (545).
- **Смета/реклама** `lessons/estimate-ads-leads.md`: дефолт — фолбэк, не показанное число.
- **3D-конфигуратор** `lessons/flat3d-configurator.md`: у камер обратный знак угла; цвет мерить в исходной текстуре; интерфейс — под сценой.
