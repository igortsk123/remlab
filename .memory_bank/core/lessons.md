# Lessons — что НЕ сработало и почему

> Только инкрементальные bullets; писать сразу, читать перед каждым планом.

(1–177 — в `../anti-patterns.md`, архив уроков; вшито в код/правила)

178. [08-06] Роль товара надо брать из ДЕРЕВА КАТЕГОРИЙ фида, а не из регекса по названию: магазин уже разделил «Шторы и тюль» (474), «Карнизы» (190) и «Шторки для ванной» (165), а все 636 наших «кашпо» лежали в ветке «Товары для сада». Дерево — 1 931 категория, 5 уровней (`feed_taxonomy.py`, `category_map.py` → `products.cat_role`).
179. [08-06] Атрибут родителя категории в фидах бывает `parentId` И `parent_id` — читая только первый, дерево схлопывается в один уровень и вся вложенность теряется.
180. [08-06] Регекс без границы слова: `ковер` ловил «гай**ковер**т» — 27 гайковёртов числились коврами гостиной.
