- 303 [26.08] Диагностика через глобальную переменную врёт: `_axis_contract.media` пишет глобал, который перетирает последний вызов плейсера, и артефакт приписывает победившей гипотезе чужие числа. Диагностику писать в meta той гипотезы, к которой она относится.

## Сессия 26–28.08 (демо-рендер)
- solver без габаритов/проёмов считает условную комнату (передавать явно); `| head -1` убивает
  процесс до записи артефактов; `str.replace()` — только с assert-якорем; в контейнере без ttf
  PIL молча теряет кириллицу.
- gpt-image: числа-координаты и depth — не управляющий вход (анти-паттерн 82); работает геометрия
  НА кадре + запреты; роль «designer» в промпте переставляет мебель — нужна роль «renderer».
- Порог видимости, применённый к списку/эталонам, «выключает» мелкий предмет из запроса — модель
  ставит на его место другое (торшер→стеллаж).
- fal-редакторы масок не принимают (коммитить только при сохранённой композиции; nano-banana для
  ремонта непригодна); маска OpenAI — guidance: побитовость вне зоны гарантирует свой коммит.
