# Lessons — что НЕ сработало и почему

> Только инкрементальные bullets; писать сразу, читать перед каждым планом.

Все уроки живут в `../anti-patterns.md`; здесь — карта, куда смотреть.

- **1–333** — § Архив: вшиты в код, правила и тесты.
- **334–393 (31.08–03.09)** — пул нод и выкатка на Salad (квоты, тело создания группы, цена смены
  образа, отказ без текста ошибки, «Running» ≠ работает, «СБОЙ» → сперва `journalctl`); тихий
  фолбэк предиката; комментарий в коде ≠ факт; trimesh не отдаёт память; приоры и пороги каталога
  (оси мерить на выборке, роли сверять после пересборки, отрицательные сигналы — через тень с gold).
- **394–399 (03–04.09, пул мешей)** — проверку ставить туда, где она выполняется; замер в памяти
  процесса — не замер; проверка пустым файлом — не проверка; статус первой группы ≠ состояние
  пула; стопоры без свода правил; мёртвый Bash — `EDQUOT`, а не `pkill -f` (399-бис).
- **400–404 (04.09)** — `autostart_policy` поднимает группу при СОЗДАНИИ, окно тарифа её не гасит;
  тарифы сравнивать на сопоставимых часах («6× дороже» вместо 15 %); «медленный темп» без проверки
  «уже готово» снимает докачавшие ноды; сухой прогон, принятый за выполнение; «400» = нет денег.
- **405–408 (04.09, вечер)** — удаление мимо API ломает его же счётчик (призрак 2.24 ГБ погасил
  пул); причина принята без проверки, что она действовала; гард по шаблону команды ловит рассказ
  о ней; пропущенный шаг цепочки даёт ноль, а не ошибку.
- **409–413 (05.09, деплой)** — падение деплоя после активации молча выключает smoke и откат;
  `scp` не удаляет исчезнувшее из репо; `:prev` протух, потому что не проверялся; smoke по 200
  подтверждает чужой успех (сверять `version`); `workflow_run` даёт не тот SHA, что прошёл CI.
