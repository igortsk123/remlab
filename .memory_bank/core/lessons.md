# Lessons — плейбук уроков (что НЕ сработало и почему)

> **Протокол (ACE): ТОЛЬКО инкрементальные правки bullets** — добавить / уточнить / пометить
> `~~устаревшим~~ (причина)`. Целиком не переписывать, в сводку не сжимать (CLEANUP_POLICY:
> COMPRESS запрещён, MERGE дублей — можно). Формат bullet:
> `N. [дата] <ситуация> → пробовали <подход> → не сработало: <причина> → правило: <впредь>`.
> **Писать:** отброшенный подход / грабля с неочевидной причиной — сразу (блокнот) или на
> `/memory-check`; «Уроки» из Completion summary планов — сюда.
> **Читать:** ОБЯЗАТЕЛЬНО перед каждым планом (`agent-workflow.md`, Этап 1).

## Уроки

1. [2026-07-28] `./deploy.sh` (arm64 под QEMU) OOM'ит DEV-VM `pakardev` (2.7 ГБ) → терялся SSH; QEMU
   и в GitHub-раннере крашил Next-SWC `SIGILL`. **Решение:** авто-деплой `deploy.yml` на нативном
   `ubuntu-24.04-arm` (без QEMU), секрет `DEPLOY_SSH_KEY`=ключ `remlab_ci_deploy`. `./deploy.sh` не
   использовать. DEV-VM: swap 4 ГБ, swappiness=10, `earlyoom` (sshd в `--avoid`).

2. [2026-07-30] «Меню обрезано» в шапке → гориз. скролл со скрытым скроллбаром → юзер не видит,
   что можно листать → правило: скролл без видимого индикатора в навигации не делать — flex-wrap.
3. [2026-07-30] Парсер цены: захват «м 2» (разорванный `<sup>2</sup>`) ловил, классификатор
   `/м²|м2/` пробел не знал → «за м²» падала в «за упак» → правило: захват и классификацию
   единиц тестировать на одном тексте-фикстуре.
4. [2026-07-30] ИИ-фолбэк parse-link при валидном ключе молча отдавал `{}` на любую ошибку →
   неотличимо от «не понадобился» → правило: неуспех внешнего вызова всегда console.error.

5. [2026-07-30] Ozon серверным fetch → пробовали браузерные заголовки, резидентский И мобильный
   РФ-прокси → не сработало: JS-челлендж (`?__rr=`-цикл, 403 + 4КБ страница) требует исполнения
   JS → правило: JS-антибот серверно не обходить (квоту прокси не жечь) — путь «needs_file»:
   юзер сохраняет страницу из браузера (Ctrl+S), там DOM уже с исполненным JS.
6. [2026-07-30] Два агента в одном worktree: параллельная сессия с авто-коммитом (`git add -A`)
   захватила чужой staged-код в свой коммит `e813bac docs(memory)…` → сообщение коммита врёт о
   содержимом → правило: параллельную работу вести в отдельных worktree/ветках; перед commit
   проверять `git status` на чужие staged-файлы.
