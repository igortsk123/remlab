# Lessons — плейбук уроков (что НЕ сработало и почему)

> **Протокол (ACE): ТОЛЬКО инкрементальные правки bullets** — добавить/уточнить/пометить
> `~~устаревшим~~`. Целиком не переписывать (COMPRESS запрещён, MERGE дублей можно). Формат:
> `N. [дата] <ситуация> → пробовали → не сработало: <причина> → правило: <впредь>`.
> **Писать** грабли сразу; **читать** перед каждым планом (`agent-workflow.md`, Этап 1).

## Уроки

1. [2026-07-28] `./deploy.sh` (arm64/QEMU) OOM'ит DEV-VM; QEMU в раннере крашил SWC `SIGILL` →
   авто-деплой на нативном `ubuntu-24.04-arm`; `./deploy.sh` не юзать.

2. [2026-07-30] Гориз. скролл со скрытым скроллбаром = «меню обрезано» → правило: скролл без
   видимого индикатора в навигации не делать — flex-wrap.
3. [2026-07-30] Захват «м 2» (разорванный `<sup>2</sup>`) ловился, классификатор пробела не знал
   → «за м²» падала в «за упак» → правило: захват и классификацию единиц тестить одной фикстурой.
4. [2026-07-30] ИИ-фолбэк молча отдавал `{}` на любую ошибку → неотличимо от «не понадобился»
   → правило: неуспех внешнего вызова всегда console.error.

5. [2026-07-30] Ozon → curl + Playwright-браузер, резид. И моб. пул proxy.market → не сработало:
   Ozon банит сам IP пула по репутации (капча, «выключите VPN») — не JS-челлендж → правило:
   Ozon/WB серверно только через прокси-АНБЛОКЕР (Bright Data/Zyte); обычный пул и браузер поверх
   бесполезны. Загрузку сохранённой страницы владелец отверг — только серверная добыча.
6. [2026-07-30] Параллельная авто-коммит сессия (`git add -A`) захватила чужой staged-код в свой
   коммит → правило: параллельные агенты — в отдельных worktree; перед commit проверять status.
