# Lessons — плейбук уроков (что НЕ сработало и почему)

> **Протокол (ACE):** только инкрементальные bullets (добавить/уточнить/`~~устареть~~`), целиком
> не переписывать. Писать сразу, читать перед каждым планом (`agent-workflow.md`).

## Уроки

1. [2026-07-28] `./deploy.sh` (arm64/QEMU) OOM'ит DEV-VM; QEMU крашил SWC → деплой только авто
   (push в main, нативный arm-раннер); `./deploy.sh` не юзать.
2. [2026-07-30..31] UI-мелочи, читающиеся как баг (скрытый гориз. скролл в навигации; мерцание
   sticky-шапки; активная кнопка «в рамочке»; подсказка под формой вместо над) → правила и детект —
   `anti-patterns.md` §6.
3. [2026-07-30] Захват «м 2» (разорванный `<sup>2</sup>`) ловился, классификатор пробела не знал
   → «за м²» падала в «за упак» → правило: единицы тестить одной фикстурой.
4. [2026-07-30] ИИ-фолбэк молча отдавал `{}` на любую ошибку → неотличимо от «не понадобился»
   → правило: неуспех внешнего вызова всегда console.error.
5. [2026-07-30] Ozon: curl/Playwright через резид.+моб. пулы → бан по репутации IP, не
   JS-челлендж → правило: Ozon/WB только через анблокер (Bright Data/Zyte); сохранённую
   страницу владелец отверг.
6. [2026-07-30] Авто-коммит сессия (`git add -A`) захватила чужой staged-код → правило:
   параллельные агенты — в отдельных worktree; перед commit — status.
7. [2026-07-31] Молчаливый дефолт в ядре (рулон 0,53 м) давал «2 рулона» до ввода данных →
   правило: дефолт — фолбэк, НЕ источник показанного числа (ADR-0034).
8. [2026-07-31] ADR-0027 удалил проёмы ЦЕЛИКОМ без явного одобрения владельца → откат (ADR-0035)
   → правило: удаление функциональности — только с явного «да» владельца, одобрение — в ADR.
