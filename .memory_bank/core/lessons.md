# Lessons — что НЕ сработало и почему

> Только инкрементальные bullets; писать сразу, читать перед каждым планом.

(1–88 — в `../anti-patterns.md`, архив уроков; вшито в код/правила)

89. [08-04] Фото товара нельзя натягивать на переднюю ПЛОСКОСТЬ коробки: у низкой мебели (столик, тумба) сверху видна столешница, и фотография оказывается вертикальной картинкой ВНУТРИ серого объёма — «отражение внутри модели». Правильно — стоячая вырезка лицом к камере (`viz_paste.billboard`), поставленная на пол на месте предмета; база — clay ПУСТОЙ комнаты, чтобы серых коробок в кадре не осталось.
90. [08-04] Каждый прогон пишет журнал шагов (`tools/scout/steps.py` → `{prefix}-steps.json`): что отправили, какой моделью, что получили. Разворачивается в страницу `process_report.py` — владелец смотрит весь путь по ссылке (требование 2026-08-04).
91. [08-04] Отчёт обязан брать итог из ЖУРНАЛА (выход последнего шага), а не по «правильному» имени файла: `process_report.py` показывал `-final.jpg` от прошлого прогона — владелец увидел серый куб вместо пуфа рядом со свежей вклейкой. Артефакты прошлых прогонов удалять при смене конвейера.
