# Композиция гостиной — Tier 1

Справка владельца (2026-08-01): для каждого типового метража гостиной (14–16 … 50+ м²) — состав
предметов и **доля проекции на пол в %** (диван 10–14% на 15 м² и т.д.); ковёр — % покрытия пола;
зеркала/полки/часы/шторы — % стены; люстра — диаметр по метражу; декор — % поверхностей-носителей.
**Глобальный кап: напольная мебель 28–38%, максимум 40% (ковры не в счёт).**

Применение: автосборка сетов (7 метражей × 3 тира), hard-чек планировщика.
Полные таблицы — Tier 2; машиночитаемо — `tools/scout/composition.json` (вне git).
