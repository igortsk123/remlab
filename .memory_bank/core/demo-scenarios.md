# Сценарии демо — Tier 1 сводка

**Что это:** карта всех кнопок и путей покупателя на `/demo` с колонкой «факт» (Tier 2). Страница —
`tools/scout/flat215-demo/index.html`.

**Путь покупателя (14.10):** карточка стиля → окно кадра `#shot` (фото · «‹ ›» ракурсы · список товаров «Заменить / В магазин»
· Изменить планировку / ♡ / Ссылка / Сохранить коллекцию) → лента замен `#sheet` → конструктор `#cons` (долгое нажатие —
перетаскивание, тап — ±90°) → «Посмотреть фото с изменениями» (серверный кадр: 3–9 с с кэшем DEV, до 40 с без него) → «Улучшить фото» (платно).

**Живые проверки (с 14.10, `demo-03`):** номер строки карты — в начале названия теста `e2e/live/*.live.ts`
(`demo-scenarios.live.ts` — кнопки, `demo-frame.live.ts` — серверный кадр обоих ракурсов и картинка коллекции),
ночной шаг `demo_live` (`tools/ops/demo-live.sh`); строка без проверки — `WARN:demo_map_uncovered`
(`tools/ops/demo-map-check.mjs`). Платный путь проверяется без трат (`/api/draft/paid`).

**Починено 14.10** (Tier 2 § 1–2): камера не упирается в близкий предмет (`camFit`, блок CAMFIT в IH, тест
`tests/unit/demo-cams.test.ts`); одна функция числа и суммы для карточки и окна (`totalsOf`, ADR-0286); «Улучшить» без
денег отвечает сразу, задания кадров переживают деплой (`tools/scout/draft_jobs.py`, ADR-0287); картинка у сохранённой
коллекции (`PATCH /api/collections/[id]`); подсказка в конструкторе; сторож DEV-рендера в дайджесте + крон подъёма.
**Открыто:** фото ≠ список (2.2), 3D без несохранённых правок (2.16) → `demo-02`. **/flat** — 2.18–2.22 (✓ 16.10), проверка `e2e/live/flat-walk.live.ts`.

**Куда идёт:** этап 4+ мастера `plans/MASTER-cost-first.md` — `demo-03` (дефекты + живые проверки по карте) →
`demo-01` (один браузерный движок сцены из `lib/viewer3d`, numpy — прогрев/фолбэк/лист GPT) → `demo-02` (окно варианта:
живая сцена, «В 3D», «Улучшить», история состояний отдельно от ракурсов, кадр = список по `stateId`). Связано: [[demo-planner]], [[apartment-configurator]].
