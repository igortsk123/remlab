# Сценарии демо — Tier 1 сводка

**Что это:** карта всех кнопок и путей покупателя на `/demo` с колонкой «факт» (Tier 2). Страница —
`tools/scout/flat215-demo/index.html`.

**Путь покупателя:** вкладка стиля → карточка комнаты → окно варианта `#shot` (Фото · 3D · План; ракурсы словами; «Заменить /
В магазин»; ⇪ ♡ ×; тап по предмету — шторка на строке; после замены камера на предмет `frameSpot`) → лента `#sheet` → конструктор
`#cons` (только из окна) → 3D с правками → «Сделать реалистичнее» (платно).

**Живые проверки (`demo-03`):** номер строки карты — в начале названия теста `e2e/live/*.live.ts`, ночной шаг `demo_live`
(`tools/ops/demo-live.sh`); строка без теста — `WARN:demo_map_uncovered` (`tools/ops/demo-map-check.mjs`). Платное — без трат (`/api/draft/paid`).

**Открыто:** фото ≠ список (2.2), 3D без несохранённых правок (2.16) → `demo-02`. 2.23 — шторка v5; 2.24–2.26 — режимы окна
(demo-09); 2.13–2.15, 2.30–2.32 — избранное сердечком, «поделиться», фокус камеры (demo-15, `tools/ops/demo-walk/fav-check.cjs`).
**Главная (18.10, demo-16/17, ADR-0307):** 2.33–2.38 — стили → комнаты, липкая шапка, избранное = корзина сертификата
(`lib/basket/basket.ts`) на экране `#screen-fav` с «← Назад»; шторка v5.2 (2.37).
**20.10 (demo-19, Tier 2 § 2c):** шапка в 2 строки + «Подробнее» (1.1, 1.3); коллекции пачкой с повтором (2.39); слой держит
страницу `index.html:lockPage` (2.40); одна шкала `certScale` (2.41); отсчёт фото `photoWait` (2.43); пара меняется вместе (2.45);
автофото избранного `autoPhoto` (2.46); «уголок» и обеденный стол — правилами сборки (2.47–2.48).
