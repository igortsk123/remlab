# Сценарии демо — Tier 1 сводка

**Что это:** карта всех кнопок и путей покупателя на `/demo` с колонкой «факт» живого прогона
(`tools/ops/demo-walk/*.mjs`, Playwright по проду). Полная таблица — Tier 2. Страница — `tools/scout/flat215-demo/index.html`.

**Путь покупателя (14.10):** карточка стиля → окно кадра `#shot` (фото · «‹ ›» ракурсы · список товаров «Заменить / В магазин»
· Изменить планировку / ♡ / Ссылка / Сохранить коллекцию) → лента замен `#sheet` → конструктор `#cons` (долгое нажатие —
перетаскивание, тап — ±90°) → «Посмотреть фото с изменениями» (серверный кадр 20–40 с) → «Улучшить фото» (платно).

**Главные дефекты прогона 14.10** (подробно — Tier 2 § 2):
- фото и список под ним — из разных состояний (список из живой расстановки, IH:2490-2503); карточка и окно считают
  предметы/сумму по-разному;
- камера №2 по умолчанию стоит в углу внутри торшера (`defaultCams` IH:1207) → кадр пустой;
- «Улучшить» без денег на канале молчит 5 мин; деплой сервиса кадров теряет задания (`/api/job` 404);
- DEV-рендер (`dev_render_backend.sh`, :8600) был убит earlyoom 13.10 — сутки запасного пути без тревоги.

живая сцена, «В 3D», «Улучшить», история состояний отдельно от ракурсов, кадр = список по `stateId`). Критика Codex —
