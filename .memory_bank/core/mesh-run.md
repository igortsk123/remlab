# Прогон мешей — рабочий вариант и процедура

**Боевая конфигурация, не эксперимент:** проверена прогоном 31.08–05.09 (2 327 мешей, лучший
день 857). Что НЕ повторять — Tier 2 § 5.

## Рабочий вариант (11.10 — без изменений с 02.10)
- **Образ:** `ghcr.io/igortsk123/mesh-hunyuan:cu124-localpaint2` =
  `sha256:f9a9ad6d0d859a24102416632d730f59dda2ec6e9a699d85664917ddc8a656cb`. К этому digest'у
  прибиты все три группы; локально образ не держим (ADR-0232). Рецепт — `tools/scout/salad/`.
- **Генератор:** Hunyuan3D 2.1, коммит апстрима `82920d643c0d`, CUDA 12.4.1, torch 2.5.1.
- **Карта:** RTX 3090/3090 Ti, `STAGED=1` (форма 8 ГБ → выгрузка → покраска 14 ГБ).
- **Группы:** `mesh-low-4`, `mesh-low-5` (low, круглосуточно), `mesh-batch-3` (batch, окно
  09–15 UTC); тариф и окно — ТОЛЬКО из `tools/scout/rules/salad-groups.json` (ADR-0177).
- **Замер:** меш ≈ 176 с; потолок 172 меша/час на ~23 машинах при `--batch 2000`; ≈1,12 ₽/меш.

## Три команды
- **Старт** (единственный законный): `tools/scout/mesh_wave_start.sh --launch`.
- **Наблюдение:** лог `$MESH_BATCH_LOG` (`tools/scout/mesh_wave_start.sh:20`); цена — `tools/scout/salad/tier_compare.py`.
- **Остановка:** `touch ~/scout-scenes/mesh-draining` — выход на границе пачки, группы гасит `finale()`.

**Перед стартом — чек-лист предусловий Tier 2 § 1** (стили, дев-база, диск, кредиты, стоп-файл):
скрипт проверяет только сирот и приёмник.

## Запреты (каждый уже стоил денег или часов)
- **НЕ собирать снимок очереди руками** и не обнулять курсор: он позиционный, снимок поверх
  неразобранного переставит сделанные меши (`tools/scout/mesh_wave_start.sh` §зачем процедура).
- **НЕ `kill -9` / `pkill -f`** по конвейеру: сироты с `ppid=1`, а `pkill -f` убьёт и сессию агента.
- **НЕ менять образ у живой группы** — только новой (ADR-0154). **НЕ удалять с приёмника мимо его
  API** (ADR-0178). **НЕ лечить цвет перегоном по seed** — он уходит только в форму (ADR-0145).
