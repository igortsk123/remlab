# Goals — «Смета-first» v0.4 (ADR-0016)

## Суть
Один продукт на всех стадиях ремонта: **посчитал → получил смету-список →
сохранил по постоянной ссылке → купил по своим же ссылкам (нам комиссия) → хвосты**:
«как будет выглядеть» (визуализация/мебель) и «найти мастера» (лид). Ядро одно — смета-лист;
различаются только первые экраны.

## Два входа
- **А «уже делает ремонт»** — калькуляторы материалов: сначала ЧИСЛО, продуктовое после ответа;
  своя ссылка юзера — через `/go/`: реферальная при маршруте магазина, иначе прямая (`lib/estimate/links.ts`).
- **Б «присматривается»** — «сколько стоит ремонт»: площадь → глубина → регион → вилка эконом/средний/дороже → та же смета.

## Монетизация и kill-критерии
Реф-комиссия (late-binding через `/go/`) → мастера-лиды (CPA) → paid-ступени и кэшбек позже
(владелец). Воронка: визит → расчёт → смета → сохранена → реф-клик → выкуп. Kill: вход А — 0
реф-кликов на 200 переходов; вход Б — CR клик→смета < 5 %; проект — CAC > 2× дохода (владелец).

## Лестница продукта (13.10, ADR-0250)
Девелоперы (РФ и UK параллельно; подписку платит застройщик) → ритейлеры (комиссия, ADR-0252) → люди
бесплатно → дизайнеры платно; Смета-first — ступени 3–4 (`b2b-*`, `conv-*`).
