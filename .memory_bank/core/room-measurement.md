# Замер комнаты по фото — Tier 1

**Код:** `services/room-measure/` (перенесён из `/home/pakar/mltest` 2026-08-04; до этого лежал
вне репозитория и в памяти отсутствовал — из-за чего наработки переоткрывались заново).

**Принцип:** геометрия — истина, генерация — убеждалка. Масштаб и позиции считает код,
нейросети именуют объекты и рисуют картинку.

**Конвейер:** лист A4 + solvePnP (масштаб) → SegFormer ADE20K (пол/стены/окна) → Grounding DINO
+ vision-именование (объекты) → план пола сверху → fit-check на Shapely → подбор реальных товаров
под зону → визуализация замены (LaMa + вставка в вычисленном масштабе).

**Проверено экспериментами:** план сверху надёжен на геометрии ПОЛА, путь через карту глубины
хрупкий; глубина предмета берётся из справочника габаритов, а не из фото; по одному студийному
фото невидимые стороны товара не восстанавливаются.

**Протокол съёмки:** 3–5 кадров, лист A4 на полу, в каждом кадре уголок потолка.

**Переиспользовать в мебельном треке:** `fit_check.py` (влезет/велик), схема `run_viz.py`
(стереть → вставить в масштабе) для генерации кадров по плану ([[llm-layout-planner]]),
справочник габаритов (свести с `tools/scout/typical-dims.json`).

**Доступы:** FAL_KEY, OPENAI_API_KEY — значения в `_secrets/ACCESS.md`, реестр —
[[access-and-integrations]].
