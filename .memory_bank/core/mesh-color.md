# Цвет мешей — Tier 1 сводка

**Диагноз (191 модель, 01.09).** Врёт СВЕТЛОТА, не оттенок: хрома отклоняется на 3/255, а
|ΔL|>40 у 26% моделей, в обе стороны (тумба (79,78,76) → чёрная). На пёстром не видно, бьёт
по однотонным серым.

**Чем НЕЛЬЗЯ** (ADR-0145): промптом; чисткой фото (каталожные снимки уже плоские —
`tools/scout/salad/photo_color.py`); обратным делением альбедо; перегоном с другим seed.

**Ключевой факт.** Seed и CFG покраски захардкожены апстримом
(`hy3dpaint/utils/multiview_utils.py`, вне репо), наш seed уходит только в форму (ADR-0143).

**Мерка.** Рендер БЕЗ света (`UNLIT=1`, `tools/scout/mesh_render.py`) против фото, разница в
стопах + гейт на коллапс. Сверена с 43 слепыми отметками владельца
(`archive/evidence/owner-marks-mesh-color-0109.txt`): знак совпал в 89%, «темнее» — 22 из 22.

**Опыт 01.09 — проведён, тема ОТЛОЖЕНА владельцем.** 4 «ок», 29 «нет»
(`archive/evidence/owner-verdict-exposure-0109.txt`): причина «нет» — не рычаг, а ШАГ (0,33 ст., глазу не
видно). Разбор — Tier 2 § Опыт с экспозицией.

**Найдено 02.09 (ADR-0185).** Часть промаха давал РЕНДЕР: свет умножался на sRGB-байты как на
линейные (до 48/255, 1,89 EV вместо 0,79) — исправлено (`scene_mesh.py`, `SCENE3D_LIGHT_LINEAR=1`).
Корпус 39 товаров демо: текстуры НЕ темнее фото магазина (темнее у 31 %, светлее у 54 %).

Без текстуры — цвет товара/серый (`meshes.ts` `fallbackMeshColor`).

**Рычаги.** Перепокраска готовой формы (paint = 42% задания, геометрия не меняется) — **болванка
`shape.glb` живёт до приёмки владельцем (ADR-0233): рычаг есть у непросмотренных и забракованных;
у 2132 мешей болванки прополоты 02.10 по возрасту (ADR-0231) — только перегон**.
Плюс сдвиг экспозиции входа в линейном RGB (`photo_color.shift_exposure`, план —
`tools/scout/salad/exposure_plan.py`: замер −2 ст. … до засветов, итог режет `EV_MAX` ±0.45). Покраска
на вход РЕАГИРУЕТ (~0.8 ст. на ступень) — закрыто опытом.
