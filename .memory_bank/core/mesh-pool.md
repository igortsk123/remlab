# Пул нод Salad — Tier 1 (деньги и эксплуатация)

**Запуск и остановка прогона — [[mesh-run]].**

**Что это.** Группы SaladCloud с образом Hunyuan3D (`cu124-localpaint2`) под конвейером
`tools/scout/salad/` (`batch_show.py` + супервизор `ssh_run.py`); тариф, окно и цена — ТОЛЬКО из
`tools/scout/rules/salad-groups.json` (ADR-0177). Путь меша — [[mesh-pipeline]].

**Состав (20.10, T-21):** `mesh-low-8` (low, 30 реплик, круглосуточно) + `mesh-batch-5` (batch, 20,
окно 09–15 UTC) — только RTX A5000, ОЗУ 24576. Почему: 3090 обрываются посреди задания с 13–16.10,
вероятнее WSL 3.0.3 у хостов (Tier 2 § 5). A5000 дают скупо (20.10: 1 нода из 30). Квота 50
реплик общая; ресурсы, GPU, образ — только новой группой (`recreate_group.py`, [[mesh-run]]; ADR-0154).

**Деньги.** Платим за `running`, не за работу (ADR-0135); цена — по ОПЛАЧЕННЫМ нодо-часам
(`tier_compare`, ADR-0176). **Тариф не меняет темп машины** (меш ≈ 200 с) — разница ₽/меш только
в ставке ($0.09 batch / $0.143/ч low). Узкое место — ТЕКУЧКА нод (урок 401). Замеры — Tier 2 § 2. **Пачка (ADR-0200):** `--batch 2000` — 172 меша/ч против ~110 при 200.

**Стопоры — один свод (ADR-0175).** Стоп-файл `mesh-group-halt.json` сильнее автостарта
(ADR-0169/0174); приёмник проверяется ДО раздачи GPU; молчащую ноду снимает
`ssh_run.silent_fault` (600 с); кредиты кончились — только по `no_credits_available` (урок 404).
Сторож денег перечитывает `SALAD_GROUP` на тике, слепой опрос ≠ «не платим»
(`tools/scout/salad/money_guard.py:blind_update`, урок 519); ручной старт — свой потолок ₽
(`tools/scout/salad/wave_cap.py`). **ADR-0198:** `/start` — только лежащим группам; шаг конвейера —
в своей группе процессов (`proc_run.run_step`), по таймауту снимается ГРУППОЙ, иначе сирота `ppid=1`.

**Чистка приёмника** — только через API `DELETE /prefix/...` (ADR-0178), сторож `sink_keeper.sh`
вне конвейера, УПРЕЖДАЮЩАЯ на жёлтом пороге 6 ГБ (ADR-0199): реактивная стоила 7 нодо-часов.
Цепочка из пяти шагов — Tier 2 § 4.
