# Пул нод Salad — Tier 1 (деньги и эксплуатация)

**Что это.** Группы контейнеров SaladCloud с образом Hunyuan3D (`cu124-localpaint2`) под
управлением конвейера `tools/scout/salad/` (`batch_show.py`, супервизор `ssh_run.py`); тариф,
окно, цена — ТОЛЬКО из `tools/scout/rules/salad-groups.json` (ADR-0177). Путь меша — [[mesh-pipeline]].

**Состав (05.09):** `mesh-low-4`, `mesh-low-5` (low, круглосуточно), `mesh-batch-3` (batch, окно
09–15 UTC). Квота 50 реплик общая — старую группу гасить. Образ меняется только новой группой
(`migrate_groups.py --apply`, без флага — сухой прогон; ADR-0154/0157).

**Деньги.** Платим за `running`, не за работу (ADR-0135); закачка бесплатна; цена — по ОПЛАЧЕННЫМ
нодо-часам (`tier_compare`, ADR-0176). 05.09 (11.8 ч): 127 мешей, 10.8 меша/нодо-час, ~1.12 ₽/меш
(batch 0.74, low 1.11–1.22), +25 % к пятнице. **Тариф не меняет темп машины** (10.2–11.1 у всех
групп, меш ≈ 200 с) — разница ₽/меш только в ставке ($0.09 vs $0.143/ч). Прогрев — 0.52 ₽ за
ноду (~9 % времени); узкое место — ТЕКУЧКА нод (медиана жизни 19 мин, 4 меша) → порог 600 с
перед снятием молчащей ноды. Сравнивать только сопоставимые часы (урок 401).

**Стопоры — один свод (ADR-0175).** Сторож денег гасит группы стоп-файлом `mesh-group-halt.json`
(ADR-0169/0174, сильнее автостарта); приёмник проверяется ДО раздачи GPU (красный =
`shared_infra`); молчащую ноду снимает `ssh_run.silent_fault` (600 с): «running + не отвечает»
≠ «греется». `no_credits_available` = кредиты кончились — сперва баланс (урок 404).

**Чистка приёмника** — только через API `DELETE /prefix/...` (ADR-0178); цепочка
`drain.sh --keep` → `ingest_registry` → `apply_repairs` → `mesh_bind` → `receiver_purge --apply`;
сторож `sink_keeper.sh` (крон `*/15`) вне конвейера.
