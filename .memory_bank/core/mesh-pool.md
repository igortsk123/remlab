# Пул нод Salad — Tier 1 (деньги и эксплуатация)

**Что это.** Группы SaladCloud с образом Hunyuan3D (`cu124-localpaint2`) под конвейером
`tools/scout/salad/` (`batch_show.py` + супервизор `ssh_run.py`); тариф, окно и цена — ТОЛЬКО из
`tools/scout/rules/salad-groups.json` (ADR-0177). Путь меша — [[mesh-pipeline]].

**Состав (05.09):** `mesh-low-4`, `mesh-low-5` (low, круглосуточно), `mesh-batch-3` (batch, окно
09–15 UTC). Квота 50 реплик общая — старую группу гасить; образ меняется только новой группой
(`migrate_groups.py --apply`, без флага — сухой прогон; ADR-0154/0157).

**Деньги.** Платим за `running`, не за работу (ADR-0135); цена — по ОПЛАЧЕННЫМ нодо-часам
(`tier_compare`, ADR-0176). **Тариф не меняет темп машины** (меш ≈ 200 с везде) — разница ₽/меш
только в ставке ($0.09 batch против $0.143/ч low). Узкое место — ТЕКУЧКА нод. Сравнивать только
сопоставимые часы (урок 401). Замеры — Tier 2 § 2.

**Скорость — от размера пачки, не от числа машин (ADR-0200):** `--batch 2000` дал 172 меша/час
на ~23 машинах против ~110 при `--batch 200` на любом их числе.

**Стопоры — один свод (ADR-0175).** Стоп-файл `mesh-group-halt.json` сильнее автостарта
(ADR-0169/0174); приёмник проверяется ДО раздачи GPU; молчащую ноду снимает
`ssh_run.silent_fault` (600 с); `no_credits_available` = кончились кредиты (урок 404).
**ADR-0198:** `/start` — только лежащим группам; шаг конвейера живёт в своей группе процессов
(`proc_run.run_step`) и по таймауту снимается ГРУППОЙ, иначе остаётся сиротой с `ppid=1`.

**Чистка приёмника** — только через API `DELETE /prefix/...` (ADR-0178), сторож `sink_keeper.sh`
вне конвейера, УПРЕЖДАЮЩАЯ на жёлтом пороге 6 ГБ (ADR-0199): реактивная стоила 7 нодо-часов.
Цепочка из пяти шагов — Tier 2 § 4.
