# Стили интерьера — Tier 1

ВНИМАНИЕ: шестёрок ДВЕ и они разные (сверка 11.10). Конвейер каталога и сетов работает на
`tools/scout/styles.json`; игра «Узнай свой вкус» (`/styles`) и «Мой стиль» (`/lab`) — на
`lib/styles/quiz.ts` (там вместо «современный» и «неоклассика» — «классика» и «прованс»).
Свести их — отдельная задача; это не один список.

Канон конвейера: 6 стилей (сканди, современный, минимализм, лофт, неоклассика, джапанди) как
данные-паспорта `tools/scout/styles.json`: веса признаков (метод владельца «доля влияния») +
гайд ремонта для фото (`render_guide` v2.1, ADR-0303; Tier 2 § «Гайды для фото»). Каждый товар гостиной имеет ВЕКТОР оценок 0–10 по всем стилям + флаг
`universal` (style-scores.json; LLM+правила+CLIP; новинки — дельтой в cron). Вклад товара в
стиль сета = вес роли × площадь (диван решает). Сборка: `tools/scout/compose2.py` (`--style [--bands all]`) →
sets3.json; судья со style_grade, замены только ниже порога и по максимальному стиль-вектору
(ADR-0047/0048). Фото: ремонт под стиль, товары неизменны.

**Как читать оценку (сверено 11.10).** Источник №1 — БАЗА (`enrich_bridge.style_scores`),
`style-scores.json` — фолбэк, в таком порядке (`tools/scout/compose2.py:pick2`). В JSON ключ — МОДЕЛЬ,
не артикул: читать по артикулу в лоб = потерять 21% пула. Пул скоринга — `lr_roles`; `тв-тумба` там есть
с 11.10 (418), `банкетка` отдельной роли нет — внутри `пуф`. Механика и замеры — Tier 2 § «Чтение оценок».

**13.10:** два источника (`tools/scout/style_attrs.py` признаки+правила; `tools/scout/style_score.py` LLM по тексту +
CLIP) не согласны, порог «≥ 6» невалиден — детали Tier 2; решение: единый вектор (`conv-01`, `conv-02`).

**14.10 (ADR-0269):** стенд по осям (`tools/scout/style_axes.py`); главный — нынешний метод.

**29.10:** отметки стиля человеком — Tier 2. **12.11 (ADR-0412):** поверх балла — калибровка по разметке (`tools/scout/style_calib.py`,
`tools/scout/rules/style-calibration.json`, порог 6,6); меняет ленты /demo, не банк и туры.
