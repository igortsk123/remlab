# 3D-конфигуратор квартиры — Tier 1

**Что это:** `/flat` — покупатель новостройки ходит по квартире в 3D, комната за комнатой
выбирает отделку и мебель, видит сумму апгрейдов и сохраняет подбор ссылкой для менеджера.
Вход для людей — кнопка «Пройтись по квартире в 3D» на `/demo/`. Три режима показа над ОДНИМ
состоянием выбора: **3D · Фото · План** (desktop открывается в 3D, телефон — в «Фото» + кнопка
«3D Lite»). Photo-конвейер НЕ переделан — конфигуратор говорит на его контракте.

## Модель (ADR-0211)
`contracts/apartment.ts` — квартира: комнаты-прямоугольники в общих координатах (см, x вправо,
y вглубь, **x/y предмета = ЦЕНТР**, rot по часовой, 0 → +y — канон `planner/models.py`),
проёмы, слоты выбора (`surface` | `builtin` | `furniture`), камеры, точка старта.
`contracts/configurator.ts` — каталог застройщика: опции (категория, tier base/standard/premium,
пакет, цена-доплата £, доступность, совместимость, ассет mesh|material|kit) и материалы.
`Configuration` = только `{слотId: опцияId}`. Всё остальное выводится
`lib/configurator/resolve.ts:resolveScene()` → предметы, поверхности, цена, претензии.
Данные демо-квартиры — `data/flat3d/` (квартира, каталог, мебель, материалы, вес моделей).

## Сцена (`lib/viewer3d/`)
- `viewer.ts` — `FlatViewer`: свет + PMREM-окружение, ленивая загрузка по комнатам (4 потока,
  на телефоне 2), прогулка WASD/стрелки + мышь, тап «иди сюда», выбор предмета лучом,
  профили `DESKTOP_QUALITY` и `LITE_QUALITY`.
- `rooms.ts` — коробка комнаты: пол, стены ОДНОСТОРОННИМИ плоскостями внутрь (двe соседние
  комнаты не дерутся за пиксели, проёмы не требуют CSG), потолок, небо и земля за окнами.
- `kits/` — параметрические кухня, санузел, кровать, шкаф (ADR-0213).
- `meshes.ts` + `transform.ts` — посадка GLB: yaw → неравномерный масштаб на обёртке → rot →
  посадка по Box3. **Сверено числами с конвейером фото** (`tests/unit/configurator-transform.test.ts`
  против эталона `tools/assets/transform_golden.py` ← `tools/scout/scene_mesh.py`).
- `walk.ts` — где можно стоять: комната с отступом от стен + прямоугольники дверных проёмов.

## Ассеты (ADR-0212)
Исходники мешей (3,9 МБ, 2048² base64) в браузер не идут. `tools/assets/runtime_mesh.py`:
текстуры 1024/512, MR-карта → скаляры, картинки в бинарный чанк, `gltfpack -cc -tc`
(Meshopt + KTX2; нужен НАТИВНЫЙ gltfpack, npm-сборка без BasisU). Замер 28.09: **3,94 → 0,29 МБ
desktop, 0,15 МБ lite**; 40 моделей 158 → 12 МБ. Публикация — `rsync` в `/opt/remlab/test/rt/`,
маршрут `/rt/*` в Caddy с `immutable` (у `/test/*` стоит `no-store` — для сцены не годится).
Материалы покрытий — `tools/assets/material_pipeline.py` (фото образца → перспектива →
бесшовность → карты → WebP + превью; 15 процедурных образцов в `public/flat3d/materials/`).
Мебель каталога собирается из лент демо: `tools/flat3d/build-catalogue.mjs` (40 опций).

## Сохранение (ADR-0214)
`POST /api/flat/config` считает цену на сервере и кладёт в `flat_configs` выбор + снимок цены +
ревизии квартиры/каталога под случайным токеном; `GET /api/flat/config/<id>` отдаёт всё, КРОМЕ
контакта. Ссылка `/flat?c=<id>` открывает подбор.

## Что НЕ сделано (следующий шаг)
Свободное размещение мебели (Sims-редактор), лайтмапы, шкафы/свет/кабинет как отдельные
категории, каталог конкретного застройщика, фото для всех комнат (сейчас ракурсы настроены
для гостиной; остальные считаются диагональю).
