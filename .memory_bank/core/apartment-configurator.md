# 3D-конфигуратор квартиры — Tier 1

**Что это:** `/flat` — покупатель новостройки ходит по квартире в 3D и комната за комнатой
собирает её под себя: пол, кухня со встроенной техникой, плитка санузла, стены, мебель.
Видит сумму апгрейдов в фунтах и сохраняет подбор ссылкой для менеджера. Вход для людей —
кнопка «Пройтись по квартире в 3D» на `/demo/`.

**Три режима над ОДНИМ выбором:** 3D · Фото · План. Desktop открывается в 3D, телефон — в
«Фото» с кнопкой «3D Lite». Photo-конвейер не переделан: конфигуратор говорит на его контракте
(`/api/render`), кадр-черновик собирается ~6 с.

**Из чего собрано** (подробности — Tier 2):
- модель: квартира → комнаты → слоты (`contracts/apartment.ts`), каталог опций застройщика
  (`contracts/configurator.ts`), выбор = `{слот: опция}`; всё остальное даёт чистая
  `resolveScene()` (`lib/configurator/resolve.ts`) — из неё работают все три режима;
- сцена: `lib/viewer3d/*` (комнаты с проёмами, параметрические кухня/санузел/кровать/шкаф,
  загрузка GLB с Meshopt+KTX2, прогулка, ленивая догрузка по комнатам);
- ассеты: `tools/assets/runtime_mesh.py` (3,94 → 0,29 МБ desktop, 0,15 МБ lite; отдаются с
  маршрута `/rt/*`, immutable), `tools/assets/material_pipeline.py` (материалы из фото образца),
  `tools/flat3d/build-catalogue.mjs` (40 вариантов мебели из лент демо);
- сохранение: `flat_configs`, цена считается на сервере, контакт наружу не отдаётся.

**Ключевые решения:** ADR-0210 (стек), ADR-0211 (единая модель), ADR-0212 (три класса ассетов),
ADR-0213 (kit-of-parts), ADR-0214 (сохранение без ПДн).

**Чего нет (следующий шаг):** свободное размещение мебели (Sims-редактор), лайтмапы, контуры
комнат сложнее прямоугольника, каталог конкретного застройщика, проверка фото по всем комнатам.
