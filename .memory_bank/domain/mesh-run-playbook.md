# Прогон мешей — регламент

Для сессии, которая впервые взялась за меши: выполняй по порядку, ничего не пропуская.
Рабочая конфигурация (образ, карта, тариф, замеры) — [[mesh-run]].

## 1. Предусловия — проверить ВСЕ, каждое командой
Ни одно не проверяет стартовый скрипт, а цена пропуска — оплаченный простой нод.

| # | Что | Чем проверить | Почему |
|---|---|---|---|
| 1 | **Стили собраны** | `stat -c %y tools/scout/style-scores.json` не менялся ≥15 мин И нет процесса (`ps -eo pid,comm,args \| grep style_score`) | партия набирается по близости сетов к готовности (`tools/scout/mesh_scheduler.py`), а сет собирается по стилям: без стилей ярусы считаются по устаревшей картине |
| 2 | **Дев-база поднята** | `docker exec remlab-devdb pg_isready -U remlab` | без неё `ingest_registry`/`mesh_bind` не запишут, а `receiver_purge` честно удалит НОЛЬ и приёмник забьётся (уроки 408/427). 02.10 база лежала 2 часа |
| 3 | **Место на диске DEV** | `df -h /` — свободно ≥20 ГБ | меши + болванки растут; при 85% чекпойнты БД шли 270 с вместо 4 |
| 4 | **Кредиты Salad** | ответ `400 Bad Request` при старте группы = кончились деньги (урок 404), читать ТЕЛО ответа | иначе волна «запустилась» и стоит |
| 5 | **Нет стоп-файла** | `ls ~/scout-scenes/mesh-group-halt.json` | его пишет сторож денег; есть файл — сперва разобраться ПОЧЕМУ, снимает только человек (ADR-0174) |
| 6 | **Нет чужого прогона** | `ls ~/scout-scenes/.batch_show.lock` + сообщение соседней сессии | конвейер — singleton |
| 7 | Приёмник зелёный, сироты доработали | проверит сам `mesh_wave_start.sh` | — |

## 2. Старт
```
tools/scout/mesh_wave_start.sh            # собрать снимок и НАПЕЧАТАТЬ команду (сухой заход)
tools/scout/mesh_wave_start.sh --launch   # …и запустить
```
Скрипт делает по порядку: замок → снимает флаг `mesh-draining` → ждёт сирот (до 30 мин) →
`drain.sh --keep` → реестр поколений → семейства → привязка к товарам → чистка приёмника до
зелёного → тик решений владельца → снимок очереди АТОМАРНО → запуск с `--batch 2000`.

**Почему только через него:** курсор конвейера позиционный и верен лишь для своего снимка.
Снимок, собранный поверх неразобранных результатов, заново поставит уже сделанные меши — кэш
«уже готово» на приёмнике к тому времени вычищен, и это прямые деньги на ветер.

## 3. Наблюдение
- Лог: путь задаёт `MESH_BATCH_LOG` (умолчание — `tools/scout/mesh_wave_start.sh:20`; планово
  переезжает из банка в `~/scout-logs/`, см. [[mesh-pool]] Tier 2).
- Деньги и темп: `tools/scout/salad/tier_compare.py` (цена по ОПЛАЧЕННЫМ нодо-часам), `tools/scout/salad/pool_hours.py`.
- Приёмник: `tools/scout/salad/sink_health.py:check()`; упреждающую уборку каждые 15 мин делает
  `tools/scout/salad/sink_keeper.sh` (крон), он же полет болванки после чистки (ADR-0233).
- **«Running» ≠ работает:** судить по `gpu_seconds`/`done` из `/health` ноды, а не по панели
  (урок 388). Молчащую ноду снимает `ssh_run.silent_fault` через 600 с.
- Ожидаемая норма: ≈176 с на меш; заметно хуже — смотреть прогрев, а не менять машины
  (общая медленность пересадкой не лечится, ADR-0157).

## 4. Остановка
1. **Штатно:** `touch ~/scout-scenes/mesh-draining` — `batch_show` выходит на границе пачки,
   `finale()` гасит группы сам.
2. **Проверить, что погасли** (иначе платим за `running`, а не за работу — ADR-0135):
   состояние групп через Salad API или `tools/scout/salad/money_guard.py`.
3. **Страховка:** `tools/scout/salad/idle_guard.sh` (крон `*/10`) гасит группы, если конвейера нет.
   Он НЕ пишет стоп-файл — «конвейера нет» не равно «пул не выдаёт».
4. **Жёстко и надолго:** стоп-файл `~/scout-scenes/mesh-group-halt.json` — сильнее любого
   автостарта, снимает человек.
5. **Горячий перезапуск** (не остановка): `touch mesh-draining` → дождаться выхода → снова
   `mesh_wave_start.sh --launch`. Группы при этом НЕ гасим.

**Никогда:** `kill -9`/`pkill -f` по конвейеру (сироты с `ppid=1`, а `pkill -f` убивает и сессию
агента); удаление групп (теряются исключения нод и квота); правка живого снимка очереди.

## 5. Тупики — за них уже заплатили, не повторять
| Тупик | Чем кончился | Решение |
|---|---|---|
| Генерация на `fal` (Trellis, Hunyuan 2.0 mini) | запечённый свет в текстуре (в сцене со своим светом объект не пересвечивается) + ≈$4 361 на пул против $31–105 своим образом | ADR-0131/0132 |
| Ремонт мешей (авто-починка геометрии) | владелец: «процессом ремонта ты не управляешь»; показываем оригинал генератора | ADR-0143 |
| Перегон с другим seed ради ЦВЕТА | seed и CFG покраски захардкожены апстримом, наш seed меняет только форму — деньги без эффекта | ADR-0145 |
| Пачка `--batch 200` | треть оплаченного времени уходила на границы пачек: 110 мешей/час против 172 | ADR-0200 |
| Веса не вшиты в образ (`BAKE_WEIGHTS=0`) | нода качает веса в состоянии `running`, то есть за наши деньги | ADR-0137 |
| DINOv2 и веса покраски с HuggingFace на прогреве | 81 отказ прогрева за смену; прогрев 7,6 мин вместо 1; половина нод не дотягивается до CDN | ADR-0168/0173 |
| `torch.load` чекпойнта формы копией в память | пик 12,3 ГБ при лимите 12 — контейнер умирал на каждом меше | слой `mmap` |
| PATCH образа у живой группы | молча игнорируется, группа остаётся на старом образе | ADR-0154 |
| Удаление с приёмника мимо API (`rm -rf`) | счётчик приёмника не уменьшался → ложное «полно» → 507 и простой | ADR-0178, урок 405 |
| Прополка болванок по возрасту (48 ч) | унесла рычаг перепокраски у 2 132 мешей: цвет теперь только полным перегоном | ADR-0231 → пересмотрено ADR-0233 |
| `bpy==4.0` из requirements апстрима | версии нет на PyPI, колёс под python3.10 нет — официальная сборка Tencent падает здесь же | `patch_bpy.py`, замена на trimesh+pygltflib |
| Образ `cu128` под RTX 5090 | апстримом НЕ проверен и на 4090 не запустится; в бою не использовался | `build.sh` §варианты |
| Бэкенд `s3`/R2 для результатов | написан, но никогда не настраивался: боевой путь — `http` на exit-fi + `drain.sh` | `tools/scout/salad/storage.py` |

## 6. Куда это встаёт в конвейере
Этап 5→6 в [[pipeline-order]]: очередь → **партия на сегодня** (`mesh_scheduler.py`) → генерация.
Запускать ПОСЛЕ стилей (предусловие 1). Крон-автостарта волны нет и не будет без отдельного
решения владельца: он поднимал бы платные ноды без человека.
