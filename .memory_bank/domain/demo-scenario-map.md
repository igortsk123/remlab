## 3. Инфраструктура, замеченная прогоном

  путём «DEV-бэкенд молчит — рендерю локально» с упрощёнными мешами, дайджест не кричал. Перезапущен 14.10 14:24 руками.
  → сторож в `tools/ops/dev-checks.sh` (`demo-01` п.9 / `b2b-09`).
- Сервис кадров держит задания и кэш в памяти процесса (ADR-0278 остаток): любой деплой = потеря заданий → 404.
- Машина DEV: 7,6 ГБ ОЗУ, свободно ~2,7 ГБ при работающем рендере — повтор earlyoom вероятен.
