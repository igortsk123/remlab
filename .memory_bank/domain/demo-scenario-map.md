# Карта сценариев демо (`/demo`)

Первый прогон 14.10 — скрипты `tools/ops/demo-walk/*.mjs` (Playwright, прод, 1280×900 и 390×844). После починки
(`demo-03`, 14.10) каждая строка покрыта живой проверкой на проде: номер строки стоит в начале названия теста
в `e2e/live/*.live.ts` (`demo-scenarios.live.ts` — кнопки, `demo-frame.live.ts` — серверный кадр, медленно;
`demo.live.ts` — 1.1). Ночной шаг `demo_live` (`tools/ops/demo-live.sh`); строка без проверки — `WARN:demo_map_uncovered`
в дайджесте (`tools/ops/demo-map-check.mjs`, шаг `dev_checks`). Строка, у которой «Факт» начинается с «→», ушла в другой
план и в сверке не считается.
Формат: **сценарий → ожидание → факт** (✓ как ожидалось · ✗ дефект · ◐ с оговоркой); в факте — дата зелёного прогона.
Код страницы — `tools/scout/flat215-demo/index.html` (IH), сервис кадров — `tools/scout/draft_service.py` (DS).

## 3. Инфраструктура
- **Артефакты сцены (demo-05 п.1, 18.10):** ворота публикации — `tools/scout/scene_checks.py` (наезд > 2 см по Г-следу
  `scene_checks.overlap_pairs`, тёмная модель; красный вариант не публикуется — `flat215_demo.py`); отчёт для человека —
  `tools/scout/scene_artifacts.py` (наезды, текстуры лёгких копий `/rt/` вкл. KTX2, ковёр и ваза в данных) →
  `~/scout-scenes/scene-checks/<дата>.json` + `/test/scene-checks/`. Замер 18.10: 5/5 вариантов чистые по (а)(в)(ж);
  (б) пиксели, (г) точка обзора, (д) прогулка, (е) пины — без автоматической проверки (нужен браузер/движок).
- DEV-рендер (`tools/scout/dev_render_backend.sh`, порт 8600) 13.10 убил `earlyoom`, прод сутки рисовал запасным путём
  молча. С 14.10: крон раз в 10 минут поднимает его заново; `tools/ops/dev-checks.sh` пишет в дайджест, жив ли он, видит ли
  его прод через туннель, сколько кадров прод снял без него и сколько раз он поднимался (`WARN:dev_render_*`).
- Задания сервиса кадров — файл `jobs.json` рядом с реестром кадров (`draft_jobs.py`): черновики после деплоя досчитываются,
  платные получают честный `lost` (ADR-0287).
- Машина DEV: 7,6 ГБ ОЗУ, свободно ~2,7 ГБ при работающем рендере — повтор earlyoom вероятен, теперь виден и лечится сам.
