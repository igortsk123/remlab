# Композиция гостиной — доли площади по метражу (справка владельца, 2026-08-01)

> «Доля» = проекция предмета на пол в % от площади гостиной. Для ковров — покрытие пола;
> для зеркал, часов, бра, полок и штор — доля соответствующей СТЕНЫ.
> **Глобальный предел: вся напольная мебель 28–38% площади, максимум 40%. Ковры не в счёт.**

## Применение
- Автосборка сетов: сетка **7 метражей × 3 тира ≈ 21 сет**; из доли и метража считается целевой
  footprint предмета (напр., диван для 15 м² = 10–14% → 1,5–2,1 м² → подбор по Ш×Г каталога).
- Планировщик (hard-чек): суммарная напольная мебель 28–38%, max 40% — согласуется с
  правилом «заполнение ≤50%» из эргономики (это верхняя граница, справка владельца строже).
- Машиночитаемая копия: `tools/scout/composition.json` (вне git) и будущий `data/planner/composition.ts`.
