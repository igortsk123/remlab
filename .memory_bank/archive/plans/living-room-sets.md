## Цель
~20 готовых сетов гостиной (эконом/комфорт/премиум) для «максимально быстрого» пути юзера:
Excel-выгрузки каталога по категориям → владелец руками собирает сеты из ссылок →
страница планировщика: комната → сет → раскладка → клики `/go/p/`.

## Источник задачи
Владелец 2026-08-01 (ADR-0042). Зависит от `gdeslon-catalog` (товары) и `ergonomics-planner`
(раскладка). Формат курации задан владельцем дословно: файл на категорию мебели
(Диваны.xlsx, Кресла.xlsx, Торшеры.xlsx…), в каждом 3 листа — Эконом / Комфорт / Премиум;
колонки: миниатюра, кликабельная ссылка на товар, площадь в м²; владелец скачивает с сайта,
просматривает, присылает серии ссылок «сет 1: …, сет 2: …».

ADR-0042; `gdeslon-catalog.md` (схема products); `ergonomics-planner.md` (planLayout);

## Скоуп — что входит
**Ф5 Excel + сборка сетов:**
- Таблицы `furniture_sets` (id, slug, tier econom|comfort|premium, status draft|published)
  и `furniture_set_items` (set_id, role, qty, product_mid+eid, alternates jsonb) — миграция 008.
- `tools/sets-export.ts` (exceljs): файл на категорию, 3 листа по перцентилям цен категории
  (эконом 10–40 / комфорт 40–75 / премиум 75–95 — решение владельца); колонки: миниатюра
  (встроенная картинка), название, кликабельная партнёрская ссылка, площадь м² (Ш×Г/10000),
  Ш/Г/В см (typical помечать «≈ примерные»), цена ₽, старая цена, магазин, бренд, confidence,
  ID mid:external_id (обратный маппинг). Только in_stock с картинкой.
- Выкладка файлов на сайт для скачивания (непубличная/защищённая ссылка) → ссылки владельцу.
- `tools/sets-import.ts`: вход — списки ссылок владельца; резолв в products (по партнёрскому
  url или ID); создание сета; прогон через planLayout на эталонной комнате (обязан
  расставляться без hard-нарушений, иначе предупреждение).
- `tools/sets-health.ts` + шаг в ресинке: OOS → пометка + автоподстановка из alternates
  (та же роль, ±15% цены, размеры ±10%), лог.
**Ф6 UI:**
- `app/planner/page.tsx`: шаг 1 — размеры комнаты + двери/окна (пресеты «типовая 18 м²»);
  шаг 2 — выбор сета (карточки тир×состав); шаг 3 — SVG-раскладка + карточки товаров +
  кнопки `/go/p/?source=planner&set=…` + «другой вариант» (новый сид).
- `app/api/planner/route.ts` (Zod, таймаут-кап). Аналитика: planner_started, set_selected,
  layout_generated, product_click.

## Скоуп — что НЕ входит
Другие комнаты (спальня/кухня — после валидации гостиной); телеграм-бот курации; мини-админка
сетов; оплата; «комната из фото».
