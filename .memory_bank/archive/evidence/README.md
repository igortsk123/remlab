# evidence/ — первичные свидетельства, на которые ссылается канон

Сюда переносим из `_intake/` те файлы, на которые ССЫЛАЮТСЯ канон-доки: вердикты владельца,
ответы советника, замеры. Причина переноса (11.10): `_intake/` аудит не смотрит и чистка может
его унести — тогда утверждение в каноне останется без доказательства (находка `CANON-INTAKE-REF`).

Правило: факт живёт в канон-доке, здесь — только исходник, по которому его можно перепроверить.
Сырьё, на которое никто не ссылается, сюда не тащим — ему место в `_intake/` или вне банка.
