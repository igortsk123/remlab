# Шаблон вопроса советнику — «что уже пробовали» из поиска по банку

Зачем: 27.11 советник предложил закрытое (нейросеть-художник — StableGen был основным способом до 20.11, ADR-0455); 19.11 директор второй раз спросил ключ RunPod, он уже лежал в банке. Банк есть — не сверяли. Теперь сверка — поле файла вопроса, которое проверяет код (`question_lint.py`), а не память директора. Правило P-075 («когда звать советника») не менялось.

## Порядок
1. Сформулировать, о чём вопрос, 1–3 коротких запроса словами темы (способ, правило, товар): «нейросеть художник», «вырезка chain_shape».
2. Одной командой: `python3 tools/ops/bank_search.py "запрос 1" "запрос 2" --block > черновик.md` — готовый раздел «Что уже пробовали (поиск по банку)»: у каждого запроса строка-метка («найдено N мест … дата») и места `файл:строка` с заголовком/ADR/уроком. Отметка ⚠ — в месте есть слова закрытого («отброшено», «не помогло», «не сработало», «снято»): прочитать место целиком.
3. Прочитать найденное и вписать в раздел вывод: что пробовали и чем кончилось; чего советнику НЕ предлагать; что нового с тех пор (без нового довода закрытое не открываем — урок «Check bank before try X», владелец 27.11 TG 3572).
4. Перед отправкой: `python3 tools/ops/question_lint.py vopros-N.md` — код 0.
5. Ответ советника: в нём строка «Сверено с банком: …» (что нашёл, чего не предлагает; либо «N/A: причина»); проверка — `question_lint.py otvet-N.md`. Нет строки — вернуть вопрос советнику.

## Шаблон файла вопроса (`vopros-N.md`)
```
# Вопрос Fable N — директор, ДД.ММ ЧЧ:ММ · тема одной строкой

## Факты
- числа, кадры, пути (что видно сейчас)

## Что уже пробовали (поиск по банку)
Поиск по банку: «запрос» · найдено N мест в M файлах (просмотрено K) · ГГГГ-ММ-ДД · `python3 tools/ops/bank_search.py "запрос"`
- `файл:строка` (заголовок) · ADR-… — «выдержка» ⚠ закрытое?: слова
Вывод: что пробовали → чем кончилось; что не предлагать; что нового с тех пор.

## Вопросы
1. …

Код не правь. Ответ — `~/remlab-logs/fable-1126/otvet-N.md` + короткое сообщение директору; в ответе строка «Сверено с банком: …».
```
Вопрос не про способ или пробу (оценить кадр, прочесть число) — вместо метки поиска строка «N/A: причина» (≥ 10 знаков).

## Что ищет поиск и чего не умеет
- Ищет: `.memory_bank/**/*.md` (решения, уроки, core, правила, планы с хронологией проб, архив, журнал), блокнот `_intake/session-scratch.md` и `owner-questions.md`, авто-память Claude проекта. Не читает `_secrets/` (никогда) и остальной `_intake/` (брифы, черновики; включается `--with-intake`).
- Слова сокращаются до основы (нейросеть/нейросети); место = окно из 6 строк, где есть ≥ 2/3 слов запроса. Не ищет по смыслу и синонимам: «художник» не найдёт «рисует». Два-три запроса разными словами одной темы — норма.
- «Найдено 0» — допустимый результат, но это «по этим словам нет», не «такого не пробовали»; перед «этого нет» (урок «No absence claims») — второй запрос другими словами.
- Правила работы и реестр правил товара поиск не меняет; в ответ советнику решение не вписывает — только показывает, что уже есть.
