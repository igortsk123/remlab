## Как ставить задачу
- Бриф самодостаточный (`_intake/brief-<T-ID>.md`), первая строка `[роль] T-YYYYMMDD-NN/<цикл> · <фаза>` (фаза: задание, отчёт, правки, доработка,
  принято, вопрос). Обязательны: 4 строки конвейера, «что чистит шаг», «Salad или наши ядра», границы (без sudo, rm, kill, платного без потолка, деплоя,
  `.env*`, файлов в `.claude/`, heredoc) — гейт 1 в `.claude/rules/10-decision-gates.md`, P-071, P-072.
- Отчёт рабочего: `[рабочий N] T-…/<цикл> · отчёт`, 2-я строка — ID модели; SHA от base, свои проверки, расход. Приёмка — 14 пунктов
  `.claude/rules/review-checklist.md`, до 3 циклов правок.
- Перед выдачей — доска по сути, не по T-ID (дубль T-81/T-73, 06.11): поиск по `plan-zadach.md`. Задачи ставит владелец; свободному рабочему — следующая
  по плану (P-069, P-070). Активное — только в `plan-zadach.md`; сводка — `~/.local/bin/plan-procent`, оформление — P-073.

## Грабли, которые повторяются
- Окно разрешения ≠ «waiting» в `ListAgents`: смотреть `~/.claude/sessions/*.json` → `waitingFor: "permission prompt"`. Чтение `.env*` спрашивает всегда;
  запись в `.claude/` — защищённый путь, allow его не снимает: временное — в `~/remlab-scratch/<задача>/`, `~/remlab-logs`, scratchpad, файлы — Write.
- Сервисы DEV (pakardev) не останавливать; чужие процессы по PID на глаз не снимать (цепочка `ps -o ppid`, лучше попросить владельца процесса).
- Тяжёлое — только под `tools/ops/heavy-slot.sh`: до 5 по заявкам, по факту ядер до 8 (P-072, P-038); свои циклы `free -m` не писать.
