## Шаги (по порядку; время `TZ=Europe/London date`, строка в `~/.local/state/remlab/obhod-direktora.log` — формат выше)

Бриф — по гейту 1 (самодостаточный, 4 строки конвейера, что чистит, Salad/ядра). Отчёт → `review-checklist.md`; READY TO MERGE ≠ PASS: PASS только после CI, живой проверки и свода памяти; кадры смотрю САМ.

## Принципы (не забывать)
- **Покраска — ступени** (TG 2803 + TG 3522, 27.11 «почему забыл»): пробный «ок» → **10 товаров того же типа без ошибок** (TG 3524: «10 столов без ошибок») → 3 разных типа → по одному каждого типа → все. Следующую ступень — только после «ок» владельца на текущей; ступень не перескакивать. **Показ каждого стола (TG 3532):** 3 стороны — спереди s1, сзади s4, сверху s6 — отдельными файлами, сразу после покраски, кадры смотрю сам.
- **Показ** (TG 2562): владельцу — только изменённое (сменился вердикт или правка видна на названном виде); неизменённое — числом; регресс — с причиной; покраску — только «в целом хорошо»; кадры смотрел сам; ссылка + «куда нажать, что увидеть».
- **Фронт** (TG 2571/2574): без разрывов — канон в паспорте `plans/mesh-type-rules-01.md`.
- **После прогона** (TG 2517/2527): все косяки + путь → Fable И GPT-6 одновременно до правок; Astra нельзя (P-075).
- **Дефект товара** → правило на тип/все товары → паспорт (P-034). Масштаб ~50k, автоматом (P-042).
- **Деньги**: проба ≤~$1 в одобренном — без вопроса, расход строкой; пакетами на прогретую.
- **Сообщения владельца**: голос → `stt`, «🎤 Понял»; сначала «взял», долгое — в фоне; решения/грабли — сразу в `_intake/session-scratch.md`.
- **Лимит по машинам** (владелец 28.11 TG 3835/3837/3845; общее правило `~/.claude/obshchie-pravila.md` § «Недельный лимит»): см. шаг 3б.
- **Вливание** (урок 1093): строка вердикта Fable с точным SHA — в журнале обхода ДО merge; после сжатия «уже проверено» — только по журналу.

- **Границы**: без sudo/rm/kill/pkill -f; git только `r`; `.env*`/_secrets не читать; deploy.sh не запускать; удаление данных, миграции, секреты — только словом владельца; вливает в main только директор после 14 пунктов; `--no-verify` нельзя; Hunyuan не показывать; модель на сайте ≤5 МБ.
