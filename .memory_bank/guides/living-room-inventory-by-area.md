# Состав гостиной по площади (верифицированный синтез)

> Второй документ владельца (07.08) к `archive/plans/MASTER-zones-first.md`. Ключ: состав — ВЕРОЯТНОСТНЫЙ
> prior от площади, а не жёсткая таблица; считать по USABLE placement area (минус циркуляция,
> двери, радиаторы), плюс целевой seating capacity и сценарий.

## Пороги inventory-prior (инженерный синтез, не норматив)
- **до ~8 м²**: 1 компактная группа 2–3 места (пара кресел / двухместник / компакт-sectional);
  журнальный стол НЕ обязателен (приставной/nesting/пуф-хранение); хранение вверх/узкое.
- **8–12**: 1 главный seating-объект + макс 1–2 доп; ТВ на стену лучше глубокой тумбы;
  функции совмещать (стол/пуф с хранением).
- **12–18**: диван/sectional + 1–2 кресла ИЛИ два компактных дивана; столик, ковёр,
  приставные, ограниченное хранение — норма. 15–18: цель 5–7 мест, НЕ максимизировать;
  微-зона чтения — только при свободном угле.
- **18–25**: + второй диван/крупное хранение/медиа; кресло чтения/desk — после основной
  группы и циркуляции.
- **25–30**: после ~6–8 мест — ВТОРАЯ ЗОНА вместо роста первой (два кресла+столик /
  reading nook / рабочая).
- **30–35+**: несколько зон — норма; главной зоне часто хватает одного дивана/sectional,
  вторичная — кресла+bench/банкетка, back-to-back диваны для независимых зон.

## Принципы (сверх порогов)
- **Anchor-принцип**: маленькая комната ≠ только маленькая мебель. Один нормальный anchor
  (streamlined sofa / правильный sectional) + лёгкие спутники ЛУЧШЕ множества мелочи
  (дробление). Угловой диван в малых НЕ запрещать — он использует мёртвый угол.
- **Loveseat/«диван 2»** — альтернатива двум креслам уже с 12–15 м², не привилегия больших.
- **Usable area, не room_area**: вычитать циркуляцию, door swing, радиаторные зоны;
  две комнаты 16 м² с разной геометрией имеют разную вместимость.
- **Параметры выбора**: площадь (классификация ~12/20/28 = small/medium/large по Spruce) →
  usable area и форма → целевой capacity → сценарий → шаблон группы с известным футпринтом →
  столик/ковёр/хранение/свет при сохранении проходов → вторичная зона при остатке
  непрерывного пространства.
