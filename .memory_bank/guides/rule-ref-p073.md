# Справочник · P-073 · владелец · Общение с владельцем: язык, вопросы, сводка, показ, ошибки

> Строки ниже вынесены из `.memory_bank/rules/P-073.md` слово в слово; само правило — там (P-073 — любое сообщение владельцу, сводка, показ результата, ошибка). Секции — как в правиле. Снятое — `rules/history/P-073.md`.

## Язык и вид (P-001, P-002)

- Запросы советнику, что владелец пересылает, — по-русски, «Запрос N», отдельным сообщением `format: text`.

## Сводка (P-003)

- Временный вид (TG 1741/1745/1746): «задача — %», группы «Меши» и «Остальное».

## Показ результата (P-004…P-006)

- 3D-модель — ссылкой на просмотр, без кадров; косяки — в том же сообщении «что нашёл, иду править сам».
- **До ссылки — каждую модель сам со всех сторон** (TG 2185/2202): лист «фото + перед, 3/4, бок, зад, др. бок, верх» на КАЖДЫЙ товар; быстро — браузерная съёмка 08-frames, numpy запасной; брак невидимого (зад, верх) — брак, автокрутку не выключать.
- Рендеры и фото на оценку — отдельные кадры в полном разрешении, без листов-сеток.
- В долгих пробах раз в 30–60 мин — лучший промежуточный результат, плохой тоже (ночью — в утренний отчёт); результат → показать → исследовать → «что понял» → вычеркнуть/добавить варианты.

## Ошибка, на которую указал владелец (P-063)

- Ошибку рабочего — так же: разбор и план от рабочего, причину проверяет ведущий.
- Числа о прогоне — из сводки/журнала с источником; показ — все товары прогона (страница), не выборка; страница покраски — автоматом шагом конвейера.
