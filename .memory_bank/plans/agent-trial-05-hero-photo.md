## Цель
Для каждой пробы агента — один AI-кадр гостиной с плашкой «AI-generated visualisation — not a photograph» / «AI-визуализация — не фотография»,
который догружается на страницу `/try/<id>/tour/` после мебели. Сбой или нет денег — тур остаётся рабочим, фото просто нет.

Мастер `plans/MASTER-agent-trial.md` § «Поправка 09.11, вечер»: «… мебель появляется → AI-фото догружается → две ссылки». Разбор и заготовка —
T-20261109-13 (циклы 1–2, влито `f221017c`, `cf453130`; разборы `~/remlab-logs/trial-hero/findings-1501.md` §5–7, `findings-1530.md`).
Порог доли фото в листе эталонов — T-20261109-17 (`1577c22c`, `improve_mode.MIN_PHOTO_SHARE=0.75`).

## Что есть (main)
- `tools/scout/trial_hero.py`: вход — папка сцены пробы `~/scout-scenes/trial/<id>/scene.json` (контракт — docstring), выход — `hero/hero.jpg`,
  `hero/hero.json` (`ok`, `model`, `timing`, `cost_usd`, `error_code`, `rendered.edge_risk`); `pick_hero_camera` по геометрии; широкий кадр
  k=1,08 (`TRIAL_HERO_OVERSCAN`) с обрезкой; плашка 2,2 % (`TRIAL_HERO_BADGE_EM`); отказы до оплаты (`trial_not_ready`, `trial_no_openings`,
  `trial_empty_variant`, `no_product_photos`, `bad_input`); ≈ $0,055 и ≈ 35–40 с на кадр (рендер 15–20 с + модель ~18 с).
- Тест `tools/scout/tests/test_trial_hero.py` в CI.

## Скоуп — что НЕ входит
Фото спален; несколько ракурсов; выбор стиля агентом для фото (берём первый вариант гостиной); апскейл.

## Приёмка
5 разных гостиных из НАСТОЯЩИХ проб (после влития гостиной, не flat215): мебель та же, нет новых окон/дверей/мебели, плашка читается на
375 px на обоих языках, фото ≤ 60 с после мебели у 5/5, отказ (нет денег/сбой) → тур без фото; ≤ $0,60 на приёмку.
