## Цель

   «комод есть, а столика или ТВ нет» невозможен (сейчас возможен — ниже).
2. Лампа на комоде подбирается по размеру ЭТОГО комода: влезает основание, абажур в пропорции. Сейчас на комод 42–45 см
   проходят только лампы до ~25 см, поэтому в 4y0opq комод с лампой есть в 2 стилях из 5.

**Лампа на комоде.**
- Сейчас: `tools/scout/dependent_decor.py:lamp_pick` — лампа набора, затем лампы того же стиля из банка (`candidates`), ПЕРВАЯ, что
  проходит решатель `planner/dependents.py` по норме `occupancy.json → distances_cm.dependents.surface_decor`: отступ от края
  ≥ max(8, ½ основания + 3), декор ≤ 20 % площади столешницы. Основание сводится к квадрату max(Ш, Г), площадь — Ш×Г всей лампы
  (`dependents.py:231`). Сцена /demo повторяет проверку при замене комода по присланным числам `fit`
  (`lib/configurator/carrier-decor.ts:60`).

  минимализм 25–34, современный 30–34; комоды глубиной 40–50. 80×42: 20 % = 672 см² → проходит лишь ≤ 25×25.
- Внешние источники (Codex, перепроверены 13.11): основание целиком на поверхности, не у края — инструкции производителей и
  IEC 60598-2-4 / UL 153 (устойчивость самой лампы); «лампа с абажуром ≤ ~⅔ стола» и «абажур ≈ 2 диаметра основания» — Pottery Barn
  (эвристика); реальные спецификации: у Visual Comfort Aspen абажур 40,6 см при основании 11,4×22,9. Нормы ASID/NKBA «абажур к
  глубине комода» нет. 20 % — внешним источником не подтверждено (задумано для суммы декора).

## Скоуп — что входит
**А. Ядро прежде комода (решатель + туры, одно правило для /demo и туров).**
1. `plan_key` v1: ярус `len(unplaced)` (обязательное, не вставшее) сразу после `missing_req`, до маршрута и света. В `plan_key_v2`
   уже есть — не трогаем, только тест-сравнение версий на этом случае.
2. `trial_demo.py`: одна функция «ядро по итоговым предметам» (диван + столик + ТВ-носитель, как `bank_invariants.CORE`) — в
   `retry_next`, `rescue` и в последней проверке перед выпуском варианта; /demo уже проверяет — сверить, что ядро то же (один источник).
**Б. Лампа по размеру комода.**
3. Новая норма `occupancy.json → distances_cm.dependents.table_lamp_on_surface` (вазы остаются на `surface_decor`): основание
   целиком на столешнице с отступом `edge_clear`; абажур не свисает в сторону прохода; доля площади — по основаниям и мягкая;
   пропорции (ширина абажура к ширине комода, глубина к глубине, высота к высоте) — мягкий счёт для выбора. Источники и статус — в
   `_source` правила.
4. Основание лампы: из меша (нижний срез модели, проекция на пол, прямоугольник; `support_source=mesh`, уверенность); не вышло —
   осторожный запасной путь: весь габарит лампы должен целиком лечь на столешницу (без 20 %). Доля «основание = X абажура» не
   используется как разрешение.
5. `dependent_decor.lamp_pick`: перебрать ВСЕ лампы стиля из банка (набор → банк стиля), отсеять по норме, выбрать лучшую по
   пропорции к этому комоду; при равенстве — своя лампа набора, потом устойчивый порядок по артикулу. Не нашлась — атом снимается,
   как сейчас.
6. `dependents.py` (решатель места) и `carrier-decor.ts` (сцена при замене комода): основание по двум осям + отдельный габарит
   абажура; числа сцене — в строке `fit` (`lamp_row`), формула одна; общий набор векторов «вход → да/нет» для Python и TS.
**В. Проверка — на /demo и всех турах.**
7. Тень всех туров с гостиной тем же способом, что T-122 (`~/remlab-logs/t122-1112/`, входы `inputs/`), до/после: ядро полное,
   комод с лампой, «комод есть, а ядра нет» (должно быть 0 построчно), снят атом; /demo — сборка и проверка ядра.
