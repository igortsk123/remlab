## Место в очереди (ADR-0251, уточнено 13.10)
**Этап 0 — минимальный переключатель** вариантов кухни/отделки от партнёров застройщика (3–5 вариантов, фото,
цена или «включено», без стилей и без посадки в план) — в демо и 3D сразу после `conv-09`/`b2b-06`, потому что без
него английский застройщик не видит своей ценности. Полная кухня (модели, посадка, шаблоны) — В САМОМ КОНЦЕ очереди: кухни делаются по схеме гостиной, когда гостиная доведена,
владелец пришлёт кухни и проверит. Готовиться (контракт опции, оба пути моделей) можно раньше.

## Цель
Вкладки «Кухня», «Спальня 1», «Спальня 2» в демо перестают быть «скоро». Этап 1 — кухня: варианты
застройщика, привязанные к конкретной квартире (владелец пришлёт 5 кухонь на тест, БЕЗ стилей),
которые покупатель переключает в плане кухни и в 3D, с выбором отделки/сантехники из 3–5 вариантов.
Этап 2 — спальня: роли каталога, нормы, шаблоны расстановки, комплекты по стилям, лента замен (как
гостиная). Этапы 3–4 — ванная, прихожая. Порядок — решение владельца 13.10 (В8–В10, В19).

## Источник задачи
Презентация: вкладки по комнатам. Обследование 13.10: движок, шаблоны, сеты и роли — ТОЛЬКО гостиная
(`services/planner-solver/rules/templates.json:57` — 12 зон, 60 раскладок; `compose2.py:1095` ядро
гостиной; `category_map.py:30-64` DENY исключает кухню/ванную/кровати/технику/прихожую; в базе 0 кроватей,
плитки, сантехники, техники). В 3D кухня/ванная/спальня — слоты-уровни без реальных товаров
(`catalogue-base.json`), кухня — одна прямая линия (`lib/viewer3d/kits/kitchen.ts`). Ответы владельца:
кухня первой; кухни = опции застройщика (как опции отделки у застройщиков UK), не каталожные сеты;
пути — наши меши из фото поставщика ИЛИ готовые модели поставщика, уметь оба; отделка — выбор из 3–5.

## Этап 1 — кухня (опции застройщика)
1. **Контракт «опция квартиры»** (живёт в `b2b-06`): тип (кухня / плитка / раковина / душевая / пол),
   варианты (имя, фото, цена или «включено», модель 3D, поставщик), по умолчанию какой, к какой комнате.
   Для кухни у варианта: состав модулей по фото (нижние/верхние/колонны/остров), техника (встроенная —
   из того же фото), размеры по стене, цвет фасадов/столешницы.
2. **Модели кухонь — два пути.** (А) Фото готовой кухни от поставщика → вырезка → меш тем же
   конвейером, что мебель (`cutout_sync` → Salad), с паспортом размеров по стене; (Б) готовая модель
   поставщика (GLB/OBJ) → нормализация (масштаб, ориентация, лёгкая копия) → тот же реестр. Выбор пути —
   по тому, что пришлёт владелец; оба должны работать.
3. **Посадка в план кухни этой квартиры:** грубые схематичные шаблоны формы (прямая / угловая / П /
   остров), как делали для мебели: стена установки, рабочий треугольник (мойка–плита–холодильник),
   проходы ≥ 100–120 см, окно/вентиляция; солвер получает `room_type=kitchen` (поле в модели комнаты,
   `planner/models.py:48-62`) и правило посадки гарнитура без каталожного подбора.
4. **Демо и 3D:** вкладка «Кухня» активна: план кухни из квартиры (`b2b-06`), переключатель 5 вариантов
   (фото + цена + «в ипотеку/сертификат»), кадр; в 3D — те же варианты заменяют нынешние «уровни»
   (`kits/kitchen.ts`), отделка/сантехника — слоты «3–5 вариантов» (В9).
5. **Техника:** из фото кухни поставщика (встроенная) — отдельного каталога техники нет (В4).
6. Процесс-тест: «у квартиры есть ≥ 1 вариант кухни с моделью; все варианты открываются в демо и 3D».

## Этап 2 — спальня (каталожная, как гостиная)
1. **Каталог:** снять DENY для ролей спальни (кровать, матрас — как параметр кровати, тумба
   прикроватная, комод, шкаф, туалетный столик, бра/настольная лампа); правила `category_map.py`,
   `dim_resolver` (кровать: спальное место ≠ габарит); `lr_roles` → `room_roles` с полем «комната»;
   замер: сколько товаров с фото/размерами/наличием по ролям; нет в фидах — честно сказать владельцу
   (дополнительные магазины Гдеслона).
2. **Шаблоны спальни:** зоны (сон, хранение, туалетный, окно) с нормами (проходы у кровати ≥ 70 см,
   дверь/купе и вылет, окно/радиатор) из источников с перепроверкой Codex; `room_type=bedroom`;
   экзамен на 30+ сценах спальни.
3. **Комплекты спальни:** `compose2 --room bedroom`: ядро кровать · тумбы · шкаф/комод · свет · текстиль;
   7 полос × 6 стилей × 3 тира, стиль — единый вектор (`conv-02`).
4. **Демо:** вкладка «Спальня» по геометрии квартиры, лента замен по `conv-03`, меши — профиль очереди
   «спальня»; пока мешей нет — честно фото без 3D.

## Этапы 3–4 — ванная, прихожая
Ванная: плитка стен/пола, сантехника, душевая — как опции застройщика (3–5 вариантов) по контракту
этапа 1 + мебель под раковину из каталога. Прихожая: шкаф/обувница/зеркало из каталога по образцу спальни.
