## Цель
Вкладки «Кухня», «Спальня 1», «Спальня 2» в демо перестают быть «скоро»: для каждой комнаты есть
роли каталога, шаблоны расстановки с нормами, сеты по стилям и лента замен. Первой — спальня
(проще: кровать, тумбы, шкаф, комод), затем кухня (по шаблонам прямая/угловая/П), затем ванная и
прихожая. Порядок — по ответу В10.

## Источник задачи
Презентация: вкладки по комнатам, «1000+ вариантов мебели и техники». Обследование 13.10: движок,
шаблоны, сеты и каталог — ТОЛЬКО гостиная: `services/planner-solver/rules/templates.json:57` (12 зон,
60 вариантов, все гостиная), `compose2.py:1095` `CORE` гостиной, `category_map.py:30-64` DENY
исключает ванную, кухню, технику, матрасы/кровати, прихожую; в базе 0 товаров кроватей/плитки/
сантехники/техники (только «стулья для кухни» и «шкаф» 1 871). В 3D кухня/ванная/спальня — слоты с
плейсхолдерами уровней (`catalogue-base.json`), не реальные товары. Экзамен расстановки 266/272
(6 сцен `MEDIA_MISSING`), трек `MASTER-zones-v7` на паузе (владелец 19.08).

## Скоуп — что входит (этап 1 — спальня; этапы 2–4 — после приёмки этапа 1)
1. **Каталог:** снять DENY для ролей спальни (кровать, матрас — как параметр, тумба прикроватная,
   комод, шкаф, туалетный столик, бра/настольная лампа), правила `category_map.py`, `dim_resolver`
   (кровать: спальное место ≠ габарит), `lr_roles` → `room_roles` с полем «комната»; замер: сколько
   товаров с фото/размерами/наличием по ролям. Нет данных в фидах → честно сказать владельцу (вопрос
   о дополнительных магазинах Гдеслона).
2. **Шаблоны спальни:** паспорт зон (сон, хранение, туалетный, окно) с нормами (проходы у кровати
   ≥ 70 см, шкаф — дверь/купе и вылет, окно/радиатор) из источников (эргономика, Neufert/ГОСТ-нормы —
   с перепроверкой Codex в интернете); `templates.json`/`zones.json` получают поле `room_type`;
   солвер — `room_type` в модели (`planner/models.py:48-62`) и экзамен на 30+ сценах спальни.
3. **Сеты спальни:** `compose2 --room bedroom`: ядро кровать · тумбы · шкаф/комод · светильник ·
   текстиль; 7 полос × 6 стилей × 3 тира — как гостиная, с тем же единым стилем (`conv-02`).
4. **Демо:** вкладка «Спальня» активна, геометрия из квартиры (`b2b-06`), лента замен по `conv-03`,
   меши — очередь с профилем «спальня» (`mesh_priority`), пока мешей нет — честно фото без 3D.
5. **Техника** (слово в презентации): источник фида — вопрос В4; без фида «техника» = уровни в 3D-кухне,
   как сейчас.
6. Процесс-тест: «у каждой готовой комнаты в демо каждый слот имеет ≥ 1 товар с мешем».
