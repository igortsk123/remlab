## Решение (свой вывод → Codex 09.11 → итог; ответ — `_intake/codex/floorplan-bench-2026-11-09-answer.md`)
- **Основной путь — свой OpenCV без нейросети (каскад, не «порог+открытие»):** нарезка листа на панели (этажи/постройки) и
  отсечка UI/легенд; два слоя — толстые стены и тонкая графика (окна, дуги дверей, стрелки); толщина локально (distance transform),
  наружные/внутренние; центрлайны → граф стен; щели закрывать только после классификации door/window/unknown; выпрямление по
  локальным семействам углов (±2–3°), диагонали C сохранять. A — цветовая маска синего.
- **Масштаб — по подписям комнат, считает код:** подпись «имя + A×B м (+футы)» → комната по точке текста внутри эродированного
  полигона; кандидаты размера — P95 хорды / медиана хорд главного тела / части Г-комнаты (не bbox и не minAreaRect как основа);
  перестановка A×B и масштаб — робастно (RANSAC) по всем комнатам панели; масштаб — на КАЖДУЮ панель; метры против футов —
  проверка чтения; `sx`/`sy` отдельно для диагностики растяжения.
- **Подписи:** золото — расшифровка подписей по картинке (имя, A×B м, точка) вручную в `gold/*.json`; второй путь — VLM
  (по образцу `tools/scout/drawing_dims.py:ask`, шлюз Vercel, gemini-flash) читает подписи с точками — сравнить с золотом.
- **VLM «рисует стены JSON-ом»** — только сравнение, одна попытка на план.
- **Третий путь — MobileSAM (Apache-2.0, CPU) по точкам комнат** — только если бесплатно и ≤1 ч; цель — меньше ручной обводки ≥30 %,
  иначе убрать. Raster2Seq/CubiCasa — нет (веса CC BY-NC; GPU нет). Код FloorPlan Vision/floorplan-vectorizer не копировать.
- **3D:** стены = выдавливание footprints графа (2,6 м; окно — подоконник 0,9 м и перемычка от 2,1 м; дверь — проём до 2,1 м),
  серый материал, пол-полигон; этажи рядом/стопкой. Рендер — Playwright по странице на three.js из `node_modules` проекта;
  кадры: сверху под углом на каждую панель + один вид изнутри комнаты на высоте глаз.

## Критерии приёмки (порог «годно», Codex п.4; подписи UK — сами ±0,1 м по RICS)
- [ ] Каждая панель A/B/C: нет пропущенных/лишних комнат и ложных слияний (по золоту подписей)
- [ ] Размеры комнат, оставленные вне калибровки (leave-one-room-out): MAE ≤ 0,10 м, P95 ≤ 0,20 м, средняя относительная ≤ 3 %
- [ ] Площадь этажа против «Gross internal area» с листа — ≤ 5 % (предупреждение, не отказ)
- [ ] Углы стен > 1 м: медиана ≤ 1,5°, P95 ≤ 3° к линии на картинке; диагональ C сохранена
- [ ] Проёмы: найдено ≥ 95 % (по ручному счёту на A и B)
- [ ] Серое 3D: кадры каждой панели, ведущий смотрит сам рядом с исходником — пропорции и формы совпадают
- [ ] Таблица путей: OpenCV / VLM-геометрия / (MobileSAM) — комнаты, ошибки, ручная правка (оценка), время, деньги, лицензия
- [ ] pytest зелёный; без rm, без sudo, без деплоя
