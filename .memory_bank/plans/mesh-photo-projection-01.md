## Цель
Поднять у краски MV-Adapter контраст и резкость фактуры (дерево, ткань, принт) ближе к каталожному фото, не потеряв её цвет и не получив «двойной узор».
Только автоматика на 20 000+ товаров (TG 2224):
- каждый перенос сам себя проверяет;
- при сомнении остаётся чистый MV-Adapter, а в журнал пишется причина отказа.

Отказ — нормальный исход: если рисунок MV не совпал с фото, мы не «дотягиваем» фото до рисунка, а оставляем MV-Adapter.

## Скоуп — что входит (порядок Codex: А0 → А1 → А2-lite → запекание с приоритетом фото → А3)
- **Ш0 · эталонный набор (бесплатно).**
  - **Товары с двумя фото.** Сколько товаров каталога имеют ≥ 2 фото разных ракурсов. В фидах YML бывает несколько `<picture>`; хранит ли их наш каталог — не сверено.
  - **Дубли карточек.** Похожие товары и дубли карточек с другими фото.
  - **Раскладка набора по слоям:** фрезерованные фасады, дерево, однотонные, диваны (обивка, стёжка), кресла, принты, металл и стекло, тонкие ножки.
  - **Объём.** 30 товаров хватит для А0 и пилота. Для настройки порогов отказа на 20 000 нужно ~600 принятых примеров: при нуле ошибок верхняя граница «ложно принят» ≈ 3/n ≈ 0,5 %.
- **А0 · где теряются резкость и контраст** (без денег — кроме одного малого прогона, см. ниже).
  - **Опция воркера `mv_keep_stages=1`** (только проба) сохраняет без потерь:
    - вид MV 768;
    - вид после RealESRGAN 1536;
    - рендер запекания 4096 из камеры вида;
    - рендер итога 2048;
    - запекание только из вида 0 рядом с обычным из шести видов.
  - **Перепрогон.** Опции нужен перепрогон 5–8 товаров из 30 в пробной группе: покраска ~$0,01 на товар плюс прогрев ~$0,08, потолок — по слову директора.
  - **Мерка во всех точках — с ОДНОЙ зафиксированной регистрацией.** Регистрация — по силуэту и кромкам формы. Внутри `pattern_grad_ncc` — `register=None`: своя ECC-гомография метрики (`pattern_metric.py`) может скрыть сдвиг.
  - **Что мерим:** энергию высоких частот L*, σ L* фасада к фото, тексели развёртки на пиксель фото (якобиан UV↔экран по патчам).
  - **Итог** — таблица «теряется в генерации / в смешивании 6 видов / в запекании / в уменьшении 4096→2048». Если виновато уменьшение или смешивание, лечим дёшево: итог 4096, веса видов. До переноса деталей тогда дело может и не дойти.
- **А1 · контраст по яркости, без координат.**
  - **Что делаем.** Монотонная кривая только для L* или log Y; цвет (a*b*) не трогаем — он у MV верный.
  - **Откуда статистика.** По видимым пикселям рендера в камере фото, отдельно по крупным материальным кластерам (дерево, графит, ножки).
  - **Ограничение.** Наклон кривой 0,8…1,3; одна кривая на всю связную материальную область. Без локальных μ/σ — они дают ореолы.
  - **Риски** (Codex: «не нулевой»): кривая может усилить запечённую тень и блик, склеить материалы в одно распределение, испортить невидимые стороны.
    Поэтому гейт: ΔE00 по низким частотам не хуже чем +1; кадры при двух светах.
- **А2-lite · резкость только там, где рисунок уже совпал.** Не «перенести рисунок фото», а «добавить амплитуду и мелкие детали совпавшего рисунка».
  1. **Камера.** `fit_photo` (перспектива), затем гомография для плоского фасада.
  2. **Остаточная подгонка** — гладкая сетка/TPS с шагом 8–12 % ширины фасада, **не** свободный поток DIS/RAFT: он растянет один лист в другой и закрепит ошибку MV.
     Короткий плотный поток допустим только последним шагом: ≤ 4–8 px, на уже согласованных патчах.
  3. **Ограничения подгонки:**
     - p95 сдвига ≤ 2 % габарита фасада;
     - якобиан > 0 (без складок), растяжение 0,8…1,25;
     - ошибка «туда-обратно» ≤ 1–2 px на 768;
     - совпадение однозначное: нет второго почти равного пика (повторяющийся узор).
  4. **Гейт на патч из трёх частей:**
     - E_geom — есть ли сильный рельеф (нормали, глубина, кривизна);
     - A_geom-photo — совпадают ли ориентированные кромки рельефа с кромками фото после снятия низкочастотного света; сравнивать в координатах поверхности или ориентированным Chamfer;
     - периодичность.
     Решение по патчу:
     - рельефа нет → риска двойного узора нет, идут остальные проверки;
     - рельеф есть, кромки не совпали → перенос запрещён;
     - совпали → только малая гладкая коррекция;
     - периодика с неоднозначным совпадением → отказ.
  5. **Частоты.** Лапласова пирамида в координатах фото (до проекции); полосы σ = 0,5 %, 1 % и 2 % ширины фасада (≈ 4, 8, 15 px при 768), каждая полоса принимается отдельно.
     Крупнее 2 % (листья 5–10 %) автоматически не переносим.
     Формула в log Y: `detail = log Yфото − edge_aware_lowpass(log Yфото)`, `Yновый = Ymv · exp(gain · detail)`; gain ограничен по робастным процентилям.
     Низкие частоты (свет и тон) остаются от MV.
  6. **Свет.**
     - Блик = несколько признаков вместе: высокий V, падение S относительно окружения, положительный выброс яркости, клип канала; маска расширяется.
     - Тень: подавляем широкие направленные градиенты; снижаем уверенность у сильных кромок яркости без кромки цвета или рельефа.
     - Тёмную прожилку от узкой тени по одному фото не отличить, поэтому уверенность снижается плавно, без жёсткого да/нет.
  7. **Запекание с приоритетом фото.** Вес текселя = уверенность (угол, обрывы глубины, край силуэта, якобиан UV, гейты выше), растушёвка в 3D по поверхности.
     Сшивка в градиентах — по идее Texture Consolidation.
     Считается на видеокарте в том же воркере после `unproject`, на той же форме и развёртке (цель ≤ 10 с на товар).
- **А3 · только достройка невидимого (позже, платно, своя реализация).**
  - Порядок: уверенные пиксели фото обратно проецируются на частичную текстуру → рендер её в 6 камер MV как prior → repaint_mask = 0 на надёжном, мягкий переход, 1 на неизвестном.
  - Запекание — с уверенностью, иначе пять равных видов снова размоют якорь.
  - «Фото 3/4 сразу в ортовид 0» — неверно геометрически.
  - `sdedit` из VecSet брать нельзя (нет лицензии), в официальном MV-Adapter его нет.
  - Диффузия не гарантирует сохранить точные прожилки и раскладку; реальные пиксели фасада держит А2, А3 — только для невидимого.

## Мерка пользы (три уровня)
1. **Эталон — только доказательство пользы.** Товары с фото 2 другого ракурса: красим по фото 1, меряем ΔE00 и pattern_grad_ncc в камере фото 2. Плюс дубли и синтетические каталожные рендеры с известным альбедо.
2. **Безопасность — на каждом товаре, это гейты автоприёма:**
   - **совпадение силуэта:** IoU ≥ 0,85; ошибка границы — медиана ≤ 0,5 % габарита, p95 ≤ 1,5 %;
   - **подгонка:** p95 сдвига ≤ 2 %; ошибка «туда-обратно» p90 ≤ 1–2 px; якобиан без складок;
   - **совпадение рисунка до подгонки:** локальная NCC градиентов ≥ 0,5; проверяется на отложенных патчах, которые не участвовали в подгонке;
   - **принятая площадь** ≥ 15–20 % видимого фасада, иначе отказ («обработано 3 %» = не обработано);
   - **швы:** энергия шва на 0/30/45/60°;
   - **тень и блик не приклеены:** кромки альбедо стоят при двух светах;
   - **цвет:** ΔE00 низких частот не хуже чем +1; pattern_grad_ncc +0,10, p10 не падает.
   Это стартовые числа пилота (Codex), не готовые боевые пороги.
3. **Санитарные (не доказательство):** ΔE00 и pattern в камере фото 1, энергия градиентов, согласие 6 видов MV.
4. **Глазами:** полноразмерные кадры 0° и 45° отдельными файлами (TG 1319), обязательно диваны с обивкой и кресла (TG 2213); каждый кадр, который уходит владельцу, смотрит проверяющий.
5. **Числа для решения:** доля автоприёма, отказы по причинам, секунды на товар, размер GLB.
