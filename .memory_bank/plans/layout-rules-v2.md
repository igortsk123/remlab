## Цель
Полный пересмотр системы правил расстановки на основе снятых дизайнерских priors
(18 804 сцены, `/test/priors/`) и вердиктов владельца по референсной десятке. Ядро смены
парадигмы: от «предмет ставится по своим правилам» к «комната делится на ФУНКЦИОНАЛЬНЫЕ ЗОНЫ,
предмет живёт в своей зоне». Beam остаётся инженером (hard-правила неприкосновенны), priors
и зоны — новым здравым смыслом скоринга.

## Источник задачи
Вердикты владельца 2026-08-07 по `/test/layout10/` (сет 59 и др.):
1. стол обеденный ЗА диваном — нелогично; к столу обязаны идти стулья (стол-«сирота» запрещён);
2. стеллаж/витрина ВНУТРИ обеденной зоны — хранению там не место;
3. «где-то диван не напротив ТВ» — ориентация диван→ТВ обязана держаться жёстче.
Плюс: «делай план улучшений от полученных датасетов, полностью пересматривай систему правил».

## Этапы

### ~~R0~~ — снят (решение владельца 2026-08-07: «мои вердикты — более комплексно»)
Точечные вердикты НЕ хардкодим отдельным слоем — их закрывает системно R1 (зоны: стол-сирота,
хранение в зоне, «за спинкой») и R2 (ориентация диван→ТВ из priors). Вердикты остаются
ПРИЁМКОЙ: референсная десятка + сет 59 в приёмочном наборе страницы.

### R2-пре — качественная пересъёмка калибровок (вскрыто перепроверкой 2026-08-07)
Первое извлечение имело две методологические ошибки: (1) 26% пар «диван↔столик» — ПЕРЕСЕЧЕНИЯ
рамок (gap=0 занижал медианы); (2) конвенция yaw в экстракторе сдвинута на 90° (пик «ориентации
к стене» на 75–90°) — метрики «спинка к стене» мерились вбок. Пересъёмка v2: автокалибровка
конвенции (4 гипотезы facing, выбор по максимуму «диван спинкой к стене»), gap только по
непересекающимся + overlap-доля отдельной метрикой, ПОЛНАЯ матрица пар топ-ролей,
ко-присутствие ролей в комнате (для R3-состава), счёт предметов и хранения по площади.
Страница v2 — с блоком «Выводы для правил» простым языком (прошлую подачу владелец не понял).

### R1 — функциональные зоны как первоклассная сущность движка
- Зона = связный регион полигона комнаты: РАЗГОВОРНАЯ (диван, ТВ, столик, кресла, пуф, ковёр),
  ОБЕДЕННАЯ (стол+стулья, у окна по priors/референс-планам), ХРАНЕНИЕ (периметр, вне зон),
  ПРОХОДЫ (дверь→зоны). Разбиение — до расстановки предметов, по полигону (совместимо с Э8
  [[layout-polygon-rooms]]: зоны = регионы произвольного контура).
- Предмет ставится ТОЛЬКО в свою зону (hard); скоринг зоны — связность и не-пересечение.
- «За спинкой дивана» = граница разговорной зоны: там консоль/низкое (канон) или ПРОХОД,
  но не обеденная зона и не хранение выше 90 см (обобщение TALL_BEHIND_SOFA).

### R2 — priors → шкалы и score-термы (данные вместо интуиции)
Из `layout-priors.json` (родословная: только 3dfront-дизайнеры; infinigen — не источник):
- диван↔столик: вилку 36–50 пересмотреть к p10–p90 данных (5–65, медиана 25) — РЕШЕНИЕ
  ВЛАДЕЛЬЦА по таблице сверки (данные плотнее канона);
- диван↔ТВ 180–300 — подтверждена, оставить; столик↔пуф ≤60 — подтверждён;
- НОВЫЕ пары в score: кресло↔столик, диван↔кресло (p50 35), диван↔ковёр;
- wall-affinity по ролям из `wall_gap|*`: у кого спинка к стене всегда, кто плавает;
- Г-диван: prior p50 95 см до угла — ослабить жёсткую притяжку в угол (совпадает с нашим
  компромиссом «ТВ важнее угла»), финальная вилка — вердикт владельца;
- ориентация к ребру стены (`wall_align`) — включая косые стены (Э8);
- спальня (задел): кровать↔тумбочка p50 5, симметрия p50 5 — готовые правила для трека спальни.
- Термы `learned_spatial_priors` в score() с весами; калибровка весов — вердикты владельца
  по референсной десятке (страница-конвейер).

### R3 — зоны в компоновке сетов (состав тоже по зонам)
- compose2: состав сета проверяется НА ЗОНЫ до сборки: есть стол ⇒ есть стулья (и наоборот
  стулья без стола вон); хранение — количество под площадь периметра, а не «сколько влезло»;
  сет 113-класс (полкомнаты пусто) → большие комнаты обязаны получать обеденную зону или
  второй смысловой центр. Связь с [[MASTER-catalog-ai]] К5 (зоны, оценка набора).

### R4 — перегон, страница, калибровка
- Полный перегон 126 + референсная десятка на страницу; DUMB_T и веса — по вердиктам
  владельца (итерация «вердикт → подкрутка → перегон» до сходимости);
- еженедельный полный прогон уже в кроне (понедельник).

## Критерии приёмки
- [ ] Антипаттерны владельца невозможны (тесты): стол за диваном / стол без стульев /
      хранение в обеденной зоне / диван мимо ТВ — HARD-провалы.
- [ ] Перегон 126: hard-чистых не меньше, чем сейчас (98), «глупых» по DUMB_T — вдвое меньше.
- [ ] Референсная десятка: вердикт владельца «логично» ≥8/10.
- [ ] Тесты ядра зелёные; детерминизм; время ≤ +30%.
