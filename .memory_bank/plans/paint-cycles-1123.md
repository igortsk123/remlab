# Круги покраски — до «свет в конце туннеля»

**Правило владельца (голос 23.11 14:35–14:37, TG 2256/2258/2260):** промежуточные результаты ему не слать. Каждый прогон: снимки всех
моделей со всех сторон → разбор каждой, все косяки записаны → этот план (как делали + косяки) → GPT (codex-sol) → план исправления →
проба → снова круг. Ссылку владельцу — только когда выполнены **5 признаков**: (1) нет заплаток; (2) покраска чёткая; (3) где должно
быть однотонно — однотонно; (4) рисунок перенесён; (5) нет жёстких недокрасов, переходы цвета плавные. «Ускоряйся».

**Мерка выхода:** доля товаров, прошедших все 5 на всех сторонах (автооценка T-37 + глаз директора на каждом), на 29 из пакета и на
отложенной выборке. Цель для показа — ≥80 % на 29 и без «жёстких» дефектов у остальных.

## Круг 1 (23.11, 13:50–14:45)

**Как делали.** Пакет 29 (код 9719dfff, UltraTex выкл — ADR-0466): форма TRELLIS.2 → поза → 06 фото на атлас + `tone_oblique` →
07 «один материал — один тон» + случайное зерно → шов → 08 материал. Листы со всех сторон браузером, разбор глазами —
`~/remlab-logs/diag29-1123.md`.

**Косяки (29):** чисто со всех сторон 2 (18286, 3499). 27 — невидимые стороны 2–3 плоскими тонами с резкой границей (заплаты);
рисунок на невидимом не перенесён (вазы, кресло с сакурой, узорные шкафы); белые блики на стыках (08 глянец — исправлено 43aa7905);
светлая кромка вдоль щелей (06, ~1 % лица); узор стирался в копии для сайта (исправлено ec7dbdb7, 2048); рельеф лица на заду
(форма: 9463, 13224, 114667_1399); столешница торцом / верх не мерится в 09 (T-32).

**Найденные причины (замеры рабочих):** зад 10887 — 99,5 % synth из `tone_oblique` (06), 07 держит их как известные (р.5 T-28);
запрет по ребру не помог (плотная сетка, 491 тыс. граней); запрет по нормали источника cos≥0,7 — зад 10887 synth 99→17 %, «не одним
тоном» 23→10 %, диван 114667 36→20 %; регресс 9463 — зад тёмно-рыжий (L 77→26): 07 берёт тон чужой группы. Правка «известного
поглощения» UltraTex-рельефом по черновику (632b06a9) — эффекта нет (р.1). Блики стыков — roughness 0,38 на всём (р.2).

**Совет GPT (codex-sol, `~/remlab-logs/codex/ideal-1123-a.md`):** главное — в 07 «известное» = только фотодоказанные тексели;
тон `tone_oblique` — кандидат низкого доверия, паспорт материала вправе перекрасить (`tex_visible.py:695/1045`,
`tex_fill.py:2674`, `surface_passport.py:625`). Зерно сейчас — случайное поле с амплитудой фото (`surface_passport.py:641`) — не
перенос рисунка. Родная текстура TRELLIS.2 — дешёвый кандидат невидимого (снять низкие частоты, перенести тон фото, проверить чужие
детали). Генерация видов сзади — только эскалация для узорных. Оценка: кадры всех сторон + маска происхождения в кадре; p95 скачка
ΔE00 внутри зоны (~8–10), энергия фактуры против фото-образца 0,5–1,5, незакрашенное 0, ложные ручки/двери на заду — бинарно;
VLM — только калиброванный второй голос.

**Критическая оценка совета.** Согласен с главным: совпадает с замером р.5 (synth держится в 07). Не согласен «не поднимать угол»
полностью — v2 по нормали источника уже дала 99→17 % на заду; берём оба: v2 + отдельное происхождение. Риск: без synth-тона 07 красит
зад тоном чужой группы (9463) → нужен выбор группы по геометрии панели. UltraTex — не возвращаем без новой A/B (ADR-0466: помог 2,
навредил 9); родная текстура TRELLIS — пробуем как кандидат в круге 2.
