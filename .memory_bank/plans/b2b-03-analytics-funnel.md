## Цель
Для каждого ЖК видно: сколько отправленных ссылок открыли, сколько меняли мебель, сохранили,
поделились, обратились к менеджеру, дошли до встречи и до сделки. Цифра «в N раз реже отказываются» берётся
из этих данных, а не из слайда.

## Источник задачи
Презентация: «покупатели в 4,5 раза реже отказываются от сделки после заявки». Обследование 13.10:
на `/demo` аналитики нет (ни PostHog, ни Метрики), на `/flat` только просмотры (`app/layout.tsx:49-57`,
`components/MetrikaPageviews.tsx`); PostHog выключен без `POSTHOG_KEY` (`lib/analytics.ts:5-22`);
статусов встречи/сделки нет; A/B нет.

## Мерило (владелец 13.10, В5; уточнено ADR-0252)
Мы измеряем принятие и действия (открыл, выбирал, обратился); сделки считает застройщик по своей статистике
менеджера (например, 15 вместо 10 за три месяца) — ему и отчёт. По оценке владельца ≈ 6 сделок на 100 лидов
(лид = состоявшийся контакт); для питча «+1…3».

Цифра «4,5 раза» — из анализа A101, рекламная. Рабочая гипотеза: +1 сделка на 100 лидов (состоявшихся контактов с менеджером; знаменатель один для книги, ADR и планов), а не на 100 прошедших показ
(РФ ≈ 15 млн ₽, UK ≈ £300k). События привязаны к персональной ссылке (`b2b-02`); «встреча/сделка»
ставит менеджер.

## Скоуп — что входит
1. **Словарь событий** (один файл `lib/analytics/events.ts`, читают и Next, и демо-страница):
   `designer_open`, `variant_view`, `item_swap`, `item_move`, `collection_save`, `share_link`,
   `manager_contact_click` (консультация/ипотека), `alternative_request`, `3d_open`, `3d_save`; у всех —
   партнёр/ЖК/квартира/`send id`/стиль/язык.
2. **Демо-страница:** лёгкий клиент событий (Метрика `reachGoal` + наш `POST /api/events` в БД —
   чтобы не зависеть от внешнего сервиса и блокировщиков); без ПДн, с согласием на cookie (`b2b-04`).
3. **`/flat`:** те же события через `lib/analytics.ts`.
4. **Воронка отправок:** статусы из `b2b-02` → таблица «отправки по ЖК и статусам» → страница отчёта застройщику по ссылке с ключом (ADR-0254): сколько людей заходили по ссылкам его менеджеров, какая активность, до каких шагов доходили, за неделю и нарастающим итогом; плюс строка в дайджесте владельцу. Считаем по отправкам, не по людям. Наш отчёт — об использовании (открытия, выбор,
   обращения, статусы); вывод об эффекте в сделках делает застройщик по своей статистике, «было 10, стало 15»
   не выдаём за доказанную причинность.
5. **Отчёт для питча:** SQL/скрипт «открыли → заявка → встреча → сделка» по ЖК, с датами; честная
   формулировка на слайд.
6. PostHog: решить — включить (ключ, хост; для РФ — self-host или отказ из-за трансграничной передачи,
   `b2b-04`) или оставить Метрику + свою таблицу. Рекомендация: своя таблица + Метрика.
