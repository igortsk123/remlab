4. Шаг 8 → `part_grain`: пол зерна 1,4 L; `photo_sigma_min` = 0,8 (одно число).

## Критерии приёмки
- Все флаги выкл → выход побайтно равен main на эталонах (sha до/после).
- Все флаги вкл → sha итоговых GLB шести товаров = таблица `frozen-set.md` (или разница объяснена строкой).
- Тест «флаг меняет выход» на каждый ключ; тесты в job CI своих файлов; `test_tmp_hygiene`, `conveyor_check`, `conveyor_ids --block` зелёные.
- В main — выключенным. Включение на 29 — отдельно, только с замером «до → после» на тех же 29.
