## Цель
На /calc/plitka у каждой стены можно добавить проём(ы) — окно/дверь (Ширина × Высота);
их площадь вычитается из расчёта. Без общей галочки: ввёл проём → вычитается.

## Источник задачи
Владелец 2026-07-31: «нужна возможность добавить проём к каждой стене; это было раньше,
не знаю, почему убрали; мне это не нравится; нужно чтобы учитывалось в расчётах».

## История (почему пропало) — восстановлено по git/ADR
- ADR-0022 (21.07): проёмы у плитки/краски по галочке «Учесть окна и двери» (дефолт выкл) +
  у каждой стены «+ добавить проём».
- ADR-0027 (22.07, коммит ab49573): UI проёмов убран ЦЕЛИКОМ с формулировкой «путали и давали
  ложную точность». Модель данных НЕ трогали: `Surface.openings`, `room.countOpenings`,
  вычет в `geometry.ts`/`formulas.ts` и тесты живы до сих пор.
- Владелец решение 0027 не одобрял как окончательное → возврат = откат ADR-0027 (новый ADR-0035).
Вывод: восстановление — почти чистая UI-работа, ядро готово.

## Решение UI (моё, на утверждение)
**Кнопка с плюсиком у каждой стены, БЕЗ общей галочки.** Путаницу в ADR-0027 создавала
именно двухступенчатость «галочка наверху + кнопки внизу»: галочку не замечали или не понимали.
Кнопка под полями стены — «+ окно или дверь» — самообъясняющая:
```
│ Стена 1                        удалить
│ ДЛИНА, М        ВЫСОТА, М
│ [3______]       [2,5____]
│   Проём 1                      удалить
│   ШИРИНА, М     ВЫСОТА, М
│   [0,8____]     [2______]
│ + окно или дверь
```
- Проёмов у стены сколько угодно (дверь + окно). Тип не спрашиваем — на площадь не влияет.
- Есть проёмы → в результате «Площадь: 8 м² (без проёмов; всего 10 м²)» — вычет ВИДЕН
  (лечит «ложную точность» из ADR-0027 показом, а не скрытием).
- Галочка `countOpenings` в модели остаётся (совместимость localStorage), но UI её не ставит:
  формула для плитки/краски переходит на «вычитаем всегда, когда проёмы введены» (net; без
  проёмов net == gross — поведение прежних расчётов не меняется).

## Скоуп — что входит
- `SurfaceEditor`: у каждой стены список проёмов (Ширина×Высота, «удалить») + кнопка
  «+ окно или дверь». Только плитка (и краска — вопрос 2).
- Формулы: плитка/краска — площадь net всегда (проёмы вычитаются фактом ввода).
- Обои НЕ трогаем: расчёт полосами, проёмы в запас, иконка-дверь объясняет (ADR-0021).
- Тесты: «проём вычитается» (без галочки), «нет проёмов → gross», golden-числа.
- ADR-0035 (возврат проёмов, откат ADR-0027) в `decisions.md`.

## Скоуп — что НЕ входит
- Обои/ламинат (у ламината пол — там «исключённые зоны» уже есть).
- Тип проёма (окно/дверь/арка), количество-множитель — не возвращаем (упрощение из ADR-0022 верное).
