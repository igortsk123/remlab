- [ ] **А. Замер покрытия:** живые готовые модели кроватей по ширине и стилю; список пустых ячеек для волны кроватей (без узких 90 см, решение TG 1377).
- [ ] **Б. Адаптер комнаты:** все спальни всех этажей из `floorplanResult` (`contracts/trial.ts`) → модель комнаты (контур, проёмы, размеры, этаж); id комнат и вариантов уникальны в задании.
- [ ] **В. Подбор:** назначение и ширина кровати по площади; только реальные товары с моделью; наборы по стилям подбираются под эту комнату и проверяются решателем. Готовую расстановку другой квартиры по совпадению стиля не брать.
- [ ] **Г. Исход по комнате:** готово / частично / отказ + текст; масштаб не подтверждён — отказ, без подгонки мебели; запросов к агенту нет.
- [ ] **Д. Выход:** варианты спален — в общую версию данных задания (`trial_bundle`), без названий и ссылок магазинов; проверка очисткой вывода.
- [ ] **Ж. Заполнение и повторный замер:** волна кроватей (запрет снят владельцем 09.11, TG 1387) → замер покрытия по ширине 120–180 см и стилю → пустые ячейки добирать следующей партией → прогон на новом плане. Цель — мебель в каждой спальне, куда по площади входит кровать; отказ — только когда подходящего товара действительно нет.
