## Критическая оценка V5 (обязательный раздел — правило владельца)
Проверено против кода и интернета (10/10 arXiv-ссылок существуют; у Architect-Ant заявленные
«best-of-K / fail-and-fix» абстрактом не подтверждаются). Полный факт-чек — `referee-v5-brief.md`
(корень репо, передан владельцу для рефери).

**Принято** (подтверждено кодом):
- Зависимость «кресло 2 только от кресла 1» реальна — `planner/candidates.py:576-579`
  (`return []` без первого кресла), фильтр парных кандидатов по подстроке note («пара» /
  «фланг камина») — хрупкая управляющая логика на русских строках.
- Метрика волны — retention группы, а не clean-rate (95% уже; но кресло дропается в 29% сцен).
- Камин-дрифт: гейт 35° (`candidates.py:541`), валидатор 35°/45° (`validate.py:1028`) при
  тексте нарушения «75°» и комментарии «50°»; secondary-зона 75°/20–280 (`validate.py:323,335`)
  при докстроке «45°».
- CompoundCandidate/joint-группы — детерминированно, ДО любого AI.
- AI — только bounded (1 вызов/сцену, K гипотез, сидер ветвей существующего zoned), только если
  измеренная нужда останется. Валидатор всегда поверх.

**Отклонено / рескоп** (с пруфом):
- «Воспроизвести baseline» — уже есть (`tools/scout/acceptance_run.py`, 252 сцены, resume).
  Реальная задача — довести перегон после ADR-0078 (падал: TIMEOUT + крэши на сетах 56–72).
- «61 код» → фактически 58 (`rules/severity.json`), реестр закрыт тестом.
- Legacy sofa-table — уже вычищен (T6/W2); остался хвост `planner/llm_planner.py:74`.
- chair pull-out — уже есть как клиренс (`clearances.py:79`, ACCESS_BLOCKED H0).
- UNREACHABLE bottleneck-диагностика — полезно, но 1 сцена из 252 → низкий приоритет (L6).
- CP-SAT/MIP, SFT, fail-and-fix-обучение, DPO, VLM-планнер, полная Constraint IR, инжест
  Panero/Time-Saver — отклонены до доказанной необходимости (гейты в L5/L7).
