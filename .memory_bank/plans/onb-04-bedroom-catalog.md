## Цель
`room_catalog` закрывает все назначения спален: + детские кровати по возрасту, рабочие столы и стулья, диваны-кровати. Честные
габарит и спальное место; признак ткани обивки (спальня и гостиная), проверенный на выборке; замер годного по ролям и магазинам.
Вход для `onb-05` и `onb-06`.

## Источник задачи
Метаплан `onb-00` § «Метаплан — подпланы» (волна 1), вопросы 2 и 4; этап 2 п.1 `b2b-10`; ⚑1 владельца 05.11 «спальни — полностью».
Рамка — ADR-0330 (`onb-0A-contracts` п.2, п.5): каталог в изоляции, глобальный `DENY` в `category_map.py` НЕ снимаем, включение — флагом.

## Что есть (сверено 05.11)
- `room_catalog` (ADR-0279; почему не `products` — `room_catalog.py:8-10`), ночной шаг `refresh_daily.sh:431`. Роли — точные категории +
  правила по названию `rules/bedroom-roles.json` → `room_catalog.py:role_of`; детское отсекается всегда (`room_catalog.py:56`);
  бра, лампа, ковёр, шторы — из гостиной (`_about`).
- Кровать — `bed_dims.py:parse` (рама ≤ +70/+60 см, `bed_dims.py:24`), линейка — `room_catalog.py:line_dims`; прочее — `dim_resolver.py:resolve` (`room_catalog.py:72`).
- Показ — `room_catalog.py:shown_where` (цена, фото, свежий фид), живость фото не проверяется. Демо берёт ВСЕ роли
  (`flat215_demo.py:bedroom_catalog`, по умолчанию 8 на роль — `:1047`): новые роли сами уйдут в `D.bedroom_catalog`.
- Диван-кровать — роль «диван» в `products` (`category_map.py:50`, урок 467); в `room_catalog` запрещён (селфтест `room_catalog.py:214`).
- Ткань не хранится; «Обивка» читает только стиль (`style_score.py:42`). Запас 14.10: кроватей 1 367, шкафов 814, комодов 640, тумб 266
  (`core/bedroom.md`); детских кроватей, столов, стульев — не мерили.

## Скоуп — что входит
1. **Назначения ролей** в `rules/bedroom-roles.json`: роль → назначения (пара · один · детская 0–3 · 3–12 · подросток · кабинет · гостевая);
   `room` остаётся `bedroom` (`room_type` по ADR-0330), назначение — свойство роли, не новая комната.
2. **Новые роли** (точными категориями + правилом по названию): кроватка (до 3 лет), кровать детская (спальное 70–90), кровать
   подростковая (90–120), стол рабочий (письменный, компьютерный, растущая парта), стул/кресло рабочее, диван-кровать (из веток диванов,
   только со спальным местом в параметрах/названии). Детское — ТОЛЬКО в детские роли; остальные роли фильтруют его как сейчас.
   Глобальные `DENY`/`KIDS` в `category_map.py` и роли `products` не трогаем.
3. **Флаг:** новые роли загружаются, но выключены (`roles_enabled` в правилах) — `shown_where` и `bedroom_catalog` берут только
   включённые; включает ведущий после Т6.
4. **Размеры:** пороги рамы для кроватки и детских — по замеру (не переносить 70/60); диван-кровать — спальное место отдельно от
   габарита (как `dim_resolver.py:transformer_dims`); у стола — высота (растущая парта — диапазон).
5. **Ткань обивки** — новый модуль и своя таблица (ключ товара + откуда: `products`/`room_catalog`): тип (велюр, рогожка, букле, шенилл,
   флок, микровелюр, жаккард, экокожа, кожа …), «антикоготь», «легко чистится»; источник (параметр/название) и версия правил.
   Для гостиной — диван, кресло, пуф; для спальни — кровати с мягким изголовьем, диван-кровать. Пометки «питомцы»/«дети» — по нормам
   с источниками. Никто не читает признак, пока выборка не принята.
6. **Замер** (`room_catalog.py --report` расширить): роль × магазин — в свежем фиде, с ценой, с живым фото (проверка скачивания
   заголовками `flat215_demo.py:grab`, урок 468), с полными размерами, с честным габаритом (кровати).
7. **Ночь:** шаг `room_catalog` грузит новые роли сам; шаг ткани — после него, за флагом; `WARN:` только по разобранным находкам (урок 470).
8. **EN:** `data/names-en-dict.json` `roles`/`types` — кроватка, детская кровать, рабочий стол и стул, туалетный столик, диван-кровать.

## Критерии приёмки
- [ ] Гостиная не изменилась: `products` (роль × товар) до/после равны; `category_map.py` `DENY`/`KIDS` без правок; живой банк тот же
- [ ] Отчёт роль × магазин: в продаже · с живым фото · с полными размерами · с честным габаритом. Ориентир (14.10): кровать ≥ 1 000,
      шкаф ≥ 600, комод ≥ 500, тумба ≥ 200; каждая детская возрастная группа, стол и стул рабочие, диван-кровать ≥ 50 моделей с фото
      и размерами — иначе «мало» с причиной
- [ ] Кровати: ≥ 70 % показываемых с честным габаритом; 0 «габарит = спальное место» среди допущенных к расстановке
- [ ] Детское: 0 детских названий вне детских ролей (тест на 30 названиях + живой счёт)
- [ ] Ткань: точность ≥ 90 % на 50 (разметка ведущего), покрытие ≥ 60 % мягкой мебели; ниже — признак помечен «не использовать»
- [ ] Флаг выключен → `D.bedroom_catalog` побайтно как до; включён → новые роли в данных
- [ ] Ночь: шаги `ok|warn`, новых тревог без разбора нет; `--selftest` `room_catalog`, `bed_dims`, `upholstery` зелёные (CI `scout-selftest`)

## Риски
- Детское протекает в спальню пары/гостевую (как подушки demo-24) — правило «детское только в детских ролях» в одном месте.
- Орматек — габарит линейки (`bed_dims.py:12`); у кроваток иные пропорции рамы. Диван-кровать в двух таблицах — расхождение цены.
- Ткань: описание врёт (урок 469), «Обивка» пуста у части магазинов → честное «неизвестно».
