## Цель
У диванов и кресел divan.ru глубина берётся из карточки («Размеры: Глубина габаритная»), а не пустует; 30 сетов банка с такими
диванами снова расставляются (экзамен set58/77/78 — OK); состав сетов не меняется.

## Источник задачи
Разбор FAIL экзамена после demo-31 (урок 548, отчёт рабочего T-20261102-01/7). Владелец 03.11 TG 103 «А» — разобрать с Codex и принести
план. Разбор 04.11 (ведущий common + Codex `.claude/tmp-chk/codex-sofa-depth-answer.md`, проверено по коду):
- 36 из 126 сетов с диваном d=None, это 8 угловых товаров: 6 divan.ru (30 сетов) и 2 «Кинг Твин» (6 сетов).
- Причина: `tools/scout/dim_resolver.py:42` DIM_KEYS для d знает у divan.ru только «Размеры: Ширина габаритная» (комоды);
  у диванов/кресел поле «Размеры: Глубина габаритная». Раньше дыру закрывал приор роли; 22.10 коммит 51193d71 (Н6, `dim_prior.py:183`)
  снял глубины без источника → `footprint.require` (`tools/scout/footprint.py:77`) → DimsUnknown.
- Лечение `--enforce-contracts` тут не лекарство: оно меняет или снимает диван (`sets_incremental.py:866`); предохранитель 25 % не трогаем.

## Скоуп — что входит
1. Алиас d: порядок «Глубина*» → «Размеры: Глубина габаритная» → «Размеры: Ширина габаритная» (только shop 112923, если SQL покажет
   ключ у других магазинов); `HASH_VERSION` 7→8 + новый `RULES_FINGERPRINT` (`tools/scout/load3.py:47`); тест на оба ключа; selftest.
2. Сухая проверка до записи: SQL Codex (охват по магазинам/ролям; ожидание ≈ 439 товаров с ключом, ≈ 353 со сменой геометрии — 316 диванов,
   37 кресел; у шкафов/комодов/столов ключа нет), список d_cm=null.
3. Бесплатный `load3` → `dim_prior --calibrate/--apply`; у 6 банковских SKU `d_cm` есть, `dims_evidence.d.source=param`.
4. Банк: снимок `sets3.json`, синхронизация размеров (`sync_metrics`/`catalog_media`) на КОПИИ, diff — меняются только d/fp, SKU те же;
   dry-run `--enforce-contracts --roles диван` без `--apply` (ожидание: замен нет — конверт дивана по ширине, `sets_incremental.py:288`).
5. Пересчёт сцен 30 затронутых сетов бесплатно (+ set58/77/78), `bank_invariants`; зелёное → копия в банк.
6. Дефект конвейера (Codex): правка только размеров не пишется в `set_changes` → `resolve_affected.py:38` не пересчитает сцены сам.
   Записать геометрию в журнал (reason `dims_changed`) — или отдельный план, если правка шире 1 файла.
