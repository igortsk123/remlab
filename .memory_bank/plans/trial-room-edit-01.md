## Цель
На «Плане квартиры» тура пробы: подпись каждого помещения — по центру; у помещений без подписи на листе — название по правилу
владельца; человек может поправить название и размеры (или площадь) любой комнаты — 3D этой комнаты перестраивается сам, мебель и
фото сами не запускаются.

## Источник задачи
Владелец 10.11: TG 729 (снимок плана тура: «Туалет», «Лестничная площадка», «Санузел при спальне» у края, «Помещение» мелко) — «по центру
помещения везде подписи; каждое помещение — возможность отредактировать название и площадь; отредактировали площадь — автоматом
перестраивать 3D, генерацию автоматом не запускать». TG 734 (голос) — пересчитывать только комнаты, чьи габариты изменились на ≥ 10 см;
названия: известное — как есть, неизвестное — «Неизвестное помещение»; без подписей: самое большое — гостиная, самое маленькое — туалет,
ещё одно ≤ 1,5× туалета — ванная, следующее по размеру после них — кухня, остальные — спальни; не подходит — «Неизвестное помещение»;
площадь — примерно, если известна площадь всей квартиры, иначе не писать; человек меняет название, габариты (→ площадь) или площадь
(→ габариты по пропорциям). Это сводка 2, строка Н6 (новое, не из ночного плана).

## Скоуп — что входит
**Е1. Подписи по центру** (только `index.html`, демо не меняется — проверка пиксель-в-пиксель /demo). Среди свободных прямоугольников
с кеглем ≥ 0,9 от наибольшего брать ближайший к «центру» комнаты (точка внутри контура, наиболее удалённая от стен — polylabel по
контуру), кегль не ниже читаемого минимума; узкой комнате — подпись в одну строку (имя), площадь — второй строкой, если влезает.
**Е2. Названия по правилу владельца** (сборщик `tools/scout/trial_*.py` / `tools/floorplan/pipeline.py`, worktree):
- известное (подпись VLM) — как есть, с русскими регулярками типа (спальн|гостин|кухн|ванн|туал|санузел|коридор|прихож|холл) рядом с английскими;
- безымянные помещения этажа/квартиры — по рангу площади: наибольшее — гостиная; наименьшее — туалет; ещё одно ≤ 1,5× туалета — ванная;
  следующее больше — кухня; остальные — спальня, КРОМЕ помещений шириной < 1,5 м — «Коридор» (владелец TG 736); правило не применимо (например, одно помещение) — «Неизвестное помещение»;
  уже названные комнаты в ранг не входят (если гостиная подписана — правило «гостиная» не применяется), флаг `guessed_name`;
- площадь угаданной комнаты — примерно (знак «≈»), только если есть площадь квартиры (опора масштаба `area`/лист/текст); нет — без площади;
- «Неизвестное помещение» не обставляется, пока человек не переименует (владелец TG 738); угаданная «гостиная/спальня» — обставляется как сейчас (честная пометка «название угадано»).
**Е3. Правка комнаты** (страница + API + воркер):
- на плане тура тап по комнате → окошко: название (список типов + свой текст), ширина × длина (м), площадь (м²); меняешь площадь —
  ширина/длина по пропорциям; меняешь габариты — площадь пересчитана; кнопка «Сохранить»;
- сохранить → `POST /api/trial/<id>/room-edit` (ключ правки как у текста размеров, суточный лимит), правки хранятся отдельно
  (миграция 027, pg_dump перед) и накладываются после каждого перечитывания плана (иначе `ListingRebuild` их сотрёт);
- воркер, новый вид пересборки `edit`: комнаты, чьи габариты изменились ≥ 10 см, — пересчёт их контура и 3D; остальные — как были
  (их данные, мебель и коробки не трогаем); переименование — имя/тип без пересчёта геометрии;
- мебель и фото сами НЕ запускаются: изменённая комната получает статус «размеры изменены — Обустроить заново» (кнопка → подбор этой
  комнаты по запросу); переименованная в гостиную/спальню — «Обустроить» по кнопке; старая мебель изменённой комнаты не показывается;
- публикация — новая версия данных тура (как сейчас, `lib/trial/repo-bundle.ts`).

## Решения после Codex (`_intake/codex/room-edit-2026-11-10-answer.md`)
- **3D — одна коробка, 2D — как прочитан лист.** Коробка комнаты в туре строится отдельно из её контура (`trial_bundle.py:296`, `:791`,
  `index.html:2163`) — пересчитать одну можно. Общий 2D-план (`index.html:1660–1672`) после правки НЕ перерисовывает контур (наложение
  на соседей нельзя выдавать за точный план): контур прежний, подпись — новые имя/площадь, пометка «размеры поправлены». В окне комнаты
  3D — по новым размерам. Проёмы переносятся пропорционально по своей стене; оторвался/не встал → честный исход, правка сохранена.
- **Стабильный id комнаты** (UUID в canonical result), при перечитывании — сопоставление по панели, пересечению и центру, единственное
  совпадение; неоднозначно → правка не применяется молча, пометка «проверьте комнату». Правки — таблица (миграция 027) и наложение на
  canonical result ДО сборки (`ListingRebuild` заменяет result, `conveyor.py:518`, `:553`); публикация result+бандла — одной операцией
  (`lib/trial/repo-rebuild-worker.ts:93`), с `base_version`, под той же блокировкой «одна пересборка» (`db/init/024-trial-rebuilds.sql:42`).
- **Порог 10 см — по каждой оси от последней построенной геометрии** (не от прошлой правки); правка площади → обе оси пропорционально;
  площадь/bbox/`dims` пересчитываются согласованно (`pipeline.py:539`, `contracts/trial.ts:96`). Только имя — без геометрии, мебель цела.
- **Мебель одной комнаты по кнопке — новый путь:** база — текущий бандл, считается только выбранная комната, её `rooms_geo`/запись/
  варианты заменяются, остальные варианты не пересчитываются (сейчас `Rebuild` собирает весь бандл, `conveyor.py:388`, `:412`;
  `trial_bedroom.build` — все спальни, `:683`, `:701`); серверная проверка кнопки расширяется (`lib/trial/repo-rebuild.ts:23`, `:52`).
- **Фото после правки геометрии — выкл. у этой комнаты** (`photo_ok=false`): правка человека не подтверждает масштаб (`trial_bundle.py:666`) —
  вопрос владельцу, включать ли фото по его размерам.
- **Названия — ранг по всей квартире**, после `room_kind` и сборки всех панелей (не в `room_titles`); известная подпись важнее; явно общие/
  проходные (лестница, площадка) — не в ранг; сомнение → «Неизвестное помещение». Правило «гостиную не угадывать» (T-12, `trial_room.py:319`)
  меняется осознанно: угадывать по правилу владельца только среди безымянных, флаг `guessed_name`, в туре «название угадано — поправьте».
- **Подпись** — polylabel + прямоугольник кегля ≥ 0,9 max ближайший к нему; запасной режим, чтобы подпись была у КАЖДОГО помещения
  (сейчас `trFitLabel` может отбросить всю, `index.html:1741`): одна строка мелким кеглем по центру или выноска.
