## Цель
Черновая сцена гостиной выглядит опрятно и одинаково во всех трёх местах, где её видит покупатель: живая сцена в окне варианта
(`demo-01`, движок `lib/viewer3d`), квартира `/flat`, серверный кадр (`draft_render.scene3d_frame`). Белые стены — чистые и
«дорогие» (без серых пятен и полос), двери и окна — с рамами, откосами и подоконниками, одной геометрией для всех проёмов;
за окном — подставляемая картинка «вид из окна» (из карточки застройщика/ЖК, с запасным видом по умолчанию).

## Источник задачи
Владелец 14.10: «…сделай белые стены красивые и двери окна чтоб были аккуратные везде и вид из окна чтоб подставить можно
было». Контекст — черновой просмотр (3D и два ракурса) должен показываться сразу после замены, с красивой крутилкой
(требование уходит в `demo-02`).

## Что есть (сверено 14.10 по коду)
- `/flat` и живая сцена демо (тот же движок): окна и двери УЖЕ объёмные — `lib/viewer3d/openings.ts` (рама `WHITE_FRAME`
  0xf4f3f0, откосы `REVEAL`, стекло `GLASS` opacity 0.07, подоконник, две створки со средником; дверь — полотно + наличник +
  ручка, межкомнатная показана открытой; портал без полотна) — сделано по слову владельца 29.09 «вставь вид из окон…».
  Стены — `paint-white #f2f0ed, roughness 0.95` (`demo-scene.ts:liveApartment`), пол `#dcc7a6`; свет FlatViewer —
  environment + hemisphere + sun + fill + тени (`viewer.ts:195-227`). **Вида из окна нет**: за стеклом пусто/фон — окно читается
  как светлая дыра; углы стен без затенения выглядят плоско.
- Серверный кадр (ночные карточки, запасной путь, лист для GPT): numpy «clay» — окно = синий прямоугольник (108,166,208),
  дверь = коричневая панель (176,136,84) (`draft_render.py:1145`, `:89-93`), стены без материала, без AO — поэтому в кадрах
  `scene3d-*.jpg` стены серо-бежевые с «грязными» углами; промпт для GPT просит нарисовать «настоящее окно» словами.
- Паспорта отделки в данных нет: `data/flat3d/apartment.json` — комнаты и `openings` (kind/wall/offset/width/height/sill),
  материалы — только как опции каталога (`flooring`, `walls`); у `demo.json` (карточка застройщика) — ничего про отделку и вид.

## Скоуп — что входит
1. **Один паспорт отделки комнаты** в манифесте сцены (`contracts/scene-manifest.ts` из `demo-01`): цвет/материал стен, пола,
   потолка, плинтус; проёмы — тип (окно/дверь/балконная дверь), размеры, рама, откос, подоконник, направление открывания;
   вид из окна — ссылка на картинку + яркость/время суток. Источник — карточка квартиры/ЖК (`data/partners/*.json`,
   `b2b-06`), по умолчанию — наш набор (белые стены, дуб светлый, вид «город днём»).
2. **Стены.** В движке: материал «белая матовая краска» (`paint-white`) + мягкое затенение углов (SSAO в desktop-профиле или
   запечённая полоса у плинтуса/потолка в lite), environment с тёплым небом — чтобы белое было белым, а углы читались.
   В серверном numpy — та же палитра стен/пола/проёмов (вместо clay-синего окна и коричневой двери) и простая аппроксимация
   затенения углов (без GI); цвет стены совпадает ±ΔE 5 между браузером и сервером (тест по пикселям стены).
3. **Проёмы везде одинаковые.** Параметрика из `lib/viewer3d/openings.ts` — единственный источник; серверный кадр получает ту же
   геометрию (экспорт параметров проёма → простые коробки в numpy, или один раз собранный GLB-набор проёмов из тех же
   параметров) — проверка «браузер и сервер дают один силуэт проёма». Довести сами проёмы: балконная дверь, окно в пол,
   открывание двери по данным (`swing`), наличники снаружи комнаты.
4. **Вид из окна.** Плоскость-подложка за стеклом (`openings.ts` стекло 0.07 остаётся прозрачным, подложка — за ним, по размеру
   окна × 1,3, лёгкая дымка, яркость по времени суток); картинку задаёт застройщик в карточке ЖК (вид с этажа, по сторонам
   света) или мы (набор по умолчанию: город день/вечер, двор, парк — `public/scene/views/`). Та же подложка — в серверном кадре
   (проекция картинки в проём). Права на фото застройщика — чек-лист `b2b-04`.
5. **Приёмка глазами** (⚑ владелец): три кадра (окно варианта, `/flat`, серверный) на одной странице `/test/scene-look/`
   для 2 стилей; критерий — «одна комната, не три разные».
