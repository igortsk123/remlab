## Цель
Стены комнаты (/demo, туры, рендер Blender) — по стилю и под набор мебели: базовая стена стиля + акцент из ранжированных вариантов
или «без акцента» (ADR-0427). Поверхности правдоподобные: рельеф, разнотон, без видимого повтора.

## Скоуп — что входит
- Ш1 (рабочий 2, идёт): кирпич в Blender — ошибка вертикали тайла, высота/утопленные швы, разнотон, разрыв повтора, 2K-карты;
  та же проверка вертикали у всех стеновых материалов. Кадры до/после.
- Ш2: образцы — по 2–3 варианта на стиль (скандинавский, современный, минимализм, лофт, джапанди) × спальня/гостиная из CC0
  (ambientCG/Poly Haven: свежая отделка, без трещин и грязи); рейки/панели — геометрией. Рендер ОДНОЙ комнаты на образец, полный
  размер, по одному кадру. Показ владельцу — до любой выкладки (design-first).
- Ш3 (после «ок» владельца на образцы): данные `finish-cc0.json` — варианты стиль × комната с весами и отсевом (одна стена; не окно/
  дверь; свободная ширина; сильный акцент ≥ ~12 м²; яркая/пёстрая мебель → none/тон в тон), выбор воспроизводим для набора;
  `lib/configurator/accent.ts` читает новое правило; /demo, туры, экспорт Blender — одно правило. Телефон: цвет+normal 512–1024.
- Ш4: выкладка, живая проверка, ссылка владельцу + «что смотреть».

## Скоуп — что НЕ входит
- Переключатель отделки стен для покупателя и цены работ (позже, ❓3); пол — как есть.
- Неоклассика (только каталог). Кухня, прихожая, детская — позже.

## Критерии приёмки
- На кадрах нет «наклейки»: швы/рельеф ловят свет, нет повтора на стене 2,6–2,8 м, масштаб модуля реальный.
- В лофт-спальне по умолчанию нет красного кирпича; в каждой комнате ≤ 1 акцент, не на стене с окном; есть исход `none`.
- Правило в данных, без ID наборов/туров в коде; RU/EN для новых надписей; тесты на отсев и воспроизводимость.
