## Цель
Покупатель всегда первым видит улучшенное фото варианта. Ночное обновление после публикации и прогрева само переснимает фото
нейросети только у тех стилей, у которых нет фото ТЕКУЩЕЙ расстановки. Трата — не больше 50 ₽ за ночь, со счётчиком и строкой в утренней сводке.

## Источник задачи
Владелец 23.10 на вопрос «А — ночью сам, только изменившиеся, ≤ 50 ₽; Б — вручную по утрам»: «а».
Повод: правки мягкого и цветов сменили номер состояния у всех 5 стилей → окно варианта открывалось в «3D» (нет фото нейросети
этого номера, `tools/scout/flat215-demo/index.html:vwRealShots`), пока ведущий не переснял вручную (`tools/ops/demo-realistic.mjs`,
≈5–6 ₽ за стиль, 23.10 — 6 заданий ≈ 30 ₽: одно прервал деплой).

## Что есть (сверено ведущим)
- Ночь: `tools/scout/refresh_daily.sh` — `flat215_demo` → `demo_rt` → `flat215_publish` → `scene_artifacts` → `demo_warm` (только
  черновые эскизы 3D, бесплатно) → `demo_live`. Фото нейросети ночью не снимаются.
- `tools/ops/demo-realistic.mjs`: сухой прогон (кому нужно фото, доступно ли улучшение — `/api/draft/paid`), `--go` (один пробный),
  `--go --all` (все), стоп на первой ошибке, счётчик «снято / не вышло». Цены задания в выводе нет.

## Скоуп — что входит
1. Режим ночи в `demo-realistic.mjs` (например `--night --cap-rub 50`): снимает всех без фото своей расстановки, пока сумма не
   превысит потолок; цена задания — из фактического учёта (найти, где сервис улучшения пишет стоимость: трейс/журнал/ответ), если
   не найдена — консервативная оценка из настройки (обосновать в отчёте). Прерванное задание «результат неизвестен» считается
   потраченным. Ошибка → стоп, без повторов вслепую. Улучшение недоступно (баланс) → ничего не тратить, WARN.
2. Шаг `demo_real` в `refresh_daily.sh` после `demo_warm` (публикация прошла; если `flat215_publish` FAIL — шаг пропускается).
   Выход: строка `DIGEST:фото нейросети: снято N, не вышло M, ≈X ₽` (или «все стили с фото — 0 ₽»); сбой — `WARN:demo_real:…`.
3. Потолок и цена — в настройке (не зашиты в коде), 50 ₽ по слову владельца.
4. Самопроверка без денег (`--selftest`): выбор «кому снимать», остановка на потолке, учёт прерванного, пропуск при недоступном
   улучшении, пропуск после неудачной публикации; строка в CI-список, если там такие есть.
