## Источник
Владелец 12.11 TG 1064–1079 (ведущий common на паузе algor): подушки — мешами на диване «только в шаблоне предусмотри»; правило единое:
шаблон комнаты собран комплексно из доступных предметов, уже расставлен, свой набор на тип комнаты → товары стиля в размере −20…+10 % →
лучший по стилю на то же место. «Сначала полностью гостиную доделай, затем по аналогии любая комната». Путь — как спальня у algor
(ADR-0369: вопрос советнику → схемы в масштабе на реальных комнатах → показ → код). Образец схем — `tools/scout/bedroom_schemes.py`
(ветка `worktree-bed-schemes-1112`, 0570f4ae), понравился владельцу (TG 1076–1077). Принцип ролей стен — TG 1078.

## Что есть (сверено ведущим)
- /demo, 6 стилей гостиной: в 3D — диван, столик, ТВ-тумба, ковёр, торшер, стол + 2 стула, иногда стеллаж/пуф; декор — ваза, 2 картины, шторы;
  подушки ×2 — только список (`tools/scout/salad/asset_strategy.py:soft_roles`); люстры, пледа, кресла, кашпо, лампы нет ни в одном стиле
  (люстры нет в экспорте вовсе: `tools/scout/flat215_demo.py:DECOR_ROLES` без неё).
- Шаблоны — `services/planner-solver/rules/templates.json` (зоны крупной мебели; `decor` пустая), декор — отдельные постпроцессы.

## Совет Codex (`_intake/codex/2026-11-12-living-full-templates-answer.md`, 12.11 09:03; сверять по коду до решений)
- Цельный паспорт комнаты с зависимыми местами: носитель → предмет (диван → подушки, плед; столик → ваза; тумба/комод → лампа; стена над
  диваном/комодом → картины; центр зоны → люстра; окно → шторы; свободный угол → кашпо). «То же место» = тот же слот и якорь носителя, координаты
  пересчитываются от реального товара.
- 7 шаблонов + модификатор: LR-C1 компактная напротив · C2 вытянутая · C3 угловой диван · M1 диван+кресло · O1 кухня-гостиная с диваном-разделителем
  · O2 кухня-гостиная у стен · L1 большая П/Г · L2 два дивана (только Г/П) · X1 эркер/окно.
- Деградация: только целыми составами (столовая 6→4→2, торшер вместо лампы); «не поставился предмет — остальные оставили» — убрать.
- Дыры каталога: приставной столик 0, стенка 0, плед 2 SKU, шторы 5, торшер 3, подушки 11; меши — до ~37 проверок/генераций; люстры — привязать
  63 готовых меша, не генерить.

## Этапы
- **Т0 (бесплатно):** схемы гостиной в масштабе по образцу `bedroom_schemes.py` — комнаты демо 439×325, малые 14–15, UK lounge, «Этажи»
  кухня-гостиная, L 30 м², 35+; каждая: роли стен → шаблон → уровень → реальные SKU → результат; мелочи условными знаками + врезка носителя;
  матрица «комната → шаблон → почему». → показ владельцу ⚑.
- **Т1:** формат паспорта общий со спальней (согласовать с algor, ADR-0369) → солвер + экспорт мелочей на носители.
- **Т2:** меши мелочей — пробная партия (подушки, плед), потом очередь; люстры — привязка готовых; шторы — параметрические.
- **Т3:** тот же формат — прихожая, детская, кухня-гостиная (по ADR-0369).

## Критерии приёмки
Ни одного товара «в комплекте и цене, но без места в 3D»; каждый слот шаблона заполнен товаром стиля в конверте −20/+10 либо честный отказ уровня.
