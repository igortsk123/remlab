## Цель
Публично живыми остаются только «Посчитать материалы» и «Моя лаборатория»; остальные входы
закрыты аккуратными заглушками с бейджем «Скоро»; сайт вычищен от «нейросетевых» длинных тире.

## Скоуп
- `components/ComingSoon.tsx` (новый): бейдж «В разработке», текст раздела, хвост + CTA
  «Посчитать материалы» / «На главную». Тексты — согласованы в чате 2026-07-28.
- Заглушки за флагом `NEXT_PUBLIC_SHOW_WIP=1` (флаг ВКЛЮЧАЕТ старое содержимое; по умолчанию
  прод показывает заглушку; код страниц не удаляется): `/calc/remont`, `/start`, `/styles`,
  `/sovety` (+robots noindex на время заглушки).
- Главная: бейдж «Скоро» на плитках закрытых сервисов; CTA «Сколько стоит ремонт» с бейджем;
  блок «Как это работает» → рабочий путь калькулятора; тире → обычные формулировки.
- Шапка: пометка «скоро» у Дизайн/Стили/Советы и «Сколько стоит ремонт» (ведут на заглушки).
- `/calc`: баннер бюджета скрыт (тот же флаг), иконка обоев 🧻 → 📜.
- Свип длинных тире по видимым текстам app/ + components/ + lib (UI-строки).
- Директ: список «кампания → посадочная» игнорируем в коде; владелец кампанию «ремонт» не включит.
