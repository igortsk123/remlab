## Цель
Любой агент недвижимости (UK) заходит на лендинг → «попробовать бесплатно» → кидает фото или PDF планировки (+ необязательно текст
объявления с размерами) → конвейер сам: стены → 3D → расстановка по нашим шаблонам → реальные товары → фотокадры → ссылка на 3D-тур.
Ждёт с анимацией и таймером (цель ≤ 3 мин) или оставляет почту — ссылка придёт, когда готово.

пиши, подумаю». «Это общая большая задача, а 3D — подзадача». «Пиши мета-план и иди по нему».

## Решения владельца (TG 294, 09.11, голос) — поверх советов Codex
- Миграции БД — без вопросов на время пилота (pg_dump перед каждой — остаётся).
- Товары — как британские (демонстрация), БЕЗ названий магазинов и ссылок на магазины, как в демо (маска ADR-0328); ярлык «Illustrative demo
  products» Codex — не нужен; лендинг не публикуется, это показ человеку; UK-агрегатор (аналог Гдеслона) — позже.
- Кровати — столько, сколько нужно под спальни (T2), без привязки к сумме; кончатся деньги — сказать владельцу.
- Письмо агенту — ссылка на ЕГО персональное демо по его объекту (T9; для пилота — имеющийся `lib/leads/mailer.ts`).
- Асинхронно: ссылка открывается сразу, фото догружаются, до них — заглушка.

## Скоуп — НЕ входит
Оплата/тарифы для агентов (решение человека), личный кабинет, CRM-интеграции агентств, генерация новых мешей на лету, юр. тексты (TODO).

## Критерии приёмки мастера
- Агент с улицы: лендинг → загрузка → ссылка на тур, без ручной работы с нашей стороны, на 4 слепых планах владельца (D–G).
- Время «загрузил → тур» по таймеру шагов ≤ 3 мин (иначе — отчёт владельцу с узким местом и вариантами).
- Нечитаемое — честно помечено («не прочитал»), без молча неверных комнат.
- Стоимость одной пробы посчитана и в потолке, согласованном владельцем.
