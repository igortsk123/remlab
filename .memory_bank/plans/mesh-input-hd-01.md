## Цель
Во всех путях входа мешей фото берётся из `image_url_hd`, при его отсутствии — из `image_url`. Мелкая вырезка в меш не идёт:
статус `photo_too_small` с причиной и счётчиком. Решение владельца — TG 1792, 1861, 1864; решение записано как ADR-0452.

## Контекст
- Пробные входы (`tools/scout/salad/trellis/make_inputs.py` → `catalog_media.media()`) брали `products.image_url`: превью imgng 450 px.
  Находка T-20261119-93: у каждого товара в БД есть `image_url_hd` (оригинал магазина): диван 2560×1188, комод divan.ru 800×600.
- Часть конвейера уже читает `coalesce(image_url_hd, image_url)`: `mesh_quarantine.py`, `bedroom_enrich.py`, `pack_qty.py`.
  Боевой вход мешей нужно проверить по коду, ничего не предполагая.
- TRELLIS.2 сжимает вход до ≤1024 по длинной стороне, режет квадрат по маске и смотрит его в 512 и 1024 — поэтому мелкая вырезка
  растягивается и мылится (код microsoft/TRELLIS.2 @75fbf018, T-94).

- Адрес фото divan.ru подписан: запрос большего размера даёт 403 (T-93) — к задаче «оригиналы крупнее 800 px» (TG 1895, после выбора покраски).

## Шаги
1. Найти по коду ВСЕ места, где для мешей выбирается фото: Salad-конвейеры hunyuan/trellis, ночной шаг, `catalog_media`,
   `make_inputs`, перевыпуск. Составить список «файл:строка → какое поле».
2. Замер на выборке ~300 товаров мебельных ролей, бесплатно (только HEAD или частичная загрузка, с паузами):
   размер HD и размер вырезки. Распределение размеров и сколько товаров отсекут пороги 384 / 512 / 640 px по меньшей стороне вырезки.
3. Сделать одно общее правило выбора фото — одна функция, все места из шага 1 вызывают её.
   Сторож размера: порог — из конфига, значение предлагает директор по замеру, утверждает владелец.
4. Статус `photo_too_small` и счётчик в отчёте ночи. Предупреждение, если `hybrid_error` пишется не в inputs.json.
5. Тесты: выбор поля, сторож на пороге и рядом с ним, пустой `image_url_hd`. Каждый тест прописать в нужном job CI.

6. (после T-96, итог T-93/1 р.1) В боевую вырезку `_cut_chain` — шаг чистки островков по цвету тела (проба: trial/input-1119
   t93_input/clean_islands.py, на 20 товарах срезал 8, ножки целы) после prune_attached; явный запас поля вокруг предмета (комод divan.ru впритык
   к рамке 800×600). Сеть вырезки не менять: BiRefNet_HR в 5–9× медленнее без выигрыша, BEN2 хуже (след тени), RMBG — лицензия.

## Критерии приёмки
- Для каждого места из шага 1 доказано, что оно берёт фото через общее правило.
- Таблица замера с числом отсекаемых товаров на каждом пороге.
- Тесты зелёные, prepush зелёный, ID товаров в коде нет.
- Перевыпуск мешей не запускать: только код и замер.
