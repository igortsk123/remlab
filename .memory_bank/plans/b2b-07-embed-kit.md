## Приоритет понижен (владелец 13.10, В3)
Менеджер девелопера САМ отправляет покупателю ссылку после показа — встраивание на сайт нужно позже,
когда появятся платящие девелоперы. Делать после `b2b-02` и `b2b-06`.

## Цель
Девелопер вставляет одну строку скрипта (или iframe) на страницу квартиры, передаёт id квартиры и
получает сигналы менеджеру — без копирования нашей страницы к себе. Домены разрешены по списку партнёра.
Инструкция на одну страницу, проверка «подключилось» — за минуты, а не дни.

## Источник задачи
Презентация: «Быстрый старт — подключение к сайту девелопера за 5 дней». Обследование 13.10:
embed-кита нет; страница ходит в `/api/render`, `/test/share/shots.json`, `/flat` по корневым путям
(iframe на `remont-lab.online` работал бы, копия на чужой сайт — нет); CSP/`frame-ancestors`
отсутствуют (`caddy/Caddyfile`, `next.config.mjs`); публикация — ручной `scp` (`publish_demo.sh:9-25`).

## Скоуп — что входит
1. **Режим встраивания** демо и 3D: `/embed/<partner>/<flat>` — без шапки сайта, с `postMessage`
   наружу (высота, события: открыл/сохранил/обратился к менеджеру) и внутрь (язык, квартира, стиль).
2. **Скрипт-лоадер** `embed.js` (создаёт iframe, подстраивает высоту, передаёт UTM) + вариант «чистый
   iframe» для сайтов без JS-правок.
3. **Безопасность:** `frame-ancestors` по списку доменов партнёра (из `b2b-06`), проверка `Origin`
   на ручках заявок/коллекций/событий, подпись партнёра в запросах.
4. **Инструкция** `docs/embed.md` (RU/EN): шаги, пример кода, что прислать нам (планировки, цены,
   домены, адрес CRM/почты), чек-лист «подключилось» (страница-проверка показывает зелёные пункты).
5. **Тестовая страница-«сайт девелопера»** в `/test/embed-sample/` для показа и e2e.

## Скоуп — что НЕ входит
- Белая метка (логотип/цвета девелопера) — следующий шаг, если попросят.
- SDK для мобильных приложений.
