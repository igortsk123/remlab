## Паспорт типа — поля
1. Как выглядят фото (ракурс, фон, материалы, особые формы); 2. вырезка: дефекты с номерами → причина → правило;
3. автосторож вырезки (без человека); 4. покраска: каким видам фото, чем становятся невидимые стороны, подпись;
нужна ли 3D-покраска вообще; 5. проверочная выборка (сколько, какие); 6. признаки ошибочной роли.
