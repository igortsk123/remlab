# Проба открытых генераторов мешей (П1.91, владелец TG 1983–1987)

**Зачем.** Владелец: найти генератор мешей лучше нынешнего (Hunyuan3D 2.1 на Salad) — по 20 одинаковых товаров на модель, сравнить по
кадрам со всех сторон при свете, по 20 кадров на модель ему. Только **открытые** модели (TG 1987: платные Hi3D/Meshy/Tripo — нет).
Разбор Codex — `_intake/codex/2026-11-18-mesh-models-answer.md` (протокол и метрики взяты оттуда; платный раздел отброшен владельцем).

## Кандидаты (открытые, ставятся на Salad)
| Модель | Почему | Карта |
|---|---|---|
| Hunyuan3D 2.1 (контроль) | нынешний, тот же сид, сырой и после recolor — отдельно | как сейчас |
| TRELLIS.2-4B (MIT) | лучший открытый с полным PBR, тонкие поверхности | ≥24 ГБ (4090) — замер |
| Pixal3D (MIT, на TRELLIS.2) | цвет фасада «пиксель в пиксель» | ≥24 ГБ — замер |
| Step1X-3D (Apache-2.0) | запасной с текстурой | 32 ГБ (5090) |
| TripoSG форма + покраска Hunyuan 2.1 | сильная геометрия тонких частей, краска наша | 16–24 ГБ |
| SPAR3D (по желанию) | дешёвая нижняя планка скорости | 8–11 ГБ |
Hunyuan 3.x открытых весов нет (только API). Direct3D-S2, Hi3DGen, Sparc3D — только форма, во второй круг через ту же покраску.

## Шаги
**Порядок моделей (владелец TG 1991/1993):** TRELLIS.2 первой, Pixal3D второй, остальные — после них.
0. **TRELLIS.2 на Salad:** образ (по устройству `tools/scout/salad/`), замер VRAM/время на 4090, 1 товар — проверка, что встаёт и сколько стоит.
1. **Пилот 3 товара** (серый комод с плоским верхом, стул с тонкими ножками, цветной тканевый диван) × все кандидаты. Вход — одна и та же
   вырезка `tools/scout/salad/hybrid_mask.py`, хеш входа в отчёт. Потолок пилота — $3 Salad (холодные старты включены), счётчик отказов.
   Своя временная группа Salad на кандидата (с согласия директора), гасить по завершении; боевую очередь мешей не трогать.
2. **Кадры:** вращение 8 ракурсов (0…315°, наклон 15°) + сверху 55° + снизу −20° = 10 видов × (текстура при свете Cycles, «глина») = **20
   кадров на модель**, одинаковые камера/свет/выдержка (настройки `tools/scout/cycles_probe/render_cycles.py`, отдельный предметный стенд).
   Полный размер, каждый кадр отдельно (не сетка; правило владельца).
3. **Числа:** надёжность и время/деньги; силуэт IoU спереди и на held-out фото сбоку/сзади; цвет ΔE00 по unlit BaseColor (`mesh_render.py`
   `UNLIT=1`), отдельно ΔL; пустой зад/серый верх по итоговому GLB (идея `view_guard.py`); тонкие части; треугольники, МБ, PBR-карты.
4. **Показ владельцу:** по товару — фото + модели анонимно A–F, потом раскрыть. Владелец решает, идём ли на 20.
5. **20 товаров** (диваны 3, стулья 3, шкафы 3, столы 3, лампы 2, кровати 2, комоды 2, вазы 2; ≥8 трудных) — только после «да» владельца по пилоту.
6. Победитель → отдельный план встраивания в `tools/scout/salad/` (контракт `model.glb`, образ, воркер) — не в этой пробе.

**Упор 18.11 21:30:** TRELLIS.2/Pixal3D тянут закрытую DINOv3 (Meta, нужен HF-ключ владельца, ❓ TG 1999); RMBG-2.0 некоммерческая — не качаем, вход наша вырезка.

## Границы
Без платных API. Без замены боевого генератора. Крупная генерация — после починки цвета (TG 1925). Кадры и меши — вне банка, в
`~/remlab-logs/mesh-models-1118/`. Деньги — в отчёт.

## Критерии приёмки
Пилот: по каждому кандидату 3 GLB или причина отказа; 20 кадров на модель на одном стенде; таблица чисел; деньги ≤ потолка; кадры
посмотрены директором до показа.
