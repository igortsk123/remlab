## Цель
Три правки по фидбеку владельца: (1) вкладка «Материалы» в /lab → «Расчёты материалов»;
(2) на странице расчёта видно, что она внутри «Моей лаборатории» (крошка заметнее, заголовок
скромнее); (3) сопутствующие товары (клей, грунтовка, шпатели…) убрать из позиций расчёта —
показывать отдельным блоком с галочками «Не забудьте».

## Источник задачи
Владелец (2026-07-31, по живой странице /e/…): сопутка «не к месту» среди позиций; крошка
слишком незаметна рядом с жирным заголовком; вкладку переименовать.

## Скоуп — что входит
1. **Вкладка**: «Материалы» → «Расчёты материалов» (`app/lab/page.tsx`). «Ремонт»/«Дизайны»
   не трогаем (владелец просил только материалы).
2. **Иерархия на `/e/[id]`**: крошку сделать заметной строкой обычного размера —
   «🧪 Моя лаборатория / расчёт» (ссылка акцентным цветом), заголовок «Расчёт обоев» — меньше
   и спокойнее (сейчас самый жирный элемент страницы «перебивает» принадлежность к лаборатории).
3. **Сопутка галочками**:
   - `lib/calc/to-estimate.ts` — при сохранении БОЛЬШЕ НЕ добавлять сопутку в позиции
     (позиции = только расчёты по комнатам);
   - `/e/[id]` — легаси-позиции сопутки (note «сопутствующее…») скрыть из списка
     (данные не удаляем — обратимо, старые расчёты очищаются сами);
   - новый блок-карточка «Не забудьте» с чекбоксами по виду материала (`COMPANIONS[kind]`),
     отметки живут в браузере (localStorage), на сервер не пишутся;
   - блок показывается только у расчётов с `meta.kind` (у ремонта своей сопутки нет).
4. Тесты: обновить unit `calc-to-estimate` (сопутки в позициях нет); e2e «Клей обойный» остаётся
   видимым (теперь в блоке галочек) — проверка не ломается.

## Скоуп — что НЕ входит
- Удаление сопутки из БД (скрываем отображением — обратимо).
- Сопутка со ссылками/ценами (будущая монетизация «наши подборы» — отдельно).
- Мёртвые `CalcForm`/`createFromCalc` (follow-up прежнего плана).
