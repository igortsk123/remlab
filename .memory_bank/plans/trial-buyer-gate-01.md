# Ссылка покупателя — только после подтверждения планировки (trial-buyer-gate-01)

**Слово владельца 12.11 (TG 1778–1780):** «у покупателя не нужно писать „подтвердите планировку“ — он это сделать не может вообще;
не активна должна быть ссылка покупателя, пока планировка не подтверждена»; текст — «Ссылка не активирована, обратитесь к вашему
менеджеру». Повод — владелец открыл тур по ссылке покупателя и искал кнопку (TG 1775): кнопка есть только у агента (`?k=`).

## Сейчас (по коду)
- Кнопка «Подтвердить планировку» и правки — только при ключе агента (`tools/scout/flat215-demo/index.html:tcfInit`, `trKey()`).
- Покупателю в окне комнаты видна кнопка-подсказка «Подтвердите планировку» (`index.html:confirmTag`), ведёт на «План квартиры».
- Подтверждение — `POST /api/trial/[id]/confirm` (`lib/trial/repo-confirm.ts:askConfirm`): ключ → пересборка `edit` в `trial_rebuilds`
  (всегда, даже без черновиков) → галочки «размеры верны» (`dims_ok`). Ключ в базе — только sha256 (`trial_jobs.edit_key_hash`).

## Что сделать
1. Признак задания «планировка подтверждена» — одна точка правды (вывод из `trial_rebuilds` подтверждения или явное поле —
   решить с Codex; миграция в пилоте разрешена, перед ней `pg_dump`).
2. Страница тура без ключа агента, пока не подтверждено, → экран «Ссылка не активирована, обратитесь к вашему менеджеру» (EN:
   «This link isn’t active yet — please contact your agent»), без плана, 3D, цен и товаров; на сервере (до отдачи данных тура), не
   скрытием на клиенте. С ключом агента — как сейчас. После подтверждения — ссылка покупателя работает сразу (кэш `tour-cache` учесть).
3. Покупателю (без ключа) нигде нет «Подтвердите планировку» (`confirmTag`, `TR_PH_TXT.ask` и пр.): после подтверждения у него — без
   этих подсказок (размеры подтверждены агентом); «Размеры примерные» — только где согласие «как есть».
4. Старые задания без `edit_key_hash` (агента с ключом нет — подтвердить некому): не закрывать — список туров «было открыто → стало».
5. Тесты (unit + e2e тура: без ключа до/после подтверждения, с ключом), снимки экрана-заглушки телефон 375×667 и 1280.

## Критерии приёмки
- Ссылка покупателя неподтверждённого тура не отдаёт данных тура (проверка запросом), показывает текст владельца.
- После «Подтвердить планировку» агентом та же ссылка покупателя открывает тур.
- Ни в одном виде покупателя нет «Подтвердите планировку».
- Список всех туров на проде: какие закроются для покупателя после выкладки.
