# T-198/1 — PartLLM (этап 03) → границы материальных зон в 07 (22.11, владелец TG 1771–1772 «включай»; исполнитель router-7)

**Salad или наши ядра (P-067): Salad — да.** PartLLM = GPU-модель (≈17 ГБ видеопамяти, карта RTX 4090 по профилю `parts_segment`, тариф low → medium); на наших ядрах pakardev её не посчитать. Этап 07 после — Salad cpu_stage (профиль `cpu_stage`, пакет р.4), части ему едут файлом `parts.npz` в задании.

## Что делаю
1. Прогон PartLLM `prompt_set=fine` на 28 товарах страницы fill07 (список — `~/remlab-logs/t189-1122/order28.txt`, GLB форм — колонка `form_hd_glb` манифеста р.6): одна группа/нода Salad, меш за мешом (прогрев один раз), `heavy-slot --prio 2`, потолок $0,30, счётчик отказов, остановка группы после. Образ — `mesh-parts-trial@sha256:38990c38…` (тот же, что в пробах pl1–pl4), код воркера едет в env группы.
2. Выход → `parts.npz` с ключом `part` (int32, длина = число граней GLB формы; формат ровно тот, что читает `tex_fill.parts_from_npz`, согласовано с р.4 22.11) + `parts.json` (номер части → имя PartLLM, доля граней). Конвертер — `tools/scout/salad/parts/parts_to_npz.py`, проверка длины против граней GLB.
3. Подключение к 07: флаг `zones_from: parts|panels` в `tools/scout/rules/paint-fill.json` (по умолчанию `parts` при наличии валидного `parts.npz`, иначе `panels`); драйвер 07 (`stage_trial.py --parts-root`) кладёт `parts.npz` в задание (`extra_in`). Нет файла / длина не сошлась → `panels` + строка причины в items (07 не падает).
4. Тест: конвертер, выбор источника зон, сборка входа 07.

## Конвейер (P-032, 4 строки)
- **Этап:** 03 части → 07 заливка невидимого.
- **Что меняет:** границы материальных зон в 07 = части PartLLM (панели формы не склеиваются через границу части), вместо зон только по панелям формы.
- **Где ещё действует:** все типы товаров без ID; корпусная мебель (комод, шкаф, тумба) — фасады остаются по панелям пока (SegviGen — проба, ADR-0460).
- **Перевыпуск:** 07 по 28 (второй прогон после р.4) и страница р.6 (fill07 «наш 07»).
- **Что чистит шаг (P-041):** временные файлы `~/remlab-logs/t198-1122/` (входы Salad, выходы по товарам до приёмки, worktree `wt/`) — список на удаление директору, сам не удаляю.
