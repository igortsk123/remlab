## Цель
Дизайнер и владелец видят весь новый вход (приветствие → вопросы → 3 стиля → новая главная → бюджет-корзина → стиль комнаты) собранным
из наших компонентов в обеих книгах, плюс страницу «Как внедряем» (что меняет каждый вопрос и когда появится). Это эталон для кода
`onb-03`, `onb-07`, `onb-09`.

## Источник задачи
Метаплан `onb-00-quiz-master` (§ «Скоуп — Фигма Ф1–Ф4», «Вопросы опроса», ответы владельца 05.11). Методика дизайнера — её рамки на
Mobile 123:2 x ≥ 3900 (снимки `tools/design/figma/shots/0511-1207-designer/`, тексты `mobile-texts.json`). Как работать с книгами —
`core/design-figma.md`, `tools/design/figma/README.md`, лог `design-02-figma-components` (П6: экраны из экземпляров).

## Скоуп — входит
- **Ф1 компоненты** (Mobile, затем Desktop; имена по Ant Design, как П4): `Quiz / Option` (варианты: текст · фото · образец цвета ·
  с подписью «скоро»; состояния default / checked / disabled), `Quiz / Steps` (N шагов, закрашен текущий и пройденные — по Ant `Steps`),
  `Quiz / Header` (шаг «2 из 3», вопрос, подсказка), `Quiz / Result Card` (фото, стиль, «вам понравилось» / «похоже»), `Modal / Quiz`
  (окно опроса на `Modal / Mask`: шапка, тело, низ [Назад] [Далее]). Вложенные экземпляры наших `Button / CTA`, `Button`, `Link`.
  Свойства: TEXT для вопроса/подсказки/кнопок, BOOLEAN «Назад», VARIANT `lang` ru/en.
- **Ф2 экраны RU, телефон** — новая страница Mobile «Onboarding (project)»: 0 приветствие (с именем / без имени) · 1 «Какая гостиная
  вам ближе?» (5 фото наших гостиных — картинки из «Экраны RU»/демо, можно 1–2) · 2 «Кто будет жить?» (+ раскрытие «возраст детей») ·
  3 «Какие цвета вам ближе?» (4 палитры образцами) · итог (3 карточки, листание, [Выбрать «Сканди»] · [Все стили]) · новая главная
  по её 158:452 (стиль строкой «Сканди · Выбрать другой», «Изменить ответы», бюджет, вкладки «Интерьер / План», комнаты: гостиная
  ready, «Спальня 2 · детская — скоро» по ответу, кнопка связи с менеджером) · «Выбрать другой» → прежняя лента стилей · бюджет-корзина
  по её 161:64 · комната со своим стилем (окно варианта + выбор стиля для комнаты). Вопросы 4 и 5 — серые рамки «появятся со спальнями /
  с кухней».
- **Ф3** — те же экраны EN (Mobile, ₤ и английские тексты как в EN-демо, без магазинов — маска ADR-0328) и RU/EN Desktop 1440
  (окно опроса по центру поверх затемнения; главная — по нашим Desktop-экранам П6д).
- **Ф4 «Как внедряем»** — страница в Mobile: схема пути стрелками (вход по ссылке менеджера / без; обход по `#v/#c`; `/embed` без
  опроса — из матрицы `onb-02`), таблица «вопрос → что меняет → ступень → когда», полоса ступеней 0–4 со статусом. Обновляется после
  каждой ступени (строка в лог).
- Список вопросов дизайнеру (полоса шагов, повтор «Спокойно и натурально», фото вместо слов) — рамкой-заметкой рядом с её работой
  (её узлы не трогаем) и строкой в лог.
