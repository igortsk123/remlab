## Цель
Британские спальни малы (Bedroom Three 2,44×3,33 м из объявления владельца TG 260), кровать там — UK single 90×190. Сейчас она в
расстановку не попадает: назначение `single` держит раму ~135×215 с полосой −20 % → кровать уже ~108 см не встаёт. Добавить НОВОЕ
назначение и НОВЫЙ шаблон под узкую односпальную, старые не трогать; показать все шаблоны спальни на странице канонов тем же кодом
решателя, чтобы владелец проверил глазами.

## Источник задачи
Владелец, TG 297 (09.11, голос): «односпальные тоже влезать могли… не поправить, а добавить — новый шаблон. Пришли ссылку на
шаблоны, которые существуют… когда добавишь новый — я проверю. Шаблоны расстановки — это важно, вспомни, зачем они нам нужны».
Зачем шаблоны: ADR-0088 (шаблон = паспорт + машинные инварианты), ADR-0089 (сеты строятся ПОД шаблон — конверт слота), ADR-0109–0114
(каноны выбираются по якорю комнаты); страница `/test/canons/` рисуется кодом решателя (`tools/scout/canon_gallery.py`).

## Скоуп — что входит
- Раздел «Спальня» в `tools/scout/canon_gallery.py`: каждый шаблон `services/planner-solver/rules/bedroom.json` → `templates`
  (`bed_center_wall`, `bed_corner`, `storage_solid_wall`, `work_at_window`, `dressing_table`) и каждое назначение (`couple`, `single`,
  `guest`, `office`, `child:7-12`) — мини-план, разложенный НАСТОЯЩИМ `planner/bedroom.py:solve_bedroom`, + карточка паспорта
  (когда применяется, почему, правила `_enforce`, статус). Комнаты: три спальни из объявления TG 260 (3,77×5,61; 3,96×3,60; 2,44×3,33).
- Новое назначение (рабочее имя `single_narrow`, подпись «узкая односпальная (UK single)»): кровать по спальному месту 90–100 см,
  длина 190–200, рама-идеал ~100×205; тумба 1; шкаф/комод по месту; стол рабочий — по месту. Во ВСЕХ файлах правил, где перечислены
  назначения (`services/planner-solver/rules/bedroom.json`, `tools/scout/rules/bedroom-composition.json`, `tools/scout/rules/bedroom-roles.json`
  и что найдётся grep'ом) — добавлением.
- Новый шаблон (рабочее имя `bed_narrow_wall`): узкая кровать длинным боком к стене или в угол, проход с одной стороны, тумба у
  изголовья с открытой стороны; машинная проверка — существующие правила/коды, новый код — только если без него шаблон не проверяется.
- Тесты решателя на новое назначение (2,44×3,33 с окном и дверью — кровать 90 встаёт, жёстких нарушений нет).
- Публикация `/test/canons/`.
