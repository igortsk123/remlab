## Цель
Покупатель по ссылке менеджера: «Анна, здравствуйте!» → 3 вопроса → 3 стиля с настоящими фото → упрощённая главная (стиль одной
строкой, бюджет-корзина, комнаты с подписями по «кто живёт»). Менеджер получает сигнал с ответами без имени. Всё за флагом `quiz.enabled`.

## Источник задачи
Метаплан `onb-00-quiz-master` § «Вопросы опроса», «Ступени» (1), «Метаплан — подпланы» (волна 2). Контракты — ADR-0330
(`onb-0A-contracts`). Вход — PASS `onb-02` (матрица входов, `quiz.json`, эталоны, список проверок) и экраны Ф2 (`onb-01`), принятые владельцем.

## Скоуп — входит
Опрос (вопросы 0–3 + итог), новая главная, бюджет-корзина, стиль комнаты (заготовка, скрыта при одной готовой комнате), имя (бот +
страница менеджера → `#n=` → страница), событие и сигнал, счётчики, EN/маска, `/embed` без опроса, живые и unit-проверки, выкладка.

## Скоуп — НЕ входит
Вопросы 4–5 и мебель по «кто живёт» (`onb-07`, `onb-09`); хранение имени/ответов на сервере; колонки отчёта застройщику; юр. тексты.
