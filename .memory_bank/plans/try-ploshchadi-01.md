# /try — спросить площади (T-…)

## Зачем
Без площадей на листе размеры плана не с чем сверить: план строится, но масштаб угадан. Человек часто знает общую площадь
(или площади комнат из БТИ). Спросить — секунды; проверка становится строже, а пропустивший видит честную пометку.

## Источники
- План шага — Fable `~/remlab-logs/fable-1126/otvet-56.md` (весь; § 1–5 — канон поведения).
- Макет, принятый владельцем, — `~/remlab-logs/t-maket-ploshchadi/` (`a.html`…`d.html`, `maket.css`, снимки `snimki/*-375.png`,
  `*-1280.png`); тексты экранов — дословно оттуда.
- Разведка rab-4 — `~/remlab-logs/t-maket-ploshchadi/OTCHET.md` § «Разведка».

## Что уже есть в коде (сверено директором 28.11)
- Читатель подписей нового листа — `labels4` (`tools/floorplan/vlm.py`, `LABEL_KINDS`): по каждой комнате уже отдаёт НАЗВАНИЕ
  (`null`, если не напечатано), размеры сторон, площадь, тип. Отдельный labels5 подключать НЕ нужно (поправка к разведке).
- Общая площадь как опора масштаба уже есть: `tools/floorplan/pipeline.py` (`listing.total_area` / `scale_of`, статус `area`);
  «Размеры своими словами» после результата — `lib/trial/repo-listing.ts`, `lib/trial/size-ask.ts`, `SizesBox.tsx` (только агенту по `?k=`).
- Плашка «Масштаб не подтверждён» — `lib/trial/i18n.ts` (`scaleTitle`).

## Что сделать
1. **Ранний шаг читателя.** Сразу после загрузки — вызов `labels4` (тот же кэш, что потом берёт чтение плана — второго платного
   вызова быть не должно). Основное чтение НЕ ждёт ответа человека.
2. **Выбор экрана** по ответу читателя (одно правило, одно место):
   - ≥ 3 комнат с площадью ИЛИ с размерами сторон (площадь = произведение) → ничего не спрашиваем;
   - 1–2 таких → экран «Проверьте и допишите» (найденное подставлено, пометка «с плана»);
   - названия есть, площадей и размеров нет → «Впишите площади комнат» (его комнаты с номерами на плане + общая);
   - нет ни названий, ни цифр → «Укажите общую площадь».
   Все поля необязательные, «Пропустить» видно всегда.
   **В списке — ТОЛЬКО комнаты, у которых читатель нашёл на листе НАЗВАНИЕ** (владелец TG 3985: иначе не понять, какое число к какой
   комнате). Комнаты без названия в список не попадают — по ним только общая площадь. На экране «Проверьте и допишите» — так же:
   найденные площади + пустые поля только у названных комнат.
3. **Числа человека → проверка** тем же путём, что подписи листа / общая площадь объявления, с пометкой источника «со слов
   человека» (в данных результата отдельно от подписей листа). Комната ↔ число — по полю (номер в списке = комната читателя).
   Число — свидетель, не истина: сумма комнат > общей или расхождение втрое → вопрос человеку «проверьте цифры», не тревога по плану.
4. **Пересчёт без нового чтения**, если человек вписал после готовности (как «Обустроить», без платного вызова).
5. **Пропустил** → на результате плашка «Размеры не подтверждены…» + поле общей и «Уточнить» (экран г макета).
6. RU/EN: тексты в `lib/trial/i18n.ts` (EN — для UK-страницы).

## Приёмка
- Тесты на 4 ветки выбора экрана, на частичные ответы (только общая; общая + 1–2; ≥ 3; ничего), на «сумма > общей».
- Нет второго платного вызова читателя на одну загрузку (счётчик вызовов в тесте).
- Живой прогон на DEV: 4 листа (по одному на ветку, из подбора; не экзамен, не резерв 74, не отложенные) — снимки 375×667 и 1280×800,
  директор смотрит сам; владельцу — тестовая ссылка, после «ок» выкладка.
- `pnpm -s typecheck`, lint, test, build; тесты Python — в окружении своего CI-job.
