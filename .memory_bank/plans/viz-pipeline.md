## Цель
Витринные фото сетов: черновик из реальных фото товаров в честной проекции → чистовой рендер →
VLM-QA. Планка: форма+цвет каждого предмета = как у товара; текстура — допустимо упрощение.

## Источник задачи
Владелец 2026-08-01, «деплой» после серии пилотов (Сет 1). ADR-0043. Прототип: `tools/scout/pipeline.py`.

## Тюнинг-лист Этапа A (замечания владельца 2026-08-01)
- [x] QA-ретрай ЛОКАЛЬНЫМ инпейнтом — маска ТОЛЬКО по нашим bbox вклеек (VLM-боксы врут),
  каждая ≤12% кадра, сумма ≤18%, откат кадра если issues не убывают; base/fix — отдельные файлы
- [x] QA-правило «ничего лишнего» (в QA-промпте; исключения by design: ТВ, окно+шторы, отделка)
- [x] Кашпо + растение: ампельная подача — кроп листвы, свис через край, кашпо поверх стеблей
  («стеблем вверх» = «вверх ногами», замечание владельца)
- [x] Люстра в кадре (клэмп y0≥10); столик/ваза разнесены от дивана (Z=2.35)
- [x] Контроль ΔRGB кодом (хрома-инвариант, порог 15; белое и роли с полом в bbox — исключены:
  тёплый свет даёт ложный дрейф)
- [x] ГЛАВНЫЙ фикс: камера F=1100/CY=500/CAMX=1.9 — раньше пол при Z<3.9 был за кадром, столик/
  тумба/ковёр отсутствовали в макете и ВЫДУМЫВАЛИСЬ моделью («тумбочка не та»)
- [x] В промпт передаются названия+назначение+размеры товаров и колор-хинты из name_color
  (просьба владельца); силуэты «не заменять дизайн» (торшер-арка вылечена)
- [x] Вырезка: flood-fill от границ (вотермарки уходят); white-on-white монолиты (тумба) —
  фолбэк «фото прямоугольником»; тонкие роли — никогда (ложный тригер на ножках)
- [x] Сверка владельца: ковёр «Pyramid» — техковрик, из сета убран, промпт «NO rug»;
  плед/кресло доведены точечным инпейнтом с рефами (розовый плед с кремовым подбоем)
