## Цель
Сеты, которые выглядят собранными дизайнером, а не каталогом: единый стиль, согласованная
цветовая гамма (не только «нейтраль+акцент»), правильные пропорции вещей, визуальная
«дружба» предметов. Бюджет улучшения: ₽0 обязательная часть, ≤10 ₽ опциональный VLM-фильтр.

## Источник задачи
Владелец 2026-08-01: «подбор сетов можно сильно улучшить дёшево/бесплатно? …чтоб как дизайнер».
База: `tools/scout/compose.py` (v1: перцентили цен, доли площади, 1 акцент, dominant-цвет PIL).

## Скоуп — что входит (по убыванию эффект/цена; всё локально и бесплатно, кроме Ф6)
**Ф0 Заморозка.** `sets.json` утверждённых сетов — неприкосновенен: v2 пишет в `sets2.json`;
фиксированный seed → детерминированная пересборка (грабля: v1 недетерминирована).
**Ф1 Стиль-теги из текстов (главный эффект).** Словарь стилей по названию+params товара:
сканди/лофт/классика/неоклассика/прованс/минимализм/современный; + тон дерева
(орех/дуб/венге/бук/белёный) + металл (латунь-золото/чёрный/хром). Правила сета:
один стиль (или совместимая пара: сканди↔минимализм), ЕДИНЫЙ тон дерева, ЕДИНЫЙ металл.
**Ф2 Палитра v2.** Вместо «нейтраль+1 акцент»: 2 кластера цвета на товар (k-means по фото);
тёплая/холодная температура гаммы сета — все нейтрали одной температуры; акцентная ПАРА
из дизайнерских гармоний (терракота+оливка, синий+горчица, роза+графит…) вместо одного
акцента; дерево участвует в палитре как цвет.
**Ф3 Пропорции и капсульные правила.** Столик 50–70% ширины дивана; тумба ≥ 120% ширины ТВ
(ТВ 43″); кресло сопоставимо с диваном по «весу» (высота спинки ±15 см); подушки = акцент
+ нейтраль; торшер у дивана ≥140 см; повторение фактуры ≥2 раз (рогожка диван → рогожка пуф).
**Ф4 Визуальная похожесть (embeddings).** open_clip ViT-B/32 на CPU (бесплатно) → вектор фото
каждого товара гостиной (~15 тыс., разово часы) → в pgvector (dev-БД). Скоринг кандидата =
косинус к «якорю» сета (диван) + анти-клоны. Это придаёт «одно настроение» вещам.
**Ф5 Кандидаты и скоринг.** На каждый слот — топ-3 кандидата; итоговый скор = стиль (Ф1)
+ палитра (Ф2) + пропорции (Ф3) + похожесть (Ф4) + цена-фит; победитель в сет, №2–3 → в
`alternates` (пригодятся для OOS-замен). Отчёт «почему выбран» в лог сета (объяснимость).
**Ф6 (опция, ≈5–10 ₽ на все сеты).** VLM-судья gpt-5-mini по мудборду: «какой предмет
выбивается и почему» → пересбор слота. Только финальным фильтром, не в цикле.
**Ф7 Фидбек владельца.** `sets-feedback.json`: отклонённые товары → чёрный список,
одобренные сеты → эталоны для скоринга похожести.
