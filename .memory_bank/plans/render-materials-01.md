## Цель
Мебель в рендере читается своим материалом: рогожка — мягкая ткань, а не кожа; дерево, металл, стекло — сами собой. Товар не меняется
(цвет и форма — как сгенерированы, ADR-0419); добавляется слой для рендера («надстройка», владелец TG 1343). Автоматически на тысячи
товаров. Рендер одного кадра на облачной видеокарте ≤ 15 с (16 — допустимо, цель 10 с; владелец TG 1343/1344/1347).

## Источник задачи
Владелец 17.11: TG 1341 («обивка как кожа», «текстуры из генерации — использовать?», «сжатые или полные модели?»), TG 1343 (надстройки
можно; быстро), TG 1344 (30 с — это GPT, Blender ≤ 15 с), TG 1347 (посоветоваться с Codex — архитектурная задача; «может, слой
материалов на сжатые модели перед рендером»; написать план).

## Факты (сверено директором и рабочим 2, 17.11)
- Меши — Hunyuan3D 2 (`model.glb` ~3,9 МБ, 40 тыс. тр.): ОДИН материал на весь предмет — цвет + карта «блеск/металл», карты рельефа нет;
  свет частично запечён в цвет. Оригинал есть у всех 434 моделей (hunyuan 432, галерея 417).
- Копия для сайта `tools/assets/runtime_mesh.py` (KTX2 1024 / 512 для телефона) выкидывает карту «блеск/металл»; рендер сейчас берёт эту
  копию (`tools/scout/cycles_probe/render_cycles.py`; флаг `--mr` карту не вернёт — её в копии нет).
- Цвет: ткань на фото магазина 169·153·143, в текстуре меша 171·149·135 — почти совпадает; розовость кадров дал тёплый свет (исправлено).
- Время: CPU i5-13400F 8 потоков, 1536 px, 64 выборки — 164–205 с. Пересчёт на видеокарту по Open Data — только ориентир
  (4090 ≈ 11,7 тыс., 3090 ≈ 5,8, L4 ≈ 3,6, A10 ≈ 2,8), обещать 10–15 с без замера нельзя.

## Решение (свой вывод → Codex `_intake/codex/2026-11-17-material-realism-answer.md` → сверка)
Совпало: класс материала из данных товара, настройки по классу, мелкий рельеф готовой картой в реальном масштабе, подготовка один
раз на товар, на кадр — из кэша. **Новое от Codex (принято):** один материал на весь меш → «ткань» попадёт на ножки; сперва маска частей
(ткань / ножки-каркас), при низкой уверенности — нейтральная поверхность без фактуры. Маску по яркости цвета не делать.
Отложено: удаление запечённого света, увеличение текстур нейросетью, AI-оценка материалов по фото — риск подменить вид товара.

## Шаги
1. **Оригинал против копии сайта** при одном свете и ракурсе (диван Нумо-Мини + 3–4 предмета разных классов): чётче ли цвет, что даёт
   своя карта «блеск/металл». 0 ₽. Если лучше — рендер берёт оригинал (экспорт сцены отдаёт путь к нему).
2. **Класс материала** — данные `data/flat3d/material-classes.json` (10–12 классов: рогожка, велюр, букле, кожа/экокожа, массив/шпон,
   ЛДСП, крашеный МДФ, металл, хром, стекло, керамика; запасной — нейтральный): порядок — характеристики товара → слова названия с
   отрицаниями («кожа» не бьёт явную «рогожку», цвет ≠ материал) → роль. Результат с причиной и уверенностью — в данные товара, не в код.
   Отчёт: охват 434 мешей по классам и спорные.
3. **Маска частей**: ткань vs ножки/каркас по геометрии меша (связные части, положение, толщина) с уверенностью; где не уверены — слой не
   кладём. Проверка глазами на 20 предметах.
4. **Слой для рендера по классу**: Principled — шероховатость, «ворс» (sheen) для тканей, лак (coat) для кожи и МДФ, готовая карта рельефа
   CC0 (ambientCG / Poly Haven, источник в реестре) в физическом масштабе (рогожка — период 0,15–0,4 см, букле — 0,3–0,8 см). Старт —
   диапазоны Codex, подбор A/B. Без смещения геометрии (displacement).
5. **Время на GPU**: пилот на облачной видеокарте (связь с шагом 6 `render-3d-01`): 24–48 выборок, адаптивный порог 0,03–0,05, шумодав
   с альбедо и нормалями (OptiX против OIDN), меньше отскоков; замер от нажатия до картинки p50/p95 на полной комнате, ₽ за кадр.
   Сперва пробная партия в потолке владельца.
6. **/demo** — облегчённо: только если на телефоне укладывается (sheen и одна сжатая карта рельефа — замер байтов и первого кадра).

## Критерии приёмки
- [ ] Владелец вслепую на 5 парах «ткань или кожа?» — ткань узнаётся; дерево и металл — своими
- [ ] Цвет ткани в нейтральном свете ≈ фото магазина (ΔE ≤ 5), габариты и силуэт те же, на ножках нет фактуры ткани
- [ ] Классы и маски — данными, с причиной; нет ID товаров в коде; CC0-источники в реестре
- [ ] Кадр ≤ 15 с на выбранной видеокарте (p95 ≤ 16 с) — по замеру, не по пересчёту
- [ ] Кадры владельцу — отдельными файлами в полном размере, рядом фото магазина

## Чего шейдер НЕ исправит (честно)
Швы, кант, толщину подушек, петли букле геометрией, точные границы материалов — это качество самих мешей (генерация), отдельный вопрос.

## Риски
Неверный класс или масштаб — «чужая» фактура (защита: уверенность и нейтральный запасной вариант); лицензии весов нейросетей — не берём;
время на GPU — только по замеру.
