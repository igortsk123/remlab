## Цель
Для малых гостиных: **защитить медиакоммуникативное ядро и проходы**, а остальные зоны
ужимать/объединять под остаток — вместо четырёх конкурирующих зон одни и те же участки
работают на несколько функций.

## Источник задачи
Свод владельца 13.08 №3 (small rooms; Samsung/RTINGS, H&G узкие столы у стены, дизайнерский
консенсус по вертикальному хранению и compact-мебели). Исполняется в очереди после
MASTER-tv-sofa-pair и large-room-mode; вместе они образуют триаду режимов
(small / transitional / large).

## Критическая оценка
Свод совместим с построенным и с large-room-сводом; возражений с контр-пруфом нет.
Совпадения с уже сделанным: пары ТВ↔диван (П1), тумба перед окном, «столик после проходов»,
лестница деградации, «щель не повод для кашпо», хранение по периметру. Ключевые НОВЫЕ идеи:
режимная триада с триггером по короткой стороне; «размер ТВ адаптируется к комнате легче,
чем планировка к ТВ»; compact-шаблоны столовой (у стены/круглый/складной); вертикальный
бонус хранения; уровни A/B/C/D для деградации; отдельный WallScore-порядок для small.

## Уровни деградации (свод §19–20) — в данные
LEVEL A (не трогаем): проходы, диван, медиа, дверь/окно.
LEVEL B (масштабируем): столовая, хранение.
LEVEL C (опционально): кресло, столик, пуф.
LEVEL D (декор): кашпо.
Порядок удаления: кашпо → пуф → доп.кресло → столик→side table → меньше стол → складной стол
→ уже/вертикальнее хранение → и только потом менять диван/медиа.

## Всё — в терминах шаблонов
- «Ядро» = пара медиа-блок × блок посадки (П1) с малым L_required и small-WallScore.
- Compact-столовая = НОВЫЕ паспорта: `dining.against_wall` (уже есть wall_side — расширить),
  `dining.round_compact` (Ø80–100, 2–4 места), `dining.foldable` (требует данных каталога:
  флаг «раскладной/откидной» из обогащения — есть в rules.features).
- `storage.vertical_bonus` — не паспорт, а правило скоринга слота (высокий узкий > низкий
  широкий при равном объёме); `media_storage_combo` — паспорт объединённого блока
  (стеллажи по бокам носителя — расширение текущей медиа-схемы с флангами).
- Уровни A/B/C/D — атрибут паспортов зон (`degradation_level`), лестница читает его.

## Этапы
**S1. Режимная триада.** `room_map`: mode = small / transitional / large (пороги свода);
transitional генерирует оба и сравнивает финальным скором.
**S2. Small-WallScore и порядок позиций дивана.** Веса из таблицы; позиции 1–4 по порядку
свода; L_required с малым запасом.
**S3. «Меньший ТВ» как рекомендация.** Комната короче цели → в артефакт пишется
`tv_advice: {max_diag}` (смета/подбор смогут предложить меньший ТВ); геометрию не ломаем.
**S4. Compact-столовая.** Паспорта against_wall / round_compact / foldable + каскад масштаба
(4→2→складной); reject-правила свода.
**S5. Хранение: вертикальный бонус + media_storage_combo.**
**S6. Уровни A/B/C/D в паспортах + сторожа.** Сторож: в small-сценах медиа+посадка образуют
связное ядро (расстояние блоков ≤ compact-порога); проходы ≥76 везде; LEVEL A не деградирует.
