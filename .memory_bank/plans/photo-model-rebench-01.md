## Источник задачи
Владелец 07.11 TG 397–398: «сделай исследование для нашего кейса — наша модель лучшая по цена-качество или нет»; «цена-скорость-качество».

## Наш случай (что модель должна уметь)
- Вход: лист из двух видов 3D-сцены (2048×3072 телефон / 3072×2048) + эталонные фото товаров + промпт improve-v4.3; выход — фото,
  где мебель на МЕСТАХ и в ЦВЕТЕ товара, отделка по стилю (кирпич лофта, молдинги неоклассики), два вида согласованы.
- Нынешняя: `gpt-image-2.5-sunburst` medium через шлюз Vercel — ≈ 5 ₽ за лист, модель ≈ 29–33 с (ADR-0302, замер T-33).
- Уже проверено и отвергнуто: Nano Banana 2/2.1/Pro (ломали второй вид и цвет дивана, в 2K дороже), FLUX 3 (129 с), gpt-image-2
  (40 с, 12 ¢), flare 2.5 (T-33/2 07.11: −4…−8 с, +1 ₽, хуже верность), quality `low` (T-33/1). Повторно их не гонять без нового довода
  (новая версия — довод).

## Шаги
1. **Разведка (бесплатно).** Какие модели правки картинки по нескольким входным изображениям есть сейчас у шлюза Vercel (список моделей
   API шлюза) и у fal.ai (ключ — `core/access-and-integrations.md`, скрипты, `.env` не читать), что вышло после 17.10: `gpt-image-2.6-sunburst`
   / `2.6-flare`, новые Google, Seedream, Qwen-Image-Edit, FLUX Kontext и т. п. Таблица: модель · где доступна · цена 2K-листа · заявленная
   скорость · берёт ли ≥ 3 входных картинки · размер выхода · источники. Шорт-лист ≤ 4 новых.
2. **Ведущий → владельцу:** шорт-лист и цена бенча — до траты.
3. **Бенч (платно, после слова владельца).** Те же 5 сцен, что в T-33 (сканди гостиная, лофт и джапанди спальня 2, сканди спальня 1,
   современный гостиная), входы байт в байт; на каждую модель сперва 1 проба → проверка → остальные; счётчик отказов, без молчаливых except.
   Время модели, цена по счётчику, пары «нынешняя | кандидат».
4. **Оценка** по чек-листу плейбука (`domain/viz-fidelity-playbook.md`): мебель на местах, цвет товара, отделка стиля, согласованность видов,
   артефакты (полосы, лишние предметы) — баллы по каждой сцене; ведущий смотрит сам, вслепую (подписи скрыты), затем владельцу.
5. Итог: таблица цена · скорость · качество; рекомендация — оставить / сменить / держать запасной.
