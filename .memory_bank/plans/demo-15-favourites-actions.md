## Цель
Покупатель на телефоне: видит 3D со свёрнутой шторкой (как скрин 1 владельца); тап по предмету — шторка раскрывается до верха на
строке этого предмета (скрин 3); после «Заменить» камера сама показывает новый предмет; ракурсы переключаются понятными
словами, а не «‹ ›»; избранное — одно сердечко вверху окна, видно всегда, с именем коллекции; «Поделиться» — иконкой в окне и на
карточке; все сохранённые коллекции собраны в разделе «Избранное» на главной.

## Источник задачи
Владелец 18.10 (три скрина iPhone): «1 — так должен выглядеть экран со свёрнутой шторкой в 3D; 2 — когда выделяем объект, должна
открываться шторка полностью и показывать как в 3; человек или смахнёт шторку, или выберет «Заменить»; после замены фокус камеры
автоматом напротив предмета, чтобы посмотреть, что выбрал; стрелочки назад/вперёд сейчас непонятно что значат — явнее; кнопки
«В избранное» и «Сохранить» — одно и то же: оставить избранное тапом на сердечко, сердечко наверх, чтобы видно в свёрнутом
состоянии, по тапу поп-ап с названием коллекции (автоматом «Джапанди #1», можно дописать); «Сохранить» убрать; «Ссылка» —
иконкой «поделиться» и в окне, и на карточке; все сохранённые коллекции — в «Избранное», раздел на исходной странице».

## Что есть (сверено fable-lead 18.10, `tools/scout/flat215-demo/index.html`)
- Тап по предмету: `vwHighlight(idx)` (~4690) — выделение в сцене, подсветка строки на 4 с, на телефоне шторка открывается только
  до СРЕДНЕЙ остановки (`vwSheet(2)`), строка может остаться под шторкой.
- После замены (`remlab:hist` → `vwAfterChange`, ~4525): режим 3D, шторка сворачивается, строка подсвечивается; камера НЕ наводится.
  Наведение в движке есть: `sc.focus(idx)` (`LIVE.focus`, ~4937/5111) — используется при открытии из карточки.
- Ракурсы: кнопки `‹ ›` (`#shotPrev/#shotNext`, ~3420) + точки `.vdots`; подписи нет (владелец 16.10 снял «View 1/2», а стрелки
  оказались непонятны). Точки съёмки C1/C2 известны с позицией (`cams`, стены комнаты и проёмы известны: `D.room.openings`).
- Избранное/сохранение: в окне кнопки `#shPick` «♡ В избранное», `#shLink` «Ссылка», `#shSave` «Сохранить коллекцию» (внизу шторки);
  на карточке — «Ссылка» + сердечко (`data-pick`, отмечает вариант в избранном, `feedShare` «Избранное» → шаринг отмеченных);
  в развороте карточки — «Сохранить коллекцию» (`#collSave` → `POST /api/collections` со снимком и `name ≤ 200`, `contracts/collection.ts`);
  свои коллекции — `localStorage['remlab-collections']` (`MINE`, ~5358), страница `/c/<id>`.
- Главная: раздел «Коллекции расстановок» (готовые варианты, `#coll`), отдельного раздела «Избранное» нет.

## Решение
1. **Тап по предмету → шторка до верха на строке.** `vwHighlight`: на телефоне `vwSheet(3)` (полная), список прокручивается так, чтобы
   строка была в верхней трети видимой области, подсветка держится, пока предмет выделен (не 4 с). Повторный тап по тому же
   предмету или по пустому месту сцены — снять выделение, шторку не трогать. Свайп вниз/тап по чипу — как в v5.
2. **Камера на заменённый предмет.** После замены через ленту: `vwAfterChange` → 3D, шторка свернута, затем `sc.focus(idx)` нового
   предмета (плавно, 500 мс, камера остаётся в проходимой зоне ≥ 1 м от предмета, предмет в центре кадра) + пин подсвечен 3 с;
   «Другой ракурс» после этого возвращает к поз. C1/C2. То же после смены пола/стен — без наведения (вся комната).
3. **Ракурсы словами.** Вместо `‹ ›` и точек — переключатель из двух подписей под сценой (над шторкой): имена по положению
   камеры: ближайшая стена к точке съёмки — с окном → «От окна», с дверью → «От двери», иначе «Вид 1»/«Вид 2»; активная подпись
   жирная, тап по другой — переход (в 3D — плавный `goToPose`, в «Фото» — смена снимка). EN: «From the window» / «From the door».
   На компьютере — тот же переключатель. Свайп по сцене в «Фото» остаётся.
4. **Одно избранное — сердечко вверху окна.** Сердечко `♡` в шапке окна рядом с «×» (видно при любой шторке). Тап → поп-ап:
   поле «Название» с автоподстановкой «<Стиль> #N» (N = число своих коллекций этого стиля + 1), кнопки «Сохранить» / «Отмена»;
   сохранение = `POST /api/collections` (снимок + имя), сердечко становится `♥`, тост «В избранном: Джапанди #1». Тап по `♥` →
   поп-ап «Переименовать» / «Убрать из избранного» (удаление — локально из `MINE`; серверная запись остаётся по правилу истории).
   Кнопки `#shPick`, `#shSave`, «Сохранить коллекцию» в развороте карточки — убрать; сердечко на карточке списка = то же действие.
5. **«Поделиться» иконкой.** `#shLink` → иконка ⇪ («поделиться», системная глифа) в шапке окна рядом с сердечком; на карточке —
   та же иконка вместо «Ссылка». Тап: `navigator.share` (телефон) с заголовком коллекции/варианта и ссылкой; нет `share` —
   копирование + тост «Ссылка скопирована». Ссылка — на `/c/<id>` для сохранённой коллекции, иначе на вариант (`#v=`).
6. **Раздел «Избранное» на главной.** Над «Коллекции расстановок»: заголовок «Избранное», карточки своих коллекций (`MINE`):
   миниатюра (лучший снимок состояния / кадр сцены), имя, стиль, дата, сумма; тап — открыть `/c/<id>` (или окно варианта с этой
   расстановкой), иконка «поделиться», «⋯» → переименовать/убрать. Пусто — раздел скрыт. Кнопка `feedShare` «Избранное» — убрать.
7. EN-словарь для всех новых подписей; аналитика: `favourite_save`, `favourite_rename`, `share`, `view_switch` (одно событие с полем).

## Критика Codex (18.10, `_intake/codex/2026-10-18-favourites-actions-critique.md`) — обязательные уточнения
1. **Связь предмет ↔ строка — по стабильному `sid`/slot-id**, не по `sku.name` (коллизии у одинаковых названий и комплектов, `index.html:4690`);
   подсветка строки живёт в `VW.sel` (не таймер 4 с), пустой тап её снимает; `vwSheet(3)` и прокрутка к верхней трети — после конца анимации.
2. **Один компонент ракурсов** вместо двух навигаций (`shotPrev/shotNext` ~3415 и `vPrev/vNext`+`.vdots` ~4418, фото и 3D переключаются разной
   логикой ~4833): одно состояние `cameraId`, одна функция перехода; удалить обе пары стрелок и точки.
3. **Имя коллекции и переименование — безопасно:** в `contracts/collection.ts:41` корневого `name` нет, `PATCH` принимает только снимок
   (`[id]/route.ts:34`). Добавить `displayName` в контракт/GET/repository; при `POST` возвращать секрет редактирования (хранить хеш), rename —
   только с секретом; по публичному `id` переименовать нельзя.
4. **Избранное — локальное («Избранное на этом устройстве»):** `MINE` ограничен 10 записями (`index.html:5358, 5412`), серверные записи живут год
   (`db/schema.ts:443`), канонический адрес сейчас `/demo/#c=…`, не `/c/<id>` (`:5446`). Снять лимит (или пагинировать локальный индекс),
   один построитель `shareUrl`; межустройственное «все» — только с аккаунтом/owner-token (не в этом плане).
5. **Фокус камеры — `frameItem`, не tween:** `focus` сейчас лишь мгновенно поворачивает взгляд (`demo-scene.ts:218`, `viewer.ts:1556`), прямая
   интерполяция позиции пройдёт сквозь стену/мебель. Делать: после `await sc.update` — если текущая точка валидна, предмет виден и до края
   его повёрнутого footprint ≥ 1 м — только плавный поворот; иначе перебрать кольцо 1–1.8 м вокруг footprint, фильтр `canStand` + внутри
   комнаты + прямая видимость, ближайшая к текущей, движение по проверенному пути; нет точки — только поворот, сообщить результат.
- **(а) Имена ракурсов:** по месту камеры, не по содержимому кадра: «Со стороны окна» / «Со стороны двери»; обе у одной стены — «…слева/справа»
  относительно взгляда в комнату; нет привязки или имена совпали — «Ракурс 1» / «Ракурс 2» в порядке C1/C2 (без тупиков).
- **(б) Модель:** источник истины — локальный `FavoriteRef {collectionId, editToken, displayName, style, stateId, sourceVariantId, createdAt}`;
  сердечко = совпадение текущего `stateId` (изменил расстановку — снова контурное). `data-pick` → `data-favorite`; `feedShare` с избранным не
  смешивать. Миграция: все `remlab-collections` → в избранное; старые `pick` не сохраняются (`:2759, 2771`) — не угадывать. Номер имени —
  `max использованных суффиксов + 1`. «Поделиться» для изменённой несохранённой расстановки — сперва snapshot, иначе ссылка `#v=` отдаст базовый вариант.
