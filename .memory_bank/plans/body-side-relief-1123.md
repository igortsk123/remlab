- **Ш1 — «что дадут р.5+р.6 без меня».** Круг на 11 body с кодом main + `feat/t39-body-r5` (в merge-worktree, не в основной копии), ≤6 нод, ≈$0,01, ≈12 мин, метка владельца. Меряем «рисунок» было→стало. Если ≤3 из 11 — моя часть сводится к автопроверке (Ш3), правила не нужно.
- **Ш2 — правило на остаток (только если Ш1 не закрыл).** По типу, не по товару: для `hidden_pattern=body` на невидимых тексельях НЕ-фасадных частей («корпус»): выход = тон корпуса + зерно донора (р.6); энергия полосы рисунка после заливки не выше `side_max_ratio × энергия корпуса на фото` (срез/сглаживание превышения к тону соседней корпусной части).
