## Цель
У каждого товара, которому нужен меш, есть хеш текущего фото. Готовые меши не висят в вечном stale, а сменившееся фото
законно ведёт к переделке. Порог качества 0.65 работает так, как записан: «≥ 0.65» включительно.

## Источник задачи
Разбор T-20261021-05 (рабочий 1; ведущий сверил `cutout_sync.py:200-208` и `select 0.65::real >= 0.65` → false на DEV):
- **Разные ворота.** Хеш пишет только `cutout_sync` и только для пула подбора (`tools/scout/cutout_sync.py:POOL_SQL`, quality ≥ 0.65),
  а меш нужен по воротам `tools/scout/mesh_bind.py:95-110` без качества. 405 представителей `mesh_required` без хеша:
  stale 176, quarantine 8, none 221 (ещё не генерировались — после первой генерации станут вечными stale).
- **Граница real.** `product_enrichment.quality` — `real`; `0.65::real >= 0.65` (numeric) = false, хранится 0.6499999…
  572 строки с 0.65; из пула подбора молча выпало 377 активных товаров. То же сравнение — `tools/scout/candidates.py:70`,
  `tools/scout/mesh_queue.py:202`, `tools/scout/compose2.py:58`, `tools/scout/pipeline_funnel.py:28`, `cutout_sync.py:206`.
- Все 176 stale на деле актуальны: скачанное сейчас фото (HD, ADR-0182) даёт тот же sha256[:16], что у поколения seed 0.
- Направление «один владелец хеша» — совет Codex 21.10 (`_intake/codex/mesh-stale-nohash-2026-10-21-answer.md` § 3).
Владелец 21.10: «порядок 1 → 3 → 4, работай». Этот план (п.4) идёт раньше банка (п.3): банк должен строиться на верном пуле с 0.65.

## Скоуп — что входит
1. **Один писатель хеша.** Модуль `tools/scout/photo_hash.py`: URL = `coalesce(image_url_hd, image_url)`, sha256[:16] байтов,
   единственный писатель `product_photo_current`. Зовут `cutout_sync` (как сейчас) и хеширование для `mesh_required`;
   `mesh_queue.ingest` свой SHA не считает — копирует из `product_photo_current` (`mesh_queue.py:402-408` уже так).
2. **Кого хешировать:** пул подбора ∪ представители `mesh_required`; порядок — сначала `mesh_required` stale/none.
3. **Граница 0.65:** во всех местах сравнения `quality >= 0.65` — через `round(quality::numeric, 2) >= 0.65` (одна константа/функция, не 6 копий).
4. **Бэкфилл** (бесплатно, ~405 скачиваний): один проход по представителям `mesh_required` без хеша; затем `mesh_bind` → ожидание
   176 stale → ready. Журнал «было/стало».
5. **Сторож** в `tools/scout/pipeline_map.py` (рядом с метрикой stale, пороги `tools/scout/rules/pipeline-map.json`):
   `mesh_required_rep_without_photo_hash` — число и возраст старейшего; тревога > 0 дольше 24 ч.
6. Тесты: граница 0.65 (real) — включительно; photo_hash — единственный писатель (grep-тест на `insert into product_photo_current`);
   кого хешировать — `mesh_required` без качества попадает.
