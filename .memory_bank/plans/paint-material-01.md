# Покраска: поверхность → материал → вся поверхность (paint-material-01)

## Зачем
За 4 дня и 4 круга на 29 товарах честно прошло 0 из 29 (пять признаков). Тон по пикселям фото в 06 и цепочка хуков 07 дают заплатки, недокрас ножек и
«двойной свет» (свет фото запечён в текстуру + сайт светит ещё раз → верх Крита сверху белеет, +5 L, −6 C). Фото покрывает 4–15 % поверхности — остальное
всё равно придумываем; придумывать надо по частям и материалам, а не по пикселям. Утром 24.11 советники это уже сказали (Р5), днём вместо этого добавлены
4 выключателя в 06 — ошибка порядка работ (директор, TG 2674).

## Схема (одна на все типы; признаки товара — параметры, не отдельные правила)
- **Ш1 · Части с ролями.** Части 03 (`~/remlab-logs/t198-1122/parts-root/<id>/03-parts`, папки есть у всех 29, но в прогонах 06/07 не подключены и могли разойтись с нынешними мешами — сверка Ш1-0) → роль: столешница, ножка, царга, корпус, фасад, сиденье, спинка, обивка, кромка. Мост «имя части → роль» уже влит вхолостую (T-17/2); у столов Base/Body = столешница по геометрии (горизонтальная, верхняя, самая большая), ножки — согласие по форме. Разбиение меша ≠ карта материалов: две роли в одной части — делить по нормали/высоте.
- **Ш2 · Чистые пиксели фото на часть.** Только прямой взгляд (z-буфер), не у края маски (≥ 4 px), не в тени; доля чистых пикселей — в паспорт части.
- **Ш3 · «Ровный материал» или «рисунок» — замером**, не по типу: ручки, щели, рифление, крупный принт, мрамор с жилами, стёжка → «рисунок».
- **Ш4 · Материал части** = тон + маленький образец фактуры (направление вдоль длинной оси части, масштаб в см) + матовость по словам карточки. Тон подбирается так, чтобы кадр модели **под светом сайта с камеры фото** совпал с фото (тон без запечённого света), а не «текстура без света = фото».
- **Ш5 · Наложение.** Ровная часть — материал на всю часть, видимое и невидимое одинаково (проекция по осям части с запеканием, не через мелкие острова развёртки TRELLIS). Часть с рисунком — фото только на лицевую грань, остальные грани — материал корпуса.
- **Ш6 · Невидимое — лесенка:** своя часть с её видимого куска → лучшая видимая часть той же роли (все ножки = лучшая ножка; `legs_common_tone` в `tex_fill.py` уже есть, выключен) → соседняя часть того же материала / слово карточки → спокойный тон типа с пометкой «не уверен». Родной цвет TRELLIS — никогда; тон из тени под столешницей — нельзя.
- **Ш7 · Одна проверка.** Кадр под светом сайта с камеры фото против фото по частям (ΔL, ΔC, доля почти белых L>90 C<8 — распределение, не среднее) + ровность каждой части со всех сторон, для столов/комодов — строго сверху (90°). Один набор света на ВСЕ страницы показа (neutral, exposure 1, shadow 0). Глазами — выборка, директор сам.

## Что убираем / оставляем
- Убираем для ровных частей: тон с острого угла в 06 (~35 настроек `tools/scout/rules/tex-visible.json`, включая 4 выключателя 24.11), шов «фото | заливка», цепочку хуков 07, переписывающих друг друга. Новые выключатели в 06/07 — не добавлять.
- Оставляем: z-буфер, камеру, политику по типу, группы материала, синтез фактуры (`tex_fill.py`), 08 (материал), 09/10.

## ПРАВИЛА НОВОЙ ПОКРАСКИ — свод (владелец + Fable + замеры, 24.11 23:55; владелец TG 2717 «всё записывай в конвейер, ничего не потеряй»)
Действует для всех задач новой покраски; ниже в плане — откуда каждое правило. Ответы советника: `/home/pakar/remlab-logs/t-adv-paint-29types/answer.md` (все 29 и типы), `answer-2.md` (нахлёсты, свет/материал) — algor, копия answer.md на pakardev `~/remlab-logs/t-adv-paint-29types/`.
1. **Деталь — одним материалом целиком** (TG 2667/2671/2703): единица — роль-часть; у жёсткой мебели — плоская панель по геометрии (`tools/assets/ref_zone.py` panel_ids/face_sides, `part_shapes.py`, `material_parts.py`), у мягкой — часть PartLLM, у вазы — пояса по высоте. Роли: столешница, ножка, царга, фасад, **бок**, **зад**, верх, корпус, сиденье, спинка, обивка.
2. **Разметка чистится ДО покраски** (TG 2705, Fable А1–А4): каждая грань — одна роль; границу жёсткой мебели резать плоскостью; приоритет лицевой/крупной — только в узкой полосе у границы; мелкое контрастное (ручки, наконечники, подлокотники) не съедать; рамка в плоскости фасада и двухцветный фасад — не съедать большинством. После покраски — только проверка кадром, не подкраска.
3. **Тон детали — «цвет большинства»** (TG 2703): главный кластер Lab чистых пикселей (прямой взгляд, ≥4 px от края, без бликов/теней), меньшинство (захват соседа, тень) — отброс; доля главного кластера — в паспорт, низкая → «не уверен».
4. **Оттенок — со своей полосы, светлота — с опорной поверхности группы** (TG 2708, Fable Б8–Б11, р.2 T-66/2): тот же материал = угол оттенка (°) при C > ~10 в допуске; бок того же материала на фото темнее фасада на 10–15 L («студийная тень») → бок = тон фасада; бело-серо-чёрные сливать только одинаковые по роли (4 ножки, два бока), разные роли — по карточке. Опорная = медиана поверхности с наибольшей медианой L при достаточном числе прямых пикселей (не самые светлые пиксели).
5. **Все ножки (и все одинаковые детали) — один тон** (TG 2703): с ножки с наибольшим чистым кластером; разные ножки на фото = тени.
6. **Невидимое — лесенка** (р.4 T-68): та же роль → тон всего товара → карточка (только вето/подсказка, из специфичного поля) → спокойный тон типа ТОЛЬКО пометкой «не уверен», не краской. Верх корпусной на фото почти не виден (3/11): первым — карточка/библиотека. Родной цвет TRELLIS — никогда; тень под столешницей — нельзя.
7. **Узор — только на лицевую грань** (Fable): фасад с рисунком/ручками/рифлением, принт — фото на лицо; бока и зад — материал корпуса; рельеф дверей на заду — форма. Ткань — один материал на подушки/спинку/бока/зад, тени швов не переносить.
8. **Фактура:** дерево — готовое дерево по оси детали + цвет с фото (кусок с фото есть лишь у 12 % деревянных частей, ножки 0/16 — р.2 T-66); ткань — образец с фото, где прямой взгляд (58 %). Ось — по плоскости (склейка почти копланарных панелей: у TRELLIS верх Крита = 3780 панелей), круглая плита — ось ширины товара (`object_basis`), доски прямые; плитка — реальный `tile_cm` бина + сдвиг/зеркало по панели (иначе решётка «глазков»); амплитуда узора — по σL самой поверхности на фото, узор только по светлоте (иначе крапка); бледных пород в библиотеке нет — пробел (р.2 T-69).
8в. **Зерно — два предохранителя** (р.2 T-69/4: зерно тон держит, ΔE00 к ровному тону 0,02–0,84, крапки нет): амплитуда ≤0,65 (у затенённых частей σL фото — тень, не рисунок); нет высокочастотной σL фото ≥~0,8 L → амплитуда = медиана соседних частей товара, иначе без зерна (крашеный матовый комод не должен получить «дуб»). Пороги — проверить на новых товарах.
8г. **Этап меняет только свою заявленную маску; фото-тексели (prov 1–3) — байт в байт** (р.5 T-23/в–г, `tools/scout/salad/trellis/stage_mask_gate.py`): лицо портили 07b (synth prov-4) и шов (20–45 % фото-текселей у 6 из 28 — по устройству); 08 цвет не меняет. Каждый этап — маска «разрешено менять», ворота сравнивают с ней.
8д. **Непокрытые тексели** (р.4 T-70, `tools/scout/texel_pad.py`): прежний отступ 8 px не трогать; дальше — среднее покрытых соседей; доля непокрытых — в check этапа.
8а. **Тень в краску не запекать** (TG 2697, Fable Б11): краска = собственный цвет материала, свет даёт сайт; затенённые на фото детали светлее фото — не брак.
8б. **Тон лица/верха — по пикселям самой поверхности на кадре (≥500 px), кромка — только запасной источник** (р.2 T-69/2: лососевый Крит — тон верха брали с кромки в тени: L 57/C 26 против верха L 76/C 13; перенос фото→06 чистый).
9. **Мерка:** ΔE2000 + сдвиг оттенка Δh (только ΔL/ΔC увели Крит в лососевый — Ш0); по поверхностям; строгое совпадение по L — только на опорной, на теневых — оттенок; «чужой бок» = угол оттенка, не ΔE; невидимые — счётчик «чужой тон на панели»; не ругать «нет рисунка» на однотонных боках (14/27 падали так). Нахлёст: граница на ребре ≥80 %, рваность ≤1,3, полоса у границ фото ≤10 % чужого (стартовые).
10. **Свет — потом** (TG 2697): единый свет страниц и мерка светом сайта отложены до «научились дорисовывать».
11. **Система на 50k** (TG 2691, P-042): одно правило, тип — параметры; всё решает замер; сомнение → фото остаётся / пометка; глазами — выборка по клеткам «тип × материал × ступень лесенки»; пороги проверять на НОВЫХ товарах, не на 29.
12. **Советник — постоянная сессия Fable** (P-075 ⓪, TG 2709/2713): при неудаче, тупике, архитектуре — сам, не по мелочам; давать все типы и кадры всех товаров.
13. **Один материал = один тон; граница РАЗНЫХ материалов — законна** (р.3 Ш4а 1edcca59d, решение директора 25.11 00:35): опорная часть — по видимым пикселям на площадь, не по верху; мерка 07 «ступень» границу разных материалов не считает; кромку не размывать (шкаф: ступени 0,77→0,44, перёд/зад ΔE 5,0→1,9).
14. **Заморожено, не вливать** (замер на 29 не прошёл «один лучше, остальные не хуже», ADR-0476): 07b донор тела (`feat/t2423-body-paint`; back_tone 52→58, pattern 49→54) и ножки по форме T-21 (`legs_common_tone`, «все 5» 1/29 = 1/29) — «все ножки один тон» делает Ш4а по ролям (п.5). Новый хук 07 без замера «до → после» на 29 и без ворот маски (п.8г) — не вливать (уроки 948–949).
15. **Круг 29 Ш4а (р.3, 25.11 05:00, $0,045) и шкаф с нишей** — лицо↔зад dE00 2,56→0,38 на 13 крашенных, НО у шкафа 283809 лицо стёрто (щели дверей, 141 989 фото-текселей) и ниша тёмная (главный кластер L22 = тень, доля 47,5 %); far_excess 5,6→43 % — настоящий (правка мерки f141a753b снята: сдвиг ворот). Fable 05:45 (кадры A/B v0–v4): **(а) «доля главного кластера ≥0,6» — не признак материала** (тень наберёт >0,6, дерево/принт — <0,6); **(б) «фото на лице, красить невидимое» вернёт шов и запечённый свет** → замена: лицо = тон материала + МЕЛКИЕ детали фото (яркость − сглаженная, мельче ~3–5 см; щели/кромки/зерно остаются, тени/блики уходят), проверить на шкафе, диване с тенями, Крите. Тень/материал: тон — только по прямым пикселям фото; заслонённые грани (ниша, проём, низ) — «подозрение на тень» по форме, тон с наименее заслонённой панели; медиана по панелям, тон — светлейшей с ≥N px; один оттенок разной светлоты = один материал (брать светлый); карточка — сторож. **Ворота «лицо против фото» — жёсткий отказ круга** (лучше лицо↔зад за счёт стирания лица — не улучшение); ниша/проём — класс «внутренность», не малая группа корпуса; в отчёте — доля «не уверен → старый путь» и знаменатель (16 из 29 воздержались — почему).
   Второе мнение (Codex — лимит до 15:25, вместо него субагент Opus по коду, `~/remlab-logs/t2463-1124/shk/answer-opus.md`): задняя стенка ниши на фото и правда тёмная (L~27), «светлый дуб» — кромки/боковые стенки/полка (L 60–75); сломано растеканием ролей — дуб <2 % группы «фасад»/«бок» залит белым, полка взяла тон тени «корпуса» (3 % кадра → 30 % площади); у белого фасада доля 0,436 — (а) убила бы и его; k-means без seed — доля плавает (дефект воспроизводимости). Совпало с Fable: лицо = тон × (фото / размытое фото); тон по освещённой части (p70–p85 L), открытость грани исключает ниши/низы. Новое: **подгруппы «свой материал»** — связные области роли с оттенком/C, отличными от тона группы, остаются на фото. **Ворота шага (жёсткий отказ):** регресс к фото (ΔE00 >10 после при ≤10 до: >0,5 % или пятно >0,2 % кадра), щели (black-hat по L → контраст кадра/фото <0,5), запечённая тень (тон группы против p80 L чистых пикселей >15 — флаг); пороги — стартовые, не под шкаф.
   Ш4а/13 по плану Fable/Opus (р.3 7cd3617d2, ВЫКЛ, 25.11 07:00, локально): seed k-means фиксирован; ниша/проём/низ = класс «внутренность» (по глубине кадра), корпусной тон туда не идёт; лицо = тон × (фото / сглаженное); ворота «лицо против фото» (кадр 840 px: цвет, пятна, щели) — отказ → воздержание.
