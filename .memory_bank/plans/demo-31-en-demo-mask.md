## Цель
В английском демо (британский двойник `demo-uk-215`, ADR-0298) товары витрины выглядят как британские: названия по-английски,
цены в 1.5 раза выше нынешних в £, ни названия российского магазина, ни кнопки «To shop». Временно — до загрузки реальных
британских товаров; снимается одним полем в данных застройщика. Русская версия — без изменений.

## Источник задачи
Владелец 30.10.2026: «для англ демо чтоб временно все товары названия были на английском а цены в 1.5 раза выше… кнопку в магазин
убери и название интернет магазина русского убери. Это временно для демо и только в англ версии. В рус остается как есть».
Меняет ADR-0298 в части «названия товаров остаются из фидов (кириллица допустима только в них)» → новый ADR.

## Как сейчас (по коду)
- Английское анонимное демо открывает двойника `demo-uk-215` (`data/partners/demo.json` → `enTwin`, `lib/partners/registry.ts:demoProfile`,
  `app/api/apartments/[id]/route.ts`). Цены витрины — рубли фидов, показ в £ по курсу `fx` застройщика (`data/partners/demo-uk.json` → `fx.rate 0.0089`).
- Пересчёт цены — два места: страница `tools/scout/flat215-demo/index.html:fxRate()/toCard()/money()` (≈ стр. 4201) и 3D-обход
  `/flat` — `lib/configurator/source.ts:fxOf` → `lib/configurator/fromDemo.ts` (`ctx.fxRate`). Под ценами — пометка `fxNote()`
  «≈ Prices converted from roubles…». Корзина узнаёт смену курса по ключу `fxKey` (`rate@asOf`, ≈ стр. 7137).
- Названия — `p.name` из `demo-data.json` (пишет `tools/scout/flat215_demo.py`, ≈ стр. 1733; собирает и публикует крон
  `tools/scout/refresh_daily.sh`). 894 разных названия, 1087 товаров; магазины divan.ru (931), tvoydom.ru, mnogomebeli.com,
  ormatek.com, divanboss.ru. **Домен магазина часто вшит в само название** («Диван прямой divan.ru Викс Рогожка Серый»).
  Слой перевода интерфейса `I18N` (конец `index.html`) переводит только слова интерфейса и роли, названия товаров не трогает.
- Магазин и ссылка «В магазин»/«To shop» на странице выводятся в ~17 местах: списки товаров кадра (≈ 2611/2615, 2679/2682),
  картинка-список JPG (≈ 3013), карточки (3048, 3070), карточка у якоря `pinCard` (4220), строки корзины (4285/4291), карточка товара
  (4414/4423), шторка замены (4963/4966), список (6916/6920). В `/flat` — `BuildBar.tsx` «view in shop» по `shopUrl`,
  подписи уже чистятся от домена `lib/configurator/label.ts:shopStripper`.

## Решение (предлагаемое; критика Codex 30.10 учтена — `_intake/codex/demo-31-critique-2026-10-30.md`)
1. **Один переключатель у квартиры-двойника** — `data/partners/demo-uk.json` → `demoMask: { priceMarkup: 1.5, englishNames: true,
   hideShops: true, note: "временно до британских фидов, владелец 30.10" }` (схема — `contracts/partner.ts`). Карточка `demo-uk-215`
   открывается только английским анонимным демо (и вручную `?flat=demo-uk-215` для проверок) — маска действует на любое открытие
   этой квартиры; отдельный «признак анонимного запроса» не нужен. Русская квартира, ссылки менеджера, встраивание — не затронуты.
   Убрать поле = вернуть как сейчас (карточка кэшируется 5 мин — откат не мгновенный, это нормально).
2. **Цены ×1.5 — одним множителем к курсу**, в тех же двух местах: страница `fxRate()` → `rate × priceMarkup`, сервер
   `lib/configurator/source.ts:fxOf` → то же (Codex сверил: третьего пути пересчёта нет, двойного умножения нет — корзина
   `lib/basket/basket.ts:141` применяет курс только к строкам магазинов, опции застройщика — без курса). Курс `fx.rate` не трогаем.
   Сертификат, опции застройщика, цена квартиры — не меняются. Ключ корзины `fxKey` → `rate×markup@asOf` — старая корзина
   пересчитается. Пометка «≈ converted from roubles» при маске скрыта.
3. **Английские названия — гибрид, бесплатно:**
   - текущие 894 названия переводит сам рабочий (он — Claude, перевод в сессии, без платных сервисов) в файл соответствий
     `tools/scout/data/names-en.json` (ключ — `sid`, запасной — исходное название), коммит в репо, ведущий смотрит выборку глазами;
   - новые товары из ночных фидов — `tools/scout/names_en.py`: вырезать домен магазина → тип по словарю («Диван прямой» →
     «straight sofa») → материалы/цвета («Рогожка» → «woven fabric», «Серый» → «grey») → имена моделей транслитерацией
     («Викс» → «Viks»), размеры как есть;
   - **ни одной кириллицы**: если после всех шагов осталась буква — нейтральное название по роли («Sofa», «Rug») + строка в отчёте
     сборки; публикацию витрины (и русской тоже) это не останавливает;
   - сборка `tools/scout/flat215_demo.py` пишет `name_en` (и английское название цвета/варианта, где оно видно) в каждый товар
     `demo-data.json`.
4. **Показ — через поиск по `sid`, а не по копии товара.** Товар копируется в нескольких местах (`applyKit` ≈ 1648, кадры
   `productsOf` ≈ 3484, замены ≈ 4993/5015), старые подборки хранят только `name` (`lib/collections/prices.ts:20`). Поэтому на странице —
   одна карта `sid → name_en`, собранная из `demo-data.json` при загрузке, и три помощника: `itemName(p)` (при маске — из карты по
   `sid`, иначе `p.name_en`, иначе нейтральное по роли), `itemShop(p)` (при маске — пусто), `itemUrl(p)` (при маске — пусто ⇒ ссылки
   «To shop» нет). Все места вывода — на помощники: списки кадра, JPG-список, карточки, карточка у якоря, корзина, карточка товара
   с цветами (≈ 4367/4416/4945), шторка замены, выбранный предмет (≈ 4703), результат примерки со ссылкой (≈ 5023).
   Данные товара (url, shop) в подборках и корзине хранятся как есть.
5. **«Отправить себе»** — отдельная страница, её рисует `tools/scout/draft_service.py:prod/block` (≈ 655–672: жёстко ₽, магазин,
   ссылка). Страница демо при маске отправляет уже готовое: английское название, цену в £ (`toCard`), без магазина и ссылки, плюс
   валюту; сервис рисует £ и не делает ссылку. Сервис крутится на DEV — перезапуск после выкладки делает ведущий (рабочим сервисы
   DEV не останавливать).
6. **3D-обход `/flat`** — `lib/configurator/fromDemo.ts`: поле `name_en` в типах (стр. 108, `lib/configurator/demo-feeds.ts:8`); при маске
   `titleEn ← name_en` для основного товара, ленты, ковра и декора (≈ 220, 268, 304, 395); английские роль и стиль слота
   (≈ 237, 358, 389 — сейчас там русские); `shopUrl`/`shopName` не передаются (кнопка «view in shop» в `BuildBar.tsx` пропадает сама);
   сохранённые `/flat?c=` — название по `sid` из текущей витрины (≈ 446).
7. **Это маска показа, не сокрытие данных:** `demo-data.json` и API подборок по-прежнему отдают русские `name/shop/url` — так и
   задумано (временно, для показа). Сохранённые до маски итоги `GET /api/flat/config/[id]` остаются старыми — исключение.

## Скоуп — что входит
- Английское демо `/demo/?lang=en` (двойник `demo-uk-215`): главная, кадр, списки, шторка замены, корзина, избранное, подборки,
  картинка-список, «отправить себе», 3D-обход `/flat` из демо.
- Тесты, живые проверки, порядок выкладки.

## Скоуп — что НЕ входит
- Русская версия, ссылки менеджера `?s=`, встраивание, русская `?flat=` — без изменений.
- Отчёт застройщику и бот менеджера; сырые ответы API/JSON (см. п. 7).
- Отключённый сейчас каталог спальни (свой рублёвый формат, ≈ 6904) — снят с показа, не трогаем.
- Настоящие британские товары и фиды.
- Партнёрские ссылки в английском демо пропадают — для временного показа это нормально.
