## Цель
Рендер «Сделать фото» считается на видеокарте за десятки секунд, когда машина включена; владелец включает/выключает её кнопкой
в любом боте remlab (common, algor, pakardev) и сам получает «машина прогрелась, готова». Без машины — честный запасной CPU DEV.

## Решение (директор + Codex)
1. **Безопасность до запуска.** `infra/server/salad-deadman.py` сейчас гасит ВСЕ живые группы проекта при старой отметке меш-конвейера
   (`groups()`, стоп в `main()`), рендер-группу убьёт посреди кадра → охраняемые группы — правилом данными (меш), `render-*` — своим
   сторожем. `idle_guard.sh` — по `SALAD_GROUP`; меш-правила `rules/salad-groups.json` рендер не наследует. VPN-ноду не трогаем.
2. **Образ рендера** (без меш-весов): закреплённые Blender + OptiX + OIDN, базовые слои раньше кода, ничего с внешних CDN на старте.
   `render_cycles.py:109` ставит CPU — устройство параметром с проверкой фактической GPU. Размер и холодное скачивание — замерить.
3. **Транспорт:** Salad Job Queue, одно задание = два ракурса в одном Blender; сцена — манифест с хешами + короткие подписанные URL,
   кэш по хешу; кадры — в хранилище по ключу задания (лимит ответа очереди 10 МБ). Шлюз Gateway как синхронный путь — нет (100 с).
4. **Готовность:** `/health` — процесс жив; `/ready` — GPU/OptiX, доступ к ассетам и выгрузке, малый реальный Cycles-прогон. Сообщение
   владельцу «прогрелась» — один раз на запуск, только при `running && ready`; деградация — отдельным сообщением.
5. **Один контроллер вкл/выкл.** Кнопки ботов на трёх серверах вызывают локальный CLI, он шлёт идемпотентную команду одному контроллеру
   (желаемое on/off, поколение, кто нажал, срок, расход); `/start` `/stop` пишет только он. Повторный «вкл» не плодит машин. Автостоп —
   N минут после последней ГОТОВОЙ пары (не во время работы); дневной потолок $ и максимум непрерывной работы — независимые предохранители;
   отдельный сторож на другом сервере гасит только render-группу, если контроллер умер.
6. **Маршрутизатор** (`draft_service.py`): заказ сразу получает ID; есть готовая Salad → туда, нет → одно CPU-задание DEV с честным ETA.
   Потеря машины: проверить выгруженные кадры, недостающее — повторить; без CPU-дубля по короткому тайм-ауту; пара публикуется атомарно.
7. **Замер ≤ $5 (стоп $4):** 3090 и 4090 high, холод/тепло, гостиная+спальня, C1+C2, 1536×1117/64 + OIDN; pull, выделение, `/ready`,
   ассеты, BVH, каждый кадр, выгрузка, p50/p95, счёт. 4090 выгоднее, только если быстрее 3090 больше чем в 2,2 раза. Плюс 32 выборки +
   шумодав и меньший кадр для телефона.
8. **Сравнение с serverless** (без простоя, оплата по секундам): Modal / Cerebrium L4 ≈ $0,023 за пару (условные 90 с), Beam 4090 ≈
   $0,044; Salad при 24/7 и 30 парах в день — $0,16 (3090) / $0,35 (4090) за пару из-за простоя. Проба на той же сцене — нужен аккаунт
   (❓ владельцу). Фермы (GarageFarm/RebusFarm/SheepIt) для кнопки не годятся.
