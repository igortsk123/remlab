## Цель
Покупатель, открыв ссылку от менеджера на телефоне, на первом же экране видит: коротко про свою квартиру и сертификат, вкладки стилей
и начало фотографий. Внутри стиля — комнаты. Любую комнату в любом стиле можно поменять и положить в «Избранное» (глобальное, через
стили) — это и есть его выбор: сертификат считается по избранному, у комнаты с несколькими вариантами один помечен «Включить в сертификат».

## Источник задачи
Владелец 18.10 (голосовая заметка, по телефону): (1) человек уже видел квартиру — нужна минимальная информация: что это, сколько комнат,
площадь, стоимость; плашка сертификата — сколько доступно на мебель и технику; (2) вместо вкладок-комнат — вкладки-стили; текст
«Подобрали вашу квартиру в разных стилях. Можете менять мебель, отделку и встраиваемое»; на первом экране всех современных телефонов
видны вкладки стилей и начало фото — сейчас без прокрутки виден только текст и непонятно, что это; (3) выбрал стиль → ниже комнаты
(гостиная, кухня, спальня 1, спальня 2, санузел, прихожая) — варианты этих комнат; (4) избранное — глобальное, кросс-стилевое: зашёл
в любую комнату любого стиля, поменял, добавил — в избранном «Гостиная #1» (имя по комнате, можно изменить); (5) после добавления —
тост «Добавлено в избранное» на несколько секунд + ссылка «Перейти в избранное», оттуда «назад» возвращает туда, где был; (6) липкая
верхняя шапка: название квартиры, цена, избранное, маленькие кнопки (ипотека/рассрочка/консультация) и навигация; при прокрутке внутри
стиля сжимается ещё сильнее; переключение стилей по вкладкам в любом месте, как сейчас по комнатам; (7) сумма сертификата считается
только по тому, что добавлено в избранное (как корзина): товары, встраиваемое, пол, стены по комнате; при открытии следующей комнаты
это учитывается; (8) несколько гостиных в избранном — на карточке пометка «Включить в сертификат», выбирается одна на комнату.

  На SE 375×667 карточки стилей — ниже первого экрана.
- Избранное (demo-15, 18.10): локальный `FavoriteRef`, сердечко в окне, имя «<Стиль> #N», раздел «Избранное (на этом устройстве)»
  на главной; «Остаток» считается по ТЕКУЩЕЙ расстановке окна (`totalsOf`/`vwSum`), не по избранному.
- Данные: карточка квартиры `/api/apartments/<id>` (`data/partners/*.json`): комнаты, площадь, цена, сертификат, опции застройщика по

## Решение
### 1. Первый экран телефона (макет 375×667, всё до сгиба)
```
┌──────────────────────────────┐
│ 3-комн · 73,7 м² · 12 450 000 ₽   ♡ 2   │  ← липкая шапка (1 строка; при прокрутке остаётся)
│ ЖК … · сдача … · 7 этаж   [Ипотека] [Консультация] │  ← вторая строка; при прокрутке скрывается
│ Сертификат на мебель и технику: 470 000 ₽ · остаток 301 872 ₽ ▓▓▓▓░░ │
│ Подобрали вашу квартиру в разных стилях. Меняйте мебель, отделку и встраиваемое. │
│ [Сканди] [Современный] [Минимализм] [Лофт] [Джапанди] [Неоклассика] →  │  ← вкладки-стили, горизонтальная прокрутка
│ ┌─ Гостиная ───────────────┐ │
│ │  ФОТО (верхняя половина видна до сгиба) │ │  ← начало карточки комнаты видно без прокрутки
└──────────────────────────────┘
```
- Строка квартиры — из карточки (`rooms`, `areaM2`, `price`); текст про «оплата 100 %» и подсказка — в поп-ап по тапу на цену.
- Сертификат — одной строкой с полосой (как плашка «Остаток» окна, тот же компонент); при пустом избранном «остаток» = вся сумма.
- Проверка «до сгиба»: на 375×667 и 390×844 вкладки стилей и ≥ 120 px первой карточки комнаты видны без прокрутки (метрика).
### 2. Стили → комнаты
- Вкладки = стили (6); внутри стиля список комнат из карточки квартиры в порядке плана: гостиная (есть варианты), кухня, спальня 1,
  спальня 2, санузел, прихожая — у неготовых комнат карточка с единой заглушкой «появится следующим шагом» (без плиток/кнопок), чтобы
  порядок и состав квартиры читались; «План квартиры» — ссылкой в шапке/в окне («План»), не вкладкой.
- Карточка комнаты: фото (реалистичное или кадр 3D), «N предметов · сумма», сердечко (если в избранном — ♥ и имя), ⇪, «Открыть».
- Переключение стиля в любом месте страницы (вкладки в липкой шапке при прокрутке); текущий стиль — в URL (`?style=`), чтобы ссылка
  менеджера могла открывать нужный стиль.
### 3. Избранное — глобальная корзина
- Имя по комнате: «Гостиная #N» (N = max суффикс + 1 среди избранного этой комнаты); в карточке избранного — комната, стиль, сумма, дата.
- Тост после добавления: «Добавлено в избранное · Перейти →» (4 с); «Перейти» открывает раздел «Избранное» поверх (лист/страница с
  историей браузера), «Назад» возвращает в то же окно/комнату/ракурс/положение шторки (состояние сохраняем в `history.state`).
- Раздел «Избранное» — вверху главной (под липкой шапкой, свёрнутая строка «♡ Избранное · 3 · остаток …», тап раскрывает) и по ♡ в шапке.
- **Сертификат = корзина:** остаток = сертификат − Σ по комнатам (товары + встраиваемое + доплаты пола/стен, по правилам settlement:
  что вне сертификата — отдельной строкой «доплата застройщику») того варианта комнаты, который помечен «Включить в сертификат».
  Несколько вариантов одной комнаты → переключатель на карточках («Включить в сертификат» — ровно один на комнату; первый добавленный —
  по умолчанию). В окне варианта плашка «Остаток» показывает: остаток по корзине **без этой комнаты** минус текущая расстановка окна
  (подпись «с этой гостиной»), чтобы человек видел последствие до добавления.
- Изменил избранную расстановку в окне → сердечко контурное (другой `stateId`, demo-15), корзина не меняется, пока не добавил заново.
### 4. Липкая шапка
- До прокрутки — две строки + сертификат; при прокрутке — одна строка (квартира · цена · ♡ N) + вкладки стилей, остальное
  скрывается; высота липкой части ≤ 96 px на телефоне. Кнопки ипотеки/консультации — маленькие, в одной строке; на компьютере — те же блоки шире.
### 5. Что меняется в demo-15 (согласовать до кода)
- Имя избранного — по комнате, не по стилю; раздел «Избранное» — вверху (не над «Коллекции расстановок»); «Остаток» — по корзине.

## Критерии приёмки (fable-lead смотрит сам на 375×667, 390×844, 1440×900)
- [ ] Первый экран телефона без прокрутки: строка квартиры, сертификат одной строкой, текст-подсказка, вкладки стилей, ≥ 120 px фото первой комнаты
- [ ] Вкладки — стили; внутри — комнаты в порядке плана; неготовые — единой заглушкой; стиль в URL; переключение стилей из липкой шапки при прокрутке
- [ ] Добавление в избранное из любой комнаты любого стиля; имя «<Комната> #N»; тост с «Перейти →», возврат «назад» в то же место и состояние окна
- [ ] Раздел «Избранное» вверху с карточками (комната, стиль, имя, сумма, фото), «Включить в сертификат» — ровно один вариант на комнату
- [ ] Остаток сертификата = по корзине (включённые варианты комнат), доплаты застройщику отдельно; в окне — «с этой комнатой»; цифры совпадают с `settlement`
- [ ] Липкая шапка ≤ 96 px при прокрутке, ничего не перекрывает; EN без кириллицы; живые проверки и метрики зелёные
- [ ] ⚑ Владелец утверждает макет первого экрана (статичная страница `/test/share/home-v2/` с 2–3 вариантами) ДО кода
