## Цель
Перестать вручную кодировать «здравый смысл дизайнера». Решение о схеме расстановки принимает
LLM (она видела миллионы интерьеров), геометрическое ядро остаётся ПРОВЕРЯЮЩИМ: клиренсы,
проходы, шкалы, притяжка к стенам. Цель — раскладка, которую владелец не бракует с первого взгляда.

## Источник задачи
Владелец 2026-08-03: «планы надо серьёзно пересмотреть, гадания какие-то»; «может, ИИ-модель
найти, которая расстановку умеет, обучена на интерьерах».

## Что выяснено (проверено 2026-08-03)
- **Правила из интернета дают ЧИСЛА, но не ПРОЦЕДУРУ.** Дистанции/проценты/высоты есть; какой
  схемой заполнять комнату 4×4.6 с дверью в углу — нет. Отсюда «числа соблюдены, расстановка глупая».
- **Готовых коммерческих моделей расстановки нет.** ATISS/DiffuScene/InstructScene — 3D-FRONT,
  некоммерческая лицензия (проверено 2026-08-01). Новое: [SpatialGen](https://github.com/manycore-research/SpatialGen)
  (3DV 2026, веса на HF) — лицензию ПРОВЕРИТЬ отдельно.
- **Актуальный подход в статьях — LLM-агент как дизайнер:** InteriorAgent (3DV), Agentic Designer
  (arXiv 2607.20866), FlairGPT (arXiv 2501.04648). Это не отдельная модель, а связка «LLM решает —
  код проверяет», то есть ровно то, что у нас уже под рукой (Э6 прод-ядра, отложенный).
- Наш опыт дня: 15+ точечных правил добавлено реактивно (диван за дверью, пуф за диваном, кресло
  у ТВ, комод боком к стене...), каждый кадр вскрывал следующую дыру.

## Подход
1. **LLM-планировщик.** На вход: габариты комнаты, положение двери/окна/радиатора, список ролей
   с габаритами, наши шкалы. На выход — СХЕМА (какая типовая раскладка) + грубые позиции ролей.
   Строгая JSON-схема ответа, температура 0, трейсинг вызова (ADR-0013).
2. **Геометрическое ядро — проверяющий.** Существующие правила (клиренсы, проходы, шкалы,
   спинкой к стене, зона не разваливается) применяются к предложению LLM: сначала притяжка
   (snap к стенам/сетке), потом hard-проверки, потом локальное уточнение. Наш beam остаётся
   фолбэком, когда LLM недоступна или её вариант не чинится.
3. **Эталонная приёмка.** Набор эталонных раскладок для типовых комнат (7 бэндов × 2–3 схемы):
   регресс ловится автоматически, а не глазами владельца. Метрика: доля раскладок без hard-нарушений
   + доля, совпавших со схемой эталона.
4. **Проверить лицензию SpatialGen** — если коммерчески пригодна, использовать как второй источник
   схем/оценщик.

## Что переносится из отменённых планов
`entry-and-axis` (зона входа, ось зоны), остаток `set-quality-fixes` (QA против стайлинга,
подмена дизайна светильников, второй ракурс) — становятся ПРОВЕРКАМИ в п.2, а не генератором.
`adaptive-sets` (подбор варианта поменьше) — остаётся страховкой, приоритет низкий.

## Критерии приёмки
- [ ] На 10 контрольных сетах разных площадей владелец не бракует расстановку с первого взгляда
- [ ] 126 сетов: не хуже текущих 122 чистых по hard-проверкам
- [ ] Время на сет ≤ 15 с (включая вызов LLM), детерминизм при температуре 0
- [ ] Фолбэк без LLM работает (beam-движок), качество не ниже сегодняшнего
