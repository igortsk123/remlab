## Цель
Движок расстановки работает на РЕАЛЬНЫХ сложных контурах, а не только на прямоугольнике:
Г/П-образные комнаты, кухня-гостиная единым пространством (зоны без стен), эркеры, ниши.
Требование владельца 2026-08-07 (прислан план евродвушки: спальня 15.6 + кухня-гостиная
14.4+6.5 одним Г-контуром с эркером, диван-спинкой делит кухню и гостиную): «в нестандартных
сложных планировках будет работать расстановка нашего алгоритма — с учётом этого понимания
правила строй все».

## Что уже заложено (перепроверить, не переписывать)
- Вся геометрия ядра полигонная (shapely): `footprint`, `free_space`, проходы через эрозию
  полигона — форме контура безразличны (`services/planner-solver/planner/geometry.py`).
- Прямоугольник живёт в ОДНОМ месте: `Room(width_cm, depth_cm)` (`planner/models.py`) +
  кандидаты «у стены» перебирают 4 стены (`candidates.py WALLS`).
- Задел из core/layout: «непрямоугольный контур = поле контура + кандидаты "у стены" по
  рёбрам, не переделка».

## Скоуп — что входит
1. **Room с контуром**: `Room.polygon` (список вершин, см) с обратной совместимостью
   (прямоугольник = частный случай); проёмы/радиаторы привязаны к РЁБРАМ контура, не к
   4 именованным стенам.
2. **Кандидаты по рёбрам**: скольжение «спинкой к стене» вдоль каждого ребра контура
   (включая внутренние углы Г-формы); углы = пары смежных рёбер.
3. **Зоны открытого пространства**: кухня-гостиная одним контуром — функциональные зоны
   (кухня/столовая/гостиная) как мягкие регионы; диван-разделитель (спинка к кухне) — паттерн
   из реальных планировок; ТВ-зона в своей части контура.
4. **Эркеры/ниши**: низкие подоконные зоны — можно ставить низкое/декор, нельзя высокое.
5. **Правила и priors — сразу в терминах контура** (связка с [[layout-priors-from-datasets]]:
   статистику снимать С РАЗБИВКОЙ по форме комнаты — прямоугольник/Г/open-plan; датасеты
   3D-FRONT содержат реальные не-прямоугольные комнаты — использовать их контуры).
6. **Тест-набор реальных планировок**: 5–10 контуров из реальных планов (включая присланный
   владельцем) как фикстуры + страница расстановок на них.

## Скоуп — что НЕ входит
- Автозамер контура по фото (это [[room-measurement]] / unified-measurement-pipeline —
  отдельный трек; здесь контур подаётся данными).
- Мультикомнатные квартиры целиком (по одной комнате/пространству за раз).

## Критерии приёмки
- [ ] 60+ тестов ядра зелёные; прямоугольные сеты не деградировали (перегон 126).
- [ ] Присланная владельцем евродвушка (кухня-гостиная Г-контуром) расставляется валидно:
      зона гостиной у эркера, диван-разделитель, кухонная линия не перекрыта.
- [ ] Страница расстановок умеет показывать полигональные комнаты.
