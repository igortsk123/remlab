## Цель
На листе с несколькими рисунками («Этаж 1 / Этаж 2», «Ground / First Floor», «Garage») сверять площадь каждого
разобранного этажа с площадью, напечатанной под ним, чтобы пропущенная или потерянная часть этажа ловилась, а не
тихо давала неверные метры. Только проверка — не новый источник масштаба.

## Источник задачи
Владелец, TG 1160–1164 (16.11, голос): «учитывать подписи под объектами: этаж 1, этаж 2 — делить отдельно площадь
этажа 1 и этажа 2». На вопрос «добавить сверку как страховку, не как масштаб» — «с кодексом реши и я согласен».
Codex (ephemeral, 16.11): `_intake/codex/2026-11-16-floor-area-check-answer.md`.

## Как сейчас (сверено с кодом 16.11)
- Заголовки рисунков VLM отдаёт с точками (`tools/floorplan/vlm.py` `labels3/4.titles`), лист режется на панели
  (`bench.py:run_plan`), масштаб по подписям размеров — свой у каждой панели (`fpcore.py:fit_scale`).
- Итоговые площади листа VLM отдаёт списком без точек (`areas: [{label, m2}]`); `pipeline.run` сразу сворачивает их
  в одно число `listing.sheet_area` (Total, иначе сумма частей, флаг `area_sum_of_parts`) → `pick_area`.
- Масштаб по площади — один на лист (`pipeline.py:area_scale`), сверка общей площади — только агрегатная
  (`scale_of`, `AREA_CONFLICT_REL` 10 % линейно ≈ 20 % площади — грубо для пропущенной комнаты).
- Посекционная сверка есть только в стенде (`bench.py` около `log['areas']`, по ручному золоту): A 1,2 % / 3,9 %,
  B +8,3 % (`/home/pakar/remlab-logs/t38/bench-after3/metrics-{A,B}.json`).

## Решение (свой вывод + Codex, сведено)
- **Только проверка, не масштаб панели:** подгонка масштаба этажа под его площадь обнуляет саму проверку, а пропуск
  комнаты превращает в раздувание остальных (Codex и свой вывод совпали).
- **Место:** `pipeline.to_result` — после `scale_of` и `_scale_model`, до `panel_result`.
- **Мера — как напечатано:** UK GIA ↔ геометрическая GIA панели (`P.gia_m2`, при статусе `area` × k²); RU «общая /
  площадь этажа» ↔ сумма ГЕОМЕТРИЧЕСКИХ площадей комнат модели. Не брать `areaM2` результата — она заменяется
  напечатанной площадью комнаты (`area_shown`), сверка стала бы круговой. Прочие меры (NIA, living, usable) → `unknown`.
- **Привязка площади к панели только при высокой уверенности:** точное нормализованное совпадение с уникальным
  заголовком панели; заголовок панели внутри подписи площади; единственная нетотальная площадь + единственный рисунок.
  Всё прочее — `inconclusive` (не по порядку, не по ближайшему bbox, не «House» к этажу).
- **Порог расхождения:** `|√(получено/напечатано) − 1| > 5 %` И `|разница| > 3 м²` (5 % линейно ≈ 10 % площади:
  B +8,3 % проходит, пропуск комнаты ловится; 10 % линейно — слишком грубо).
- **Запрет блокировки** при `panel_title_guess`, `panel_titles_merged`, `vlm_panels_disagree`, `area_pages_skipped`,
  кусках одного рисунка — там вероятнее ошибка привязки.
- **Слияние двух комнат площадью не ловится** (GIA не меняется) — остаются флаг `merged` и покрытие подписей; в
  объявлении возможностей так и писать.

## Скоуп — что входит (этап 1, «тень», 0 ₽)
- Сохранить исходный список `areas` VLM рядом со свёрнутой общей площадью.
- Общий помощник `floor_area_checks(...)` в `tools/floorplan/` (не в стенде); стенд `bench.py` переводится на него.
- Поле результата `areaChecks: [{scope, panelIds, status ok|mismatch|inconclusive, printedM2, reconstructedM2,
  measure, scaleDelta, label, association}]` — штатное расширение `contracts/trial.ts` + схема; необязательное.
- Только запись и флаг панели, без `awaiting_check`; прогон `regress.py` по корпусу trial-листов → распределение
  расхождений по мере / статусу масштаба / привязке.
- Тесты: мера (gia/rooms/unknown, ×k²), привязка (точный заголовок, единственный рисунок, повторы, `First Floor` /
  `First Wing`, House/Outbuildings, куски), порог (ровно 5 % / 3 м²), золото A/B/C (A — обе ok, B — не mismatch,
  C — House inconclusive), листы без площадей — результат без изменений, кроме отсутствующего `areaChecks`.

## Скоуп — что НЕ входит (этап 2, отдельное решение после «тени»)
- Новый промпт `labels5` (у площади `pt`, `panel_title`, `measure`, `unsure`, исходная единица) — меняет кэш VLM
  только для новых заданий; цена — в пределах потолка $0,10 на задание, решать по данным этапа 1.
- Блокировка: флаг комнаты `panel_area_mismatch` в `SIZE_CHECK_FLAGS` (`tools/scout/trial_bundle.py`) → комнаты этажа
  в `awaiting_check` при высокой уверенности и статусе `verified` / `listing` (у `area` — только при нескольких
  панелях); надпись RU/EN: «Площадь этажа не сошлась с указанной на плане — проверьте размеры» / «This floor's
  reconstructed area does not match the plan — please check the dimensions».
- Масштаб по площади этажа — не делаем вовсе.

## Конвейер, не заплатка
1. Правило: сверка площади рисунка с его подписью — общее для всех листов RU/UK, без ID в коде.
2. Где действует: все загрузки /try, перевыпуск туров (reparse), стенд и регресс распознавания.
3. Пересборка: результат разбора пересобирает `pipeline.py`; туры — штатный перевыпуск, руками ничего.
4. Особых случаев нет: привязка только по заголовкам и правилу единственного рисунка.
