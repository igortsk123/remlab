## Цель
У диванов mnogomebeli.com (shop 114667) и divanboss.ru (114082) глубины нет текстом — только «Изображение с размерами» (чертёж с
подписанными размерами). Проверить, можно ли НАДЁЖНО читать глубину с чертежа. Надёжно → глубина в каталог (источник `drawing`),
диваны и их готовые меши (≈826) становятся пригодны; ненадёжно → блокировка «нет глубины — нет меша/расстановки» остаётся.

## Источник задачи
Владелец 04.11 TG 138/141/143 (голос): «а по фото разве нельзя?… попробуй А… проверяй, можем ли мы глубину определять; если получится —
разблокируешь, если нет — оставишь блокировку». Разбор ведущего: 918 активных без d_cm (361 угловой), у почти всех есть чертёж
(пример «Кинг»: спереди 291 — общая ширина = карточке, сверху 242 — прямая часть, 160 — общая глубина, 65 — сиденье).
Codex 04.11 — `.claude/tmp-chk/codex-drawing-dims-answer.md` (архитектура, гейты, порядок).

## Скоуп — что входит
1. **Бесплатно — инвентаризация:** по фидам обоих магазинов — эллигибельные SKU (нет d), ссылка на чертёж, дедуп по URL и sha256 байтов
   (Codex: 1 641 оффер → 321 уникальный путь; путь не встречается у разных ширин — перепроверить), тип (прямой/угловой/модульный, сторона).
2. **Бесплатно — контакт-лист:** HTML-страница 30–50 чертежей (стратифицировано: оба магазина, прямые/угловые/модульные/П, повторяющиеся),
   рядом ширина/высота карточки — ведущий размечает глазами «какая цифра — общая глубина» (эталон пилота).
3. **Новый модуль `tools/scout/drawing_dims.py`** по образцу `tools/scout/rug_kids.py` (кэш, строгий JSON, ошибка ≠ вердикт): модель
   возвращает ВСЕ размерные линии (вид front/top/side, ось, тип overall/subdimension/seat/sleeping, число, единица); детерминированный код
   выбирает: общая ширина = карточке `|Δ| ≤ max(3 см, 2 %)` → перпендикулярный overall вида сверху = d. Гейты: единица явная; d — overall,
   не seat/sleep; прямой 70–150, угловой 120–260, модульный/П 120–400; у углового d > глубины сиденья; несколько ширин/конфигураций — отказ;
   confidence модели ничего не разрешает. Кэш по sha256 + модель + версия промпта/схемы. Счётчики: eligible, unique, hit/miss, сбои
   скачивания/модели/разбора, no-overall-width, width-mismatch, no-overall-depth, multi-variant, implausible, accepted.
   Фикстуры ответов + тест разборщика без сети.
4. **Платно, пилот:** 20 уникальных чертежей (из размеченных в п.2), cache-only, без БД. Модель — через Vercel AI Gateway (деньги продукта,
   ADR-0301); fallback на прямой OpenAI выключен. Ведущий сверяет каждый вердикт со своей разметкой.
   **Стоп-кран:** хоть одно ложное принятие (принята не та цифра) → блокировка остаётся, итог владельцу.
5. **Пилот чист →** shadow по всем уникальным чертежам (~321), ручная проверка ≥ 50 принятых + все классы отказов/выбросов.
6. **Включение (одним шагом):** `load3.assign()` после `resolve_dims()` подмешивает принятую глубину из локального кэша без сети
   (`dims_evidence.d`: source `drawing`, raw, unit, sha чертежа, URL, model, prompt/schema ver, ширины и Δ, статус); `drawing` не учить
   в `dim_prior` и `mesh_dims` (исключить из эталонов); материализовать из кэша каждый прогон только при совпадении sha;
   один подъём `HASH_VERSION` (baseline, без stale); снимок до/после; откат — убрать кэш-оверлей.
7. Downstream — ночной порядок `refresh_daily.sh` (dim_prior → capabilities → mesh_family → mesh_bind → bank); выборочно глазами
   растяжение мешей угловых по новым W×H×D.
