## Источник задачи
Владелец 07.11 голос TG 434: «если дети есть — показываем пару детских: два варианта, наиболее популярные стили детских, но чтобы была
разница; спальню — из того, что есть по конвейеру; детскую собрать отдельно». TG 437: «детская — это та же спальня, просто детская
кровать, стол для ребенка для учёбы. Наполняй, делай расстановку. Можешь в конец, ночью поработаешь». Правило TG 430: дизайн — сначала владельцу.

## Что уже есть (сверено ведущим 07.11)
- Детские роли грузятся в `room_catalog` с onb-04 (ADR-0330): `kids_roles` = кроватка, кровать детская, стол детский, стул детский
  (`tools/scout/rules/bedroom-roles.json`); в показ не включены (`roles_enabled` — только взрослые); назначения `child:0-3|3-7|7-12|teen`
  у ролей (`purposes`), `purpose_requires child:0-3 → кроватка`; детский магазин `kids_store.enabled:false`.
- Состав спальни по назначениям — `tools/scout/rules/bedroom-composition.json` (`purposes.couple|single|…`), профиль
  `tools/scout/rules/profiles/bedroom.json`, сборщик `compose_bedroom.py`; камеры `CAM_ZONES.bedroom` в `tools/scout/flat215-demo/index.html`.
- Опрос: экран «Какой стиль детской вам ближе?» (`rules/quiz.json` → `nursery_style`) показывает пару фото СПАЛЕН; ответ → спальня 2.
- Возраст и число детей — в ответах опроса (`household.child.ages/kids`).

## Решение
1. **Назначение `child` (одно, школьное 7–12 по умолчанию; `teen` — та же раскладка с кроватью 90×200).** Детская = спальня 2 с назначением
   `child`: слоты — кровать детская (или односпальная 80–90 × 190–200), стол для учёбы (стол детский / стол рабочий 90–120 см) + стул,
   шкаф или комод, стеллаж/полка; декор — лампа на стол, ковёр, шторы из каталога гостиной (с детским фильтром — детские ковры можно).
   Кроватка 0–3 — НЕ в этом плане (одна ступень возраста, иначе вдвое работы); в опросе «до 3 лет» → та же детская.
2. **Два стиля детской (контрастных, популярных):** гипотеза — «сканди светлое дерево и белое» | «яркая/цветная» (или «джапанди
   спокойная»); проверить по источникам (подборки детских у Divan/Hoff/IKEA/Pinterest-трендов 2026, РФ и UK) и по наличию товаров в каталоге
   каждого стиля (≥ 2 кровати, ≥ 2 стола в стиле). Выбор с источниками → ⚑ ведущий, владельцу одной строкой.
3. **Каталог:** включить детские роли в показ только для назначения `child` (флаг на роли+назначение, взрослая спальня байт в байт та же);
   при нехватке — `kids_store` (детский магазин) после сухой выгрузки и счёта.
4. **Расстановка:** правила спальни + стол у окна (свет слева для правши — гипотеза, по нормам проверить), проход ≥ 60 см у стола, кровать
   не под окном; экзамен на спальне 2 flat215 + ≥ 10 сцен 8–12 м²; спальня взрослых без регресса.
5. **Меши:** детские кровати и столы выбранных наборов — в очередь мешей (пул Salad, тот же учёт и приёмка `core/mesh-pipeline.md`).
6. **Фото:** камеры — как спальня (`CAM_ZONES.bedroom` + стол в кадре), 2 вида на набор; конвейер ночью; сперва 1 проба → глазами ведущего.
7. **Показ:** в опросе экран «детская» — пара фото детских двух стилей (если обе есть; нет — экран как сейчас), выбор → набор спальни 2
   `child`; карточка «Детская · N м²» вместо «Спальня 2» при ответе «с детьми»; без детей — спальня 2 как сейчас.

## Не трогаем
Взрослые спальни, гостиную, кухню (T-40), кроватку 0–3, двухъярусные (2+ детей — одна кровать, подпись менеджеру).

## Порядок и деньги
Ночь 07→08.11, после текущих задач. Меши — по тарифу пула в пределах ночной квоты; фото ≈ 5 ₽ лист × ~4 = 20 ₽; поиск стилей — бесплатно.
Дизайн экрана (опрос + карточка) — снимок владельцу ДО выкладки (TG 430).

## Критерии приёмки
- [ ] ≥ 2 набора детской двух разных стилей на спальне 2 flat215: кровать детская/односпальная, стол для учёбы со стулом, хранение; без наездов.
- [ ] Фото нейросети детской — 2 вида на набор, мебель на местах, ведущий смотрит сам; ни одного голого 3D.
- [ ] Опрос «с детьми»: пара детских → выбор попадает в спальню 2; без детей — без изменений.
- [ ] Взрослая спальня и гостиная — экзамены и golden без регресса; тесты scout `CI=1`, tsc, vitest зелёные.

## Правки по критике Codex 07.11 (главнее текста выше; ответ — `~/remlab-scratch/codex-kids-1840/answer.md`)
- Модель верна: `bedroom-2`, `room_type=bedroom`, `purpose=child`, `child_age=7-12` (новый room_type НЕ вводить — ADR-0330).
- Тракт `child` сейчас мёртвый: композиция child — pending, солвер `PURPOSE_PENDING` (`planner/bedroom.py`), `compose_bedroom.py` не передаёт
  `child_age`, `purposes_of()` в подборе не участвует. Взрослая кровать/рабочий стол ребёнку разрешены только `teen` → для 7–12 только детские роли.
- Каталог (снимок onb-04, 05.11): кровать детская 102 (20 семейств), стол детский 81 (15), стул детский 6 (5) — узкое место стулья.
  Шаг 1 — отчёт `7-12 × стиль × роль × семейство`; на стиль ≥ 2 семейства каждой основной роли; не хватает — ОДИН стиль.
- Каталог по назначению (purpose-aware), не глобальное включение `kids_roles`: детские шкафы/комоды выкидывает `catalog_items.py` — снятие
  фильтра пустит их во взрослые комнаты. Тест «0 детских товаров во взрослых комнатах» + взрослые golden байт в байт.
- Нормы — числа только в `occupancy.json`: кровать — проход 75 см сбоку, 60 см в ногах; стол — 75 см под стул (не 60); «у окна ≤ 100 см» и
  «кровать не под окном» — мягкий штраф; свет слева — мягко (ведущую руку не знаем). Псевдонимы ролей детская кровать→кровать,
  стол детский→стол рабочий, стул детский→стул рабочий — в `planner/bedroom.py` / `bedroom_checks.py`, тесты `test_bedroom_solver.py`.
- Камеры: детские роли в `profiles/bedroom.json` и `CAM_ZONES.bedroom` (сейчас узнают только взрослые названия).
- Меши: только недостающие у двух выбранных наборов (≤ 6: 2 кровати, 2 стола, 2 стула), потолок в рублях.
- Фото: свой промпт «комната школьника 7–12» (без люльки, двухъярусных, людей, лишней мебели, чужих постеров); 1 проба → ведущий.
- Опрос: «до 3 лет» в школьную детскую НЕ вести (кроватки нет) — для 0–3 экран детской не показывать; 2+ детей — подпись «одна кровать» в UI.
- Полка — конфликт с deny-правилом (`bedroom-roles.json`): в MVP без полки. Настольная лампа — отдельное правило декора.
- Геометрия спальни 2: комментарий в `index.html` «комнату нельзя обещать» — сверить до показа.
- **Ночь 07→08.11 — только шаги 1–3** (отчёт каталога и выбор наборов; `child_age` через композицию/солвер + каталог по назначению + тест
  утечки; псевдонимы ролей, обязательные кровать+стол+стул, нормы, тесты на обеих площадях спальни 2). Сборка, меши, фото, опрос — следующими циклами.
