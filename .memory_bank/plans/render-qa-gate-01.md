## Цель
Ни один кадр с браком (пустая картина, пропавшие шторы, не тот ракурс, висящий предмет, пересвет) не уходит человеку — ни владельцу,
ни покупателю. Источник: владелец 17.11 TG 1567/1568/1570 «че с картинами», «ты плохо проверяешь», «продумай как проверять лучше» —
директор отправил 16 образцов стен с белыми картинами (товары «Рельеф … Белый»), раньше — рендер «как на телефоне» без штор.

## Решение (директор + Codex `_intake/codex/2026-11-17-render-qa-answer.md`)
Сверять цепочку **товар → выгрузка → реально загруженный GLB/материал → видимый пиксель → отправляемый файл**, а не намерение.
1. **До рендера** — оплачиваемые позиции против слотов выгрузки и собранной сцены (`demo_scene_dump.mjs:70` выгрузка, `:86` узлы GLB);
   ошибки загрузки, хеши, привязка карт к материалам. Нет обязательной геометрии/карты — стоп. Исключения ткани (`scene-export.ts:219`,
   `data/flat3d/textile.json`) — явные, не «потеря». Опора/коллизии — по классу предмета (подушка на диване не брак).
2. **Каждый кадр** — Cryptomatte-маски: обязательные предметы, видимые в этом ракурсе; у картины — маска полотна без рамы и бликов,
   ≥400 пикселей, сверка с загруженной картой; мало пикселей → «неопределимо», не «чисто».
3. **Паритет «как на телефоне»** — та же камера, аспект, состояние сцены; сравнение силуэтов штор и крупных предметов, не только центров.
4. **Последний файл** — лёгкие проверки на ровно том файле, что уходит (включая результат фотосервиса). VLM (`viz_qa.py`) — второй
   сигнал и очередь разбора; сейчас при недоступности модели он отдаёт `ok: true` (`viz_qa.py:112`) — воротами не годится.
5. **Один компонент** с отчётом по `scene/variant/camera/output hash`; отправка и публикация принимают только кадр с пройденным отчётом
   того же хеша. Ночной прогон — охват комнат, стилей и всех мешей.
6. **Отбор декора** — картины в набор по умолчанию только с видимым рисунком/цветом (T-20261117-18, рабочий 2); белое искусство
   остаётся в каталоге как замена — сторож кадров его не бракует, если товар выбран человеком.
7. **Директор** перед отправкой владельцу смотрит каждый кадр по списку: картины, шторы, растения, подушки, окна.
   **Владелец 17.11 TG 1640: «сам проверяй все фотографии — система не справляется»** → глазами — ОСНОВНАЯ проверка каждого кадра
   (владельцу и при приёмке работ), включая мебель целиком; сторож из пп. 1–5 — вторая страховка, не замена.

## Проверка сторожа
Инъекции: убрать карту картины, сделать её белой, убрать штору, подменить камеру, скрыть товар, оборвать загрузку, подменить кадр после
проверки. Допустимое: белое искусство по выбору, гладкие ковры, частичное перекрытие, тюль, исключённый плед. Считать долю пойманного
по типу, ложные блокировки и «неопределимо»; пороги — по этим примерам на нескольких комнатах.
