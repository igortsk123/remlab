## Цель
Покупатель двигает мебель и меняет товары, нажимает «Сохранить» — коллекция получает адрес, появляется
карточкой в «Коллекциях расстановок», открывается по ссылке на любом устройстве и у близких, уходит в
обращение к менеджеру (`b2b-02`) и в 3D (`b2b-06`). «Создать свой» = новая карточка, а не редактирование чужой.

## Источник задачи
Презентация/демо: «все предметы можно двигать, сохранять коллекции и делиться с близкими».

список» — печать в PDF (`:868`), JPG `disabled` (`:815`); `flat215-mine` читается, не пишется (`:948-953`).
Предпосылка из `MASTER-interactive-planner` P0/P7 и `demo-flow-3d-en`: передавать СНИМОК СЦЕНЫ с хешем,
не номер варианта.

## Скоуп — что входит
1. **Контракт коллекции** (один с `b2b-06`): партнёр/квартира/комната, `send id` отправки (учёт по отправке, не по человеку, ADR-0254), базовый вариант (стиль), список
   предметов (sid/msid, координаты, поворот, габариты), декор, камеры, сумма, язык, версия квартиры,
   ревизия, время. Без ПДн. Хеш содержимого — для кэша рендера. Цены в коллекции при открытии всегда текущие (из `conv-10`), пропавший товар помечается, не подменяется (ADR-0254).
2. **Сервер:** `POST /api/collections` → id (короткий), `GET /api/collections/<id>`; хранение в
   Postgres (таблица `collections`), лимит размера, срок хранения (`b2b-04`), рейт-лимит (`b2b-01`).
   Демо-страница статическая → ручка в Next с CORS на свой origin (как `b2b-02`).
3. **Страница:** «Сохранить» (без аккаунта: ссылка + локальный список «мои коллекции»), карточка в
   коллекциях с бейджем «моя», «Поделиться» копирует `/demo/#c=<id>` (с языком), «Создать свой» →
   копия выбранного варианта → карточка; кадры — через существующий рендер по снимку сцены.
4. **JPG/печать:** JPG включить (кадр из реестра), печать — список с суммой и ссылкой на коллекцию.
5. **Связь:** обращение к менеджеру (`b2b-02`) и вход в 3D (`b2b-06`) принимают id коллекции.
5b. **«Отправить себе»** (В6): заглушка остаётся до конца этого плана; затем — доставка ссылки на коллекцию
   через Telegram-бот/почту без файлов с контактами (контакты — в базу, `b2b-01`).
6. Тесты: unit контракт, e2e «подвинул → сохранил → открыл в приватном окне → то же».
