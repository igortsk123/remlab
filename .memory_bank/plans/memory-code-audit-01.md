## Цель
Каждое утверждение «как работает» в банке совпадает с кодом; устаревшее — в архив; дубли сведены к одному месту; у каждой сводки
честный `last_verified`. После уборки агент, читающий INDEX → core → domain, не получает неверных фактов.

## Источник
Владелец 18.11 TG 1875 (голос): «большой аудит кода относительно памяти, прибраться полностью, чтобы всё было чётко».
Состояние до: 40 сводок `core/`, 26 `domain/`, 14 `guides/`; аудит — 5 CODE-DRIFT, самая старая сверка — `core/market.md` (11.07).

## Как (на каждый док своей половины)
1. Субагент `verify` (режим «по списку доков», `.claude/agents/verify.md`) → таблица «утверждение → `файл:строка` / не найдено».
2. MISMATCH → переписать утверждение по коду (с условиями: флаги, роли); устаревшее целиком → `archive/` + строка в
   `changelog/memory-log.md` (не удалять). Нет якоря на код → добавить `путь`/`путь:символ`.
3. Пара Tier 1 ↔ Tier 2: сводка не противоречит деталям; один факт — одно место, второе — ссылка `[[имя]]`.
4. `last_verified` = сегодня ТОЛЬКО если сверен весь док; строка `node tools/memory-health.mjs --log-verify <док> --claims N
   --mismatch M --fixed F --reason drift|rotation`.
5. Конец половины: `node tools/memory-audit.mjs --check .` и `node tools/memory-project-audit.mjs .` — чисто; коммит ТОЛЬКО своих
   путей (`r git add <пути>`), без push.
