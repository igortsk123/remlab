## Цель
Оформить генератор как БАЗОВЫЙ алгоритм + комбинируемые модификаторы (SMALL+ELONGATED+
WINDOW-HEAVY действуют одновременно через скоринг, а не три отдельных алгоритма), и добрать
правила свода №5, которых ещё нет.

## Источник задачи
Свод владельца 14.08 №5 (Livingetc, H&G, Ideal Home, AD): 14 модификаторов + принцип
«меньше нормальных предметов лучше многих маленьких», типы clearance, visual mass,
multi-function, концентрация хранения, «без дивана», масштаб divider'а, квадратные/L/косые/
колонны/двойной фокус/swivel/окна/эркер/open-plan/потолки.

## Критическая оценка
Возражений с контр-пруфом нет. Архитектурно свод ПОДТВЕРЖДАЕТ выбранное направление:
модификаторы = наши mode/shape + скоринг (уже комбинируются). Значительная часть УЖЕ ЕСТЬ —
фиксируем соответствие, НЕ дублируем:
- «не растягивать беседу >2.4 м» = group_compactness/VIS_FACE (large-свод) ✔
- вертикальное хранение, media+storage combo, концентрация (≤2 зон, вторая на другой стене) ✔ (частично)
- «TV не обязан быть визуальным центром» = у нас камин/медиа раздельно, смягчённая симметрия ✔ (частично)
- окно с учётом ВЫСОТЫ предмета = WINDOW_BLOCKED (h vs подоконник) ✔ — свод расширяет score
- elongated / large / small — сделаны ✔
- «шаблон без дивана» = ступень armchair_pair лестницы ✔ (проверить достижимость)
- эркер: контуры есть, но спец-кандидатов эркера нет ✖

ГЛАВНЫЕ ЗАВИСИМОСТИ ОТ ДАННЫХ (честное ограничение): visual_mass, тип подлокотников, ножки,
низкий профиль, swivel, «столик с хранением», nesting — ЕСТЬ в обогащении каталога
(model.visual_mass, specific.arms, legs, functional_subtype, rules.features) — модификаторы
подбора реализуемы БЕЗ новых пайплайнов; console как роль — НЕТ в каталоге (отложить).

## Сверка конфликтов
| Существующее | Риск | Решение |
|---|---|---|
| quality_gate маршруты 90/76/60 | «типы clearance» свода — те же числа + DEAD_SIDE | расширить quality: классификация is_path; DEAD_SIDE без пешеходного зазора; числа НЕ дублируем — та же таблица |
| group_compactness | «large: масштаб мебели, не расстояния» | совпадает; добавить только «сначала крупнее мебель/вторая пара — потом расстояния» в лестницу large |
| Штраф пустой границы (E4) | «divider по масштабу» | расширить E4: div_span/границы; мелкий предмет не может быть divider (пуф-граница = штраф) |
| media_mirror/фокусы | MULTI-FOCAL «visual vs functional» | камин=visual, ТВ=functional уже разделены; добавить кандидатов «TV offset/adjacent» без требования симметрии |

## Этапы (пакетами; гейт каждого: 252/252, медиа 252/252, все сторожа)

### M-A. Подбор: эффективность и масса (свод «малые»)
A1 seating_efficiency: места/площадь; sectional-бонус при ≥мест и меньшей площади; штраф
«много мелких предметов» (items_count не есть добро). A2 visual mass в скоринг подбора:
дефицит ширины → slim/armless бонус; дефицит глубины → shallow; перегруз пола → ножки
(поля обогащения). A3 округлость при конфликте траекторий: столик/пуф round/oval бонус,
если прямоугольный режет ≥2 циркуляционных конверта. A4 multi-function: прежде нового
предмета — поиск существующего с функцией (пуф=сиденье, столик-с-хранением, банкетка).
A5 концентрация хранения в малых: один блок 180 лучше 100+80 на разных стенах (бонус
кандидату-конкатенации, штраф разбросу).

### M-B. Clearance-классификация (свод «очень тесные»)
B1 quality.py: классификация пространства is_path (main/secondary/between/dead_side);
90 — цель ГЛАВНОГО маршрута; между мебелью 40–60; dead_side — без пешеходного зазора.
B2 пересмотр жёстких клиренсов валидатора по классам (не ослаблять main!).

### M-C. Геометрия комнат
C1 SQUARE: aspect≈1 → приоритет симметричных центральных схем (sofa+2 кресла вокруг
круглого стола; sofa-table-sofa); при «сплошных прямоугольниках» бонус округлым. C2
L-SHAPED: детект вогнутого угла → декомпозиция на 2 прямоугольника; большой — primary,
малый — secondary; штраф мебели через «локоть». C3 IRREGULAR: две семьи кандидатов
FOLLOW_WALL vs INTERNAL_GEOMETRY, скорить обе; косой угол → сперва округлое. C4 COLUMN:
колонна = граница кластера (бонус выравнивания), штраф колонны внутри группы; при делении
пола — отдельные регионы. C5 BAY: спец-кандидаты эркера первыми (window seat/скамья/
компакт-кресло/растение); штраф прямоугольнику с клиньями по бокам.

### M-D. Фокусы, окна, open-plan, потолки
D1 MULTI-FOCAL: PRIMARY_VISUAL vs PRIMARY_FUNCTIONAL; кандидаты TV centered/offset/
adjacent_to_fireplace; sightline отдельно от симметрии. D2 swivel: rotation_mode из
обогащения; бонус поворотному креслу при двух направлениях внимания. D3 WINDOW-HEAVY:
window_blocking_score = перекрытие × высота × важность окна (расширение WINDOW_BLOCKED
в скоринг). D4 OPEN-PLAN divider-оформление: sofa+console/open-shelf как варианты
(console — после появления роли). D5 HIGH-CEILING: vertical_scale_score — при высокой
большой комнате штраф «всё низкое», бонус высоким стеллажам/крупным растениям (высота
потолка — параметр сцены, добавить в Room).

### M-E. «Без дивана» и divider-масштаб
E1 достижимость armchair_pair: если ВСЕ кандидаты дивана ломают циркуляцию/функции —
лестница легально уходит в кресла+стол (не failure). E2 divider-масштаб: пуф/мелочь не
может быть границей зоны (расширение E4 elongated).

## Порядок
M-B (дёшево, разблокирует малые) → M-A → M-C (C5 эркер первым — есть сцены) → M-E → M-D.
Каждый пакет — свой прогон и коммит; модификаторы комбинируются скорингом.
