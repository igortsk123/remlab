## Цель
Покупатель сразу видит, что у дивана (кресла, стула…) есть другие цвета — без «Заменить»; в увеличенной карточке товара тап по
цвету мгновенно меняет фото (и цену/ссылку, если отличаются), «Сохранить» меняет ЦВЕТ этого товара, а не модель.

## Источник задачи
Владелец 23.10: «если несколько цветов — открываем карточку дивана… меняем цвет и сразу видим, как меняется фотография; „Сохранить“ —
диван не заменяется, меняется его цвет. Это первый вариант. Второй — все цвета как отдельные товары… визуально увеличит выбор.
Посоветуйся с Codex»; «сейчас другие цвета видны, только если нажать „Заменить“, а это не очевидно».
Разбор: `_intake/codex/color-variants-2026-10-23-answer.md` (gpt-6-sol, запасной канал по слову владельца) — гибрид, вариант 1 в основе.
Совпало с выводом ведущего. Данные (выгрузка 23.10): у divan.ru диваны/кресла — семейства по 3 (до 7–8) цветов, у каждого цвета своё
фото, цена обычно одна; у tvoydom/Орматек цветов в семействах нет.

## Что есть (по разбору, исполнителю — сверить)
- Лента замен уже: одна плитка на другую модель с «ещё N цветов», цвета ТЕКУЩЕЙ — чипами сверху; тап по чипу СРАЗУ применяет SKU
  (`tools/scout/flat215-demo/index.html:4734/4743/4760/4772`). Предпросмотра и «Сохранить» нет.
- 3D: цвет варианта — приблизительный `tint` по тону фото поверх меша представителя (`lib/viewer3d/meshes.ts:172`, `flat215_demo.py:1531`);
  не выделяет обивку от дерева/металла.
- Экспорт: `sid` товара и `msid` модели раздельно, лимит ленты 30 SKU на подкатегорию×стиль (`demo_swap_pool.py:61/125/147`,
  `rules/demo-swap.json:3`) — «N цветов» считать по реально доступным в ленте, не по всему семейству; имя цвета — из названия.
- Группировка строк — по `url|name` (`index.html:2520/2613`), избранное хранит `sid`/цену/ссылку/`stateId` (`:6746`).

## Решение
1. **Строка списка** (вариант, «Избранное»): под названием — ряд кружков-образцов (до 5, дальше «+N»), если у товара ≥ 2 доступных цвета.
   Тап по кружку → увеличенная карточка (T-09 Д) сразу с этим цветом в предпросмотре.
2. **Увеличенная карточка:** ряд образцов с подписью цвета; тап — мгновенно фото/цена/ссылка выбранного цвета (предпросмотр, ничего не
   применяется); кнопка «Сохранить» (только если выбран другой цвет и он в продаже) — меняет SKU в слоте, модель та же; без «Сохранить» —
   закрытие ничего не меняет. Цвет без рабочего фото — не показывать; не в продаже — не давать сохранить.
3. **Лента замен:** чипы цветов текущего товара — тоже через предпросмотр+«Сохранить» (одно поведение), плитки моделей — «N цветов» как сейчас.
4. **3D и фото:** после смены цвета — нынешний приблизительный `tint`; тост «Нажмите «Сделать реалистичнее», чтобы увидеть изменения»
   (как у мягкого, строка `CTA_REAL`); номер состояния меняется (фото устаревает — честно).
5. **Учёт:** группировка строк и корзина — по `sid`; сохранённое избранное молча не менять (новый выбор — новое состояние); `/flat` — id опции
   по `sid`, не `msid`. Парные кресла — цвет меняется у пары.
