## Цель
Автоподмена банка начинает давать готовые ячейки: кандидат не переезжает каждую ночь, меши, заказанные под ячейку,
доживают до её готовности, а свежая привязка меша видна promote в ту же ночь.

## Источник задачи
Ночь 23.10: 0 подмен (wait 118, blocked 8). Разбор T-20261023-07/1 (исполнитель): ночной кандидат и проба через 30 мин совпали в
1109 из 2754 позиций, капсула другая в 107/126; две пробы подряд — 12 ячеек разные. Codex (`_intake/codex/bank-candidate-stability-2026-10-23-answer.md`):
корень составной — pending считается ДО `mesh_bind_early` + churn кандидата; promote не «слишком строгий». Часть conv-14 (очередь MASTER).

## Решение (по Codex, сверено ведущим)
1. **Порядок ночи** (T-08): `enrich/decisions → mesh_family_early → обновление чёрного списка → bank_prepare (без pending) →
   mesh_bind_early → bank_pending --update → bank_promote`. Чёрный список — из текущих решений и семейств до сборки
   (`compose_gates.py:24` читает сохранённое состояние), keyed по `mesh_family_rep` (`bank_ready.py:93` vs `compose_gates.py:42`).
2. **Детерминизм** (первым из трёх): полный ключ ничьей `(−score, price, mid, eid)` (`compose2.py:532`); тест `PYTHONHASHSEED=1/2/3` →
   126/126 одинаковых `selection_hash` на одном снимке.
3. **Kept:** предыдущий КАНДИДАТ (не живой банк, `compose2.py:549/613` `_PREV`) — источник удержания; пересобираются только
   invalid-ячейки. Два хеша: `selection_hash` (роли/SKU/кол-во — удержание и `since` ожидания) и полный `candidate_hash` (проверка публикуемой версии).
   Сразу пересобрать: gone, policy/reject/failed-terminal, контракт роли, запрещён представитель семейства. Держать: новые URL/цена/фото того же SKU
   (пересчитать media/готовность). `wait_catalog` — 2–3 ночи отсрочки, затем пересборка; `wait_asset` — пересмотр через 21 ночь;
   цена вне сегмента — гистерезис 10–15 % и две ночи; новый лучший товар не трогает ячейку, ждущую меш; плановое обновление — раз в 30 дней
   при `Δscore ≥ max(1.0, 2× p95 шума)`.
4. **Бонус готовому мешу** — только последний разрыв ничьей в узком окне качества (не основной скор).
5. **Метрики в дайджест:** `ready_after_bind`, promoted, published; уникальные недостающие семейства: missing / queued / done, доля missing с
   заказом; стабильность: % ячеек с тем же `selection_hash`, % сохранённых роль→SKU, меши брошенные до promote.
