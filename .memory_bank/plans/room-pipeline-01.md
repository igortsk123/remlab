## Цель
Один автоматический конвейер для любой комнаты (спальни, прихожая, кухня; санузлы — позже): тип комнаты — данные (роли, нормы,
зоны и виды, слоты и допуски, квоты мешей), алгоритмы — плагины. Готово = на главной `/demo` каждая комната как гостиная: чистовые
фото с двух видов на зону, смена мебели → перегенерация, подбор по стилю. Гостиная не меняется до доказанного паритета.

## Решение (Codex 05.11, принято ведущим; отклонено: «--room во все скрипты», перенос в `products` сейчас, монолит)
Контракты: `CatalogItem` (единый адаптер `items(room_type)` поверх представления БД), `RoomProfile` (данные типа комнаты, с версией),
`RoomInstance` (реальный контур, проёмы, назначение), `RoomDemand` (слоты с допусками для конкретной комнаты) → кандидаты/ассеты/наборы →
плагин солвера → профиль камер → сборка сцены поставщиком ассета → рендер. Гостиная — на старом пути, новый путь воспроизводит её в тени.
Квота мешей — по `стиль × роль/слот × размерная корзина` и бюджету (не «30 на стиль»). Вход будущего «план с фото» — `ApartmentPlan → RoomInstance[]`.

  (не гостиная); негативные тесты; экзамен гостиной и спальни до/после равен.
- **Волна Б (после влития А):** схема `RoomProfile` + загрузчик + линтер + профили living/bedroom/hall/kitchen; адаптер каталога
  `items(room_type)` (представление БД) + тест равенства гостиной в тени; стенд паритета гостиной (эталонные хеши артефактов);
  аудит покрытия ассетов (меши-сироты комнат).
- **Волна В:** обрезка, размеры (цепочка поставщиков: чертёж → описание → достроить → выкинуть), стиль — через адаптер и профиль (T-35);
  спрос и привязка мешей по `RoomDemand` (меши комнат перестают быть сиротами); очередь ≈ по слотам −20…+10 %; платно — по пробе.
- **Волна Г:** интерфейс составителя и судьи, профиль камер (2 вида на зону), ночной DAG новых комнат (`refresh_daily.sh` — один
  интегратор последним), публикация `.next` → главная после проверки ведущего.

## Критерии приёмки
- Каждая комната flat215 (кроме санузлов) на главной: фото двух видов на зону, смена мебели → перегенерация, 3D по расстановке.
- Новая комната = новый профиль + (при нужде) плагин солвера, без правок этапов конвейера.
- Гостиная: эталонные хеши артефактов до/после равны; две чистые ночи.
- Неизвестный тип комнаты падает с ошибкой (тест).
