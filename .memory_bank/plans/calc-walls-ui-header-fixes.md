## Цель
1) На /calc/oboi (и плитка, краска) — новый флоу добавления стен: пустое состояние = подсказка
+ кнопка «+ добавить размеры стены»; после клика кнопка исчезает, появляется карточка со стеной,
внутри карточки под полями — «+ добавить стену»; удалили все стены → снова исходная кнопка.
2) Шапка: убрать мерцание при скролле вверх; заменить «тонкую рамочку» вокруг активной
кнопки («Посчитать материалы» / «Сколько стоит ремонт») на аккуратное выделение.

## Источник задачи
Просьба владельца 2026-07-31 (чат): порядок блоков в калькуляторе стен, перенос кнопки
добавления внутрь белой карточки, мерцание шапки при скролле вверх, некрасивая рамка
на активной кнопке шапки.

## Скоуп — что входит
- **Флоу стен** (oboi, kraska — общая ветка; plitka — секция «Плитка для стен»):
  - Пусто (0 стен): подсказка «Введите размеры, чтобы посчитать площадь и количество.»
    (уже есть, EmptyNote), под ней кнопка «+ добавить размеры стены» — как сейчас.
  - После добавления первой стены: отдельная кнопка внизу ИСЧЕЗАЕТ; появляется белая карточка
    со стеной (SurfaceEditor); внутри той же карточки, под полями размеров — кнопка
    «+ добавить стену».
  - Удалены все стены → surfaces пуст → автоматически возвращается исходное состояние
    (подсказка + «+ добавить размеры стены»). Логика уже реактивна от surfaces.length.
  - laminat не трогаем (там пол, стен нет).
- **Мерцание шапки при скролле вверх**: причина — на мобильном ряд кнопок скрывается/появляется
  (site-header--collapsed), высота шапки меняется на ~46px, а гистерезис порогов 80/40 = 40px —
  меньше изменения высоты; scroll-anchoring браузера прыгает через оба порога → цикл
  скрыть/показать = мерцание. Фикс: `overflow-anchor: none` на html + развести пороги
  (сворачивать при y > 160, разворачивать при y < 40 — зазор больше высоты ряда).
- **Рамка активной кнопки шапки**: `.nav-cta--active` сейчас = box-shadow-кольцо 3px — выглядит
  как фокус-баг. Выделение текущего раздела оставить нужно (ориентация «где я»), но сделать
  иначе: активная кнопка — более тёмная заливка (hover-тон) без кольца. Кольцо убрать.
