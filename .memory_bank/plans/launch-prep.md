## Цель
Подготовить remont-lab.online к публичному запуску: рабочими остаются только «Посчитать
материалы» (вход А, М2) и «Моя лаборатория»; всё недоделанное закрыто аккуратными заглушками
«в разработке / скоро»; UX калькуляторов доведён до «не стыдно лить трафик»; чтение ссылок
на товары — надёжное (очищенный HTML → LLM, пометки авто/вручную).

### П5 — Чтение ссылок 2.0 (пп. 19–23, + добивание HTML)
- Аудит текущего автозаполнения на наборе реальных ссылок (Леруа/Петрович/ОБИ/OZON/WB…)
  по всем 4 видам → короткий отчёт владельцу простым языком «как сейчас» + доля полей.
  Сейчас: OG-мета + regex (link-parse.ts), ИИ-фолбэк gpt-4o-mini только на пропуски и только
  при ключе (link-parse-ai.ts) — проверить, есть ли OPENAI_API_KEY на проде.
- Пайплайн 2.0: скачанный HTML → вычистка (скрипты/стили/меню/картинки/чужие ссылки → чистый
  текст контента) → LLM с жёстким JSON-заданием по виду материала («верни ширину/длину рулона,
  раппорт, цену…»); детерминированный парсер остаётся первым дешёвым слоем. Тесты на фикстурах.
- **Добывание HTML всегда (антибот-защиты магазинов).** Цепочка: (1) прямой серверный fetch
  (как сейчас) → (2) при ошибке/блоке — fallback через РФ резидентский/мобильный прокси из
  VPN-проекта (есть, медленный ~6 Мбит/с → повышенные таймауты, только на неудачу; адрес/доступ —
  секреты в `.env` на сервере, в память только указатель) → (3) оба не смогли — заметная ошибка
  + ручной ввод. Клиентское скачивание браузером юзера ОТКЛОНЕНО: браузер запрещает читать
  чужие сайты из скрипта (защита CORS) — технически нереализуемо без расширения. Опционально
  рассмотреть last-resort «вставьте текст со страницы» (копипаст → тот же LLM-разбор).
- Пометки полей «авто / вручную» (упрощённый вариант sup2 field-source, без БД — в состоянии
  проекта): новая ссылка стирает ТОЛЬКО авто-значения, ручные остаются.
- Проверить изоляцию: ссылка из обоев не появляется в плитке (черновики per-kind — закрепить тестом).
- Строчка о товаре под полем ссылки: название + 1–2 характеристики («основа флизелин, винил») —
  видно, что данные реально с этой ссылки.
