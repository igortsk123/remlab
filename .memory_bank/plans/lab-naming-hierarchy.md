## Цель
Убрать путаницу имён: одна и та же вещь сейчас называется «Мою лабораторию» (кнопка), «Смета-список»
(страница), «Смета: обои» (заголовок) и «Расчёт обоев» (список в /lab). Ввести одну простую
иерархию: **Лаборатория — полка со всем сохранённым; на полке лежат «расчёты» (и в будущем
«дизайны»)**. Отдельный раздел «Мои сметы» НЕ нужен.

## Источник задачи
Владелец (2026-07-31): кнопка при сохранении не совпадает с названием страницы, куда ведёт;
внизу той страницы ещё одна кнопка «Моя лаборатория» — читается как третий раздел; классификация
«плывёт». Нужна иерархия с учётом роста проекта.

## Принцип (правило на будущее — уйдёт в память)
1. **«Моя лаборатория» — единственное хранилище** всего сохранённого. Вкладки: Материалы /
   Ремонт / Дизайны (+ «Мой стиль»). Новые сохраняемые вещи = новые вкладки, не новые «разделы».
2. **Сохранённый документ называется «расчёт»** — одинаково на кнопке, в списке и в заголовке
   его страницы. Слово «смета» из НАВИГАЦИИ убираем (в рекламных/SEO-текстах употреблять можно,
   но не как название раздела).
3. **Страница документа всегда помечена, где она лежит:** сверху ссылка-крошка
   «🧪 Моя лаборатория → расчёт», внизу возврат «← Все мои расчёты» (а не «ещё один раздел»).

## Скоуп — что входит (всё — тексты и мелкие правки, логика не меняется)
1. Страница сохранённого расчёта `/e/[id]`:
   - «Смета-список» → ссылка-крошка «🧪 Моя лаборатория → расчёт» (кликается в /lab);
   - заголовок — «Расчёт обоев» (как в списке /lab; та же подпись и для старых сохранённых);
   - нижняя кнопка «🧪 Моя лаборатория» → «← Все мои расчёты».
2. Заголовок при сохранении: «Смета: обои» → «Расчёт обоев» (и «ремонт» аналогично).
3. Пройтись по всем видимым текстам со словом «смета» и привести к «расчёту» — но ТОЛЬКО
   в навигации (кнопки, крошки, названия разделов). В SEO-текстах, метатегах и рекламных
   описаниях слово «смета» СОХРАНЯЕМ — по нему приходят из поиска (М7, ~90k/мес).
4. Обновить e2e/тексты тестов, если завязаны на старые надписи.

## Проверка на будущее (мастер-план М0–М7 — всё ложится в схему «полка → вкладка → расчёт»)
| Будущая вещь (ступень) | Куда ложится |
|---|---|
| ИИ-обогащение, «подберём дешевле», реф-ссылки (М1) | внутри страницы расчёта |
| «Сфоткай — посчитаем» (М2 v1.5) | способ ввода; итог — обычный расчёт |
| Стоимость ремонта (М3) | вкладка «Ремонт» (уже стоит тизером) |
| Визуализация + мебель (М5) | вкладка «Дизайны» (уже стоит тизером); вход «посмотреть, как будет выглядеть» — кнопка на странице расчёта |
| Платные фичи М5 (PDF, обновление цен) | кнопки внутри расчёта («Подробный расчёт (PDF)»), НЕ новый раздел |
| Мастера-лиды (М6) + «найдём дешевле» | будущая вкладка «Мои заявки» (уже в follow-up lab-hub-tabs) |
| Шаринг и e-mail-возвраты (М7) | ссылка ведёт на страницу расчёта с крошкой — человек сразу видит, где он |
| Аккаунты вместо анонимной сессии (sub-e3) | полка та же, меняется только способ входа |
| Рынок UK | «Моя лаборатория»/«расчёт» переводятся без ломки структуры |
