# T-20261109-35/1 · задание — окно комнаты в туре агента точь-в-точь как в /demo (владелец 09.11, TG 593/594/596)

Задание самодостаточное, на прошлые задачи не опирайся.

## Зачем (слова владельца)
«Когда открываю — внешний вид не такой же как на демо, внутри в модалке просто открывает бродилку 3D. Внешний вид должен быть строго
такой же.» «Нажми гостиная — модалку открою, и там вообще всё не то, что на демо.» «Если даже мебели нет — всё равно должно открыться
визуально всё как на демо, в таком же дизайне.»

Тур агента — та же страница `tools/scout/flat215-demo/index.html`, режим `TRIAL()` (данные `D.trial`). Живой пример (ключ агента, только
смотреть, ничего не менять в нём): `https://remont-lab.online/try/Hm1xgIqBU5IKOF2X5Ml0rA/tour/?lang=ru&k=7LWmV6aCLFuKJsMa95lDag#v=trial-living`
— в нём гостиная и спальня БЕЗ мебели («Нет подходящих товаров…»). Образец — `https://remont-lab.online/demo/` (окно варианта гостиной).
Тур с мебелью для сравнения — найди на DEV свежий `done` с обставленной гостиной (`~/scout-scenes/trial/*/scene.json` со `status` ok)
или собери свой локально, как в прошлых пробах тура (`e2e/trial.spec.ts`, `tools/ops/demo-walk/*`).

## Что сделать
1. Разведка: снимки окна комнаты /demo и тура рядом (1280×800 и 375×667, RU), список ВСЕХ отличий (шапка, вкладки, панели, кнопки,
   шторка, подписи, цвета, отступы, что открывается первым). Для каждого отличия — где в коде ветка `TRIAL()` или пустые данные дают
   иной вид. Отличия, которые нужны по смыслу (в туре нет цен — `PRICES_OFF`/`vprice`, нет корзины партнёра), — оставить, перечислить.
2. Исправить: окно комнаты в туре — та же разметка и оформление, что в /demo (одна функция отрисовки, без своей «облегчённой» ветки).
   Комната без мебели (`no_products`, `refused`, «не разобрана», ждёт размеров) — ТО ЖЕ окно: план комнаты, 3D пустой комнаты (стены,
   окна, двери), вместо ленты товаров — тихая строка по причине (RU/EN, коротко, по тону страницы; для агента с `k` — что можно
   сделать: «Обустроить» / уточнить размеры, если такие кнопки уже есть). Без технических слов вроде «шаблонам».
3. /demo не меняется (сравнение пикселей до/после, как в T-27).

## Проверки (DoD)
- Снимки «до/после» в новую папку `.t35-shots/` рядом с worktree: /demo, тур с мебелью, тур без мебели — 1280×800 и 375×667, RU и EN;
  в отчёте — пути и таблица «отличие → было → стало».
- `pnpm typecheck && pnpm lint && pnpm test`, **`pnpm e2e e2e/trial.spec.ts`** (CI-гейт). Тяжёлое — под `tools/ops/heavy-slot.sh`.

## Как
- Worktree: `r 'git worktree add -q .claude/worktrees/trial-window -b worktree-trial-window main'`; работать в нём (кроны берут
  `index.html` из основной копии — правка в main станет живой).
- Коммит на ветку с меткой (T-20261109-35/1). Без слияния, push, выкладки — это делает ведущий.
- Границы: без sudo и удалений (снимки — в новые папки, старое не чистить), без pkill/pgrep -f, ничего платного, `.env*` не читать,
  сервисы DEV не трогать, `.memory_bank/` не править. Файлы — инструментом Write, в Bash только запуск, без `$(…)` в цели `>`.
- Команды проекта и git — через `r` (выполнит на pakardev в той же папке).
