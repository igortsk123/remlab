# T-20261117-17 · ярлыки ткани в 3D (план задач П1.77, владелец TG 1507)

**Запрос владельца (голос, 17.11 16:54):** «ты стикер пледа сделал — по аналогии сразу стикер штор; когда нажимаем
«Скрыть цены» — просто иконка без цены, кругляшочек висит; когда с ценами — уже с ценами».

## Что сделать
1. **Шторы получают ярлык**, как плед (T-20261117-10): миниатюра фото товара + цена, нажатие — карточка. Геометрия штор
   ОСТАЁТСЯ (`render.curtain: true`) — ярлык поверх, над местом штор (верх проёма/карниз), не закрывая окно целиком.
   Включение — данными: `data/flat3d/textile.json` → `label.curtain: true` (+ строка в `why`). Код ярлыка — тот же
   (`vwLabelAt`/`vwLabelFill`/`pinSpots(onSpot)` в `tools/scout/flat215-demo/index.html`, `isClothLabel`) — обобщить с пледа на
   любую форму из `label`, без особого случая «штора» в коде; aria-label по форме (RU/EN пары: «Шторы: …»/«Curtains: …»).
2. **«Скрыть цены» (PRICES_OFF):** сейчас гасит все ценники, и ярлык пледа тоже. Нужно: ценники мебели — как сейчас (скрыты);
   ярлыки ткани — сжимаются в кружок ~36–40 px (палец ≥ 44 px по зоне нажатия) с фото товара внутри, без цены; нажатие — та же
   карточка. «Показать цены» — полный ярлык. Без фото — кружок со значком ткани (нейтральный, в тон страницы).
3. Туры: тот же код страницы — проверить на одном туре, что ярлык штор встаёт.
