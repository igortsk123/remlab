# T-20261109-34/1 · задание — фото в туре агента как в демо (К9, владелец 09.11 TG 555 «должно быть как в демо»)

Задание самодостаточное. План — `.memory_bank/plans/agent-trial-08-demo-as-template.md` (§ Р2-текст «Правило фото» и «Устройство после
Codex 09.11» под ним, п.4).

## Зачем
В туре агента (`/try/<id>/tour/`, та же страница `tools/scout/flat215-demo/index.html` под `D.trial` / `TRIAL()`) кнопка «Сделать
реалистичнее» выключена (`vwRealistic`: `if(TRIAL())return false;`, кадры заранее `vwPreOk` — тоже). Владелец хочет как в демо:
кадры из 3D у человека → заказ → фото нейросетью за ~30 с, с ходом работы на вкладке «Фото».

## Правило фото (владелец TG 578 + Codex) — обязательно
Фото только для комнаты с ПОДТВЕРЖДЁННЫМ размером: масштаб `verified`/`listing` и комната не ждёт проверки, без флагов размера
(`dims_mismatch`), не `approx_consent` (обставлено «как есть» — мебель есть, фото НЕТ), не `area` без сверки. Сделай одну функцию
доверия по комнате (страница; если нужно — поле в данных тура от сборщика `tools/scout/trial_bundle.py`, тогда тесты). Нет доверия →
кнопки нет, вместо неё тихая строка «Фото — после уточнения размеров» RU/EN.

## Что сделать
1. Разведка по коду: что нужно серверу фото (`tools/scout/draft_render.py` improve ~3700–3800, `draft_service.py`, `/api/render`,
   `/api/render/frame`, `tools/scout/draft_guard.py` лимиты) для комнаты тура — товары, роли, геометрия, стиль, промпт; хватает ли
   данных тура (`D.*` под `TRIAL()`), есть ли привязка к квартире 215/партнёру, учёт денег (`photo-cost.jsonl`, `cost_label`). Запиши
   выводы в отчёт до большой правки.
2. Включить путь демо в туре: `vwRealistic` + кадры заранее (`vwPreOk`) при доверии комнаты; заказ — с `views` (кадры у человека,
   правило владельца TG 567: сервер сцену сам не строит; запасной серверный путь для тура — НЕ включать, без 3D — без фото).
   `cost_label='trial'`. Лимиты: на задание тура не больше N фото в сутки (предложи N, например 10) — сервер, не только страница.
3. Покупатель (ссылка без `k`) — фото можно (это и есть показ), но с тем же правилом доверия и лимитом.
