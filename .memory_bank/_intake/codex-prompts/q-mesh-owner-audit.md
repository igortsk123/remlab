## Что предлагает план (кратко)
Прод: страница `/lab/mesh-audit?page=N` (та же кука, что у mesh-review), 3 таблицы
(`mesh_audit_items`, `mesh_audit_decisions` append-only, `mesh_audit_batches`), 3 API-ручки
(кука для владельца, Bearer для DEV, курсор решений). Карточка: `<model-viewer>` + постер 320px,
модель грузится по клику; кнопка «переделать» → append-only решение + пометка на карточке.
DEV: `mesh_audit_sync.py` (--push списка, --pull решений, --serve по крону раз в минуту),
`mesh_audit_publish.py` (партия 200 мешей ≈ 1,5 ГБ: удалить каталог партии на проде, залить
новую, прогресс через API), `mesh_audit_posters.py` (постеры короткоживущими процессами).
По решению: `asset_revisions.status='owner_reject'` + дозапись задания с новым seed в ХВОСТ
`mesh-queue-v1.json` под локом; после двух переделок — статус «нужна замена товара/фото».
