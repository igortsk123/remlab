# Варианты зон гостиной в практике дизайнеров vs наши шаблоны — поиск агента (16.08)

Источники: Roomlay (U/H/L-shaped seating, spacing), Home Stratosphere/Parachute/Castlery (layouts),
Emily Henderson (5 go-to configurations), StyledToGlow (27 large-room layouts), Decorilla/Neptune/
Homes&Gardens (multi-zone large rooms: 18–22 ft → 2 зоны, >22 ft → 3; console за диваном как
делитель; ~50″ между зонами), Direct Fireplaces/Mantels Direct/H&G (media wall: symmetrical /
softly balanced / asymmetrical; TV+fireplace+flanking storage), Apartment Therapy/Castlery/CHITA
(dining в гостиной: банкетка у стены/L-банкетка, стол за спинкой дивана, круглый стол, консоль).

## 5. Выводы (мои, до Codex)
- Базовые посадки покрыты; дыры: **secondary/третьи зоны как атомы** (второй pod с ковром/лампой; reading с мини-стеллажом), **sectional + 2 кресла**, **conversation circle**, **fireplace-symmetrical с приставными**.
- Медиа: нет **softly balanced/asymmetrical** композиций (закрытое+открытое хранение), полки настенные не в плане.
- Столовая: **nook/L-банкетка/за спинкой/круглый** — главные дыры (Q6).
- Остаток: **консоль за диваном** и **стеллаж-делитель** — есть паспорта, нет реализации/данных.
- Много «есть по имени, но одна геометрия» (Codex уже отметил).
