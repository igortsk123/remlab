# T-20261111-12/1 — площади комнат по подписям на листе застройщика («Этажи», часть Г из T-06)

Тур-образец «Этажи»: задание `aOv8kTVEKMgu2H6iD6UIJg` (прод), исходный лист `~/remlab-logs/etagi/in-1641/plan.png` (+ `listing.txt`).
На листе у каждой комнаты подписана площадь (например «кухня-гостиная 20,80», «балкон 2,70 (0,80)»). В туре площади считаются по
найденному контуру и масштабу и расходятся с подписями.

## Что сделать
1. Таблица «комната → площадь по подписи → площадь в result → расхождение» для «Этажей» и ещё 2–3 листов с подписанными площадями
   (английские листы со «sq ft/m²» — найди в `~/remlab-logs/trial/` или в регресс-наборе `tools/floorplan/regress_cases*.tsv`).
2. Найти, где расходится (масштаб, контур комнаты, учёт стен/ниш), и сделать масштабируемое правило: подписанная площадь — истина для
   показа (и проверка контура/масштаба), если расхождение больше порога — честный флаг, а не подгонка контура. Учти уже влитое:
   `room_edits._scaled` (правки размеров агентом), флаг «размер не подтверждён» (`bench.attach_flags`), `outdoor_share`
   (`tools/floorplan/pipeline.py`). Решение по устройству (что истина: подпись или контур) — сначала короткий разбор в отчёт-ход, если
   есть развилка; правило владельца: решения масштабируемые, без фиксов «под один план».
3. Регресс разбора: `tools/floorplan/regress.py` против main — сломано 0; таблица до/после.
