# Самоанализ агента ДО консультации Кодекса — комментарии владельца по галерее (свод №12)

Дата: 2026-08-15. Галерея /test/acceptance-plans/; нумерация = сорт отчёта по (set, id) —
зависит от порядка завершения воркеров (нестабильна между прогонами — само по себе дефект).
№1=set1-bay №2=set1-base №3=set2-long №5=set3-pylons №11=set6-base №12=set6-long
№16=set8-base №17=set9-pylons №19=set10-long №172=set80-r17 №174=set80-r20 №177=set80-L
№192=set87-pylons.

1. **ТВ не по оси (№1, №2 — системно).** axis_contract.media class=centered, offset 16.1 /
   12.9 см: класс допускает люфт, внутри класса ничто не тянет к 0; позиция «ровно на оси»
   не генерируется. Корень: пороговые классы без внутриклассовой минимизации + кандидаты
   не привязаны к оси дивана.
2. **Пустота за диваном у окна (№2).** Схема легальна (ADR-0095), но «функция пустоты за
   спинкой» проверяется только для elongated+floating (E4). Проверить простые комнаты.
3. **Пустота перед диваном в длинных (№3, «тянется давно»).** set2-long: ~2×3 м пусто,
   fill 19.5% при каноне floor_cap_pct 33–50 (данные) и цели композитора [28,38,40] —
   три несогласованные цели; «25%» владельца в данных нет. Причины: вторая зона проигрывает
   dining, в 15 м² dining без региона → в остаток ничего; заполнители за/перед диваном
   (консоль, раннер, divider) спят со свода №6; нет знания «очередность наполнения».
4. **№5 «прямоугольник у окна»** = пилон контура сцены set3-pylons; не подписан на плане.
5. **Стол у двух стен (№11, 12, 17; №172).** Везде dining mode=edge, island_infeasible,
   reject=island_candidates_failed; edge-кандидаты включают угол без штрафа за второе
   прилегание. Для 35 м² «остров недостижим» подозрительно.
6. **№16 ТВ далеко, альтернативы не перебраны.** class=relaxed, offset 110, centered_generated=0
   (дверь съела сегмент). После выбора пары/ступени НЕ перебираются: кресло с другой
   стороны, состав без кресла, сдвиг дивана, угловой диван. Жадная цепочка.
7. **№19 градусы.** Прямоугольники УЖЕ повёрнуты; не показан фронт; в JSON голые rot.
   → стрелка фасада + facing в экспорте.
8. **Большие (№172/174).** Банк set80 даёт 1 кресло → sofa_2armchairs недостижим
   (продолжение C-6); шаблонов «инсталляций хранения» для длинной стены нет; носитель без
   учёта масштаба стены.
9. **№177 без медиа — грубое нарушение.** Known-list focus-empty {set80-L, set21-mirR/L}
   легализовал дефект. Медиа-инвариант должен быть hard для всех; известный список снять.
10. **№192 два кресла подряд + пуф.** sofa_2armchairs поставил оба кресла в ряд (x=343/229,
    rot=180): генератор допускает и жадно берёт первый прошедший вариант, вместо перебора
    конфигураций (по бокам столика, зеркально) с лексо-сравнением. Пуф без назначения.
11. **Мета-корень (владелец прав).** пара → ступень → жадная цепочка зон. Внутриступенчатые
    конфигурации не перебираются как гипотезы, сравниваемые лексо-ключом. Нужен
    многогипотезный слой (K компоновок → полная цепочка → ключ) с бюджетом. НЕ нейросеть-
    расстановщик; LLM — офлайн-советник по данным.
12. **Подача/процесс.** Нумерация галереи стабилизировать; fill-цель унифицировать и
    показывать «цель vs факт».

Сверка с Кодексом (после): совпадение по всем 13 сценам; Кодекс шире в 4 пунктах —
семантические полосы за диваном (window_access/radiator_service), `dining_need` как входной
параметр, паспорт↔runtime parity (u, media_storage_combo), ложный «0 gaps» template_gaps.py.
