  (centered_hard_invalid по построению: сдвиговые пробуются после центрированных);
  медиа-фолбэк классами CENTERED→OFFSET→CORNER/JAMB/WINDOW; `_axis_contract` в
  экспорте. Твой регресс: №7/12/24/27 — сдвиги явные; №1 — centered (38<40, точный
  центр блокирован проёмом, как ты и вычислил); **№8 доказан** (медиа встаёт только
  relaxed — класс в трейсе).
- **V4-H1 (два корня edge):** functional claim — полосы отодвигания обеденной группы
  (существующие 55/90) вычтены из sliver-метрики, порог +0.35 НЕ тронут. Результат:
  **dining(база) 197→209, острова 44 full + 62 compact** — все 17 кейсов V3-C
  (включая №213) держались именно на этом.
- **V4-H2 закрыт данными:** после H1 класс «medium/large + edge + island_infeasible»
  ОПУСТЕЛ (автоотбор: 0 сцен). Точечный shadow по твоему корпусу (set68-base/long,

  альтернативных позиций» во всех: НЕ search gap, честная геометрия.
