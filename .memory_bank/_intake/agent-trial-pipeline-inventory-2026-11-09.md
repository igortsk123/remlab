## Критический путь ≤ 3 мин (оценка, при условии что пробелы закрыты)
- **Посчитать заранее:** каталог и стили (ночной крон), меши (Salad: холодный старт 35 мин и 176 с на меш в 3 минуты не влезают),
  банк сетов по ячейкам «стиль × размер комнаты», прогретые GLB в рендере. На запрос — только подбор из готового.
- **Последовательно:** файл → подписи VLM (10–48 с) параллельно со стенами OpenCV (2–20 с) → починка (≤ 45 с, панели параллельно)
  → контракт. Итого ≈ 60–90 с (оц.).
- **Параллельно по комнатам:** расстановка (~15–30 с на комнату, оц.) → подбор из банка → черновой кадр (5 с) → фотореализм
  (~55–80 с на лист, через шлюз все сразу). Итого ≈ 80–110 с (оц.).
- **Тур** открывается сразу после контракта и расстановки (3D рисует браузер); фото подъезжают позже.
  Всего ≈ 2,5–3,5 мин (оц.), если: без проверки человеком (сейчас `b2b-13` её требует), без генерации мешей,
  на рендере с ≥ 8 ядрами вместо DEV через туннель.
- **Упирается:** в GPU Salad (по запросу нельзя), в проц и память DEV (рендер и солвер), в скорость модели фото (~50 с).
  На путь «любая квартира» нужно: мост стенд → контракт квартиры с многоугольниками; сборка демо без flat215;
  комнаты кроме гостиной; UK-каталог; загрузка файла, очередь и письмо.
