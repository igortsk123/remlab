# Конкуренты RemLab — список с комментариями владельца (TG 278, 09.11.2026)

Контекст: владелец (TG 277) поставил макро-цель — лендинг для агентов недвижимости «попробовать бесплатно»: фото/PDF плана → 3D →
расстановка по шаблонам → товары → 3D-тур за ≤ 3 мин (или ссылка на почту). Лендинг строить, «просмотрев всех конкурентов выше и мои
комментарии читай обязательно». TG 279: «это общая большая задача».

Вывод списка: продукта, который целиком повторяет концепцию (авто-3D квартиры + свободный выбор реальной мебели разных ритейлеров +
фотореалистичный рендер + актуальные цены + платные опции застройщика), не найдено.

## Ближайшие
- **InsideWalk** — 3D-конфигуратор для застройщиков с мебелью, отделкой, ценами. Владелец: очень близко, но проекты под заказ (заявляют
  48 часов), авто-генерации квартиры и открытого каталога разных ритейлеров не увидел.
- **Livinit** — конфигуратор квартир с AI-визуализацией, отделкой, мебелью, платными опциями. Владелец: скорее заранее подготовленный
  проект под конкретного застройщика.
- **GBuilder** — платформа застройщиков: 3D-квартиры, upgrades, продажа мебели. Владелец: нет открытого каталога разных ритейлеров с
  выбором товаров и сравнением цен.
- **SenHOME** — AI-платформа: генерация 3D-мебели, каталоги брендов, визуализация, торговля. Владелец: нет свободного выбора мебели из
  конкурирующих магазинов.
- **Flatwalk** — авто 3D-планировка, мебель IKEA и Bonami, цены, AI-рендер; часть в beta. Владелец: ещё не тестировал, потенциально
  близкий — посмотреть внимательнее.
- **Realitiq** — конфигуратор недвижимости: отделка, мебель, стоимость. Владелец: выглядит как The Sims, инструмент точного
  планирования, а не реалистичный коммерческий интерьер.
- **Realtix** — британский конфигуратор, от £1,500 за проект (три типа квартир) + подписка; похоже на кастомную подготовку контента.

## Технологически близкие, другая модель
- **Maket** — 3D-мебель из фото, размещение, рендер. Владелец: нет экономики покупки квартиры, магазинов, пакетов застройщика.
- **Coohom** — AI-планирование интерьеров, 3D-мебель, рендер. Владелец: профессиональный инструмент дизайна, не наш сценарий.
- **Tunzone** — 3D-мебель из фото, каталоги, расстановка, визуализация. Владелец: для мебельных производителей; интересен сценарий для
  мебельных ритейлеров.
- **Atyl** (UK) — AI-подбор мебели по стилю и бюджету, каталог реальных товаров. Владелец протестировал: нельзя выбрать конкретный диван;
  подбирает всё под бюджет; на тесте сообщил, что товары недоступны.
- **ShopMyRoom** (UK) — AI-визуализация комнаты с мебелью британских магазинов и подбором под бюджет, без интерактивного 3D.

## Предварительный вывод (из списка)
Отдельные технологии есть у конкурентов; преимущество RemLab — сочетание: авто-подготовка 3D-квартиры и мебели, выбор конкретных
товаров из разных магазинов, сравнение цен, фотореализм, коммерческие опции застройщика, минимум ручной подготовки контента.
