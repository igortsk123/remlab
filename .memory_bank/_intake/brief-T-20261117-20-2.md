# T-20261117-20/2 · задание рабочему 2 — вкладка «Фото»: «Сделать фото» = рендер, «Улучшить фото» = GPT поверх рендера (П1.79)

Решение владельца — TG 1665/1667/1668/1670 (17.11 19:10–19:20), всё «строго по аналогии с нынешним GPT, ничего не путать»:
- **3D, расстановку не меняли и фото этой расстановки есть** → кнопки «Сделать фото» нет.
- **3D, фото нет или расстановку изменили** → «Сделать фото» (нынешняя кнопка шторки и нынешняя модалка «Вы изменили комнату…» —
  вид не меняем) → заказ РЕНДЕРА → ход с процентами, как сейчас → по готовности автопереход на «Фото» (как сейчас) → два ракурса рендера.
- **«Фото», показан рендер этой расстановки, не улучшен** → внизу, на месте нынешней кнопки шторки, «Улучшить фото» → нынешний GPT-путь
  с `render_key` (сервер уже в main: `improve-render-v5.2`) → ход «Улучшаю · N %» → улучшенное фото.
- **На улучшенном фото кнопок нет.** Меток «Рендер»/«Улучшено» на кадре нет.
- **Ошибка** — дословно TG 1667: «Расстановка сохранена, но что-то пошло не так. Попробуйте ещё раз.» / «Your layout is saved, but
  something went wrong. Please try again.» + «Повторить», в том же месте, что сейчас `#vCtaErr`.
- Ход рендера — «Делаю фото · N %» / «Rendering · N %»; «Улучшаю · N %» — только за «Улучшить фото». Замок правок на время рендера —
  «Менять можно, когда фото будет готово» / EN парой. Ожидание — из ответа сервера (`eta`/`eta_range`, `percent`), не `PHOTO_EST_S=30`.
- /demo и туры — одинаково (`/api/render/cycles` и `/api/trial/<id>/photo` с `"mode":"render"`; контракт — `contracts/trial.ts`,
  `tools/scout/draft_service.py`). Повтор той же расстановки — мгновенно из кэша (`check:true` → `cached`).

Карта кода — твоя таблица из отчёта T-18/2 («шаг → где в коде → что меняем», `tools/scout/flat215-demo/index.html`).
