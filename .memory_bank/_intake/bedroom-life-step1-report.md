## 2. Почему пул ламп пуст у лофта и джапанди (воспроизведено: `lamp_stages.py`, `bedroom-composition.json decor.лампа`)

Воронка роли «лампа» (каталог декора 1499 товаров, лампа 419; порог стиля 6.6; полоса высоты 36–49.5 см = идеал 45 ±; фильтр «рабочая/ночник»):
- нет Ш×Г×В в карточке — **243** (в основном у Mantra, Viokef, Brizzi, Lucia tucci) → отсев по правилу «без размеров не ставим» (`compose_bedroom.py:gate`);
- высота вне полосы — 121;
- годны по размеру — 55; из них «рабочая/ночник/прищепка» (`lamp_task`, `deny_model`) — 11; остаётся **44**.
- Из 44 в стиле ≥ 6.6: сканди **1**, современный 9, минимализм 6, **лофт 0**, **джапанди 0**, неоклассика 12.

Лофт (13 ламп стиля ≥ 6.6 в наличии): 4 Gauss без размеров/«рабочие», 5 без размеров или ниже 36 см (Arte Lamp A5122/A5124/A5123 h 33–34, Fusion h 33), Braccio h 54 (выше полосы), и **одна годная — Arte Lamp Cord A1210LT-1BK** (11×7×42, 1899 ₽) — её режет `lamp_task_models: ["A1210LT","A7051LT"]` («рабочая по фото»). Меша нет ни у одной.
Джапанди (2 лампы стиля): «Настольный CITILUX Киото» без Ш×Г×В (h 35) и «Абажур Vitaluce Лён» (не лампа вовсе). Меша нет.

## 4. Выводы

1. Три из четырёх «пустых» стилей (лофт, джапанди) пусты не из-за нехватки ламп вообще, а из-за **правил отбора**: 243 лампы без Ш×Г×В, полоса высоты 36–49.5 (отсекает 121), правило «рабочая по фото» убило единственную годную лофтовую лампу.
2. У сканди ровно **одна** годная лампа на весь каталог → в двух комнатах стоит один и тот же товар (`WARN:demo_room_dup`) — хрупко.
3. Для минимализма/современного лампа держится на единицах SKU с мешем (a2589lt, CLINT): уходит меш с сервера — лампа исчезает с `WARN:lamp` (уже случалось в прогоне раньше).
4. Бра: размеры в карточках есть у большинства, **мешей нет совсем** — это и есть главная стоимость шага 2.
5. Все 10 комнат: тумба есть с обеих сторон → в данной раскладке нужда в бра «вместо лампы» только в 4 комнатах (лофт, джапанди); «бра при узкой/отсутствующей тумбе» в /demo сейчас не возникает.
