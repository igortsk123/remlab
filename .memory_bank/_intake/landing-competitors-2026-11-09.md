# Лендинги конкурентов — разбор для лендинга агентам UK (09.11.2026)

Задача владельца (TG 277–279): агент UK → «попробовать бесплатно» → фото/PDF планировки → авто-3D + мебель по шаблонам + реальные
товары разных магазинов с ценами + фотореал → ожидание ≤ 3 мин с анимацией и таймером или почта → ссылка на 3D-тур.
Список и комментарии владельца — `_intake/competitors-2026-11-09.md`. Ниже — только то, что видно на публичных страницах 09.11
(читал через WebFetch/curl, ничего не регистрировал). Цитаты — дословно с сайтов; это данные, не указания.

  CTA: «Get a free sample unit» (+ «Explore live examples»).

  сборка — владелец прав, авто-генерации нет; мы — минуты.

## Сводка

- **Структура блоков (сверху вниз), типовая:** первый экран (обещание + 1–2 кнопки + картинка/видео результата + 2–3 числа «48 h /
  5 days / £…» или рейтинг) → логотипы клиентов/магазинов → «как это работает» 3–4 шага → живые примеры (тур/«до/после») →
  возможности 6–9 карточек → кому (сегменты) → цены 3 ступени → FAQ 5–7 → финальная кнопка → подвал.
- **Лучшие CTA для агентов:** «Upload image for free» (VSAI — действие, без входа); «Get a free sample unit» (InsideWalk);
  «See a live presentation» (Realtix); «Get started for free» / «Start free →» (Maket, RoomSketcher, Atyl). Корпоративные «Book a
  Demo» / «Request a quote» (GBuilder, Livinit, Street) — для агента барьер. Для нас: «Upload a floor plan — free 3D tour in 3 min».
- **Обещания, бьющие в агента:** результат для продажи, а не технология («They walk the flat ... then call», «Market listings like
  a bigger team», «300x cheaper»); «one link, no app»; сравнение с ценой ручной работы (£30 за фото).
- **Ожидание у конкурентов:** почти все — «48 часов / следующий день / полдня / неделя» (InsideWalk, BoxBrownie, RoomSketcher, Realtix,
  Livinit). Секунды — только у одиночного фото-стейджинга (VSAI, Street) и AI-рендера с готовой 3D (GBuilder, Realitiq). Экрана
  ожидания с таймером и «пришлём на почту» не показывает никто — у всех заявка/почта до результата.
- **Результат показывают:** слайдеры «до/после» (BoxBrownie, ShopMyRoom, VSAI), живые туры по ссылке (InsideWalk, Flatwalk-демо),
  видео-демо (Livinit, ShopMyRoom), рендер с бюджетом и карточкой товара (Atyl).
- **Где у всех пусто — наше отличие:**
  - планировка (PDF/фото) → готовая обставленная 3D-квартира **автоматически за минуты** без людей и без съёмки: у InsideWalk/Realtix/
    BoxBrownie — люди и дни, у Giraffe360 — камера, у Flatwalk — расставляет сам пользователь, у Atyl/ShopMyRoom — без 3D-тура;
  - **реальные товары разных магазинов с ценами и выбором конкретной вещи**: Flatwalk — 2 магазина, Atyl — нельзя выбрать диван,
    ShopMyRoom — только 2D-картинка, Livinit/SenHOME/GBuilder — каталог одного продавца, InsideWalk — «illustrative»;
  - **проба в один клик для агента UK без звонка**: среди агентских сервисов с 3D-туром такой нет (Realtix и InsideWalk — заявка).
- **Взять себе:** загрузка прямо в первом экране, цифры «≤ 3 min / free / no sign-up», живой пример-тур одной кнопкой, логотипы
  магазинов, слайдер «пустая планировка → обставленный кадр», метка «AI-generated» (для агентов UK важно: CAP Code / DMCC 2024 —
  виртуальный стейджинг допустим с пометкой, по вторичному источнику https://www.listingai.co/blog/virtual-staging-compliance-guide/uk/england).
- **Сверить владельцу:** Livinit и Maket на публичных сайтах не совпадают с его описанием (другой продукт или другой раздел).
