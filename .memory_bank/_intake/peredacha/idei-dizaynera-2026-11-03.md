# Передача: идеи дизайнера для сайта (владелец 03.11, голосом TG 1205)

**Кому:** ведущий remlab на common (`remlab-18`). **От:** ведущий algor (0fc5fa15-18ef-4ce4-8057-cd8e736aa9a1).
**Слова владельца:** «это ты передаёшь сессии common, она смотрит и планирует реализацию, а затем делает, аккуратно внедряет».
Ведущий algor делает только Фигму (план `design-02-figma-components`).

**Где смотреть:** книга Mobile https://www.figma.com/design/KeoB3huA9ce58swtNrDyrx/Mobile , страница «Счастливый путь»
(node 123-2), всё правее нашего листа (x ≥ ~3900). Коннектора Figma на common нет. Тексты и id ниже сняты чтением с algor.
На сайте (`tools/scout/flat215-demo/index.html`) ничего из этого нет: сверено grep 03.11, «Убрать» есть только в «Убрать из
избранного».

## Идеи (не доделаны — это направление мысли)
1. **Опрос-знакомство перед стартом** (6 окон 158:126 → 158:140 → 158:201 → 158:244 → 158:304 → 158:399 на затемнении):
   «Приветствуем, Анна! Давайте подберём интерьер для вашей квартиры. Мы выделили для вас сертификат на обстановку 600 000 ₽.
   Ответьте на 4 вопроса…» [Начать] / [Посмотреть все стили].
   - 1 из 4 «Кто будет жить?» (можно несколько): один человек / пара / дети / питомцы / родители.
   - 2 из 4 «Какую атмосферу…?» (несколько): уютно и тепло / светло и воздушно / строго и современно / спокойно и натурально.
   - 3 из 4 «Какие цвета вам нравятся?» (до двух): светлые и нейтральные / тёплые земляные / холодные и графитовые / с яркими акцентами.
   - 4 из 4 «Что для вас важнее всего?» (один): комфорт / красиво и эффектно / практичность и долговечность / спокойно и натурально.
   - Итог: «Мы подобрали для вас 3 варианта», листание, [Выбрать «Сканди»] / [Посмотреть подробнее].
   - Её заметка 158:386 «что определяет»: кто живёт → состав и наполнение комнат, материалы; атмосфера → базовый стиль (главный
     фактор); цвета → палитра внутри стиля; приоритет → распределение суммы по комнатам.
2. **Главная проще** (158:452):
   - сверху квартира «3-комн. 9 578 200 ₽ · ЖК „Ольховый квартал“ · сдача 4 кв. 2026», справа значок сообщения (её компонент
     «Icon / MessageOutlined» — Ant Design; видимо, связь с менеджером);
   - вместо ленты из 5 стилей — две вкладки «Интерьер» / «План квартиры»;
   - стиль одной строкой «Сканди · Выбрать другой» и подсказка «Вы можете менять мебель, отделку и встраиваемое»;
   - полоса бюджета «Выбрано 450 000 ₽ (i) 600 000 ₽» прямо на главной;
   - карточки комнат: у первой «Открыть» контурная, без сердечка и «Поделиться».
3. **Бюджет как корзина** (161:64): у товара, кроме «Заменить · В магазин», — «Убрать из выбора»; заголовок группы
   «Мебель (80 000 ₽)» + «Убрать всё»; [Свернуть].
4. **Свой стиль для отдельной комнаты** (185:89 + подпись 185:91 «Выбрать другой стиль отдельно для комнаты»).
