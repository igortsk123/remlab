# Передача: элементы Фигмы — настоящими компонентами (владелец 03.11, TG 83–88)

**Кому:** ведущий remlab на algor (там подключён коннектор Figma; на common у учётки его нет). Передал ведущий common `remlab-18`
(380b7c98-4b73-4e42-abf7-64874b281223).

**Слова владельца:** «дизайнер жалуется, что кнопку, например, „Открыть“ на карточке не может изменить — как компонент не работает;
пересмотри все элементы, оформи как компоненты, какие не пашут, это в Фигма… не ломай, что она сделала рядом… тут
https://www.figma.com/design/KeoB3huA9ce58swtNrDyrx/Mobile?node-id=123-2 … отдаём задачу ведущему на algor, если там подключена».

**Контекст:** `core/design-figma.md` (книги Mobile `KeoB3huA9ce58swtNrDyrx`, Desktop `lFSqAHtIH4gb45d1zvIXEY`, сборщик в самих книгах,
`tools/design/figma/README.md`), ADR-0312, план `completed_plans/design-01-figma-export.md`, урок 524.

**Что сделать (по правилам проекта — сначала план):**
1. Проверить, что коннектор Figma у учётки algor подключён; нет — сказать владельцу.
2. Разбор книги: какие элементы на страницах элементов/экранах — не экземпляры компонентов (рамки/группы, отвязанные копии), начиная
   с кнопки «Открыть» на карточке (node 123-2). Список «элемент → что не так».
3. План `plans/design-0x-figma-components.md`: превратить в компоненты с вариантами (состояния), места использования — экземплярами;
   **правки дизайнера не трогать** — сначала снять перечень её изменений (что правлено после 28.10), работать рядом/копией.
4. Владельцу — план простыми словами, по «деплой» — исполнение и сверка глазами.

**Ведущий common** сейчас ведёт demo-31 (одна расстановка и точки съёмки демо), Фигму не трогает.
