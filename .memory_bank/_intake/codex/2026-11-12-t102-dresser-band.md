# Вопрос Codex: комод в составе малой гостиной 14–16 м² (T-20261112-102)

Репо: /home/pakar/igor/remlab (read-only). Нужна независимая оценка нормы предметной области, с источниками (интернет:
дизайнерские руководства, исследования планировок, каталоги/ProcTHOR-подобные датасеты). Наш вывод намеренно не приводим.

## Контекст (факты)
- Банк наборов мебели гостиной собирается по полосам площади комнаты. Правила состава — `tools/scout/composition.json`
  (`bands[].floor`: роль → [min%, max%] доли площади пола). Сборщик — `tools/scout/compose2.py` (роль, которой нет в `floor` полосы,
  не берётся: `if role not in band['floor']: continue`).
- Полоса 14-16 м²: диван, кресло, пуф, столик, тв-тумба, торшер, кашпо, стол обеденный + стулья. Комода нет.
  Полосы 17-20 и выше: есть «комод» [2, 4] % пола (и стеллаж).
- Прочие правила сборщика, касающиеся хранения: норматив хранения ≤ 15 см ширины на м² (p90 по 18 804 сценам) — лишнее хранение
  выкидывается (витрина → стеллаж → комод); в ≤18 м² вторая единица хранения не добирается («концентрация»); при m2 ≥ 16 без
  любого хранения/тв-тумбы добирается комод.
- Решатель расстановки (`services/planner-solver/planner/zones.py`, ключ `plan_key`) с T-98 считает комод «носителем света», только
  если в наборе есть настольная лампа (`rules/zones.json` `light_carriers.requires_decor`). Не влезает — комод остаётся в банке.
- Типичная комната: 439×325 см (14.3 м²), окно, дверь; в ней обычно уже стоят диван, кресло, журнальный стол, тв-тумба, торшер,
  обеденный стол на 2 стула.

   уместен (при каких других предметах: тв-тумба, стеллаж, столовая зона), когда — перегруз? Источники.
2. Если уместен — какая доля площади пола (наш формат [min%, max%]) и какой типичный габарит (ширина/глубина) для такой комнаты?
   Сравнить с [2, 4] у 17–20 м².
3. Комод vs тв-тумба vs стеллаж в 14–16 м²: взаимоисключающие (одна единица хранения) или совместимы? Учесть правило «концентрации».
4. Риски для расстановки: проход ≥ 75–91 см, окно, дверь — где комод в такой комнате обычно ставят.
