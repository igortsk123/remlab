## Рекомендация

Ввести один жёсткий предикат публикации для всех 126 ячеек, `/demo` и туров:

1. Ядро присутствует в составе.
2. Каждый товар списка либо действительно видим в сцене, либо удалён одновременно из списка и суммы.
3. Для ядра удаление запрещено: только замена, следующий полный сет или скрытие варианта.
4. Для mesh-ролей источник истины — `offer_asset_binding`: `ready`, правильный внешний вид, опубликованный файл; затем подтверждённое размещение солвером.
5. Сверять перед публикацией двусторонне: `listed SKU/qty == visible SKU/qty`.

Подбор столика:

1. Годные размеры, наличие, слот и привязка.
2. Балл целевого стиля ≥ 6,6.
3. Если пусто — универсальный/совместимый предмет, но оценивать его всё равно по вектору целевого стиля.
4. Диапазон ниже 6,6 — только как измеренный review-band после человеческой проверки; Portman 6,1 годится для такой проверки, но не как основание глобально снизить порог.
5. Нет приемлемого кандидата — вариант не публиковать.

Порог 6,6 сейчас относится к ленте замен, а не является жёстким порогом композитора: [`demo_swap_pool.py:56`](/home/pakar/igor/remlab/tools/scout/demo_swap_pool.py:56), [`compose2.py:438`](/home/pakar/igor/remlab/tools/scout/compose2.py:438). ## Риски и проверка

- **Диаметр как W=D:** безопасно только при явном диаметре, признаке круглой формы либо каталожном W=D. Иначе возможны неверный footprint, масштаб и коллизии. Gatwick нельзя выпускать простым снятием quarantine.
- **Снижение порога:** размывает все стили и роли сразу; нужна ролевая калибровка, не глобальная константа.
- **«Соседний стиль»:** ярлык совместимости недостаточен; проверять надо конкретный товар по целевому вектору и всему сету.
- **Скрытие сета:** уменьшит покрытие стиля, но это лучше неполной или вводящей в заблуждение комнаты.

Приёмка: по всем 126 сетам `core_missing=0`, `gone=0`, binding-проблем `0`, разность «список ↔ сцена» `0`; затем collision/clearance-проверка и визуальные кадры каждого заменённого варианта.
