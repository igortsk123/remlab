# Вопрос советнику: как лучше построить разбор плана квартиры/дома из картинки (10.11.2026, владелец TG 761)

Ты — независимый советник (read-only). Владелец просит: «опиши весь процесс со ссылками на код, попроси поисследовать и подумать,
как лучше разбирать планы из изображения; может, подскажет инструменты или подходы». Нужна НЕ проверка нашей гипотезы, а свежий
взгляд: как бы ты построил этот конвейер в 2026 году, что из готового (открытые модели, библиотеки, датасеты, сервисы) стоит взять,
что из нашего самописного выбросить или оставить. Поищи в интернете (статьи, репозитории, бенчмарки), со ссылками.

## Задача продукта
Агент недвижимости (UK) загружает на `/try` картинку или PDF плана из объявления (Rightmove/Zoopla: цветные «агентские» листы
Metropix/Cotswold Plans и т. п., чёрно-белые, с водяными знаками, иногда несколько этажей и построек на одном листе, размеры в футах
и метрах). Нужно получить: комнаты (контур, имя, размеры, площадь), стены, двери, окна, масштаб → дальше 3D-тур с мебелью, как
наше демо. Вычислитель — CPU-машина DEV (без GPU, память ~2 ГБ на задание, `tools/floorplan/systemd/remlab-trial-worker.service`),
бюджет нейросетей — центы на план (шлюз Vercel AI Gateway). Время сейчас — от 10 с до 8,5 мин на лист.

## Как сейчас (читай код, не верь описанию)
Вход и порядок: `tools/floorplan/pipeline.py:run` (и `worker.py`, `conveyor.py` — стадии после разбора).
1. **Подготовка:** PDF → страницы (`pipeline.py:pdf_pages`), выравнивание фона (`_flat_rgb`, `prepare`).
2. **Чтение текста нейросетью** (`tools/floorplan/vlm.py`, модель `google/gemini-3.8-flash`, `MODEL` :27, temperature 0):
   три вопроса `KINDS = ('labels2','panels','unlabeled')` (`pipeline.py:40`), промпты — `vlm.py:PROMPTS`.
   `labels2` — по каждой надписи комнаты: имя как напечатано, `dims_m` (футы переводит она), `pt` — центр надписи в сетке 0–1000,
   `unsure`; плюс `areas` (общие площади с листа). `panels` — контуры зданий/этажей с заголовками. `unlabeled` — помещения без
   надписей. Кэш ответов по sha листа (`ensure_vlm`). Пример настоящего ответа — `~/remlab-logs/trial/vlm-cache/aaf717f2deda9888d839a214bdbac700/labels2/raw-T-labels2.txt` (на pakardev).
3. **Геометрия — самописный OpenCV, без нейросети** (`tools/floorplan/fpcore.py`, шапка файла — схема; `bench.py:run_plan`,
   `bench.py:auto_cfg` — выбор маски стен: синяя/тёмная/гистерезис/LSD, `fpcore.py:wall_mask_auto`): маска стен → панели
   (`fpcore.py:xy_cut`, `bench.py:panels_of`) → закрытие разрывов (`bridge_lines`, `extend_corners`, двери по скосам
   `bevel_corner_doors`, `corner_cut_doors`) → комнаты как связные области свободного места → подписи к комнатам по точке `pt`
   (`bench.py:room_at`, выноски `follow_callout`) → дотягивание открытых комнат (`openroom.py`), разрезы слитых комнат по обрыву
   перегородки (`partition.py`), поиск-исправление гипотезами (`repair.py:run` — mincut, remove, enclose, neck, partition со
   скорингом по размерам с подписей) → двери/окна (`bench.py:_analyze`, `bay_windows`) → выпрямление по семействам углов → экспорт
   панели (`bench.py:export_panel`).
4. **Масштаб** (`pipeline.py:scale_of` :458): `verified` — размеры с подписей, RANSAC по комнатам (`fpcore.py` ~1312–1351) →
   `listing` (текст объявления, `listing.py:parse_listing/match`) → `area` (`pipeline.py:area_scale` :411: ppm = √(пиксели
   квартиры / общая м²); общая площадь — `listing.py:total_area`, `sheet_area`, `pick_area`) → `not_verified` (по толщине стены,
   `_GuessScale`).
5. **Флаги неуверенности** (`pipeline.py:_room_flags`), результат — `to_result`/`panel_result`.
6. **Опыт с перерисовкой** (выключено, `FP_REDRAW`): `tools/floorplan/redraw.py` — шумный лист отдаём картиночной нейросети
   (gemini-3.1-flash-image) «стереть надписи/мебель, стены жирные, двери и окна как были», сверяем геометрию (`align`,
   `faithfulness`, `topology`, `decide`). Итог на 7 листах: принято 0 из 7 — теряет и выдумывает двери/окна, текст переписывает,
   на большом листе мы сами вырезали только часть (`crop_box` :241). Идёт проба GPT-картинки (T-26).
7. **Пробы, которые уже делали:** MobileSAM с точкой-подсказкой из подписи (`tools/floorplan/sam.py`) — стенд 09.11;
   твои прошлые советы — `.memory_bank/_intake/codex/floorplan-bench-2026-11-09-answer.md`,
   `floorplan-selfrepair-2026-11-09-answer.md`, `false-doors-merged-rooms-2026-11-09-answer.md`,
   `redraw-openings-2026-11-10-answer.md`. Уроки — `.memory_bank/lessons/floorplan-trial.md`; сводка — `.memory_bank/core/agent-trial.md`,
   `.memory_bank/domain/floorplan-trial.md`. Тесты — `tests/floorplan/`.
