# Вопрос Codex — метаплан «Попробовать бесплатно» для агента недвижимости UK (09.11, ведущий common)

Прочитай: `.memory_bank/plans/MASTER-agent-trial.md` (метаплан), `.memory_bank/_intake/agent-trial-pipeline-inventory-2026-11-09.md`
(что есть в коде, время, пробелы), `.memory_bank/_intake/landing-competitors-2026-11-09.md` (лендинги конкурентов),
`.memory_bank/_intake/competitors-2026-11-09.md` (комментарии владельца), `.memory_bank/plans/floorplan-raster-bench-01.md` (стенд план→3D).
Цель владельца: агент UK кидает фото/PDF плана → сам конвейер: 3D → расстановка по шаблонам → товары → фото → тур; ≤ 3 мин или письмо.

## Мой вывод (до тебя)
1. **MVP-срез:** первая версия — гостиная + спальня (спальня-меши: кроватей нет → нужна волна мешей заранее, ~1 ₽/шт); остальные комнаты —
   пустые серые с подписью «coming soon» (не выдумывать). Кухня/санузел — позже.
2. **Каталог UK нет** (только РФ + маска ADR-0328: английские имена, цена ×1,5, магазины скрыты). Пока владелец не дал источник UK —
   показывать товары с пометкой «sample products, prices indicative», без выдачи за британские магазины (CAP Code / DMCC 2024 — честность).
3. **Где выполнять:** прод (exit-fi, 2 ядра/3,7 ГБ) только принимает файл и показывает страницу ожидания/тур; тяжёлое — воркер на DEV
   pakardev, забирает задания из таблицы-очереди Postgres (поллинг/LISTEN), без Inngest (не подключён). Тур — страница, читающая JSON
   задания во время работы (не вшивать в сборку — сейчас реестр квартир собирается в билд).
4. **План → 3D без человека:** масштаб — из VLM-подписей/текста объявления с leave-one-out; комнаты-многоугольники → в формат квартиры
   (расширить `contracts/apartment.ts` полигонами или аппроксимировать прямоугольниками для решателя, оставив полигон для 3D); флаги
   «не прочитал» видны агенту. Проверку человеком из b2b-13 для пробы снять, для продажи застройщику — оставить.
5. **Бюджет:** VLM+стены ≤ 60 с; расстановка по комнатам параллельно ≤ 30 с; фото по комнатам параллельно через шлюз ~60 с; тур
   открывается сразу после расстановки, фото догружаются. Итог ≈ 2,5 мин; если хуже — показывать 3D сразу, фото по готовности + письмо.
6. **Порядок:** лендинг (макет → владелец) ∥ план→3D-модуль; затем очередь+страница ожидания; затем расстановка на произвольных комнатах;
   товары; фото; сквозной прогон на слепых D–G с таймером.
7. **Защита пробы:** лимит на почту/IP, капча, потолок денег в сутки, размер файла, только изображения/PDF; без регистрации.
