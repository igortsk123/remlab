# Вопрос: вид из окна (demo-04 п.5)

Контекст: проёмы уже из одного описания (IR) — `lib/viewer3d/opening-ir.ts` (браузер `openings.ts`, сервер `tools/scout/opening_ir.py`);
стена сервера вырезана (`services/planner-solver/planner/scene.py:wall_rects`), за вырезом сейчас красим небо градиентом
(`opening_ir.paint_beyond`). Есть 4 своих картинки 1600×1072 (`public/scene/views/{city-day,city-evening,yard,park}.webp`,
сгенерированы flux, горизонт ~30–45 % сверху). Браузер: стекло opacity 0.07, за домом — сфера-панорама `outside.webp`.

Мой план:
1. Где задаётся: `windowView` у квартиры в карточке застройщика (`data/partners/demo.json` → ночная сборка → `demo-data.json`
   `room.window_view`), у проёма — `view` (перекрывает). Значение — id из нашего набора или https-URL застройщика. URL —
   только через наш прокси `/api/scene/view?u=` (белый список доменов из env, `image/*`, ≤ 3 МБ, кэш), прямой чужой URL не грузим.
2. Геометрия — в IR: у окна/балкона поле `view: {u0,u1,v0,v1,back}` в осях стены: плоскость на `back`=150 см за стеной, по ширине
   выреза + запас `back·tan 70°` с каждой стороны, высота — по пропорции картинки 3:2, центр по вертикали — на уровне глаза 135
   (горизонт картинки ~ там же). Один расчёт для обоих потребителей.
3. Браузер: `meshesFromIR` добавляет плоскость `MeshBasicMaterial` с картинкой (fog off), стекло остаётся 0.07.
4. Сервер: `paint_beyond` для пикселей выреза пересекает луч с плоскостью `z=−back` (в осях стены), берёт (u,v) в прямоугольнике
   `view` и сэмплирует картинку (билинейно); стекло (`role: glass`) сервер при наличии вида не рисует (непрозрачное закрыло
   бы вид), а вид умножает на тон стекла 0.94. Картинку сервер качает по URL с прода в кэш (как меши), нет — небо, как сейчас.

Вопросы: 1) согласен с местом данных и IR-полем, или плоскость должна жить вне IR? 2) back=150 и запас tan70 — разумно? Не
появятся ли швы/двойной вид у окна рядом с углом (плоскость вылезет за соседнюю стену — она за стеной, но из соседнего окна
видна)? 3) что ещё сделать с горизонтом/яркостью (план: «яркость по времени суток, лёгкая дымка»)? 4) безопасность прокси —
что обязательно (SSRF, редиректы, размер, типы)? Коротко, по пунктам, с `файл:строка`.
