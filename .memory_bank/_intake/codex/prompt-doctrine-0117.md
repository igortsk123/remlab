   смещение и есть содержание («предмет + такое окно», «набор именно так ставится в угол»).
   Якорь — обязательная часть схемы: в планах она применяется ТОЛЬКО при наличии якоря.
2. Пунктирные предметы (контекст) — референс ОТНОШЕНИЙ: как другие объекты должны стоять
   относительно целевой группы (диван напротив носителя, экран на тумбе, дистанции).
3. Если объект/группа ПО ЦЕНТРУ — ситуационной привязки нет: чистая композиция, позицию в
   комнате дают общие правила (фокус-стена, маршруты, ось).
