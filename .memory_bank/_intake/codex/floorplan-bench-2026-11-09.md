## Мой вывод (до тебя)
1. **Основной путь — классика без нейросети (OpenCV):** на таких планах стены — самые толстые тёмные штрихи. Порог по тёмному →
   морфология (открытие ядром ~ толщины стены) убирает текст, мебель, тонкие окна и дуги дверей → маска стен. Маска → полигоны
   (`cv2.findContours` + `approxPolyDP`, выравнивание к осям по доминантному углу) → выдавливание на 2,6 м = серые стены.
   Проёмы = разрывы маски: окно (в разрыве тонкие параллельные линии) → нижняя/верхняя перемычка; дверь (рядом дуга) → проём
   до 2,1 м. Комнаты = связные области «пустоты», замкнутые стенами (закрыть щели проёмов отрезками перед заливкой).
2. **Масштаб — по подписям комнат, считает код:** VLM (Gemini, копейки) или OCR читает подписи «имя + A x B м» с точкой
   на картинке → подпись попадает в область комнаты → пара (размеры области в px ↔ метры подписи), учитывая, что подпись =
   внутренние размеры по наибольшим сторонам; масштаб = медиана по всем комнатам, выбросы (Г-образные комнаты, «max» размеры)
   отбрасывать; проверка — линейкой «APPROX SCALE» если есть. Качество = ошибка размеров каждой комнаты против подписи (MAE, P95).
3. **VLM «рисует стены JSON-ом»** — только как сравнение; ожидаю плохую геометрию (пиксели плывут), годно для подписей.
4. **Raster2Seq / CubiCasa** — веса CC BY-NC, GPU нет — в продукт нельзя; в стенде только если бесплатно и быстро, иначе пропуск
   с пометкой. floorplan-vectorizer (MIT) — посмотреть как источник идей, код без лицензии не копировать.
5. **3D:** новый модуль «стены из полигонов» (ExtrudeGeometry, серый материал) отдельно от `rooms.ts`; на картинке —
   кадр сверху под углом + вид изнутри, своими глазами; несколько этажей и постройки на одном листе — разделять на «острова»
   связности маски и раскладывать как отдельные этажи/здания.
