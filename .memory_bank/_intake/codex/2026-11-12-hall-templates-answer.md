# Решение T-20261112-70

Каталог прихожей следует принять как H1–H9, но с тремя поправками к исходной гипотезе:

1. Главный классификатор действительно не площадь, а **чистая ширина в каждом поперечном сечении**:

   `P = ширина комнаты − глубина мебели слева − глубина мебели справа`.

2. Шкаф, модуль и открытая вешалка — **варианты хранения**, а не ступени деградации. После выбора варианта уступаем только целым составом: консоль → сиденье → зеркало → обувница → отказ. Нельзя молча превратить проданный шкаф в вешалку.

3. `85 см` нельзя оставлять «жёсткой нормой». Это перенос ширины помещения из отменённого СНиП на проход между мебелью. Предлагаю для общего профиля:

   - цель — 90 см;
   - compact — 75 см только как локальное прямое сужение длиной до 200 см, не возле двери и не в повороте;
   - жёстко — 75 см;
   - в M4(2) — 90 см, локальные 75 см только по условиям M4(2), без обычной компактной деградации.

Это соответствует принятой методике: состав и уровень выбираются площадью/шириной, но проходы не уменьшаются «из-за маленькой комнаты» — [room-templates.md:57](/home/pakar/igor/remlab/.memory_bank/domain/room-templates.md:57). До кода всё должно пройти масштабные листы и показ владельцу — [room-templates.md:20](/home/pakar/igor/remlab/.memory_bank/domain/room-templates.md:20).

Статус документа — «действует» у [Росстандарта](https://protect.gost.ru/sp/details/c8b00dd7-7c13-4f17-ac0c-d9cf70311263), текст п. 5.12 — [ГАРАНТ](https://base.garant.ru/404976077/).

  - 70 см перед распашными дверцами и ящиками;
  - 50 см перед раздвижными фасадами и открытым хранением;
  - 50 см между стационарной мебелью соседних зон;
  - 30 см вдоль открытой дверцы.
  
  Источник: [Пособие, п. 3.1 и рис. 45](https://meganorm.ru/Data1/43/43566/index.htm).
- Approved Document M, M4(1), п. 1.15 и таблица 1.1:
  - обычный коридор — 900 мм;

Официальный источник: [Approved Document M, Volume 1](https://assets.publishing.service.gov.uk/media/5a7f8a82ed915d74e622b17b/BR_PDF_AD_M1_2015_with_2016_amendments_V3.pdf), статус и область — [GOV.UK](https://www.gov.uk/government/publications/access-to-and-use-of-buildings-approved-document-m).

Это planning standard, а не Building Regulations: [официальный NDSS](https://www.gov.uk/government/publications/technical-housing-standards-nationally-described-space-standard).
- London Housing Design Standards действительно требуют для соответствующей новой лондонской застройки 90% M4(2) и 10% M4(3), но это не правило общего профиля: [London City Hall](https://www.london.gov.uk/programmes-strategies/planning/implementing-london-plan/london-plan-guidance/housing-design-standards-lpg).

## 3. Общие уровни состава

Внутри каждого семейства сначала фиксируется вариант хранения:

- `CS` — купе;
- `CH` — распашной шкаф;
- `M` — готовый модуль;
- `OW` — настенное открытое хранение;
- `OF` — напольная вешалка;
- `N` — встроенное хранение в нише;
- `US` — хранение под лестницей;
- `CH+drop` — шкаф и отдельная кратковременная вешалка.

После этого уровни только целые:

| Уровень | Целый состав |
|---|---|
| A | хранение + обувница + зеркало + банкетка + консоль |
| B | хранение + обувница + зеркало + банкетка |
| C | хранение + обувница + зеркало |
| D | хранение + обувница |
| E | только хранение верхней одежды |
| Отказ | не помещается выбранный вариант хранения либо нарушен путь/дверь/фронт |

## 4. Каталог H1–H9

Легенда схем:

`E` вход, `D` дверь, `W` шкаф, `H` открытая вешалка, `S` обувница, `B` банкетка, `C` консоль, `M` зеркало над низким предметом, `>` путь, `T` лестница, `N` ниша.

### H1 — одна глубокая стена

```text
+-------------------------------+
| WWWWW      S(M)  B      D     |
|                               |
| E >>>>>>>>>>>>>>>>>>>>>>> D   |
+-------------------------------+
```

- Когда: линейный коридор; обычно ширина от 150 см, но решает формула `W − Dхранения`.
- Для шкафа 60 см: цель при `W≥150`, compact только при `W≥135`.
- Хранение — на самой длинной глухой стене; обувь/сиденье — ближе к входу; двери — преимущественно на противоположной стене или в концах.
- Длина: фактическая ширина SKU + свободные подходы к дверям; не задавать единой нормативной цифрой.
- Ветки: `H1.CS`, `H1.CH`, `H1.M`, `H1.OW`; каждая A→E.
- Частые ошибки: шкаф в зоне бокового подхода к двери, обувница в дуге входа, длинная банкетка в единственном узком месте.

### H2 — узкая линия

```text
+-------------------------------+
| HHH   S(M)       C       D    |
|                               |
| E >>>>>>>>>>>>>>>>>>>>>>>> D  |
+-------------------------------+
```

- Когда: обычно 100–149 см; глубокий шкаф не обеспечивает целевой путь.
- Максимальная глубина предмета определяется `D ≤ W−90`; compact — `D ≤ W−75` только на коротком прямом участке.
- Основное хранение: настенные крючки/полка либо доказанно мелкий модуль. Высокая slim-обувница не заменяет место для верхней одежды.
- Стена с дверями остаётся почти пустой.
- Ветки: `H2.OW`, `H2.M`; A→E, но A/B допустимы только при достаточной длине.
- Ошибки: считать любую «вешалку» основным хранением; поставить напольный hall tree глубиной 60 см; растянуть compact на всю длину комнаты.

### H3 — дверной коридор, продольные карманы

```text
+----------------------------------+
| D    WWW        D       S(M)     |
|       >>>>>>>>>>>>>>>>>>         |
| E >>>>>>>>>>>>>>>>>>>>>>>>> D    |
|          D          B            |
+----------------------------------+
```

- Когда: три и более дверей, проёмы на обеих длинных стенах, свободная стена разбита на сегменты.
- Каждая группа получает отдельный продольный карман между дверными подходами.
- В сечении должно выполняться `W − Dleft − Dright ≥ route`.
- Нельзя ставить предмет «напротив двери» только по эстетическому запрету; жёсткий запрет возникает, если нарушена таблица подхода. Напротив санузла шкаф всё равно нежелателен как дизайнерский дефолт.
- Ветки: `CS/CH/M/OW`; A→E.
- Ошибки: единая полоса 76 см перед дверью вместо расчёта угла подхода; зеркало на полотне; мебель в зоне наличника; обувница в дальнем конце.

### H4 — две стены просторного холла

```text
+--------------------------------+
| WWWWWW                   D     |
|                                |
| E >>>>>>>>>>>>>>>>>>>>>>>>> D  |
| S(M)       B        C           |
+--------------------------------+
```

- Когда: широкий холл, а не просто большая площадь.
- Условие: `W ≥ Dхранения + Dнизкой_мебели + 90`.
- Примеры, не пороги паспорта:
  - 60 + 35 + 90 = 185 см;
  - две глубокие стороны 60 + 60 + 90 = 210 см.
- Хранение — на глухой стороне, низкая мебель — напротив, но не напротив дверей.
- Ветки: `CS/CH/M` × A→E.
- Ошибки: правило «две стены всегда от 200»; размещение двух фронтов строго друг против друга; банкетка, которая при использовании перекрывает путь.

### H5 — квадратный/компактный угловой холл

```text
+--------------------+
| WWWWW          D   |
|                    |
| S(M) >>>>>>>>> D   |
| B    E             |
+--------------------+
```

- Когда: примерно квадратный холл, вход у края/угла, несколько коротких стен; площадь 2–6 м² — только диагностический признак.
- Один высокий угловой якорь; обувная группа у входа; центр сохраняется свободным.
- Нельзя автоматически заполнять все четыре стены.
- Ветки: `CS/CH/M/OW`; A→E.
- Ошибки: шкаф в углу, где ручка входной двери ударяет фасад; банкетка в центре; зеркало на ближайшей двери вместо стены.

### H6 — Г-образная прихожая

```text
+-------------+
| WWWW    D   |
| >>>>>>>>>   |
| > +---------+
| > | S(M) D |
| E | B      |
+---+--------+
```

- Когда: настоящий Г-контур, не bbox прямоугольника.
- Глубокое хранение — в широкой/тупиковой ноге; входная нога — обувь и мелкое открытое хранение.
- Внутренний угол и поворот сохраняются на 90 см.
- Ветки: `CS/CH/M/OW`; обычно B→E, A только если есть отдельный свободный сегмент.
- Ошибки: напольная вешалка во внутреннем углу; мебель на обоих плечах поворота; расчёт по bbox вместо контура.

### H7 — ниша заподлицо, модификатор

```text
+--------------------------------+
| [ N:WWWWW ]      S(M)      D   |
|                                |
| E >>>>>>>>>>>>>>>>>>>>>>>>> D  |
+--------------------------------+
```

- Это не отдельная планировка, а модификатор H1–H6.
- Ниша должна быть явным объектом с шириной, глубиной и доступной высотой; выбранный SKU должен помещаться целиком.
- Путь считается от фактической плоскости фасада, не от исходной стены.
- Ветка хранения `N`; уровень базового шаблона A→E.
- Ошибки: считать случайный простенок нишей; прятать в нише распашной шкаф без фронта 70 см; игнорировать плинтус, наличник или радиатор.

### H8 — микро-тамбур

```text
+------------+
| HHH   M    |
|            |
| E >>> D    |
|  rug/S     |
+------------+
```

- Когда: ширина около 90–120 см, длина около 120 см и более, двери занимают почти весь периметр.
- Только настенное открытое хранение, зеркало, коврик/поддон и при доказанном месте — очень мелкая обувная зона.
- Допустимые уровни: C→D→E; сейчас часто честный отказ, потому что роли настенных крючков и коврика отсутствуют.
- Напольная вешалка не является заменой настенным крючкам.
- Ошибки: продавать комплект из предметов, показанных только списком; обувница в дуге; зеркало на входной двери.

### H9 — UK hall с лестницей

```text
+-----------------------------+
| TTTTTTT | US storage | D    |
| TTTTTTT |             >>> D |
|                         >>> |
| E >>> S(M) >>>>>>>>>>>>> D  |
|       H/C                   |
+-----------------------------+
```

- Когда: лестница является явным препятствием; вход в торце; несколько дверей в комнаты.
- Хранение под лестницей — `US`; возле входа — обувница и зеркало; узкая консоль/hall tree только в доказанном кармане.
- Для примера 210×500 со лестницей 118×180 остаётся около 92 см поперёк препятствия: это проходит цель 90 до учёта плинтусов и фактического контура.
- NDSS позволяет учитывать подлестничное хранение, но не задаёт эту композицию.
- Уровни обычно C→D→E; B/A только при отдельном кармане.
- Ошибки: не моделировать лестницу; ставить высокий предмет под недостаточной высотой; сужать путь у поворота лестницы.

### Общий отказ

Любое семейство отклоняется, если:

- нет ни одного допустимого основного хранения;
- путь ниже hard;
- мебель попадает в дугу двери;
- не обеспечен рассчитанный подход к комнате;
- выбранный фасад нельзя открыть;
- локальные 75 см приходятся на дверь или поворот;
- предмет в комплекте не имеет места/габарита/3D-представления.
