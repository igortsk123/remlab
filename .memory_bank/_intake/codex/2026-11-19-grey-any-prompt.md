## Мой вывод (до твоего ответа)
Нужно правило «серость вообще»: поверхность (любая видимая роль, кроме «низ») — дефект-кандидат, если одновременно:
1. нейтральна: хрома C* (Lab, из медианы RGB поверхности) ≤ 8 — при ЛЮБОЙ яркости (не полоса);
2. однотонна: σ (среднее по каналам) ≤ 4 — настоящая ткань/дерево/бетон дают σ ≥ 8…14, пустая заливка 1–2;
3. заметна: доля площади среди видимых поверхностей ≥ 15 % (отсекает ножки, ручки, хром);
4. резко отличается от остального изделия: ΔE76 до площадь-взвешенной средней Lab остальных видимых поверхностей ≥ 20 (защита «весь предмет серый»:
   серый диван, бетонный стол — ΔE мал);
и верхний уровень (как сейчас, `effective`) снимает её, если медиана поверхности совпала с цветом фото товара (ΔL ≤ 8, Δab ≤ 8) — честно серый товар.
Вердикт — только `candidate` (мягкий карантин, не `reject`); `reject` остаётся за чистым окном 124–134. Версия правил → gt-v5.
