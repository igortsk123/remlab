## Вывод

**Не закреплял бы кирпич за лофтом и вообще не делал бы акцент обязательным.** В опубликованных квартирах 2023–2025 годов встречаются и спокойная окраска без «декоративной стены», и локальные панели, штукатурка или цвет, подобранные под мебель. Кирпич уместен как один из вариантов лофта, но в обычной новостройке он чаще означает *новую облицовку*, а не «открытую историческую кладку». Ранжирование ниже — **дизайнерская рекомендация для квартир 9–20 м²**, не статистика распространённости. ### Физика изображения

- **P — тихая штукатурка/краска:** `ambientCG Plaster002` или более гладкий `Poly Haven white_plaster_02`. Для новой квартиры оставлять вариацию цвета слабой, зерно порядка **0,2–1 мм**, расчётную шероховатость примерно **0,75–0,95**. Это *стартовые настройки шейдера*, не измеренные характеристики краски. ([ambientcg.com](https://ambientcg.com/view?id=Plaster002&utm_source=openai))
- **C — бетон/минеральная отделка:** `ambientCG Concrete003`; `Poly Haven plastered_wall_04` — лишь после отбора или очистки потёртостей: готовый ассет описан как *worn/scuffed*. Для микроцемента показывать движение кельмы примерно **20–60 см**, мелкий рельеф, а не повторяющиеся «облака» метр в метр. Не выдавать изношенный наружный бетон за свежую отделку новостройки. ([ambientcg.com](https://ambientcg.com/view?id=Concrete003&utm_source=openai))
- **B — кирпич:** для настоящего российского одинарного кирпича лицевая грань **250 × 65 мм**, глубина изделия **120 мм**; шов порядка **8–12 мм** — проектное допущение, а не размер, заданный ГОСТом. У облицовочной плитки глубину брать **из карточки выбранного изделия**, а не изображать 120-миллиметровую кладку. `Bricks085` — проверенный CC0-ассет, но **не подгонять его кирпичи насильно под ГОСТ**: текущий паспорт проекта задаёт тайл 240 × 120 см и оценивает кирпич рисунка примерно в 21 × 7 см. Нужны неплоский раствор, разная глубина граней, вариация отдельных кирпичей и разрыв заметного повтора. Белый *крашеный* кирпич требует перекраски/нейтрализации карты, а не простого умножения красного albedo на белый. ([meganorm.ru](https://meganorm.ru/mega_doc/norm/gost_gosudarstvennyj-standart/3/gost_530-2012_mezhgosudarstvennyy_standart_kirpich_i_kamen.html?utm_source=openai))
- **W — дерево и профиль:** широкие панели предпочтительнее «полосатого забора». Если выбраны рейки, пример **реального товара** — МДФ **30 × 20 × 2700 мм**; зазор **15–30 мм** предложен как спокойный проектный ритм, не как стандарт. Для молдинга существует, например, Orac `PX103` **200 × 2,5 × 1,2 см**; рисовать его **геометрией**, а не normal-map без силуэта. Зазоры, торцы и примыкания важнее повышения разрешения текстуры. ([moscow.petrovich.ru](https://moscow.petrovich.ru/product/1091958/?utm_source=openai))

**Карты:** для Cycles — albedo в sRGB, normal/roughness/height как non-color; на близком плане обычно **2–4K на исходный физический тайл**, при настоящем displacement — качественная height-карта и достаточно геометрии. Для телефона — цвет **512–1024 px**, по возможности normal **512–1024 px** и roughness меньшего размера; AO лишь когда действительно помогает. `normalMap` меняет освещение, **не силуэт**: кирпичные швы, рейки и выступающие панели лучше делать геометрией или гибридом геометрии с normal. Текущий просмотрщик уже применяет облегчённый цвет и дополнительные normal/roughness лишь в соответствующем режиме; **KTX2 — возможная оптимизация, не требование к нынешнему пайплайну**. ([docs.blender.org](https://docs.blender.org/manual/en/latest/render/shader_nodes/displacement/displacement.html?utm_source=openai))

## Правило выбора

Выбирать **набором мебели и геометрией комнаты**, а не одним `style → asset`. При этом сохранять воспроизводимый выбор для данного набора и давать покупателю переключатель **«без акцента / варианты отделки»**. Нынешние `accentWalls.styles: {"лофт":"accent-brick"}` и `accentWallFor(style)` выражают только один материал на стиль; `behind-focal` полезен как кандидат стены, но не доказывает, что в ней нет окна или что диван действительно стоит у стены.

```js
// Эскиз новой версии данных; не совместим с нынешним styles: Record<string,string>
// без отдельной доработки читающего кода.
accentWallsV2: {
  carriersByRoom: { "спальня": ["кровать"], "гостиная": ["диван", "тв"] },
  defaults: { allowNone: true, maxPerRoom: 1, noWindowWall: true },
  guards: {
    minAreaM2ForStrong: 12,          // гипотеза для проверки на превью
    minClearWallWidthM: 2.2,
    maxAccentAreaShare: 0.35,         // доля видимой площади стен; ориентир
    maxDeltaLStarFromBase: 25,       // спальня ~15–20; оценивать после освещения
    maxMajorMaterialFamilies: 2
  },
  styles: {
    "лофт": {
      "гостиная": [
        { id: "none", weight: 20 },
        { id: "concrete-soft", weight: 40, surface: "accent-concrete",
          anchors: ["behind-sofa", "behind-tv"], minAreaM2: 12 },
        { id: "brick-clinker", weight: 25, surface: "accent-brick",
          anchors: ["behind-sofa"], minAreaM2: 14,
          rejectIf: ["warm-red-sofa", "busy-upholstery", "window", "no-supplier-sku"] },
        { id: "dark-paint", weight: 15, surface: "accent-paint",
          anchors: ["behind-sofa"], minAreaM2: 12 }
      ],
      "спальня": [
        { id: "none", weight: 45 },
        { id: "concrete-soft", weight: 35, surface: "accent-concrete",
          anchors: ["behind-bed"] },
        { id: "dark-paint", weight: 15, surface: "accent-paint",
          anchors: ["behind-bed"] },
        { id: "brick-clinker", weight: 5, surface: "accent-brick",
          anchors: ["behind-bed"], minAreaM2: 14 }
      ]
    }
    // Остальные строки таблицы — тем же форматом; weights не рыночная статистика.
  }
}
```

Сначала отсеивать невозможное: окно/дверь, недостаточная свободная ширина, выступы, батареи, розетки и конфликт с открыванием; затем — несовместимые палитры и дублирование рисунка пола/мебели; потом ранжировать оставшееся. **При отсутствии подходящей стены результат `none`, а не перенос на окно или случайную стену.** Для яркой, узорной либо очень тёмной мебели повышать вес `none` и тональных вариантов. Пороги площади и `ΔL*` выше — **предлагаемые ограничения продукта для A/B-проверки**, не строительные нормы; в комнате меньше 12 м² запрещать прежде всего *сильный* акцент, не деликатную окраску.

## Покупатель, цена и риски

Переключатель стоит показывать как **вариант реальной отделки с составом работ**, а не как бесплатный визуальный фильтр. Отдельно раскрывать материал, подготовку основания, работу, доставку/отходы и статус «ориентир / подтверждённая смета». Например, реальная рейка 30 × 20 × 2700 мм в московской карточке стоила **471 ₽/шт.** при проверке; опубликованный московский прайс подрядчика указывает **от 1 860 ₽/м² за работы по декоративной штукатурке** и **от 5 420 ₽/м² за работы по микроцементу** при оговорённых объёмах. **Эти ставки нельзя автоматически умножить на одну стену 8 м² и назвать конечной ценой:** могут действовать минимум заказа, подготовка и другие условия. Цена должна быть привязана к региону, SKU и актуальной смете. ([moscow.petrovich.ru](https://moscow.petrovich.ru/product/1091958/?utm_source=openai))

Главный риск доверия — показать PBR «старый кирпич/голый бетон» там, где покупателю фактически предложат плитку или новую штукатурку. Второй — одинаково убедительный акцент на телефоне и в Cycles при разной геометрии: **сохраняйте физический размер, цвет и расположение общими**, а различия качества прямо проверяйте парными кадрами. Наконец, текстуры Poly Haven с трещинами, грязью и сколами нельзя без разбора использовать как «новую отделку». Неоклассику, пока она только в каталоге, в автоматическое назначение комнат не включать. ([polyhaven.com](https://polyhaven.com/a/concrete_wall_001?utm_source=openai))

**Что остаётся неопределённым:** частоты решений по стилям нельзя надёжно вывести из нескольких опубликованных проектов; точный физический модуль `Bricks085`, подходящий SKU клинкера и локальные цены отделки нужно подтвердить до продажи. Названные CC0 ID проверены как доступные, **но пригодность каждого конкретного тайла без видимого повтора на стене 2,6–2,8 м требует тестового рендера**.
