# Вопрос Codex: пул Salad, ночь 23→24.10 (отчёт работника T-20261022-10/4)

Факты за 8 ч (mesh-low-10, все RTX 4060 Ti): 106 мешей, 716 ₽, 6,76 ₽/меш при потолке 1,5. Генерация ≈13 % оплаченного времени.
- Обрывы mid_generation — 50 против 106 успешных (32 %); в среднем через ~7 мин после первой записи. Текст: генератор закрыл соединение,
  потом SSH «closed by remote host» (похоже на перезапуск контейнера). 22.10 было 37 %, хотя теперь машины с ОЗУ < 32 ГБ отсеиваются
  до первого задания (`tools/scout/salad/ssh_run.py:mem_reject`, `rules/salad-groups.json` node_ram.min_gb=32). Память контейнера
  группы — 24576 МБ; образ memtrim (…46dbc19b). Гипотеза работника: упираемся в потолок памяти КОНТЕЙНЕРА, а не машины.
- Отклонённые по ОЗУ (32 случая) ждут слота пересадки в `mem_low` (`ssh_run.py` ~:1028; лимит 6/ч — `node_health.py:28`),
  медиана 67 мин включёнными, потом пересадка 404 (инстанс исчез). До ≈360 ₽ за ночь (верхняя граница).

Мой вывод (проверь): (1) отклонённых по ОЗУ пересаживать сразу, мимо лимита, 404 не считать в лимит — ясно; (2) обрывы — сперва
бесплатно измерить: пик памяти cgroup контейнера (memory.peak / memory.events oom_kill) по SSH во время генерации и счётчик перезапусков
инстанса через API Salad; если oom_kill — поднять память контейнера до 32768 (заодно Salad перестанет выдавать машины 25 ГБ, и утечка (1)
исчезнет сама), если нет — искать в другом месте (драйвер, сеть, тайм-аут генератора).

Что проверить по коду с `файл:строка`:
1. Где задаётся память контейнера, как группа создаётся (`migrate_groups.py`, `recreate_group`), и выдаст ли Salad машину с ОЗУ меньше
   памяти контейнера (по докам Salad — с источником).
2. Как классифицируется обрыв (`node_health.py` классы вины) — видно ли из текста ошибки отличие OOM от сетевого обрыва; что пишет воркер.
3. Можно ли снять memory.peak / oom_kill / dmesg изнутри контейнера по SSH (cgroup v2), не меняя образ.
4. Риски (1): чехарда пула, повторная выдача той же 25-ГБ машины; что сделать, чтобы не крутить её по кругу.
5. Порядок: что делать до следующего подъёма, а что — по данным первого часа (канарейка 2 машины ≈ 1 ч).
