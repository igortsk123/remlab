# Пороги memory-audit для remlab — читают все входы (CLI, CI, Stop-хук, SessionStart). Кит v1.8+.
# CLI-синтаксис, # — комментарий; пусто = дефолты кита. Список порогов — шапка tools/memory-audit.mjs.
# Tier 0 (CLAUDE.md + INDEX) — 10 KB: было флагом в команде Stop-хука, перенесено сюда при апгрейде на 1.9 (28.09).
--tier0-max-kb 10
# Правила без paths: (TIER0-RULES, кит 1.9) — 24,1 KB при дефолте 20; вместе с CLAUDE.md и INDEX постоянная
# нагрузка ≈ 32 KB. Порог 26 = текущий вес + запас: рост ловится, шума нет. Снижать — после облегчения правил.
--tier0-rules-max-kb 26
# Индекс решений (DECISIONS-BLOAT) — 56 KB при дефолте 40. Причина: тексты уже вынесены в тома, а
# индекс по построению = строка на решение, и аудит требует строки для КАЖДОГО ADR (ADR-NOT-INDEXED),
# т.е. ~0,12 KB на решение. На 222 решениях это 42 KB — дефолт перерос сам факт роста проекта.
# 56 KB = запас примерно до 330 решений; дальше сокращать блок «По темам», а не порог.
--decisions-max-kb 56
