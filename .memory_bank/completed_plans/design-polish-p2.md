## Что сделано (все решения — с расчётом WCAG-контраста)
1. **Кнопки вернулись к прежней терракоте:** UUI-дефолт solid = brand-600 (#9a5a3d) темнил CTA;
   переопределено в brand.css: `--color-bg-brand-solid` = brand-500 (#b06a4a, прод до миграции),
   hover = 600. Белый на 500 = 4.19:1 (крупный semibold — ок).
2. **Мягче текст:** `--color-text-primary` = stone-800 (тёплый графит, 13.1:1 на креме) вместо
   жёсткого stone-900 (15.2:1); alt-CTA шапки: текст brand-700 (5.79:1 на brand-100) вместо 800.
3. **Шапка на узких экранах (≤480):** полоса разделов — одна строка с горизонтальным скроллом
   (паттерн мобильных табов); на SE (375) переносы давали 3–4 ряда шапки.
4. **Подсказки «?» (раппорт, стыковка, дверь-проёмы):** React Aria Tooltip НЕ показывается на
   тач-экранах by design → новый примитив `components/base/hint/hint-popover.tsx` (RAC
   DialogTrigger+Popover): тап — открыть, тап мимо/Esc — закрыть; заменён в MaterialParams и
   SurfaceEditor. Проверено эмуляцией тача (page.tap) на 375/393.
