## Цель
«Моя лаборатория» = единый центр сохранений: список расчётов сессии (вид/дата/сумма → /e/<id>),
кнопка «Сохранить в Мою лабораторию», счётчик в шапке и на плитке главной, сессия 30 дней с
продлением, раздел /estimates скрыт из навигации (роуты и данные живут).

## Скоуп (из зонта launch-prep П2)
- `ResultView`: кнопка «Сохранить смету» → «Сохранить в Мою лабораторию» (redirect на /e/<id> остаётся).
- `/e/[id]`: ссылка «Мои сметы» (/estimates) → «Моя лаборатория» (/lab) — понятная навигация после сохранения.
- `/lab`: вместо карточки-ссылки на /estimates — САМ список расчётов: «Расчёт обоев/плитки/…» (meta.kind
  → CALC_META, фолбэк title), дата, сумма (estimateTotal), ссылка /e/<id>. Без «грунтовка, шпателя…».
  «Мои дизайны» — компактно, только если есть.
- `/estimates` скрыт из навигации (все ссылки убраны); роут и /e/<id> живут, данные не трогаем.
- `lib/session.ts`: maxAge 365 → 30 дн + продление при активности (re-set в getSessionId).
- Счётчик расчётов: route `/api/lab/count` (по cookie) + клиентский `LabBadge` (шапка у «Моя
  лаборатория» + плитка главной; акцентный бейдж-число). SSG страниц не ломаем (fetch с клиента).

## Критерии
- [x] /lab показывает расчёты сессии списком (вид, дата, сумма, переход в смету)
- [x] Кнопка сохранения переименована; после сохранения путь в лабораторию очевиден
- [x] Счётчик в шапке/на плитке совпадает с фактом; без сохранений — не мешает
- [x] Cookie 30 дн, продлевается при активности; /estimates недостижим из UI, но роут жив
- [x] typecheck / lint / test(75) / build зелёные; авто-деплой; смоук
