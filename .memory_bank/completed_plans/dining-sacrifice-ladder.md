## Цель
Правило владельца (14.08, по разбору Плана №19): «столовая не встала, стол в банке →
пробуем пересбор с посадкой на ступень ниже; принимаем, если столовая встала и качество
(маршрут/фокус/щели) не хуже. Остаточное — уже зоны хранения» (порядок цепочки прежний).

## Обоснование
Свод №4 §5: приоритет второй зоны dining > secondary seating. Посадка сейчас выбирает
ступень жадно (максимум мест) без знания, что столовая не влезет — кресло съедает нишу
(замер №19: ниша 160×125 при потребности 150×180; без кресла — 160×270, встаёт).

## Конфликты
| Существующее | Решение |
|---|---|
| Лестница с минимумом медиа (проба=факт) | не трогаем: retry — ПОВЕРХ, вторым прогоном всей цепочки |
| Гейт деградации not_worse | он и есть критерий приёмки retry |
| E1 union-allowed | роли нижних ступеней уже в keep ✓ |
| Медиа-минимум | retry принимается только при сохранении медиа |

## Реализация
`solve_zoned`: ladder-skip параметр (пропустить N верхних доступных ступеней); после
основного прогона — если dining не встала, стол в банке и есть куда спускаться →
повторный прогон со skip+1; принять, если dining встала И качество not_worse И медиа
на месте. Данные: `zones.json → dining_sacrifice` (правило+пруф). Сторож: юнит «тесная
комната: кресло уходит, стол+2 встают»; планка доли столовой — вверх при росте замера.
