## Диагностика (сделана до плана)
- Шапка: `.site-nav` имеет `overflow-x:auto` со СКРЫТЫМ скроллбаром (`globals.css:159-163`) при
  контейнере 720px — при увеличенном шрифте пункты уезжают за край и выглядят обрезанными.
- Удаления смет нет нигде: ни в `EstimateRepository`, ни в actions, ни в UI `/lab`.
- Обои: галочка `offset` — это реальная «смещённая стыковка» (+раппорт/2 к длине полосы,
  `formulas.ts:28`), НЕ дубль раппорта. Проблема — подпись без объяснения.
- Ламинат-парсер: на странице есть «Размер доски 1380х193 мм», но regex ждёт «Размер: A×B»
  (слово «доски» ломает шаблон, `link-parse.ts:58`); «Количество в упаковке 8 шт» вообще не
  извлекается детерминированно. ИИ-фолбэк не спас (проверить OPENAI_API_KEY на проде + залогировать ошибки).
- Цена: на той же странице есть и «832.48 ₽ за м²», и «1 775 ₽ за упак» — брать м² реально;
  надстрочное ² в HTML разрывается тегом («м 2») и не матчится текущим regex цены.
- Иконки: emoji-строки в `app/calc/page.tsx:13` и `app/page.tsx:11-18`; иконочных библиотек/SVG нет.
- Тултип: есть CSS-паттерн `.help` + `data-tip` (`globals.css:275-288`), уже используется у «Раппорт».

## Скоуп — что входит
1. **Шапка**: перенос пунктов меню на вторую строку (`flex-wrap`) вместо скрытого скролла — всё
   видно при любом зуме/ширине. (Глобальное расширение страниц — вопрос №1 владельцу.)
2. **Лаборатория — удаление расчёта**: `delete(id, sessionId)` в repository (Pg + memory, только
   свои), server action, кнопка удаления на карточке в `/lab` с подтверждением.
3. **Обои**: галочку оставить (влияет на расход), но переименовать в «Стыковка рисунка со
   смещением» + «?»-подсказка простым языком (значок на этикетке рулона; +полраппорта на полосу).
   Решение владельца: оставить. Дополнительно: переписать «?»-пояснение у «Раппорт» проще и подробнее.
4. **Ламинат-парсер**: labeledRe понимает «Размер доски/панели/ламели»; «Количество в упаковке
   N шт» → `panelsPerPack`; фикстура stroyparkdiy + unit-тесты; лог ошибок ИИ-фолбэка
   (сейчас молча глотается), проверка ключа на проде.
5. **«Смещение рядов»**: «?»-подсказка у селекта (паттерн `.help`): что это, зачем, варианты
   (вразбежку/на 1/2/на 1/3) — человеческим языком.
6. **Цена ламината за м²**: основное поле ввода «Цена за м², ₽» (`pricePerM2Rub` уже в контракте);
   поле «Цена за упаковку» — запасное. Формула: приоритет м² (при известной площади упаковки —
   считать честно через упаковки: packs × округл(площадь_упак × цена_м²)). Парсер: для ламината
   предпочитать «₽ за м²» (починить матч «м 2» с разорванным ²); если только цена упаковки и
   известны размеры+шт/упак — пересчитать в м² автоматически.

### Уроки (ОБЯЗАТЕЛЬНО; для partial/cancelled — особенно)
- «Меню обрезано» оказалось скрытым overflow-скроллом (scrollbar-width:none) — скрытая прокрутка
  без индикатора читается юзером как баг обрезки.
- Regex-юнит цены ловил «м 2» захватом, но классификатор `/м²|м2/` не знал про пробел (разорванный
  `<sup>2</sup>`) — юнит-классификацию проверять на том же тексте, что и захват.
- ИИ-фолбэк с ключом на проде молча возвращал {} при любой ошибке — «тихая деградация» без лога
  неотличима от «фолбэк не нужен»; ошибки внешних вызовов всегда логировать.
