## Чего не хватает до описания владельца
- Нет кнопки «ок» и журнала нажатий: сейчас «принято» = «открыл страницу» (`seen_at`), явного «ок» нет.
- Комментарий не живёт сам по себе: без «брака» его не оставить, сохраняется только кнопкой, версии не хранятся.
- Нет разделов по типам и счётчиков по ним; продолжение с места только номером страницы.
- Фото и модель не равны: фото крошечное, увеличения на весь экран нет, сравнить рядом нельзя.
- **Постеры есть только у 802 из 2765 карточек (29 %)** (`~/scout-scenes/mesh-audit/posters`): остальным нужен прогон
  `mesh_audit_posters.py` (бесплатно, процессор DEV). Постер 320 px для увеличения мал (на снимке увеличения видны «лесенки»):
  нужен снимок 1024 px того же ракурса. Замер 12.11 (`.t118-hd.py`): 42–64 КБ, пик 0,7 ГБ, ≈ 10 с на модель на одном ядре →
  на все 2765 ≈ 150 МБ на проде и ≈ 8 ч одного ядра (ночью; правило «после заливки свободно ≥ 7 ГБ»).
- **304 карточки без роли** (`cat_role` пуст) → раздел «Без типа».

## Как переиспользовать
- **«Брак»** → та же транзакция `repo-decisions.ts:decide` (redo, а после 2 переделок replace_needed) → та же очередь через мост.
  Повторное нажатие снимает: пока решение `redo_requested`, это `cancelDecision` (как сейчас); если мост уже забрал (≈ 1 мин),
  переделку не отменить: кнопка остаётся нажатой, подпись «уже на переделке». Комментарий брака мост берёт из последней версии.
- **«Ок»** → строка в журнале + `mesh_audit_items.mark='ok'`. Для ADR-0233: `isAccepted` = (`mark='ok'` ИЛИ `seen_at`) и `status='open'`
  (`rules.ts`, `repo-items.ts:acceptedGenerationKeys`). Новая страница сама `seen_at` НЕ ставит (жена листает, это не приёмка);
  «ок» сильнее «видел». Снятие «ок» болванку не вернёт, но с 07.11 болванки старше 14 сут и так уходят — потери нет.
- **Новое поколение** (после переделки) сбрасывает `mark` и `note` карточки (как `seen_at`) → снова «не проверена», журнал остаётся.
- **Разделы**: роль из `mesh_audit_items.role` (мост уже шлёт `cat_role`) → таблица разделов `lib/mesh-audit/sections.ts`
  (14: диваны, кресла, стулья, столики, обеденные, тумбы ТВ, комоды, шкафы+стеллажи+витрины+стенки, пуфы, кашпо, вазы,
  свет = торшер+люстра+лампа, камины, без типа). Счётчик раздела = карточки с `mark` по текущему поколению.
- **Продолжить**: открывается первый раздел с непроверенными, в нём кнопка «К непроверенным» и фильтр «все / непроверенные / брак»;
  последний раздел помнит браузер.
- **Комментарий как у стилей** (`style_bench.py:vote_page` + `app/api/lab/review/route.ts`): сам через 1 с, при уходе из поля,
  при закрытии (`sendBeacon`, кука уходит); каждая версия — строка `mesh_audit_notes`; черновик ещё и в браузере до ответа сервера.
  Отдельные таблицы, а не `owner_reviews`: там нет поколения меша и входа по куке.
