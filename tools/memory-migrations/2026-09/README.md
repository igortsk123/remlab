# Миграции памяти 2026-09 (одноразовые скрипты, для воспроизводимости)

Прогон аудита памяти (план `.memory_bank/plans/memory-bank-audit-2026-09.md`). Скрипты запускались
один раз 2026-09-05; оставлены как доказательство и образец для следующей уборки. Пути внутри —
абсолютные под dev-машину; перед повторным запуском проверить.

- `split-decisions.mjs` — decisions.md → индекс + тома по блокам номеров; `adr-overrides.json` — ручные темы.
- `plans-triage.mjs` + `plans-manifest-all.tsv` — таблица триажа планов и применение манифеста архивации.
- `parse.mjs`, `topics.mjs`, `split-lessons.mjs`, `verify.mjs`, `lessons-map.csv` — уроки по темам (дословно) и сверка.
- `add-toc.mjs` — оглавление в больших доках.
