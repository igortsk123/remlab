Отличия от Mobile:
- Переключатель в Desktop двух размеров (31 и 30 px), размера 29 нет.
- Шрифт Inter в Фигме у́же шрифта сайта: где «ширина по тексту» сжимала элемент, у варианта стоит
  минимальная ширина = прежней (метки 43:169/43:180, ссылки 43:60). Расти может, сжиматься — нет.
  Вкладывая такой экземпляр, размер подгонять под рамку-рисунок только вверх.

Составные компоненты других страниц тоже можно вкладывать экземплярами (их внутреннее связывание дойдёт само).
Свойство набора к тексту внутри вложенного экземпляра не привязать — вложенный экземпляр выводить наружу (exposed instance).
У набора одно значение текста по умолчанию → к TEXT-свойству привязаны только варианты с этим текстом, остальные — переопределением.
