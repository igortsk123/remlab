Свойство набора к тексту внутри вложенного экземпляра не привязать — вложенный экземпляр выводить наружу (exposed instance).
У набора одно значение текста по умолчанию → к TEXT-свойству привязаны только варианты с этим текстом, остальные — переопределением.
