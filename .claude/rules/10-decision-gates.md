# Четыре гейта (всегда в контексте; детали — P-NNN в `.memory_bank/rules/`)

## 1. Делегирование — перед выдачей задачи
- Бриф самодостаточный, «на прошлую задачу не опирайся» (P-024); путь к плану, границы: без sudo, платного, деплоя (P-026); имя ведущего по `ListAgents`; первая строка `[роль] T-…/цикл · фаза` (P-027).
- Обязательны 4 строки конвейера (P-032) и строка «что чистит шаг» (P-041); без них — CHANGES REQUIRED.
- Платное и тяжёлое — под `heavy-slot` с `--prio` (P-038), пакетами (P-039); код кронов DEV — только в worktree (P-025).
- Рабочему: без `.env*`, без `rm -rf`, файлы не в `.claude/`, без heredoc в Bash (P-017, P-037).
- Задачу не придумывать без владельца (P-009); свободному — следующая по плану (P-016).

## 2. Приёмка — перед PASS
- Порядок — `review-checklist.md` (P-033): SHA от base, бриф↔отчёт, 4 строки, чистый diff, свои проверки на итоговом дереве.
- Видимое смотрит ведущий САМ (P-031, P-006); дефект товара → правило типа → паспорт (P-034).
- PASS — после зелёного CI и живой проверки; READY TO MERGE ≠ PASS (P-033). До 3 циклов правок, дальше — владельцу (P-029).
- Конец задачи = `/memory-check` и оба аудита чисты (P-046).

## 3. Платный или опасный запуск
- Секреты, миграции, удаление данных, деплой без права, VPN-нода — только с явного слова владельца (P-036).
- Сперва проба и счётчик отказов, потом пакет (P-010); расход строкой; потолок, бэкап, откат.
- Платные машины — пакетами, прогревы экономить, свободную гасить; молчит >10 мин — разбор (P-039); модель на сайте ≤5 МБ (P-040).
- Автоочистка рабочих файлов (P-041); решения — под тысячи планировок и ~50k товаров (P-042).

## 4. Показ владельцу
- По-русски, просто, кратко, у каждого пункта «зачем» (P-001); сводка по формату — одна, П1–П3, % у строк, ✅ только 100 %, токены в $ (P-003).
- Проверка — ссылка + «куда нажать, что увидеть» (P-004); кадры отдельные, полный размер, смотрел сам до отправки (P-005, P-006).
- Вопросы — ❓ в конце, суть и «советую» (P-002); деньги проб не спрашивать (P-010); решения человека — ему (P-011).
