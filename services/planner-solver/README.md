# planner-solver — прод-ядро авторасстановки

Геометрическое ядро расстановки мебели для гостиной: комната (полигон, двери/окна/радиаторы) +
предметы каталога → валидные раскладки с объяснениями. План — `.memory_bank/plans/prod-layout-engine.md`,
спека — `.memory_bank/guides/layout-engine-spec.md`, добытые правила — `.memory_bank/guides/layout-mined-rules.md`.

## Что уже есть (Э1)

| Модуль | Назначение |
|---|---|
| `planner/models.py` | Контракты: `Room`, `Opening`, `Radiator`, `Item`, `Placement`, `Violation`, `Layout` (pydantic v2) |
| `planner/geometry.py` | Footprint-полигоны с поворотом (в т.ч. Г-диван), зоны доступа, «открытый полигон», максимальные свободные прямоугольники |
| `planner/clearances.py` | Клиренсы по ролям + чтение канона `rules/occupancy.json` (шкалы от площади) |
| `planner/validate.py` | Hard-проверки → объяснимые нарушения (коды + факт + ожидание) |
| `planner/svg.py` | Top-down SVG: следы, клиренсы, свободное место, стрелки «лица», список нарушений |

### Ключевая механика
Клиренс **вычитается** из свободного места вместе со следом предмета (`blocked_footprint`),
а не проверяется постфактум — тогда «перед диваном» физически некуда поставить кресло.
Идея — ProcTHOR (Apache-2.0); код не копировался.

### Система координат
Сантиметры, top-down: `x` — вправо, `y` — вглубь; `y=0` — стена ТВ, `y=depth` — стена дивана.
Поворот `rot` в градусах, «лицо»: 0 → +y, 90 → +x, 180 → −y, 270 → −x.
Осевые повороты (0/90/180/270) — инвариант расстановки (ProcTHOR/Holodeck-MILP).

### Источник правил
`rules/occupancy.json` — **канон проекта** (свод ресёрча + решения владельца: динамические шкалы
кап пола / диван↔столик / диван↔ТВ, ковёр-привязка, кресло-полукруг ADR-0051). Тот же файл
читает scout-конвейер; дубля быть не должно.

## Разработка

```bash
python3 -m venv ~/venvs/planner && ~/venvs/planner/bin/pip install -r requirements.txt
~/venvs/planner/bin/python -m pytest -q        # 46 тестов, ~0.4 с
```

Приёмка Э1: 20 тест-комнат (7 бэндов проекта + вытянутые/узкие/квадратные/краевые) —
ручные раскладки признаются валидными, подсунутые дефекты (коллизия, дуга двери, занятая зона
подхода, ТВ вне шкалы, радиатор, перекрытое окно, отрезанный проход) ловятся по кодам.
