# Third-party notices — planner-solver

Реестр внешних источников, влияющих на этот сервис. Правило проекта (clean-room):
**код копируем только из Apache-2.0 / BSD-3 / MIT источников с сохранением атрибуции;
из источников без лицензии или с non-commercial лицензией берём ТОЛЬКО идеи/правила,
изложенные своими словами.**
